## Summary

The base `f735fd7` descends from `8e62c01`, which had dropped jackylee0424's
exact 7→3 "affine bridge" from `9aceb7d`. This commit puts that bridge back
and adds a second one of the same kind. In each, two identical Toffolis
bracket a block of CNOTs, and the pair can be replaced by a single Toffoli
placed after the block. Both rewrites are exact and each removes one
unconditional Toffoli, so every shot runs 2 Toffoli fewer.

Separately, the nonce tail is shortened from 96 X ops to 14, which carries
the nonce in base-1024 digits. That changes no gate that matters.

## What changed and why it saves Toffoli

All changes are in `src/point_add/mod.rs`. In `build()`, after the
post-strip fanout closure and before the tail nonce, two fail-closed splices
run. Each pattern must match exactly once (`assert_eq!(…len(), 1, …)`), and
before the last 96 ops.

**Bridge 1 (7 → 3 ops)**, the same rewrite as [`9aceb7d`](9aceb7d.md):

```
ccx(511,898->735) cx(735->897) cx(735->734) cx(735->897) cx(734->897) cx(735->734) ccx(511,898->735)
  ==>  cx(734->897) cx(735->897) ccx(511,898->897)
```

Both sides apply `q897 ^= q734 ⊕ q735 ⊕ q511·q898` and leave every other
wire unchanged. The `9aceb7d` note has the wire-by-wire table.

**Bridge 2 (14 → 13 ops), the "control-delta" bridge.** With `a = 513`,
`b = 565`, `d = 512`, `t = 566`, and `q0` as the control of the CX fan-out:

```
ccx(a,b->t)
cx(q0->b)  cx(q0->569) cx(q0->571) cx(q0->572) cx(q0->573) cx(q0->574) cx(q0->597) cx(q0->768)
cx(q0->d)  cx(d->b)    cx(q0->768) cx(q0->d)
ccx(a,b->t)
  ==>  the same 12 CX, then ccx(a,d->t)
```

Why: inside the block, `b` becomes `b ⊕ q0`, then `d` becomes `d ⊕ q0`,
then `b ^= d` gives `b ⊕ q0 ⊕ d ⊕ q0 = b ⊕ d`, and finally `d` is restored.
So the block's net effect on the controls is `b → b ⊕ d`, with `a` and `d`
unchanged. The two CCX together apply
`t ^= a·b ⊕ a·(b ⊕ d) = a·d`, which is one `ccx(a,d→t)` placed after the
block. (The code comment writes the block's action as `b ^= C·d` under "the
unchanged enclosing condition C". All ops in the matched window are
unconditional, and the CX gates make the action `b ^= d`.)

Both bridges remove one CCX that runs on every shot, so the saving is exactly
2 executed Toffoli per shot. That is the whole −2.

**Compact nonce tail.** `apply_tail_nonce` used to write 48 bits of the
nonce into 48 `X;X` pairs on qubit 0 or 1. Now it writes seven base-1024
digits, most significant first (a 4-bit top digit and six 10-bit digits),
into seven `X;X` pairs. Each pair targets the qubit whose index is the digit,
always below 1024, so below the 1154-qubit peak. `ops.truncate(start + 14)`
then drops the other 82 tail ops. Each pair is still the identity, so the
circuit, its Toffoli count and its peak do not change. Only the op stream's
hash changes. See [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

The default `SUB4_TAIL_NONCE` goes from 1337610097 to 225239250.

## Why it is still correct, and what it risks

- **Both bridges are exact.** Each identity holds for every value of the
  wires involved, so no hard input is added and λ is unchanged.
- **Fail-closed.** The patterns use fixed qubit indices. If an upstream edit
  moves or duplicates either window, the unique-match assert aborts the
  build.
- **The tail is exact** (X·X = I).
- The shipped nonce `225239250` draws a clean test set: 0 classical, 0 phase
  and 0 ancilla failures.

## Classification rationale

Both rewrites cancel a redundant CCX from an equal pair around a Clifford
block, so this is dead-gate/self-inverse removal. The tail compaction has no
effect on the score.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout f735fd7 -- src/point_add`. The base is the git
   parent. `git diff --ignore-cr-at-eol f735fd7 9b2ce61 -- src/point_add` is
   119 changed lines in `mod.rs`.
2. **Apply the patch below** from the repo root with
   `git apply --ignore-whitespace`. The flag lets the patch apply whether the
   files use LF or CRLF line endings. It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 9b2ce61 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `SUB4_*`
   or `TLM_*` overrides set. Expect:
   - 1154 qubits
   - 1,283,485 average Toffoli (rounded)
   - score 1,481,141,690
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `225239250`, encoded by this
commit's 14-op tail, and an identical op stream. Any other change needs a new
nonce hunt.
