## Summary

The ping-pong divider is used twice per point addition: once to divide
(`y ← y/x`) and once to multiply (`y ← y·x`). Each run is a fixed-depth walk,
a coefficient replay and a walk-back. In the base the divide uses 700 rounds
and the multiply 699.

This commit cuts the multiply traversal to 698 rounds. That removes one walk
round, one replay cell and one walk-back round, for −364 average Toffoli.
Qubits stay at 1279, because the peak in this tree is a budget,
`SUB4_PP_PEAK = 1279`, that the interleaved replay plan fills, not the tape
length itself. The cost is a little more exposure to inputs whose multiply
walk needs the extra round to converge.

## What changed and why it saves Toffoli

1. **`rounds_for(PingPongDirection::Multiply)`** in
   `src/point_add/pingpong_div.rs`: the default of `SUB4_PP_ROUNDS_MUL` goes
   from `rounds() − 1` to `rounds() − 2`. With `rounds() = 700` that is
   699 → 698. The divide traversal keeps `rounds()`.
   - `pingpong_mod_mul_div_in_place` reads `let rounds = rounds_for(direction)`.
     In the interleaved multiply branch, `value_walk(b, u, v, rounds)` pushes
     one tape sign per round, and the replay batches and walk-back loops all
     run up to `rounds`. So all three stages of the multiply traversal lose
     one round.
   - The saved round is the last one, where the walk registers are at their
     narrowest. So the saving is mostly one full 256-bit replay cell (chunked
     add, fold, chunk and flag repairs), plus a narrow walk add and walk-back
     add. The new comment estimates "about 350 executed Toffoli". The
     measured saving is 364.
   - **Why the peak does not move.** `plan()` returns the checkpoints
     `r1 = 503`, `r2 = 610` and the cap `SUB4_PP_PEAK = 1279`. Each replay
     cell's chunk count is chosen by
     `pick_chunks(plan, tape_len, walk_width)` from
     `allowance = peak − (tape_len + 2·N + 2·walk_width)`. The trailing
     multiply batch runs with the whole tape live, so a one-wire shorter tape
     only gives its carry ladder one more wire under the same cap. The
     comment says the cut "keeps the 1,279-qubit crest". See
     [pingpong-division](../concepts/pingpong-division.md) ("The peak and why
     ladders matter") and
     [peak-qubits-and-budgets](../concepts/peak-qubits-and-budgets.md).
   - The comment is updated. The first round below the divide depth balances
     the multiply cell's extra shifted-out wire; the second is a plain depth
     cut.
2. **Tail nonce** (`src/point_add/mod.rs`): the default
   `SUB4_PINGPONG_TAIL_NONCE` goes from 3004060 (the base) to 5512046.

## Why it is still correct, and what it risks

- **Depth is a truncation.** An input whose multiply walk has not reached
  `(±1, ±1)` after 698 rounds gives a wrong product and leaves the walk
  registers dirty, which shows as classical and ancilla failures.
- The base's comment prices one round on one traversal at about +0.05 λ.
- The arithmetic is otherwise unchanged.
- The shipped nonce `5512046` draws a clean test set: 0 classical, 0 phase
  and 0 ancilla failures. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

Cutting a fixed round count against a measured convergence rate is
iteration/threshold tuning.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout f3b2f1f -- src/point_add`.
   - `git diff --ignore-cr-at-eol f3b2f1f 1f6b836 -- src/point_add` is 14
     changed lines in 2 files.
   - Do not start from the git parent `33e2b34`. Against it the diff is 208
     lines in 3 files. It would remove moscowchill's exact dead-low carry
     helpers from `arith/const_arith.rs` and revert their five call sites in
     `pingpong_div.rs`. This commit was cut from `f3b2f1f` and never had them.
2. **Apply the patch below** from the repo root with
   `git apply --ignore-whitespace`. The flag lets the patch apply whether the
   files use LF or CRLF line endings. It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 1f6b836 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `SUB4_*`
   environment variables set (in particular no `SUB4_PP_ROUNDS_MUL`). Expect:
   - 1279 qubits
   - 943,765 average Toffoli (rounded)
   - score 1,207,075,435
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `5512046` and an identical op
stream. Any other change needs a new nonce hunt.
