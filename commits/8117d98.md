## Summary

solimander's chunked-apply commit [550895c](550895c.md) was built on `6e7ca2c`.
So it did not have mpjunior92's 4-CCX round763 compressor from
[17aad9a](17aad9a.md). This commit copies that compressor onto 550895c,
unchanged, and rescans the two reroll pads. The compressor packs three walk
steps' branch bits (27 reachable values) into 5 qubits. The new version uses 4
CCX instead of 7, it runs 8 times per block, and there are 133 blocks. That
saves 3 × 8 × 133 = 3,192 Toffoli, the same as in 17aad9a. Qubits are
unchanged.

## What changed and why it saves Toffoli

The code is the same as 17aad9a's, in `src/point_add/mod.rs`:

- New `round763_compress_lever_enabled()` (`DIALOG_GCD_ROUND763_COMPRESS_LEVER`),
  defaulted to `"1"` in `configure_ecdsafail_submission_route()`.
- `emit_dialog_gcd_round763_compressor` emits
  `cx(5→3); ccx(3,4→5); cx(1→4); cx(1→0); ccx(4,5→1); cx(0→2); ccx(2,5→0); ccx(0,1→5)`
  with 4 CCX. The base's deduplicated form had 7.
  `emit_dialog_gcd_round763_compressor_inverse` gets the gate-reversed
  sequence.
- Call count: each block is compressed or decompressed once in each of the
  four walks, and decompressed and recompressed once in each of the two apply
  passes. 8 calls × 133 blocks × 3 CCX = 3,192.
- `DIALOG_REROLL` 4 → 2 and `DIALOG_POST_SUB_REROLL` 15 → 10: the identity
  `X;X` pads, re-searched for a clean draw.

The chunked apply in 550895c does not touch the compressor or the log
layout, so the two changes are independent. The saving matches 17aad9a's
exactly.

## Why it is still correct, and what it risks

The new circuit is a different 27 → 32 injective code, not a gate-by-gate
simplification of the old one. I checked it by simulation on the 27 reachable
inputs: 10 of them get a different code, bit 5 always ends at 0, and the
inverse undoes the map. The comment's "three CCX collapse to CX" is misleading
in the same way as in 17aad9a. The change is exact, because every reader of the
log goes through the same compressor or its inverse, and the reachable-input
invariant (`b0_and_b1 = b0 AND …`) holds on every input.

No new failure mode is added. The shipped pads (2, 10) draw 0 classical, 0
phase and 0 ancilla failures for the existing truncations. See
[nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

The label is the same as 17aad9a's: specialization to the reachable inputs of
a small reversible circuit. This is a port, so it adds no new idea.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 550895c -- src/point_add`. The base is the git
   parent. `git diff --ignore-cr-at-eol 550895c 8117d98 -- src/point_add` is
   49 lines in 1 file.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line endings.
   It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 8117d98 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no
   `DIALOG_*`, `KAL_*`, `KARA_*` or `ROUND84_*` environment variables set.
   Expect:
   - 1567 qubits
   - 1,686,313 average Toffoli (rounded)
   - score 2,642,452,471
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with `DIALOG_REROLL = 2`,
`DIALOG_POST_SUB_REROLL = 10` and an identical op stream. Any other change
needs a new reroll scan.
