## Summary

Q73c makes one pin change: `HEO_PIN_PP_FOLD_WIDEN` goes from 128 to 112.
Proxy rounds 112–127 lose their extra fold-window bit, which on the proxy
envelope is the payload cells at ticks 60–69 on both legs. This undoes one of
the λ buys that q73b ([`ed31e8e`](ed31e8e.md)) made, and returns to the value
of sky20 and of jackylee0424's Q1173. The same 105 SAT rewrite rows are
re-ported to the shifted op stream. The net is −14 Toffoli at 1173 qubits. The
author reports λ 19.336, up 0.055 on q73b.

## What changed and why it saves Toffoli

All changes are in `src/point_add/mod.rs`, plus the new row file.

1. **`HEO_PIN_PP_FOLD_WIDEN`: 128 → 112.**
   - `fold_offset(proxy)` adds 1 to the fold window of every proxy round
     below `PP_FOLD_WIDEN`.
   - Rounds 112–127 lose that bit. Through the proxy envelope and the pinned
     width schedule (my mapping) they are ticks 60–69, where rounds 113–127
     occur. That is 10 cells per leg, about 20 cell-bits.
   - Each window bit is one stage of the fold's truncated carry chain, about
     one Toffoli per cell. See [modular-fold](../concepts/modular-fold.md)
     and the sky20 note [`6f2b3a6`](6f2b3a6.md), which made the same move on
     the 1174 circuit.
   - The commit comment gives "-28.3 T model". The submission note prices it
     at −25.8 T for +0.028 λ on 4,096 paired nonces.
2. **Rewrite rows: `q73b_rewrite.txt` → `q73c_rewrite.txt`, the same 105
   rows re-ported.**
   - The fold change alters ops before the square. The submission note says
     the square entry "shifts by -120 ops". In the files, 50 rows keep their
     wires at exactly that shift.
   - The commit comment describes the 105 as "102 square rows spanver-checked
     and 3 outside rows proved by SAT".
   - The submission note gives more detail:
     - the 102 square rows were wire-remapped by a row-port search and
       re-checked by a 262,144-shot span screen with a negative control. They
       were not re-proved by SAT on this stream; their SAT proofs are from
       the q73b stream;
     - the 2 late outside rows were re-mapped and re-proved by windowed SAT;
     - the prefix row (op 17,033) is unchanged.
   - Same row count, so no Toffoli change from the rows.
   - The loader is unchanged. See
     [dead-gate-strip](../concepts/dead-gate-strip.md). `q73b_rewrite.txt` is
     deleted.
3. **Tail nonce**: `TAIL_NONCE` goes from 23500078439729 to 24700083572177.

## Why it is still correct, and what it risks

- **The FOLD_WIDEN cut is a fold truncation.** It about doubles the escape
  rate of the folds at ticks 60–69. Those ticks are in the flat region of the
  `fold_shape` measurement, where the escape rate is highest. A dropped carry
  leaves a wrong field element, which shows up as a **classical** failure.
- **The square rows are screened, not re-proved.** A 262,144-shot span screen
  that passes is strong evidence but not a proof that the remapped relation
  holds on every reachable state. A wrong row would change a value or leave
  garbage, and would show up as a **classical** or **ancilla** failure. The
  author's λ run below includes the rows. The build asserts only that each
  row names its CCX.
- The submission note gives λ 19.336 ± 0.032 on 16,384 nonces (est + 2 SE
  19.400), inside the 19.5 limit that the code comment cites.
- The shipped nonce `24700083572177` draws a clean island: 0 classical,
  0 phase and 0 ancilla failures. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

The only circuit lever narrows a fold window: fold/carry truncation, like
sky20. There was no close runner-up. The rows are a re-port of existing rows,
not new ones.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout ed31e8e -- src/point_add`. The base is the git
   parent. `git diff --ignore-cr-at-eol ed31e8e 83d0f70 -- src/point_add` is
   221 lines in 3 files.
2. **Delete `q73b_rewrite.txt`**, using the `rm` command above the patch
   below.
3. **Copy the re-ported rewrite table from the commit:**
   `git checkout 83d0f70 -- src/point_add/skywalk_data/q73c_rewrite.txt`.
   It holds the 105 rows described above.
4. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line
   endings. It covers `mod.rs`.
5. **Check the tree.** `git diff --ignore-cr-at-eol 83d0f70 -- src/point_add`
   should print nothing.
6. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh`. `build()` clears
   the process environment and then installs the pinned recipe, so `HEO_*`,
   `GO_*`, `SKY_*`, `SKYX_*`, `PP_*`, `TLM_*` and `SUB4_*` overrides have no
   effect. Do not set them anyway. Expect:
   - 1173 qubits
   - 944,588 average Toffoli (rounded)
   - score 1,108,001,724
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `24700083572177` and an identical op
stream.
