## Summary

This commit makes no optimization. It only changes the tail nonce in
`src/point_add/mod.rs` (`TAIL_NONCE` entry of `env_raw()`) from 12002361956562
to 12002628222642. The new nonce draws a different clean set of 9,024 test
shots, whose average executed Toffoli is 13 lower. Ignoring line endings, the
diff touches only that literal; the only other change, in
`skywalk_data/sky12_rewrite.txt`, is line endings, which its
whitespace-splitting loader ignores. For why a nonce moves the score, see
[nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).
