## Summary

This is the next rung of the risk ladder in [`7726431`](7726431.md). The
risk-ranked dead-gate strip, from the same 320M census, goes from budget 2.5 to
3.0. That admits 253 more deletions and 116 more CX/CZ downgrades, for −320
average Toffoli. The codec normalizer edit is kept. The note's ladder prices
the step at Δλ +1.933 → +2.302 extra failing shots per draw, so a clean nonce
is about e^0.37 ≈ 1.4× rarer. The author chose 3.0 as the last rung whose
marginal return was still above 1.1M score per unit of λ.

The commit also deletes the four uncompiled `*.rs.orig` backup files that
[`a254a8a`](a254a8a.md) had added under `trailmix_ludicrous/`. That is almost
all of the 5,808-line diff.

## What changed and why it saves Toffoli

- **`src/point_add/deep_strip_keys.rs`:** same census header (320,000,000 input
  pairs, 9,073,163-op pre-strip stream). 369 key lines are added, none removed:
  `DEAD_KEYS` 12,290 → 12,543 and `DOWNGRADE_KEYS` 3,807 → 3,923.
  - The admission rule is unchanged: price each candidate on an oracle census
    and admit in ascending risk until the budget, now 3.0, is spent. See
    [`6e9f0af`](6e9f0af.md) and [dead-gate-strip](../concepts/dead-gate-strip.md).
  - The build logs "removed 12543 / 12543 dead; downgraded 3923 / 3923 to CX/CZ;
    0 stale keys skipped". Emitted ops drop to 9,060,620, from 9,060,873 at
    7726431. That is the 253 deletions; downgrades keep the op count.
  - Ladder points from the note: budget 2.5 gives 1,290,130.962 avg T at
    Δλ +1.933, and 3.0 gives 1,289,786.091 at +2.302. Both were measured with
    the original codec.
- **Deleted:** `trailmix_ludicrous/comparator.rs.orig`, `gcd.rs.orig`,
  `gidney.rs.orig` and `mod.rs.orig`. They were never compiled, so this has no
  effect on the circuit.
- **Tail nonce:** `SUB4_TAIL_NONCE` default 700076886370 → 800285149733 in
  `src/point_add/mod.rs`. It was found after 285M screened nonces.

## Why it is still correct, and what it risks

- **Empirical.** At budget 3.0 the strip adds about 2.3 expected failing shots
  per random draw.
- **Negative results the note records:**
  - Every other CCX entry of `NORMALIZER_OPS`, with either control dropped,
    breaks the circuit.
  - `MERGE25_OPS` positions 18–26 are never emitted, because `mcx_clean_k`
    replaces them. Positions 2, 4, 5, 8 and 10 are each worth 321–347 avg T,
    but all are load-bearing.
  - Neither lowering `TLM_TARGET_Q` below 1150 nor narrowing the schedule tail
    moves the 1154-qubit peak.
- The shipped nonce `800285149733` draws a clean set: 9,024 of 9,024 shots, 0
  classical, 0 phase and 0 ancilla failures. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

A larger empirical dead-gate strip; the file deletions are housekeeping. That

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 7726431 -- src/point_add`. The base is the git parent.
   `git diff --ignore-cr-at-eol 7726431 5265674 -- src/point_add` is 5,808 lines
   in 6 files. 5,437 of them are the four deleted `.orig` files.
2. **Copy the generated table from the commit:**
   `git checkout 5265674 -- src/point_add/deep_strip_keys.rs`.
3. **Delete the four `.orig` files and apply the patch below.** From the repo
   root, run the `rm` command at the top of the patch section, then apply the
   diff with `git apply --ignore-whitespace`. The flag lets the patch apply
   whether the files use LF or CRLF line endings. The diff only changes the
   nonce in `mod.rs`.
4. **Check the tree.** `git diff --ignore-cr-at-eol 5265674 -- src/point_add`
   should print nothing.
5. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `TLM_*` or
   `SUB4_*` overrides set. Expect:
   - 1154 qubits
   - 1,289,451 average Toffoli (1,289,451.458 before rounding)
   - score 1,488,026,454
   - 0 classical, 0 phase and 0 ancilla failures
6. **Nonce caveat.** The score only reproduces with the nonce `800285149733` and an
   identical op stream. Any other change needs a new nonce hunt.
