## Summary

The circuit is ea785b7's. The dead-gate strip from the same 320M-input census
is re-emitted at a larger risk budget, 2.0, which admits 1,852 more of the
next-safest candidates. That is 11,979 deletions and 3,704 CX/CZ downgrades,
15,683 keys in all, for −1,705 average Toffoli. The [`7726431`](7726431.md)
note's ladder prices budget 2.0 at Δλ ≈ +1.57 failing shots per draw, against
about +0.36 at budget 0.5.

The commit was built on ea785b7, not on the frontier cf5aa02. So it does not
contain jackylee0424's codec normalizer edit ([`330d42d`](330d42d.md),
−344 Toffoli), and its gain over the frontier is 1,356 Toffoli. 7726431 later
put the edit back. The note is mostly about pricing the nonce hunt from the
survival curve of screen survivors. This stream needed about 1.38B screened
nonces.

## What changed and why it saves Toffoli

- **`src/point_add/deep_strip_keys.rs`:** same census header as 6e9f0af
  (320,000,000 input pairs on a 9,073,163-op pre-strip stream). 1,852 key lines
  are added: `DEAD_KEYS` 10,743 → 11,979 and `DOWNGRADE_KEYS` 3,088 → 3,704.
  - Selection is the risk ranking of [`6e9f0af`](6e9f0af.md): price each
    candidate on an oracle census and admit in ascending risk until the budget
    is spent, here 2.0.
  - The build logs "removed 11979 / 11979 dead; downgraded 3704 / 3704 to CX/CZ;
    0 stale keys skipped".
- **Why it saves Toffoli.** Each deleted gate, and each CCX turned into a CX,
  stops being charged on every shot whose condition holds. Diminishing returns
  are visible: by 7726431's measurements, avg-T saved per unit of budget falls
  steadily along the ladder, from about 4,100 for the first step to about 500
  for the last ones, as the cheap gates run out.
  See [dead-gate-strip](../concepts/dead-gate-strip.md).
- **Tail nonce:** `SUB4_TAIL_NONCE` default 500008234796 → 100388236067 in
  `src/point_add/mod.rs`.

## Why it is still correct, and what it risks

- **Empirical.** The admitted gates misbehaved rarely, not never, on the oracle
  census. At budget 2.0 the strip adds about 1.6 expected failing shots per
  draw, which makes clean nonces rarer.
- **The note's density estimate.** Screen survivor rate 2,722 / 485,000,000 =
  5.61e-6. P(clean | survivor) from the trusted fail-batch survival curve is
  3.9e-4. Together that is a clean density of about 2.2e-9, roughly 460M
  nonces per win. Two pitfalls it reports: duplicate verdict rows inflated the
  sample about 29×, and on thin data the early and tail fits disagreed by 2×.
- The shipped nonce `100388236067` draws a clean set: 9,024 of 9,024 shots, 0
  classical, 0 phase and 0 ancilla failures. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

A larger empirical dead-gate strip and nothing else: dead-gate/self-inverse
removal. The missing codec edit is a side effect of the base the author chose,
not a deliberate change.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout ea785b7 -- src/point_add`.
   - Do not start from the git parent `cf5aa02`. Against it, the diff would also
     revert 330d42d's `NORMALIZER_OPS` entry in `trailmix_ludicrous/codec.rs`,
     which looks like a deliberate undo but is only the older base.
   - Against `ea785b7`, `git diff --ignore-cr-at-eol ea785b7 37ab267 -- src/point_add`
     is 1,854 lines in 2 files: 1,852 added key lines and the nonce.
2. **Copy the generated table from the commit:**
   `git checkout 37ab267 -- src/point_add/deep_strip_keys.rs`.
3. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line endings.
4. **Check the tree.** `git diff --ignore-cr-at-eol 37ab267 -- src/point_add`
   should print nothing.
5. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `TLM_*` or
   `SUB4_*` overrides set. Expect:
   - 1154 qubits
   - 1,290,503 average Toffoli (1,290,503.181 before rounding)
   - score 1,489,240,462
   - 0 classical, 0 phase and 0 ancilla failures
6. **Nonce caveat.** The score only reproduces with the nonce `100388236067` and an
   identical op stream. Any other change needs a new nonce hunt.
