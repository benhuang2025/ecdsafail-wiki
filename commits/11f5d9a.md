## Summary

This commit makes no optimization. It only changes the tail nonce in
`src/point_add/mod.rs` (`SUB4_PINGPONG_TAIL_NONCE` default in `build()`) from
3004060 to 104000102. The new nonce draws a different clean set of 9,024 test
shots, whose average executed Toffoli is 24 lower. The diff touches only the
nonce literal. The git parent [`ffc4e07`](ffc4e07.md) is the same circuit
under nonce 320000001. For why a nonce moves the score, see
[nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Reproduce

`git apply --ignore-whitespace`. `./benchmark.sh` should give 1279 qubits,
944,105 average Toffoli and 0 / 0 / 0 failures.
