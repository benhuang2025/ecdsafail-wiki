## Summary

`R_SMALL_THRESHOLD` goes from 325 to 326, so iteration 325 of each of the four
Kaliski runs does `r := 2r` as a free wire shift instead of a shift plus a
truncated constant add. That add costs 52 Toffoli, so the saving is
4 × 52 = 208. [`17ae622`](17ae622.md) had found 326 failing full validation at
the re-rolls it tried. This commit searched re-rolls 0 to 255 with the
in-process `KAL_SCREEN` screener and found `rr = 254` clean. Qubits are
unchanged. A notes file `memory/r-small-326-reroll-254.md` is added.

## What changed and why it saves Toffoli

1. **`R_SMALL_THRESHOLD`: 325 → 326** (`src/point_add/kaliski_state.rs`).
   - For `iter_idx < r_small_threshold()`, Kaliski STEP 7+8 calls
     `mod_double_no_corr(b, r)`, a swap cascade with 0 Toffoli.
   - Otherwise it calls the direct modular double, which adds
     `c = 2^32 + 977` under the old top bit with a carry chain clipped to
     `33 + W = 52` positions (`W = 19`), at one Toffoli each.
   - Iteration 325 moves to the free path in four runs (pair1 and pair2,
     forward and backward): 4 × 52 = 208 Toffoli. The cost is unconditional,
     so the average drops by exactly that.
   - The notes file says "~255 CCX saved" per iteration and that "the exact
     delta varies". Both are wrong for this tree: the correction add is the
     52-position truncated one, and 208 = 4 × 52 exactly.
2. **`KAL_REROLL`: 10 → 254** (`src/point_add/mod.rs`): 254 identity `X;X`
   pairs on `tx[0]`, which only re-draws the test inputs.
3. **New file `src/point_add/memory/r-small-326-reroll-254.md`** (27 lines):
   a plain-text log of the validation, not compiled.

## Why it is still correct, and what it risks

- **R_SMALL is probabilistic.** The bound `r[255] = 0` is only proven below
  iteration 255. At 326 it is empirical. An input whose `r` reaches `2^255`
  by then loses its top bit in the free shift, which gives a wrong inverse and
  a classical mismatch.
- **Island.** The author swept re-rolls 0 to 255 with `KAL_SCREEN`
  (`screen.rs`, from [`6e71096`](6e71096.md)), and `rr = 254` was the only
  clean one. `R_SMALL = 327` had no clean re-roll in that range. The shipped
  stream is clean: 0 classical, 0 phase and 0 ancilla failures over 9,024
  shots. See [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

A threshold that decides how many iterations take the cheap path moves by one,
which is iteration/threshold tuning.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 17ae622 -- src/point_add`. The base is the git
   parent. `git diff --ignore-cr-at-eol 17ae622 13a7a53 -- src/point_add` is
   46 lines in 3 files, one of them the new notes file.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`. The flag lets the patch apply whether the files use LF or CRLF line endings. It is the
   complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 13a7a53 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `KAL_*`,
   `AFFINE_*`, `SHIFT22_*` or `LOWQ_*` environment variables set. Expect:
   - 2025 qubits
   - 2,559,463 average Toffoli (rounded)
   - score 5,182,912,575
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with `KAL_REROLL = 254` and an identical op stream.
Any other change needs a new re-roll search.
