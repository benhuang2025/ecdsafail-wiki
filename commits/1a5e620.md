## Summary

Since [`7689eac`](7689eac.md), the λ² schoolbook square adds each wide row in
two windows. The carry between the windows is held on an ancilla `cout`, which
must be cleared at the end. It is cleared by recomputing it: the code rebuilds
the row segment and compares it with the partial sum over the whole segment,
roughly 100–130 bits. Rows 0–62 are windowed, so that cleanup cost about 25,000
Toffoli per shot, close to the cost the windowing added.

This commit compares only the top 22 bits of the segment, and rebuilds only
those 22 bits of it. The carry is decided by the top bits unless the two
values tie on all 22 of them, about 2^−22 per row. The saving is 22,624
Toffoli at the same 1221 qubits. The tail nonce was re-hunted.

## What changed and why it saves Toffoli

1. **`square_row_windowed_apply` (`src/point_add/arith/multiply.rs`).**
   - New knob `square_row_window_clean_compare_bits()` reads
     `SQUARE_ROW_WINDOW_CLEAN_COMPARE_BITS`. The default 0 means full width.
   - In the reverse sweep that clears each interior `cout` (window
     `[lo, hi)`, width `seg_w`), the code sets `trunc_w = min(k, seg_w)`.
   - If `trunc_w < seg_w`, it rebuilds only `seg[hi − trunc_w .. hi]` with
     `build_seg`, allocates a fresh `cmp_cin = |0>`, and computes:
     - forward square: `cout ^= (partial_sum[top k] < seg[top k])`;
     - inverse square: the X-wrapped borrow form, `seg[top k] > partial_diff[top k]`.
   - Both use `cmp_lt_into_fast_with_cin_borrowed_carries` on `k` bits, with
     `k` carry lanes borrowed from the clean high tail of `tmp_ext`. It then
     clears the short segment by measurement.
   - Otherwise it runs the old full-width code unchanged.
2. **`configure_ecdsafail_submission_route()` (`src/point_add/mod.rs`).**
   - New pin `SQUARE_ROW_WINDOW_CLEAN_COMPARE_BITS = "22"`.
   - A new pin `DIALOG_TAIL_NONCE = "7700044727491"` is placed at the top of
     the route. `set_default_env` only sets a variable that is still unset, so
     this first pin wins. The old pin `165002130437`, further down, is left in
     the file but no longer has any effect.
3. **Self-test.** `square_window_selftest()` runs under `SQUARE_WINDOW_SELFTEST`.
   It builds the windowed square (and square + inverse) on `nbits` bits
   (`SQUARE_WINDOW_SELFTEST_NBITS`, default 24), and checks the product, `x`
   unchanged, a clean round trip and zero phase. With
   `SQUARE_WINDOW_SELFTEST_ONLY=1` it returns no ops.
4. **Inactive additions.**
   - `add_short_to_long_qq_fast_no_cin` / `sub_short_to_long_qq_fast_no_cin`
     (`arith/nbit.rs`) add a short register into a longer one without padding
     it.
   - They are wired into `round84_compute/uncompute_quotient_c_product` behind
     `ROUND84_QPROD_SHORT=1`. That variable is not pinned, so this route does
     not use them.

**Why it saves Toffoli.**
- For row `i`, the segment width is about `(257 − i)/2`, so between 97 and 129
  bits for rows 0–62.
- The old cleanup rebuilt the full segment, one CCX per cross term, and ran a
  `seg_w`-bit measured comparator, about one CCX per bit. That is about
  `2·seg_w` Toffoli per row.
- The new cleanup costs about `2·22`.
- Summed over the 63 windowed rows, in the forward square and its inverse,
  that is roughly 2 × 63 × 2 × (113 − 22) ≈ 23,000. The measured saving is
  22,624.

## Why it is still correct, and what it risks

The boundary carry of a window is `cout = [partial_sum < segment + c_in]` over
the full segment. The truncated test compares only the top 22 bits and drops
`c_in`. It gives the same answer unless the top 22 bits of the partial sum and
of the segment are equal, in which case the low bits (and `c_in`) decide and
the test can be wrong. For random-looking data that is about 2^−22 per row.

When it is wrong, `cout` is not returned to 0. That is an ancilla failure, and
the phase of the later free can also leak into phase garbage. Values are not
affected, because the product in `tmp_ext` is already complete when the
cleanup runs. The code comment calls this "a deliberate island-hunt knob".

The shipped nonce `7700044727491` draws a clean set: 9,024 of 9,024 shots,
with 0 classical, 0 phase and 0 ancilla failures. See
[nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

The commit narrows a comparator from the full segment width to 22 bits, which
is comparator/width truncation. The comparator only uncomputes an ancilla,
so measurement uncompute was a possible runner-up. But the saving comes from
the narrower compare, not from a change in how the ancilla is erased.

+    let nbits = std::env::var("SQUARE_WINDOW_SELFTEST_NBITS")
+        .ok()
+        .and_then(|s| s.parse::<usize>().ok())
+        .unwrap_or(24);
+    assert!(nbits > 0);
+    let packed_value_check = 2 * nbits < 64;
+    let wide_value_check = nbits <= 256;
+    let mask = if packed_value_check { (1u64 << nbits) - 1 } else { u64::MAX };
+    let out_mask = if packed_value_check { (1u64 << (2 * nbits)) - 1 } else { u64::MAX };
+    let xs: Vec<u64> = (0..SHOTS as u64)
+        .map(|s| {
+            let r = s
+                .wrapping_mul(0x9E37_79B9_7F4A_7C15)
+                .wrapping_add(0xA076_1D64_78BD_642F);
+            let r = (r ^ (r >> 30)).wrapping_mul(0xBF58_476D_1CE4_E5B9);
+            r & mask
+        })
+        .collect();
+    let x_masks: Vec<u64> = (0..nbits)
+        .map(|k| {
+            if packed_value_check {
+                xs.iter()
+                    .enumerate()
+                    .fold(0u64, |acc, (shot, &xv)| acc | (((xv >> k) & 1) << shot))
+            } else {
+                let z = (k as u64)
+                    .wrapping_mul(0xD6E8_FD9D_50B5_8A51)
+                    .wrapping_add(0x9E37_79B9_7F4A_7C15);
+                let z = (z ^ (z >> 27)).wrapping_mul(0x94D0_49BB_1331_11EB);
+                z ^ (z >> 31)
+            }
+        })
+        .collect();
+
+    let build_one = |roundtrip: bool| -> (Vec<Op>, Vec<QubitId>, Vec<QubitId>, usize, usize) {
+        let mut b = B::new();
+        let x = b.alloc_qubits(nbits);
+        let tmp = b.alloc_qubits(2 * nbits);
+        schoolbook_square_symmetric_lowq_selfhosted(&mut b, &x, &tmp);
+        if roundtrip {
+            schoolbook_square_symmetric_lowq_selfhosted_inverse(&mut b, &x, &tmp);
+        }
+        let nq = b.next_qubit as usize;
+        let nb = b.next_bit as usize;
+        (b.ops, x, tmp, nq, nb)
+    };
+
+    let run = |ops: &[Op],
+               x: &[QubitId],
+               tmp: &[QubitId],
+               nq: usize,
+               nb: usize|
+     -> (Vec<u64>, Vec<u64>, u64) {
+        let mut seed = sha3::Shake128::default();
+        seed.update(b"square-window-selftest");
+        let mut xof = seed.finalize_xof();
+        let mut sim = Simulator::new(nq, nb, &mut xof);
+        sim.clear_for_shot();
+        for k in 0..nbits {
+            *sim.qubit_mut(x[k]) = x_masks[k];
+        }
+        sim.apply_iter(ops.iter());
+        let out_x_masks: Vec<u64> = x.iter().map(|&q| sim.qubit(q)).collect();
+        let out_tmp_masks: Vec<u64> = tmp.iter().map(|&q| sim.qubit(q)).collect();
+        (out_x_masks, out_tmp_masks, sim.phase)
+    };
+
+    let (ops_fwd, x_fwd, tmp_fwd, nq_fwd, nb_fwd) = build_one(false);
+    let (out_x_masks, out_tmp_masks, phase) = run(&ops_fwd, &x_fwd, &tmp_fwd, nq_fwd, nb_fwd);
+    if phase != 0 {
+        return Err(format!("forward phase garbage 0x{phase:x}"));
+    }
+    for (k, (&got, &want)) in out_x_masks.iter().zip(x_masks.iter()).enumerate() {
+        if got != want {
+            return Err(format!("forward x bit {k} changed"));
+        }
+    }
+    if packed_value_check {
+        for shot in 0..SHOTS {
+            let got = out_tmp_masks
+                .iter()
+                .take(2 * nbits)
+                .enumerate()
+                .fold(0u64, |acc, (k, &bits)| acc | (((bits >> shot) & 1) << k));
+            let want = xs[shot].wrapping_mul(xs[shot]) & out_mask;
+            if got != want {
+                return Err(format!(
+                    "forward value mismatch shot {shot}: tmp got 0x{got:x} want 0x{want:x}"
+                ));
+            }
+        }
+    } else if wide_value_check {
+        let in_limbs = (nbits + 63) / 64;
+        let out_limbs = (2 * nbits + 63) / 64;
+        for shot in 0..SHOTS {
+            let mut x_limbs = vec![0u64; in_limbs];
+            for k in 0..nbits {
+                if (x_masks[k] >> shot) & 1 != 0 {
+                    x_limbs[k / 64] |= 1u64 << (k % 64);
+                }
+            }
+            let mut product = vec![0u64; out_limbs];
+            for i in 0..in_limbs {
+                let mut carry = 0u128;
+                for j in 0..in_limbs {
+                    let idx = i + j;
+                    if idx >= out_limbs {
+                        break;
+                    }
+                    let cur = product[idx] as u128
+                        + (x_limbs[i] as u128) * (x_limbs[j] as u128)
+                        + carry;
+                    product[idx] = cur as u64;
+                    carry = cur >> 64;
+                }
+                let mut idx = i + in_limbs;
+                while carry != 0 && idx < out_limbs {
+                    let cur = product[idx] as u128 + carry;
+                    product[idx] = cur as u64;
+                    carry = cur >> 64;
+                    idx += 1;
+                }
+            }
+            for k in 0..(2 * nbits) {
+                let got = (out_tmp_masks[k] >> shot) & 1;
+                let want = (product[k / 64] >> (k % 64)) & 1;
+                if got != want {
+                    return Err(format!("forward value mismatch shot {shot} bit {k}"));
+                }
+            }
+        }
+    }
+
+    let (ops_rt, x_rt, tmp_rt, nq_rt, nb_rt) = build_one(true);
+    let (out_x_masks, out_tmp_masks, phase) = run(&ops_rt, &x_rt, &tmp_rt, nq_rt, nb_rt);
+    if phase != 0 {
+        return Err(format!("roundtrip phase garbage 0x{phase:x}"));
+    }
+    for (k, (&got, &want)) in out_x_masks.iter().zip(x_masks.iter()).enumerate() {
+        if got != want {
+            return Err(format!("roundtrip x bit {k} changed"));
+        }
+    }
+    for (k, &got) in out_tmp_masks.iter().enumerate() {
+        if got != 0 {
+            return Err(format!("roundtrip tmp bit {k} dirty mask 0x{got:x}"));
+        }
+    }
+    Ok(())
+}
