## Summary

This commit makes no optimization. It only changes the tail nonce in
`src/point_add/mod.rs` (`SUB4_TAIL_NONCE` default in `build()`) from
8000230021249 to 8000264417270. The new nonce draws a different clean set of
9,024 test shots, whose average executed Toffoli is 1 lower. The diff touches
only the nonce literal, and the emitted op count is unchanged (8,961,419). For
why a nonce moves the score, see
[nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Reproduce

`git apply --ignore-whitespace`. `./benchmark.sh` should give 1154 qubits,
1,285,658 average Toffoli and 0 / 0 / 0 failures.
