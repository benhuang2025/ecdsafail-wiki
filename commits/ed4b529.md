## Summary

The strip's admission rule so far ([`6e9f0af`](6e9f0af.md)) gave each
candidate gate a risk λᵢ, its failure rate per draw. It admitted candidates in
ascending λᵢ while Σλᵢ stayed under a budget. That treats the failure sets as
disjoint. The author measured that they are not: failures pile up on a limited
pool of hard inputs. So the expected number of failing shots is the size of
the *union* of the failure sets, which is 1.5–1.7× smaller than the sum at
these budgets.

This commit re-selects the strip greedily by max coverage. At each step it
admits the gate with the best ratio of average Toffoli saved to *new* failing
shots added. Gates whose failures land on inputs that already fail cost almost
nothing. At the same measured risk (λ ≈ 4.0) this admits 413 more keys: 13,056
deletions and 4,222 downgrades. Built, that is 381 Toffoli better than the
sum rule at the same budget. Against the base's risk-3.0 table it is −980
Toffoli.

## What changed and why it saves Toffoli

- **`src/point_add/deep_strip_keys.rs`, regenerated** ("AUTO-GENERATED by union
  max-coverage admission (census6/maxcov)"). Key format and
  `apply_deep_strip_identity` are unchanged.
  - `DEAD_KEYS` go from 12,543 to 13,056, and `DOWNGRADE_KEYS` from 3,923 to
    4,222, 17,278 in all.
  - The table was mined on the current shifted-low-square stream, so the build
    logs "removed 13056 / 13056 dead; downgraded 4222 / 4222 to CX/CZ; 0 stale
    keys skipped". The base had 251 stale keys. Emitted ops are 9,057,301.
- **How the gates were chosen** (from the note):
  1. Each candidate takes its cheapest action: delete (risk = how often it
     fires), or downgrade dropping control 1 or 2 (risk = how often that
     control was "bad").
  2. A simulation pass of 1.28M shots records which shots each candidate would
     break. For admitted sets, λ_union / λ_sum is 1.53 at budget 3.0, 1.67 at
     4.0 and 1.69 at 5.0.
  3. A random sample of 192 candidates gave a sum of 23,687 failures against a
     union of 10,714, with a mean pairwise Jaccard of only 0.0097. So the
     overlap comes from saturation on a few hard inputs, not from similar
     gates.
  4. Greedy max-coverage at cap 4.0: 17,278 keys, λ 3.9999, 15,914 avg T saved.
     The sum rule at the same cap gives 16,865 keys, λ 3.9992, 15,541 saved.
  5. Built: 1,288,492.700 (sum rule) → 1,288,111.860 (union rule), before the
     nonce.
  - Only 4,241 of about 1.36M candidates showed a failure in 12.8M shots. The
    rest are priced independently, so the rule is still conservative. See
    [dead-gate-strip](../concepts/dead-gate-strip.md).
- **`src/point_add/mod.rs`:** tail nonce `SUB4_TAIL_NONCE` 60000115034108 →
  200321420125.
- **Deleted:** the four uncompiled `trailmix_ludicrous/*.rs.orig` backup files.

## Why it is still correct, and what it risks

- **Empirical.** The strip is priced at about 4.0 expected failing shots per
  random draw, measured as a union. That is higher than the base's risk-3.0
  table.
- **The note's caveat:** the union slack can be spent on Toffoli or on a cheaper
  hunt, not both. Here it went to Toffoli, so the hunt is about as hard as
  e^-4 predicts. The winner came after 325M screened nonces (1,817 confirmed
  candidates, survivor rate 5.7e-6).
- **Depth still matters.** A 25,600-shot trial census reported 44,145 dead gates.
  At 320M it is 8,985. About 80% of the shallow "dead" gates only fire rarely.
- The shipped nonce `200321420125` draws a clean set: 9,024 of 9,024 shots, 0
  classical, 0 phase and 0 ancilla failures. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

A re-selected empirical dead-gate strip and nothing else: dead-gate/self-inverse
removal. The new part is the admission rule.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 4579b79 -- src/point_add`.
   - Do not start from the git parent `8af8a6f`. The note says the tree was
     rebuilt "with `src/point_add` replaced", and the shipped code matches
     `4579b79`.
   - Against the parent, the diff is 18,747 lines in 67 files. It would revert
     8af8a6f's coordinate cleanup widths in `arith.rs`, `ec_add.rs` and `mod.rs`,
     and bring back 58 research files. Neither is this commit's work.
   - Against `4579b79`, `git diff --ignore-cr-at-eol 4579b79 ed4b529 -- src/point_add`
     is 8,656 lines in 6 files: the key table, the nonce and the four `.orig`
     deletions.
2. **Copy the generated table from the commit:**
   `git checkout ed4b529 -- src/point_add/deep_strip_keys.rs`.
3. **Delete the four `.orig` files and apply the patch below.** From the repo
   root, run the `rm` command at the top of the patch section, then apply the
   diff with `git apply --ignore-whitespace`. The flag lets the patch apply
   whether the files use LF or CRLF line endings.
4. **Check the tree.** `git diff --ignore-cr-at-eol ed4b529 -- src/point_add`
   should print nothing.
5. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `TLM_*` or
   `SUB4_*` overrides set. Expect:
   - 1154 qubits
   - 1,288,101 average Toffoli (1,288,101.386 before rounding)
   - score 1,486,468,554
   - 0 classical, 0 phase and 0 ancilla failures
6. **Nonce caveat.** The score only reproduces with the nonce `200321420125` and an
   identical op stream. Any other change needs a new nonce hunt.
