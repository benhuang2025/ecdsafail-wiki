## Summary

Two earlier submissions improved the same 1154-qubit trailmix circuit in
different ways, and neither contained the other's change:

- `59f3428` re-ran the single-CCX target-fanout rewrite after the dead-gate
  strip (10 extra merges, about −15 T).
- `892b03b` added 832 census-mined keys to the identity-keyed dead-gate strip
  (about −756 T). Its tree was cut from before `59f3428`, so it lost the
  fanout closure.

This commit puts both into one tree. It takes `59f3428` and appends
`892b03b`'s 832 keys to `deep_strip_keys.rs`. Against its base the saving is
the 832 keys (−757 T). Against the frontier `892b03b` the saving is the
fanout closure coming back (−14 T). Qubits are unchanged. Nothing new is
invented: the commit is a merge plus a fresh nonce.

## What changed and why it saves Toffoli

- **`src/point_add/deep_strip_keys.rs`**: 832 key tuples are appended, with a
  comment crediting gopikannappan's 0c7f665 (that is, `892b03b`).
  - 461 go at the end of `DEAD_KEYS`. Each names one CCX/CCZ as
    `(kind, q_control2, q_control1, q_target, c_condition, ordinal, tuple_occupancy)`,
    and `apply_deep_strip_identity` in `mod.rs` deletes that gate from the
    finished op stream.
  - 371 go at the end of `DOWNGRADE_KEYS`. These have an eighth field `act`
    (1 or 2) naming which control is redundant. The gate becomes a CX/CZ,
    which the scorer does not charge.
  - The table now holds 12,202 dead and 4,045 downgrade keys, 16,247 in all.
    After sorting, this is exactly `892b03b`'s key set.
  - Why the keys still fit: both trees build the same pre-strip op stream,
    because `59f3428`'s fanout closure runs *after* the strip. So the ordinals
    and tuple occupancies that `892b03b` mined still address the same gates.
    A key whose tuple occupancy had moved would be discarded with a warning,
    not applied.
  - The comment explains how `892b03b` admitted these keys. A candidate's
    risk was priced on the union of classical-fail and phase-fail shots,
    instead of combining the two channels as if independent (multiplying
    their marginals), which double-charged the roughly 42% of shots that fail
    both ways. The same risk budget then admits more gates. See
    [dead-gate-strip](../concepts/dead-gate-strip.md).
- **`src/point_add/mod.rs`**: only the default `SUB4_TAIL_NONCE` changes,
  8000230021249 → 13614067923. The post-strip loop over
  `single_ccx_fanout::rewrite_first_target_fanout(ops, 96)` stays as in the
  base, including `assert_eq!(post_strip_fanout_passes, 10, …)`. The larger
  strip still leaves exactly 10 fanout matches, so the assert holds.

Each deleted gate saves one Toffoli on every shot whose classical condition
admits it. The 832 keys are worth −757 average Toffoli here, close to the
−756 that `892b03b` measured for them on the tree without the closure.

## Why it is still correct, and what it risks

- **The keys are empirical.** `892b03b`'s 10M-shot census never saw these
  gates fire (dead keys), or never saw the dropped
  control matter (downgrades). Nothing proves that. On an input where a
  deleted gate would have fired, the output is wrong or a phase is left
  behind. Each such input is a hard input, so the keys raise λ, the expected
  number of failing shots per 9,024-shot draw. A failure would show as a
  classical mismatch or as phase garbage.
- **The fanout closure is exact.** `CCX(a,b→t); CX(t→u); CCX(a,b→t)` equals
  `CX(t→u); CCX(a,b→u)` on every input.
- **The tuple-occupancy tripwire** guards against a key addressing the wrong
  gate. Here no keys go stale, because the pre-strip stream is the one the
  keys were mined on.
- The shipped nonce `13614067923` draws a clean test set: 0 classical,
  0 phase and 0 ancilla failures. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

Filed as gate/op fusion because the only thing this commit adds to the
frontier (`892b03b`) is the post-strip fanout closure, which merges two
Toffolis into one. The runner-up is dead-gate/self-inverse removal: against
the diff base `59f3428` the whole change is the 832 strip keys, and they give
most of the −757 T. Both levers come from earlier submissions, so the commit
is a merge.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 59f3428 -- src/point_add`.
   - `git diff --ignore-cr-at-eol 59f3428 16351d8 -- src/point_add` is 844
     changed lines in 2 files: 842 lines of appended keys and comments, and
     the nonce.
   - Do not start from the git parent `892b03b`. Against it the diff is
     25,229 lines in 3 files. Most of it is the key table rewritten in a
     different order with the same keys. The rest re-adds the fanout loop in
     `mod.rs` and removes `892b03b`'s dormant `TLM_ADAPTIVE_FINAL_NO_COUT`
     block from `trailmix_ludicrous/gidney.rs`.
2. **Copy the generated key table from the commit:**
   `git checkout 16351d8 -- src/point_add/deep_strip_keys.rs`. It is
   census-mined data; the section above describes what was added.
3. **Apply the patch below** from the repo root with
   `git apply --ignore-whitespace`. The flag lets the patch apply whether the
   files use LF or CRLF line endings. It covers `mod.rs`.
4. **Check the tree.** `git diff --ignore-cr-at-eol 16351d8 -- src/point_add`
   should print nothing.
5. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `SUB4_*`
   or `TLM_*` overrides set. Expect:
   - 1154 qubits
   - 1,284,902 average Toffoli (rounded)
   - score 1,482,776,908
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `13614067923` and an identical op
stream. Any other change needs a new nonce hunt.
