## Summary

This is the same lever as [`2aedb45`](2aedb45.md), pushed one step further.
`SCHED_J2` (live width of the GCD registers `u`, `v`) and `GAP_J2` (compare
window) move together again. Measured from `a254a8a`, before either commit,
the cut goes from 1 bit on divsteps 101–260 to 2 bits on divsteps 133–260. The
narrower tail makes the walk's adders, compares and cswaps cheaper, and
lowering both qubit caps from 1151 to 1150 turns the freed wire into a lower
peak, 1152 → 1151.

The price is λ, the expected number of failing shots per draw. The note
measures classical λ going from 9.67 to 13.88. About 1.1e7 candidate nonces
were needed to find one clean draw. The strip was re-mined at 1e9 inputs for
the new stream.

## What changed and why it saves Toffoli and a qubit

1. **Width schedule, `src/point_add/trailmix_ludicrous/schedule.rs`.**
   - Against `2aedb45`, `SCHED_J2` and `GAP_J2` each go **up** by 1 at indices
     101–132 and **down** by 1 more at 133–260. The sums go 35,326 → 35,230 and
     10,504 → 10,408.
   - Against `a254a8a`, the net profile is exactly −2 on every index 133–260
     (128 entries) and 0 elsewhere.
   - `SCHED_J2[i] − GAP_J2[i]` is unchanged at every index, so the lowest bit
     the `v < u` compare looks at stays where it was. The note: "move one
     without the other and the channel goes from ~8 mismatches per 9024 shots
     to ~4,600".
   - Why it saves Toffoli: every walk operation at those steps runs on
     `[..SCHED_J2[i]]`. The note's emitted CCX, before the strip, go
     1,381,252 (no narrowing) → 1,375,689 (2aedb45) → 1,372,333 (this). See
     [trailmix-jump-gcd](../concepts/trailmix-jump-gcd.md) and
     [comparator-and-width-truncation](../concepts/comparator-and-width-truncation.md).
   - The note's sweep, all strip-off: last 96 by 2 at cap 1150 gives 1151 qubits,
     1,375,272 CCX, classical λ 9.58. Last 128 by 2 gives 1151, 1,372,333,
     13.88 ± 0.81. Last 160 by 2 gives 1151, 1,370,237, 14.92. The author took
     128 at the higher λ because a 26-machine fleet could grind it in about 40
     minutes.
2. **Caps.** `TLM_TARGET_Q` 1151 → 1150 in `configure_q1153_second512_submission_defaults`
   (`src/point_add/mod.rs`) and `install_q1153_submission_defaults`
   (`trailmix_ludicrous/mod.rs`), and `TLM_SQUARE_PEAK_CAP` 1151 → 1150. As in
   2aedb45, the vent pool takes `cap − active` wires, so the cap must drop for
   the freed wire to lower the peak. The note's cap sweep shows the peak sticks
   at 1147 for every cap ≤ 1146, and that cap cuts alone lose score. The qubit
   comes from the schedule. See
   [peak-qubits-and-budgets](../concepts/peak-qubits-and-budgets.md).
3. **Re-mined strip, `src/point_add/deep_strip_keys.rs`.** The census covers
   1,000,005,632 input pairs on the new pre-strip stream (9,163,279 ops,
   1,372,333 CCX+CCZ, 1151 qubits). It finds 9,041 `DEAD_KEYS` and 2,045
   `DOWNGRADE_KEYS` (11,086 keys, was 11,168). The shipped build logs "0 stale
   keys skipped". See [dead-gate-strip](../concepts/dead-gate-strip.md).
4. **Tail nonce:** `SUB4_TAIL_NONCE` default 2000000032904 → 66014000021257.

## Why it is still correct, and what it risks

- **Width narrowing: probabilistic.** An input whose `u`/`v` has not shrunk
  enough by divstep 133–260 loses a bit when the top wire is reset, which gives
  a classical failure plus phase garbage. The note's n = 16 measurement on
  random seeds: classical 13.88 ± 0.81, phase 9.88 ± 0.73, ancilla 0. Measured
  P(clean) over 20,000 nonces is 8.9e-8, about 1.12e7 nonces per clean seed.
- **Cap change: exact** (layout only). **Strip: empirical**, as in
  [`a254a8a`](a254a8a.md).
- The executed Toffoli varies little across clean seeds: sd 7.4 over 16 seeds,
  range 1,301,793 to 1,301,824.
- The shipped nonce `66014000021257` draws a clean set: 9,024 of 9,024 shots, 0
  classical, 0 phase and 0 ancilla failures. The author checked it on two
  machines. See [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

As in 2aedb45, the change truncates per-divstep register and compare widths.
That lowers Toffoli directly and, with the cap, the peak. Comparator/width
truncation.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 2aedb45 -- src/point_add`. The base is the git parent.
   `git diff --ignore-cr-at-eol 2aedb45 3222da6 -- src/point_add` is 12,090 lines
   in 4 files, almost all of it the regenerated key table.
2. **Copy the generated table from the commit:**
   `git checkout 3222da6 -- src/point_add/deep_strip_keys.rs`.
3. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line endings.
4. **Check the tree.** `git diff --ignore-cr-at-eol 3222da6 -- src/point_add`
   should print nothing.
5. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `TLM_*` or
   `SUB4_*` overrides set. Expect:
   - 1151 qubits
   - 1,301,798 average Toffoli (1,301,797.555 before rounding)
   - score 1,498,369,498
   - 0 classical, 0 phase and 0 ancilla failures
6. **Nonce caveat.** The score only reproduces with the nonce `66014000021257` and
   an identical op stream. Any other change needs a new nonce hunt and a strip
   re-mine.
