## Summary

q73d adds two bands to `GO_CELLF`, the per-cell shift of the overflow-flag
compare width. Multiply-leg cells at ticks 150–224 and 345–420 now compare
one bit fewer when they erase the cell's overflow flag. A narrower compare is
cheaper but has twice the tie error, so this is a plain λ sell. The author
priced it at about −14 T for +0.018 λ, and the 16,384-nonce mean fell by
15.9 T. Against the q73c re-roll, the clean nonce lands 7 Toffoli lower at the
same 1173 qubits.

Because the op stream after the first sold cell is shorter, the two rewrite
rows that sit late in the stream are re-keyed to their new op indices. The
other 103 rows are unchanged.

## What changed and why it saves Toffoli

All changes are in `src/point_add/mod.rs` and the rewrite table.

1. **`GO_CELLF`: `mul:225-344:1,div:250-299:-1` →
   `mul:225-344:1,div:250-299:-1,mul:150-224:-1,mul:345-420:-1`** in
   `install_skywalk_submission_recipe()`.
   - `cell_shift(mul, t)` in `heo_carry.rs` adds
     `go_cell_delta("GO_CELLF", mul, t)` to dF. `go_cell_delta` sums every
     entry whose leg matches and whose inclusive tick range holds `t`.
   - `cell_mul` runs the cell inside `h7::with_cmp_shift((db, df), …)`, and
     `pingpong.rs` adds dF to `flag_compare(round)`. That is the width `k` of
     the cell's overflow-flag erase: `erase_with_compare(circ, overflow,
     &target[N-k..], &source[N-k..], borrow)`, a measured erase followed by
     a top-`k` phase compare. See
     [measurement-uncompute](../concepts/measurement-uncompute.md) and
     [comparator-and-width-truncation](../concepts/comparator-and-width-truncation.md).
   - The multiply envelope (`sky8_env_mul_iA.m.100.txt`) has 392 ticks
     (0–391), so the second band reaches ticks 345–391, 47 cells. The first
     band covers 75 cells. Neither overlaps the existing `mul:225-344:+1`
     buy, so the multiply leg's dF is now −1 on ticks 150–224, +1 on 225–344
     and −1 on 345–391.
   - The diff does not show how many of these cells reach a flag erase or how
     often the compare runs. The submission note gives the price: about −14 T
     for +0.018 λ on 4,096 paired nonces, and a 16,384-nonce mean of
     944,572.06 against 944,587.94 for q73c.
2. **Rewrite table: `q73c_rewrite.txt` → `q73d_rewrite.txt` (105 rows).**
   - The loader in `build()` finds one global shift `d` under which every row
     names an unconditioned CCX, asserts that the shift is unique, and replaces
     each CCX by its CX chain. See [dead-gate-strip](../concepts/dead-gate-strip.md).
   - The new cell widths change the stream only from the first sold cell on.
     The submission note puts the first differing op at 6,282,684. The 102
     square rows (ops 4,614,127–5,187,631) and the row at op 17,033 lie before
     it and keep their indices.
   - The last two rows lie after it, and their ops move by −384: 9,252,045 →
     9,251,661 and 9,254,108 → 9,253,724. One global shift cannot cover both
     groups, so these two rows are edited in the file. The note says both were
     re-proved by windowed SAT at the new positions.
   - The row count is unchanged, so the rewrite saves the same number of CCX
     as in q73c.
3. **Tail nonce**: `TAIL_NONCE` goes from 24700228103001 to 25000058104875.

## Why it is still correct, and what it risks

- **The flag sell is probabilistic.** Each sold erase compares one bit fewer,
  so its tie error about doubles. A wrong compare leaves a wrong phase, which
  shows up as a **phase** failure.
- The submission note gives λ = 19.320 ± 0.032 on 16,384 nonces (est + 2 SE
  19.384), below the 19.5 limit in the inherited 8ee337c note and above the
  18 of the PR 419 contract. The author says so openly.
- **The rewrite rows are exact** on reachable states if their proofs hold. The
  build only asserts that each row still names its CCX.
- The shipped nonce `25000058104875` draws a clean island: 0 classical,
  0 phase and 0 ancilla failures. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

The only lever is one compare bit fewer on a band of flag erases. That is
comparator/width truncation, the same kind as the sky12 re-balance
[`84e78ce`](84e78ce.md). The rewrite re-key keeps the existing dead-gate cuts
valid and adds none.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 9eace63 -- src/point_add`. The base is the git
   parent. `git diff --ignore-cr-at-eol 9eace63 7c1a800 -- src/point_add` is
   15 lines in 2 files (`mod.rs`, plus the renamed table with two re-keyed
   rows).
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line
   endings. The patch renames `q73c_rewrite.txt` to `q73d_rewrite.txt` and
   edits its last two rows.
3. **Check the tree.** `git diff --ignore-cr-at-eol 7c1a800 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh`. `build()` clears
   the process environment and then installs the pinned recipe, so `HEO_*`,
   `GO_*`, `SKY_*`, `PP_*` and `SUB4_*` overrides have no effect. Do not set
   them anyway. Expect:
   - 1173 qubits
   - 944,571 average Toffoli (rounded)
   - score 1,107,981,783
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `25000058104875` and an identical op
stream. [`e3fd358`](e3fd358.md) keeps this circuit and only re-rolls the
nonce.
