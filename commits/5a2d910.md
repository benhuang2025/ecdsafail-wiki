## Summary

This stacks three one-step truncations on nikhiljha's three-chunk tree. All
three narrow approximations that already existed, and all three are
peak-neutral:

- **The GCD width envelope margin, 27 → 26.** This is twangodev's own
  [`113f346`](113f346.md) cut. It was lost when [`f42ce5c`](f42ce5c.md) was
  built on the older `144e07f`.
- **The branch-compare schedule margin, 8 → 7.** `f42ce5c` had widened it
  from 4 to 8 to find a clean island.
- **The apply-pass overflow compare, 21 → 20 bits.** `f42ce5c` had widened
  it from 19 to 21.

Recomputing the width tables gives exactly the measured saving of 5,576
Toffoli. The reroll pair was re-searched to (0, 44).

## What changed and why it saves Toffoli

All changes are in `configure_ecdsafail_submission_route()` in
`src/point_add/mod.rs`. The step count is 396.

1. **`DIALOG_GCD_WIDTH_MARGIN`: 27 → 26.**
   - `dialog_gcd_tobitvector_active_width(step)` is
     `256 − 0.7075 · step + MARGIN`, rounded up to even and clamped to 256.
     With margin 26, 178 steps lose 2 bits. The summed width over the 396
     steps drops by 356 bits (56,562 → 56,206).
   - Each width bit costs 3 Toffoli per GCD pass: one CSWAP, one gated-load
     CCX and one bit of the measured Cuccaro subtract. There are 4 passes
     (forward and reverse transcript, for each of the two GCD passes), so the
     saving is 12 × 356 = 4,272 Toffoli. See [`113f346`](113f346.md) for the
     breakdown.
2. **`DIALOG_GCD_PA9024_COMPARE_SCHEDULE_MARGIN`: 8 → 7.**
   - The branch comparator width is
     `min(SCHEDULE[step] + MARGIN, active_width, 58)`. With both the margin
     and the active width lowered, the summed compare width drops from 19,942
     to 19,814 bits: 54 bits from the margin and 74 from the narrower active
     width on late steps.
   - At 4 runs per step and 1 Toffoli per bit, that saves 4 × 128 = 512
     Toffoli.
3. **`DIALOG_GCD_APPLY_CLEAN_COMPARE_BITS`: 21 → 20.**
   - After each apply-pass modular add or subtract, the overflow flag
     `acc_ovf` is erased by recomputing it from the top `k` bits only:
     `ccx_cmp_lt_into_fast(acc[256−k..], a[256−k..], ctrl, acc_ovf)`, which
     costs `k + 1` Toffoli.
   - One bit less at each of the 2 × 396 = 792 calls saves 792 Toffoli.

Total 4,272 + 512 + 792 = 5,576, the measured change.

4. **Reroll pair: `DIALOG_REROLL` 214 → 0, `DIALOG_POST_SUB_REROLL` 466 → 44.**
   These are the identity `X;X` counts that only re-draw the 9,024 test
   inputs.

## Why it is still correct, and what it risks

All three are approximations, and each one bit tighter roughly doubles its
own failure rate:
- **Width envelope:** a `u` or `v` that still has a bit above
  `active_width` gets truncated, and the GCD goes wrong. This shows up as a
  classical failure, or as ancilla garbage, since the late-step u-high borrow
  also assumes those bits are zero.
- **Branch compare:** if `u` and `v` agree on all of the compared top bits,
  the step can take the wrong branch.
- **Apply overflow compare:** if the result and the addend agree on their top
  20 bits, `acc_ovf` is erased wrongly, which leaves a dirty or phase-marked
  ancilla.

The reroll pair (0, 44) draws a clean set: 9,024 of 9,024 shots pass with
0 classical, 0 phase and 0 ancilla failures. See
[nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

All three knobs narrow a width or a truncated comparator, so
comparator/width truncation fits.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout e4edca0 -- src/point_add`. The base is the git
   parent. `git diff --ignore-cr-at-eol e4edca0 5a2d910 -- src/point_add` is
   14 lines in 1 file.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line endings.
   It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 5a2d910 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `DIALOG_*`,
   `KAL_*`, `KARA_*` or `ROUND84_*` environment variables set, because
   `set_default_env` keeps any value already in the environment. Expect:
   - 1434 qubits
   - 1,733,573 average Toffoli (rounded)
   - score 2,485,943,682
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the reroll pair `DIALOG_REROLL=0`,
`DIALOG_POST_SUB_REROLL=44` and an identical op stream. Any other change
needs a new reroll search.
