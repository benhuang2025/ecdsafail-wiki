## Summary

`R_SMALL_THRESHOLD` goes from 321 to 325. Below this iteration the Kaliski
step `r := 2r mod p` is a plain wire shift with no reduction. Four more
iterations in each of the four Kaliski runs take the free path, and each saves
one truncated constant add of 52 Toffoli: 16 × 52 = 832. The `KAL_REROLL`
tail goes from 43 to 10 so the new op stream draws a clean test set. Qubits
are unchanged. The commit also adds a short notes file, `memory/r-small-325-reroll-10.md`,
which has no effect on the build.

This is the same move as [`0e726ac`](0e726ac.md) on the other line, which went
to 326. Here 326 failed full validation.

## What changed and why it saves Toffoli

1. **`R_SMALL_THRESHOLD`: 321 → 325** (`src/point_add/kaliski_state.rs`,
   read by `r_small_threshold()`, env `KAL_R_SMALL_THRESHOLD`).
   - In Kaliski STEP 7+8 (`kaliski_walk.rs`, forward bodies), iterations
     below the threshold call `mod_double_no_corr(b, r)`, a swap cascade with
     0 Toffoli. The `_backward` mirrors use the matching `mod_halve_no_corr`
     or the modular halve.
   - Iterations at or above it shift and then add `c = 2^32 + 977` under the
     old top bit with `cadd_nbit_const_direct_fast`. Its carry chain is clipped
     to `33 + W = 52` positions (carry-tail `W = 19` on this tree), at one
     Toffoli each.
   - Iterations 321 to 324 move to the free path in pair1 and pair2, forward
     and backward: 4 × 4 × 52 = 832 Toffoli. See [`ac52c2e`](ac52c2e.md) for
     the lever.
2. **`KAL_REROLL`: 43 → 10** (`src/point_add/mod.rs`). This is the number of
   identity `X;X` pairs appended to the op stream. It only re-draws the
   Fiat–Shamir test inputs. See [`6e71096`](6e71096.md).
3. **New file `src/point_add/memory/r-small-325-reroll-10.md`** (23 lines).
   It is a plain-text log of the validation command, the result and the
   negative evidence, and is not compiled.

## Why it is still correct, and what it risks

- **R_SMALL is probabilistic.** The comment's proof that `r[255] = 0`
  (`max(r, s) ≤ 2^iter`) only holds below iteration 255. Up to 325 it is an
  empirical bound. An input whose `r` reaches `2^255` earlier loses its top bit
  in the free shift, and the inverse is wrong. That shows up as a classical
  mismatch.
- **Island.** The notes file records that `R_SMALL = 326` passed 512-shot
  screens for many re-rolls but failed the full 9,024-shot validation, and
  that `rr = 0` failed with 7 classical mismatches and 4 phase-garbage
  batches. Re-rolls 1, 2, 5, 6, 8, 9, 11, 14 to 19, 22, 23 and 25 found no
  clean draw. The shipped `rr = 10` is clean: 0 classical, 0 phase and
  0 ancilla failures. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

The saving comes from moving a threshold that decides how many iterations take
a cheap path, which is iteration/threshold tuning. The re-roll is the usual
companion of any op-stream change.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 233a44c -- src/point_add`. The base is the git
   parent. `git diff --ignore-cr-at-eol 233a44c 17ae622 -- src/point_add` is
   50 lines in 3 files, one of them the new notes file.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`. The flag lets the patch apply whether the files use LF or CRLF line endings. It is the
   complete diff against the base, including the notes file.
3. **Check the tree.** `git diff --ignore-cr-at-eol 17ae622 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `KAL_*`,
   `AFFINE_*`, `SHIFT22_*` or `LOWQ_*` environment variables set. Expect:
   - 2025 qubits
   - 2,559,671 average Toffoli (rounded)
   - score 5,183,333,775
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with `KAL_REROLL = 10` and an identical op stream.
Any other change needs a new re-roll search.
