## Summary

The x-coordinate tail of the point addition computes `λ²` with a 256-bit
schoolbook square. Each row of that square is added into the 512-bit result
with a "fast" Cuccaro adder: every carry sits on its own borrowed scratch wire,
costs one Toffoli, and is erased by measurement for free. Since `e0cfe2b`
(3 June) a knob kept the top carry stage of every row as an in-place
Cuccaro `MAJ`/`UMA` pair instead. That needs no carry wire, but costs two
Toffoli instead of one. It was a qubit lever, used when the square phase was
tight on wires.

This commit sets the knob back from 1 to 0, so every carry stage of every row
uses a borrowed wire again. That saves one Toffoli per row: 255 rows in the
forward square and 255 in its inverse, which is exactly the measured −510. The
square now needs one more scratch wire at a time, but the square phase is no
longer the qubit binder, so the peak stays at 1307. The tail nonce was
re-hunted.

## What changed and why it saves Toffoli

All changes are in `src/point_add/mod.rs`, `configure_ecdsafail_submission_route()`.

1. **`SQUARE_SELFHOST_GATE_SUFFIX_CARRIES`: 1 → 0.**
   - Read by `square_selfhost_gate_suffix_carries(n)` in
     `arith/multiply.rs`, which returns the knob value clamped to `n − 1`.
   - It is used by the self-hosted schoolbook square
     `schoolbook_square_symmetric_lowq_selfhosted[_inverse]_with_clean_supplement`
     on its `SQUARE_SELFHOST_SAFE_LANE_REUSE=1` path (pinned on this route).
     For row `i`, the row register holds `x[i]·x[i+1..]` (one CX plus
     `n − i − 1` CCX). It is added into the slice `tmp_ext[2i .. 2i+width+1]` by
     `cuccaro_add_fast_low_to_ext_borrowed_carries_no_cin` (the inverse uses
     `cuccaro_sub_fast_…_no_cin`), both in `arith/adder.rs`.
   - Inside that adder, `borrowed = n − gate_suffix`. Stages `1..borrowed`
     write their carry into a borrowed wire with one CCX. The reverse sweep
     clears it with `hmr` and a `cz_if` phase fix, which costs no Toffoli (see
     [measurement-uncompute](../concepts/measurement-uncompute.md)). Stages
     `borrowed..n` run `maj` forward and `uma` backward, keeping the carry in the
     source wire. That is one CCX each way, 2 Toffoli in total. See
     [adders-and-carries](../concepts/adders-and-carries.md).
   - With the knob at 1, the top stage of every row with at least two bits used
     `maj`/`uma` (2 Toffoli). At 0 it uses a borrowed wire (1 Toffoli). The
     last row, of width 1, was unaffected because of the `n − 1` clamp.
   - The borrowed wires come first from the square's own untouched high zeros
     (`tmp_ext[hi..]`), then from the caller's clean supplement, and then from
     a small global pool. For row `i` the request is `row.len() − suffix`, and
     the tail can supply `n − i − 2` of the `n − i + 1` wires needed. So the
     global pool grows from 2 to 3 wires during each row add. That is the qubit
     price of the change.
   - **Where it runs.** On this route the x-tail
     (`rounds/dialog/mod.rs`, phase `round84_fused_square_xtail_dx_sub_lam_square_lowq`)
     calls `squaring_sub_from_acc_schoolbook_lowq_shift22`, because
     `ROUND84_XTAIL_KARATSUBA=0`. That function runs the 256-bit self-hosted
     square forward and then inverse (`XTAIL_SQ_SELFHOST` defaults on).
     Each pass has 255 rows with a gated top stage. 2 × 255 = 510 Toffoli,
     which matches the measured drop exactly. The Karatsuba `z2` square also
     reads the knob, but it is not on this route.
2. **`DIALOG_TAIL_NONCE`: 2667032 → 812502068.**

**Why the peak does not move.** The suffix knob was added when the square
phase co-bound the peak. By this tree the 1307-qubit peak is set elsewhere
(the dialog-GCD phases), so one more global carry wire during the square fits
under it (see [peak-qubits-and-budgets](../concepts/peak-qubits-and-budgets.md)).
The measured peak is unchanged.

## Why it is still correct, and what it risks

The change is exact. A borrowed-carry stage and an in-place `MAJ`/`UMA` stage
compute the same sum bit and the same carry. Both return their scratch to `|0⟩`
on every input: the borrowed wire through the measured clear and its phase fix,
the `MAJ` source wire through `UMA`. Toffoli count and qubits do not depend on
the input, and λ does not change.

The nonce was re-hunted only because the op stream changed. Nonce
`812502068` validated with 0 classical, 0 phase and 0 ancilla failures over all
9,024 shots. A wrong carry stage would leave ancilla garbage on the borrowed
wire, or a phase error from a wrong `cz_if`, and also a classical mismatch in
`x3`. See [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

The published label is fold/carry truncation, but no carry is truncated and
nothing is approximate. The commit switches one adder stage per row from
in-place `MAJ`/`UMA` back to a measured borrowed carry. That trades a qubit of
slack for a Toffoli, so Uncompute Strategy → measurement uncompute, or Strength
Reduction → fast-adder reroute (the label used for the reverse move in
`639f12c`), would describe it better.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 2c3b795 -- src/point_add`. The base is the git
   parent. `git diff --ignore-cr-at-eol 2c3b795 c8f4536 -- src/point_add` is
   4 lines in 1 file.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line endings.
   It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol c8f4536 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no
   `SQUARE_*`, `DIALOG_*`, `ROUND84_*` or other route environment variables set,
   because they override the defaults in the patch. Expect:
   - 1307 qubits
   - 1,484,269 average Toffoli (rounded)
   - score 1,939,939,583
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `812502068` and an identical op
stream. Any other change needs a new nonce hunt.
