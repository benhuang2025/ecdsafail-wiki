## Summary

This commit changes one constant, `R_SMALL_THRESHOLD`, from 325 back to 326.
Below this iteration the Kaliski inverse doubles its Bézout register `r`
with a plain shift, which uses no Toffoli. From the threshold on it uses a
real modular doubling, which needs a controlled `+c` carry chain. With the
threshold at 326, iteration 325 also gets the free shift. That saves 698
average Toffoli at the same 2309 qubits.

The author's previous commit [`9fa5a56`](9fa5a56.md) had moved the threshold
to 325 as part of a joint island search. A finer sweep found that 326 is
also clean at the new W-TRUNC setting (`K0 = 24`, margin 0), and cheaper.

## What changed and why it saves Toffoli

- `src/point_add/kaliski_state.rs`: `R_SMALL_THRESHOLD` goes from 325 to
  326. The env override `KAL_R_SMALL_THRESHOLD` is unchanged.
- **What the threshold controls.** Kaliski STEP 6–8 doubles `r` mod p every
  iteration (`kaliski_walk.rs`, in the bulk-prefix iteration and in its
  backward mirror):
  - for `iter < r_small_threshold()`: `mod_double_no_corr(r)`, a cascade of
    swaps (`modular.rs`). It rotates `r` left by one bit, which is a doubling
    when the top bit is 0, and it uses no Toffoli;
  - otherwise: `mod_double_inplace_direct` or `mod_double_inplace_fast`. This
    shifts, moves the old top bit into an overflow wire, and adds
    `c = 2^32 + 977` under that wire with a carry chain (see
    [modular-fold](../concepts/modular-fold.md)).
- **Why it saves Toffoli.** One more iteration (325) uses the free shift, in
  the forward and backward runs of each inversion that reaches it (pair1 has
  399 iterations and pair2 has 397). Each skipped correction removes one
  constant-add carry chain.

## Why it is still correct, and what it risks

The shift without correction is right only if the top bit of `r` is still 0.
The comment's proof (`max(r, s)` at most doubles per iteration, starting from
1) covers only the first 255 iterations. Beyond that the threshold is
empirical. At 326 it bets that `r < 2^255` through iteration 325 on every test
input. If an input breaks this, the swap cascade, which is really a
rotation, wraps the top bit into bit 0 instead of reducing by p. `r` is then
wrong, and so is the final inverse. That shows up as a classical mismatch.

There is no nonce in this era. The author swept `R_SMALL` over 320, 322, 323,
324, 325, 326 and 327 at `K0 = 24`, margin 0, with the full 9,024-shot
evaluator. 326 is clean and the cheapest, and 327 fails. This draw is clean:
0 classical, 0 phase and 0 ancilla failures. See
[nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

The change moves an iteration threshold that switches between a cheap and an
exact form of a step, which is iteration/threshold tuning.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 9fa5a56 -- src/point_add`. The base is the git
   parent. `git diff --ignore-cr-at-eol 9fa5a56 330186c -- src/point_add` is
   2 lines in 1 file.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`. The flag lets the patch apply whether the files use LF or CRLF line endings. It is the
   complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 330186c -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `KAL_*`
   or other tuning environment variables set, and with `DUMMY_TOFFOLIS` unset.
   Expect:
   - 2309 qubits
   - 2,587,779 average Toffoli (rounded)
   - score 5,975,181,711
   - 0 classical, 0 phase and 0 ancilla failures

There is no nonce in this tree: the test set is a hash of the op stream, so the
score only reproduces with an identical op stream. Any other change draws a new
island.
