## Summary

One constant. The second Kaliski inversion pair, which uncomputes λ, runs a
fixed number of iterations. This commit lowers that number from 401 to 397.
Each iteration removed saves one forward and one backward Kaliski iteration
plus one modular doubling of λ, about 3,500 Toffoli, so four of them save
14,087 average Toffoli. Qubits stay at 2310 (this commit is built on
`a3ee589`, not on the 2309-qubit `b60eec2`). The cost is that inputs whose
Kaliski run needs 398 to 401 steps are no longer handled; the shipped draw
contains none.

## What changed and why it saves Toffoli

- `src/point_add/mod.rs`, `build_standard_point_add()`: `pair2_default` on the
  default `stack_2565_enabled()` branch goes from 401 to 397. The env override
  `KAL_PAIR2_ITERS` still takes precedence.
- Pair2 is the in-place-v run `with_kal_inv_raw_borrow_v_w_pair(b, &tx, p, pair2_iters, KalPair::Pair2, ...)`.
  Its body first applies `pair2_iters` calls of `mod_double_inplace_fast` to
  λ to cancel the `2^iters` scale that a fixed-length Kaliski run leaves on
  the inverse, then multiplies and cleans λ. See [`a3ee589`](a3ee589.md) for
  the Kaliski background.
- Four fewer iterations therefore remove 4 forward iterations, 4 backward
  iterations and 4 modular doublings. 14,087 / 4 ≈ 3,522 Toffoli per
  iteration.
- With the bulk-prefix cap at 400, all 397 pair2 iterations now use the cheap
  bulk body (before, the 401st used the generic body).

## Why it is still correct, and what it risks

A fixed Kaliski length is only correct for inputs that terminate within it. An
input of pair2's denominator `Qx − Rx` that needs more than 397 steps leaves
the inverse unfinished: λ is not cleared to zero, which shows up as ancilla
garbage, a classical mismatch, or both. The author reports 396 producing
classical mismatches on its draw and 397 clean. Because this era has no tail
nonce, the test draw is a hash of the op stream, so 397 being clean is a
property of this exact stream: 0 classical, 0 phase and 0 ancilla failures.
See [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

A loop count is lowered, nothing else: iteration/threshold tuning.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout a3ee589 -- src/point_add`.
   - Do not start from the git parent `b60eec2`. The author built on
     `a3ee589`. Against `b60eec2` the diff is 45 lines: it would put back the
     constant-|1⟩ `f1` ancilla (2309 → 2310 qubits), remove `B::z_if`, and
     undo the `R_SMALL_THRESHOLD` 327 → 326 and `BULK_PREFIX_SAFE_ITERS`
     401 → 400 re-tunes.
   - Against `a3ee589`, `git diff --ignore-cr-at-eol a3ee589 77b87f1 -- src/point_add`
     is 6 lines in 1 file.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`. The flag lets the patch apply whether the files use LF or CRLF line endings. It is the
   complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 77b87f1 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `KAL_*`,
   `POINT_ADD_*` or `BY_*` environment variables set. Expect:
   - 2310 qubits
   - 3,624,623 average Toffoli (rounded)
   - score 8,372,879,130
   - 0 classical, 0 phase and 0 ancilla failures

There is no tail nonce in this era: the test set is a hash of the op stream,
so the score only reproduces with an identical op stream.
