## Summary

This commit makes no optimization. It only changes the tail nonce in
`src/point_add/mod.rs` (`DIALOG_TAIL_NONCE` default in `build()`) from 28265
to 1006790. The new nonce draws a different clean set of 9,024 test shots,
whose average executed Toffoli is 8 lower. The diff touches only that literal
plus a new `src/point_add/mod.rs.bak`, a 4,876-line backup of an older
`mod.rs` that no `mod` declaration references, so it is never compiled. The
emitted op count is unchanged (10,758,558). For why a nonce moves the score,
see [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Reproduce

From `git checkout 75851e6 -- src/point_add`, copy the inert backup with
`git checkout 70bf11a -- src/point_add/mod.rs.bak`, then apply the patch below
with `git apply --ignore-whitespace`. `./benchmark.sh` should give 1166
qubits, 1,422,258 average Toffoli and 0 / 0 / 0 failures.
