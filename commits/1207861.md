## Summary

This is the same lever as [`ecbf87b`](ecbf87b.md), pushed one bit further and
built independently on the older tree `006e38b`. The global cap on the GCD
branch comparator goes from 61 to 58 bits. Across the 399 GCD steps that
removes 638 comparator bits, and each bit is one Toffoli in each of the four
places the comparison runs, so the saving is 4 × 638 = 2,552 Toffoli. Qubits
are unchanged. The reroll pair was re-searched to find a clean test set for the
new op stream.

## What changed and why it saves Toffoli

Both changes are in `configure_ecdsafail_submission_route()` in
`src/point_add/mod.rs`:

1. **`DIALOG_GCD_COMPARE_BITS`: 61 → 58.**
   - Each step of the binary-GCD transcript pass writes
     `b0_and_b1 = v_odd AND (u > v)`, which controls the swap of `u` and `v`.
     The comparison `u > v` looks only at the top `compare_bits` bits of the
     active registers (`dialog_gcd_ccx_cmp_gt_truncated_into_width` →
     `ccx_cmp_lt_into_fast`). That comparator costs one CCX per bit and clears
     its carries by measurement, so one bit is one Toffoli.
   - The width per step is `dialog_gcd_compare_bits_for_step` =
     `min(SCHEDULE[step] + 5, DIALOG_GCD_COMPARE_BITS, active_width)`, where
     `SCHEDULE` is the baked 399-entry `DIALOG_GCD_PA9024_COMPARE_SCHEDULE`
     table and 5 is `DIALOG_GCD_PA9024_COMPARE_SCHEDULE_MARGIN`. The global
     knob is a ceiling on the schedule.
   - With the base's settings (399 steps, `DIALOG_GCD_WIDTH_MARGIN=27`), the
     ceiling of 58 binds on 238 steps and lowers the summed per-step width by
     638 bits.
   - The comparison runs in the forward and the reverse transcript pass of both
     GCD pairs (the quotient `dy/dx` and the product after the x-tail). That is
     4 × 638 = 2,552 Toffoli, exactly the measured saving.
2. **Reroll pair: `DIALOG_REROLL` 6 → 1, `DIALOG_POST_SUB_REROLL` 28 → 14.**
   These are counts of identity `X;X` pairs on `tx[0]` (before the first
   subtraction) and `tx[1]` (after it). They change the op-stream hash, and so
   the 9,024 test inputs, without changing the circuit. See
   [`ecbf87b`](ecbf87b.md) for how this era's 2-D reroll works.

## Why it is still correct, and what it risks

The truncated comparison is wrong when `u` and `v` agree on all of their top
58 bits but differ lower down. The step then takes the wrong branch and the
transcript no longer drives the apply pass correctly, which shows up as a
classical failure (or as phase or ancilla garbage if the reverse pass no
longer mirrors the forward one). Going from 61 to 58 bits makes this about
8× more likely on each affected step, so λ rises.

The author's note says several nearby reroll pairs were clean on the first
4,096 shots but failed later in the 9,024. The shipped pair (1, 14) is clean
on all 9,024 shots: 0 classical, 0 phase and 0 ancilla failures. See
[nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

The only circuit change is a narrower comparator, so comparator/width
truncation fits. The reroll change is the usual companion of any circuit
change in this era.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 006e38b -- src/point_add`.
   - The git parent is `ecbf87b`, which already set the cap to 59 with reroll
     pair (0, 10). Its circuit differs from this commit's only in that knob,
     so diffing against it (21 lines) shows the same edits as 59 → 58 plus
     the removal of ecbf87b's comment. The author started from `006e38b`
     (its comments still say 61), so that is the base.
   - `git diff --ignore-cr-at-eol 006e38b 1207861 -- src/point_add` is 18
     lines changed in 1 file.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line endings.
   It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 1207861 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `DIALOG_*`,
   `KAL_*` or `ROUND84_*` environment variables set, because `set_default_env`
   keeps any value already in the environment. Expect:
   - 1567 qubits
   - 1,682,963 average Toffoli (rounded)
   - score 2,637,203,021
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the reroll pair `DIALOG_REROLL=1`,
`DIALOG_POST_SUB_REROLL=14` and an identical op stream. Any other change needs
a new reroll search.
