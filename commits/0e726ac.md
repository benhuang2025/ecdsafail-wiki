## Summary

Two constants change, in opposite directions.

- `R_SMALL_THRESHOLD` goes from 321 to 326. Below this iteration, the Kaliski
  step `r := 2r mod p` is done as a plain wire shift with no reduction. Five
  more iterations in each of the four Kaliski runs become free, which saves
  20 × 53 = 1,060 Toffoli.
- The shift22 spill-fold carry window goes back from 33 to 41 bits, undoing
  [`3ab1c72`](3ab1c72.md). That costs 480 Toffoli. It is there because
  `R_SMALL = 326` alone fails on the old draw (4 classical mismatches), and the
  window change re-rolls the test set onto a clean one.

The net is −580 Toffoli at the same 2309 qubits.

## What changed and why it saves Toffoli

1. **`R_SMALL_THRESHOLD`: 321 → 326** (`src/point_add/kaliski_state.rs`,
   read by `r_small_threshold()`, env `KAL_R_SMALL_THRESHOLD`).
   - In Kaliski STEP 7+8 (`kaliski_walk.rs`, all forward bodies), `r := 2r mod p`.
     The `_backward` mirrors undo it with the matching halve
     (`mod_halve_no_corr`, or the modular `mod_halve_inplace_fast_with_dirty`).
   - For `iter_idx < r_small_threshold()` the code calls
     `mod_double_no_corr(b, r)`, a swap cascade with 0 Toffoli. It assumes
     `r[255] = 0`, so doubling cannot pass `p`.
   - Otherwise it calls a modular double that shifts and then adds
     `c = 2^32 + 977` under the old top bit with `cadd_nbit_const_direct_fast`.
     That adder's carry chain is clipped to `33 + W = 53` positions (carry-tail
     `W = 20`), at one Toffoli each.
   - Iterations 321 to 325 move to the free path in each of the four Kaliski
     runs (pair1 and pair2, forward and backward). That is
     20 × 53 = 1,060 Toffoli. See [`ac52c2e`](ac52c2e.md) for the same lever on
     an earlier branch.
2. **`shift22_spill_carrytail_cut()`: `SHIFT22_SPILL_W` 33 → 41**
   (`src/point_add/solinas.rs`). This puts back the cut of 63 from
   [`3f534f2`](3f534f2.md): 16 Toffoli more on each of 30 spill-fold ops,
   +480 in total.

## Why it is still correct, and what it risks

- **R_SMALL is probabilistic.** The code comment says `r`'s top bit is
  guaranteed 0 because `max(r, s) ≤ 2^iter`. That only proves it below
  iteration 255. Up to 326 it is an empirical bound. On an input where `r`
  reaches `2^255` by then, the free shift drops the top bit, the inverse is
  wrong, and the run fails as a classical mismatch.
- **The spill window is loosened**, so that part is safer than the base.
- **Island.** There is no re-roll knob in this tree. The test set is a hash
  of the op stream, so the spill window doubles as the re-roll. The author
  reports `R_SMALL = 326` alone gives 4 classical mismatches, while the pair
  (326, 41) is clean: 0 classical, 0 phase and 0 ancilla failures. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

The saving comes from moving a threshold that decides how many iterations take
a cheap path, which is iteration/threshold tuning. The spill window change
costs Toffoli and is only a re-roll.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 3ab1c72 -- src/point_add`. The base is the git
   parent. `git diff --ignore-cr-at-eol 3ab1c72 0e726ac -- src/point_add` is
   4 lines in 2 files.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`. The flag lets the patch apply whether the files use LF or CRLF line endings. It is the
   complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 0e726ac -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `KAL_*`,
   `SHIFT22_*` or `LOWQ_*` environment variables set. Expect:
   - 2309 qubits
   - 2,402,374 average Toffoli (rounded)
   - score 5,547,081,566
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with an identical op stream. There is no re-roll
knob in this tree, so any other change draws a different test set.
