## Summary

The square's B branch used to lend six of its retained wires as scratch to
the folds that consume the branch. Each loan erases a wire for free by
measurement but must rebuild it afterwards with one or two Toffoli. This
commit turns those loans off, so the rebuild Toffoli go away. It also runs
the four exact simplifier passes a second time, after the witness pass,
which can remove a few more CCX. Peak qubits stay at 1251. Net −4 executed
Toffoli.

## What changed and why it saves Toffoli

All edits are in `src/point_add/mod.rs`. The file was also converted to a
different line ending, so a plain `git diff` shows the whole file. With
`--ignore-cr-at-eol` the real change is 10 lines.

### 1. Turn off two loans: `SQ_LEND_RETAINED_ANDS` and `SQ_LEND_RETAINED_CROSS2`, 2 → 0

- Both are branch bitmasks read in `square.rs::with_square`: A = 1, B = 2,
  C = 4. At 2, only the B branch lent. At 0, no branch does.
- While a branch square `x²` is live, `tri_square_k2r` keeps some
  intermediate values ("retained") so that the inverse can run exactly.
  Two kinds can be rebuilt from live wires, so they can be lent out:
  - **Retained AND** (`retained_and_bits`): `cross[1] = a0 · b0` in
    each node, computed as `x[0] · ¬x[lo]` because `x[lo]` holds
    `t0 = a0 ⊕ b0` at that point. It is erased with `hmr` and one `cz_if` (no Toffoli) and
    rebuilt with one `ccx` after the folds.
  - **Cross bit 2** (`retained_cross2_bits`, `cross2_erase` /
    `cross2_restore`): `cross[2] = a0·t1 ⊕ a1·t0 ⊕ a0·t0 ⊕ a0`. It is erased
    with `hmr` and three `cz_if` plus a `z_if`, and rebuilt with two `ccx`.
- With split policy 7, the B branch's retained tree has three nodes: the
  root and its `low` and `sum` children. So the loans freed 6 wires and cost
  3 × 1 + 3 × 2 = 9 rebuild CCX per point addition. Some of those may
  already be rewritten by the post-passes; I did not run the build to check.
- Why it can be a net win: the circuit is pinned at the qubit cap
  (`PP_WALK_MAX_QUBITS = 1251`), and every layout sizes itself to the room
  under it. The six lent wires only gave the B-branch folds more room. Here
  that room was worth less than the rebuild cost. See
  [venting-and-wire-loans](../concepts/venting-and-wire-loans.md) and
  [squaring-and-karatsuba](../concepts/squaring-and-karatsuba.md).

### 2. Re-run the simplifiers after the witness pass

- `build()` already ran `PP_SIMPLIFY = product,affine,quadratic,truth`, then
  `interned_witness::witnesses`, which replaces a CCX by a CX when another
  wire already holds the same product.
- This commit adds, right after the witness pass and before the nonce tail:
  `truth_simplify::simplify_products`, `affine_simplify::simplify`,
  `quadratic_simplify::simplify`, `truth_simplify::simplify`.
- The witness rewrites create new CX-only relations that the first run of
  these passes could not see. Each pass drops or weakens a CCX only when it
  can prove the gate redundant. See
  [dead-gate-strip](../concepts/dead-gate-strip.md).

## Why it is still correct, and what it risks

- **Both levers are exact.** Not lending a wire removes an erase and a
  rebuild that cancelled each other. The simplifier passes only remove gates
  they prove redundant on every input.
- **What can move.** The B-branch folds have less room, so their adds may
  split differently under the cap, and the op stream changes. The truncation
  windows themselves are unchanged, so λ should barely move.
- The shipped nonce `280927235784453` draws a clean test set: 0 classical,
  0 phase and 0 ancilla failures. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

The main lever undoes a scratch-lending choice: it trades lent wires for
fewer rebuild Toffoli. That is a scratch/ancilla reuse retune, in the
Register and Scratch Allocation family. The re-run simplifiers are a
secondary exact dead-gate strip. The runner-up was Dead-Code and Redundancy
Elimination, since the effect is a handful of removed CCX either way.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout a3bbb0e -- src/point_add`. The base is the git
   parent. `git diff --ignore-cr-at-eol a3bbb0e c8da745 -- src/point_add` is
   10 changed lines in 1 file. A plain `git diff` shows all of `mod.rs`
   (326 + / 322 −) because the line endings changed.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line
   endings. It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol c8da745 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh`. This tree reads
   no environment variables: every knob is a fixed entry in `env_raw()`, so
   `PP_*`, `SQ_*` or `SUB4_*` overrides are ignored. Leave them unset anyway.
   Expect:
   - 1251 qubits
   - 890,984 average Toffoli (rounded)
   - score 1,114,620,984
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `280927235784453` and an identical
op stream. Any other change needs a new nonce hunt.
