## Summary

Sky16 adds one pin, `HEO_R1M = 99`. Before, the default was 190. `r1m` is
where the multiply leg's walk-back stops running payload cells inside the
reverse ticks (the *fused* walk-back) and switches to a *head batch*. The head
batch runs all remaining cells against frozen rails, and only then reverses
the rails.

Moving the boundary down puts 91 more cells (ticks 99–189) into the fused
walk-back. The remaining 98 head-batch cells then run with a shorter tape
alive, so they have more free room under the 1174-qubit cap. The commit
comment says they get "room 98 and run 3 chunks instead of 4". One fewer chunk
seam per cell means one fewer approximate carry hand-off, so this saves
Toffoli and also lowers λ. Peak qubits are unchanged. The net is −392 Toffoli,
the largest step in the sky series.

## What changed and why it saves Toffoli

### 1. `HEO_R1M`: default 190 → 99 (`src/point_add/mod.rs`)

The pin is new in `install_skywalk_submission_recipe()`. `carry_cfg()` in
`heo_carry.rs` reads it as `r1m: env_usize("HEO_R1M", 190)`.

**The multiply leg's schedule** (`heo_carry::multiply`). With this recipe
(`HEO_CARRY_SEED=fd`, `HEO_BW=inv`, `HEO_LT0_MUL=1`) it takes the RB-1
single-head-batch path:

1. Rails-only forward ticks 0 … R−1, with R = 392 on the multiply envelope.
2. Loan, then a trailing batch of cells R−1 … `r2m` (370), then unloan, then
   a rails-only reverse R−1 … `r2m`.
3. **Fused walk-back**, t = `r2m`−1 … `r1m`:
   - unpack letter t (`ensure_raw`);
   - route;
   - with `HEO_CELL_INSIDE=1`, run cell t inside the reverse tick, after the
     inverse rail add has consumed the sign wire and before the rails regrow.
   - The reverse rail add uses `split_mul`. `HEO_SPLIT_MUL` is unset, so that
     is `Approx`, with `HEO_SPLIT_K = 21`.
4. **Head batch**, t = `r1m`−1 … 1:
   - the rails stay at their state entering tick `r1m`;
   - for each t: unpack, route, cell;
   - each 5-letter group is repacked when the batch leaves it, except the
     last `HEO_HEAD_LIFO_N = 2` groups.
5. FD payload at t = 0, then `Del` is freed.
6. **Rails-only reverse** t = `r1m`−1 … 0 (`SplitMode::Exact`). It unpacks
   the tape groups again as it consumes them.

**What moving `r1m` from 190 to 99 does:**

- **Ticks 99–189 change mode.** Their cells move from the head batch (step 4)
  into the fused walk-back (step 3). Their rail reverse moves from the exact
  rails-only pass (step 6) into the fused pass with windowed split repairs.
- **The head batch gets more room.** During the head batch, the live set
  includes the rails at the tick-`r1m` state and every tape letter below
  `r1m`. By my estimate from the multiply envelope (`sky8_env_mul_iA.m.100`:
  width 203 at tick 99, 142 at tick 190):
  - the two rails are about 2 × 61 = 122 wires wider;
  - the tape is 91 letters shorter, at 1.6 qubits per letter about 146
    wires;
  - net, about 24 more free wires.

  That matches the submission note's "98 qubits of room instead of 74".
- **Fewer chunks per head-batch cell.**
  - Each cell's 256-bit add (`chunked_add` / `composition_bounds` in
    `pingpong.rs`) takes the ladder `walk_max_qubits() − active_qubits()` and
    calls `chunk_layout(N, ladder)`.
  - That picks the layout with the fewest approximate boundaries that fits.
    With room 98 it needs 3 chunks instead of 4.
  - Each boundary removed is one fewer vented boundary carry and one fewer
    measured erase with its seeded top-k phase compare. See
    [comparator-and-width-truncation](../concepts/comparator-and-width-truncation.md)
    and [measurement-uncompute](../concepts/measurement-uncompute.md).
  - This applies to all 98 head-batch cells.
- **Less tape-codec traffic.**
  - In the old schedule, the groups covering letters 99–189 (about 18
    groups) were unpacked and repacked by the head batch, then unpacked again
    by the rails-only reverse.
  - In the fused walk-back each letter is unpacked once and consumed.
    `pack3` and `pack5` each cost a few CCX, so this saves a few Toffoli per
    group.
- **What it costs.**
  - The 91 moved ticks now use `Approx` split repairs (top-21 windows) where
    their inverse rail add has to split, instead of exact compares.
  - Their cells run at whatever room the fused reverse tick leaves.
  - The submission note reports the sum as a gain on both axes: static CCX
    −509 and official-nonce Toffoli −398.8 on the build without rows, with
    paired-nonce λ −0.113 ± 0.067.
  - It also reports that neighbouring values are worse: 96 and 101 cost
    about 35 T more, and 92, 97, 98 and 102 do not build.

### 2. Rewrite table: `sky15_rewrite.txt` (64 rows) → `sky16_rewrite.txt` (62 rows)

- The file is renamed, and its last two rows, at ops 8,896,638 and 8,898,701,
  are deleted. The other 62 rows are unchanged, with the same op indices.
- The loader finds the shift 0 for them.
- Changing `r1m` leaves every op before the multiply leg's tick-189 walk-back
  untouched. The submission note puts the shared prefix at ops 0–6,408,472,
  checked by an op-dump md5.
- The 62 rows lie in that prefix, so the states they were proved on are
  unchanged and they stay exact without a new SAT run. The two dropped rows
  sat inside the old head batch, whose ops changed.
- Losing them costs about +2 Toffoli.
- The commit comment and the `SKY_REWRITE` comment in `build()` are updated
  to match. See [dead-gate-strip](../concepts/dead-gate-strip.md).

### 3. Tail nonce

`TAIL_NONCE` goes from 15500142914726 to 16000761750475.

## Why it is still correct, and what it risks

- **The schedule move is exact in what it computes.** Every cell still runs
  once with the same tape letter and the same proxy-round windows. Only the
  room it sees and its position in the stream change.
- **The chunk count is a trade inside the truncation.** Fewer chunk seams
  means fewer approximate top-k repairs per head-batch cell, so phase error
  from those cells falls.
- **The moved rail ticks add risk.** They now use windowed split repairs
  (`HEO_SPLIT_K = 21`). A wrong window compare gives a **phase** failure.
- The net λ is down. The submission note gives 19.143 ± 0.032 against 19.341
  for sky15, inside the 19.5 limit that the code comment cites.
- The 62 kept rewrite rows are exact for the reason above. The build still
  asserts that each row names its CCX.
- The shipped nonce `16000761750475` draws a clean island: 0 classical,
  0 phase and 0 ancilla failures. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

The saving comes from changing which wires are live during the head batch.
The shorter tape frees room under the fixed 1174-qubit cap, and the cells
spend that room on wider chunks. That is ancilla-lifetime / venting, like
[`cc82b18`](cc82b18.md), which moved ping-pong's batch checkpoint to give the
replay wider chunks. The runner-up was iteration/threshold tuning, since the
knob is a schedule checkpoint, but no iteration count changes.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 36d313e -- src/point_add`. The base is the git
   parent. `git diff --ignore-cr-at-eol 36d313e 799153a -- src/point_add` is
   12 lines in 2 files (a rename with two deleted rows, plus `mod.rs`).
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line
   endings. The patch renames `sky15_rewrite.txt` to `sky16_rewrite.txt` and
   removes its last two rows.
3. **Check the tree.** `git diff --ignore-cr-at-eol 799153a -- src/point_add`
   should print nothing. Without `--ignore-cr-at-eol`, git may also list
   `sky16_rewrite.txt` for its line endings (the base's `sky15_rewrite.txt` is
   CRLF, the commit's file is LF), and that does not matter.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh`. `build()` clears
   the process environment and then installs the pinned recipe, so `HEO_*`,
   `GO_*`, `SKY_*`, `PP_*` and `SUB4_*` overrides have no effect. Do not set
   them anyway. Expect:
   - 1174 qubits
   - 944,124 average Toffoli (rounded)
   - score 1,108,401,576
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `16000761750475` and an identical op
stream.
