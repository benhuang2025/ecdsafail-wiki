## Summary

This commit moves compare bits between payload cells. It adds three bands to
the per-cell shifts introduced in sky8 ([`4ea960f`](4ea960f.md)):

- division cells at ticks 220–329 lose one chunk-boundary compare bit;
- division cells at ticks 250–299 lose one flag compare bit;
- multiply cells at ticks 105–194 gain back one chunk-boundary compare bit.

The multiply band lies inside sky9's `GO_CHUNK` region (cells at ticks 0–219),
so for those cells it cancels sky9's −1. The effect is to move part of the
chunk-compare sell from early multiply cells to later division cells, plus a
new flag-compare sell. More cell-sites lose a bit (160) than gain one (90), and
the measured net is −129 Toffoli at 1174 qubits. The SAT rewrite table is
re-mined for the new stream (53 rows).

## What changed and why it saves Toffoli

All changes are in `src/point_add/mod.rs`:

1. **`GO_CELLB`: `div:150-155:-1` → `div:150-155:-1,div:220-329:-1,mul:105-194:1`.**
2. **`GO_CELLF`: `mul:225-344:1` → `mul:225-344:1,div:250-299:-1`.**

How these are applied, in `heo_carry.rs` (unchanged since sky8):
- `cell_shift(mul, t)` adds `go_cell_delta("GO_CELLB", mul, t)` to dB and
  `go_cell_delta("GO_CELLF", mul, t)` to dF.
- `go_cell_delta` **sums** every entry whose leg matches and whose inclusive
  tick range holds `t`. None of the new ranges overlaps an old one on the same
  leg.
- `cell_div` / `cell_mul` run the cell inside `with_cmp_shift((dB, dF))`. Then
  `pingpong.rs` adds dB to `chunk_compare(round)` and dF to
  `flag_compare(round)`.
  - `chunk_compare(round)` is the width of every **chunk-boundary carry
    erase** in the cell's chunked 256-bit add.
  - `flag_compare(round)` is the width of the cell's **overflow-flag erase**.
- Both erases are `hmr` on the carry or flag, then, only on outcome 1, a
  phase compare of the top `k` bits of the two registers. So a compare bit
  costs about 0.5 executed Toffoli per site.
- −1 means one bit narrower (a sell). +1 means one bit wider (a buy).

The per-band effect:

| band | sites | direction | interaction with earlier pins |
| --- | --- | --- | --- |
| `GO_CELLB div:220-329:-1` | 110 division cells, every boundary | sell | outside `GO_CHUNK` (ticks 0–219), so a fresh −1 |
| `GO_CELLB mul:105-194:+1` | 90 multiply cells, every boundary | buy | inside `GO_CHUNK`, so the net shift there returns to 0 |
| `GO_CELLF div:250-299:-1` | 50 division cells, flag erase | sell | first flag sell on the division leg |

`GO_CHUNK`'s range is in proxy rounds 0–399. On the fixed proxy envelope that
is ticks 0–219 (tick 220 has proxy round 400); see [`bdff8c8`](bdff8c8.md).

The number of chunk boundaries per cell depends on that cell's chunk layout,
so the exact bit count of the trade cannot be read from the diff. The
benchmark gives the net: −129 Toffoli, rows included.

3. **SAT rewrite rows: `sky10_rewrite.txt` (52 rows) → `sky12_rewrite.txt` (53
   rows).**
   - The comment calls them "53 SAT-proven square rows re-keyed to this op
     stream".
   - Comparing the files, 13 rows name the same wires as a sky10 row, all at
     an index shift of −6,552. The other 40 are new.
   - The loader is unchanged. It finds one unique global shift, checks that
     every row names an unconditioned CCX on its wires, and replaces it with
     a CX chain. It does not re-check the proof. See
     [dead-gate-strip](../concepts/dead-gate-strip.md).
   - One more row is worth about −1 Toffoli.
   - `sky10_rewrite.txt` stays in the tree, unused.
4. **Tail nonce**: `TAIL_NONCE` goes from 10002233751843 to 12002361956562.

## Why it is still correct, and what it risks

- **The two division sells** double the top-k tie error of those erases. A
  wrong compare leaves a wrong phase, which shows up as a **phase** failure.
- **The multiply buy** halves the tie error on cells that sky9 had narrowed.
- The trade only pays if it buys back about as much λ as it spends, while
  removing more Toffoli than it adds. The code comment says the package stays
  within the 19.5 λ limit.
- The rewrite rows are exact on reachable states if their proofs hold.
- The shipped nonce `12002361956562` draws a clean island: 0 classical,
  0 phase and 0 ancilla failures. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

This is a sell/buy re-balance of compare widths with a net reduction:
comparator/width truncation.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout f260d33 -- src/point_add`. The base is the git
   parent. `git diff --ignore-cr-at-eol f260d33 84e78ce -- src/point_add` is
   65 lines in 2 files. The raw diff also rewrites `sky10_rewrite.txt`, but
   only its line endings change.
2. **Copy the new rewrite table from the commit:**
   `git checkout 84e78ce -- src/point_add/skywalk_data/sky12_rewrite.txt`.
   It holds the 53 SAT rows described above.
3. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line
   endings. It covers `mod.rs`.
4. **Check the tree.** `git diff --ignore-cr-at-eol 84e78ce -- src/point_add`
   should print nothing.
5. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh`. `build()` clears
   the process environment and then installs the pinned recipe, so `HEO_*`,
   `GO_*`, `SKY_*`, `PP_*` and `SUB4_*` overrides have no effect. Do not set
   them anyway. Expect:
   - 1174 qubits
   - 944,682 average Toffoli (rounded)
   - score 1,109,056,668
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `12002361956562` and an identical op
stream. [`1034430`](1034430.md) keeps this circuit and only re-rolls the
nonce.
