## Summary

On 0xrlawrence's [`7ca0559`](7ca0559.md) the multiply traversal of the
ping-pong divider runs a pinned 700 rounds, against 698 for the divide. This
commit pins it at 696. Four multiply rounds' walk adds, walk-back adds and
replay cells disappear, which saves 1,765 average Toffoli at the same 1278
qubits. The price is λ from the convergence tail. 0xrlawrence's notes in the
base measured the opposite move, 696 → 700, at +1,752 Toffoli for −2.0 λ, so
this commit sells about 2 λ back for that much Toffoli. A new nonce was
hunted.

## What changed and why it saves Toffoli

1. **`rounds_for(Multiply)` default: 700 → 696** in
   `src/point_add/pingpong_div.rs` (`SUB4_PP_ROUNDS_MUL`). The divide depth
   `rounds()` stays at 698.
   - The multiply traversal's walk, replay (`replay_doubling_round`) and
     walk-back each run one step per round, so four fewer rounds delete four
     walk adds, four walk-back adds and four fused replay cells.
   - The removed rounds are the last ones, where the fitted
     `WIDTH_SCHEDULE` is at its narrow floor, so the walk adds are cheap. The
     replay cells are most of the 441 Toffoli per round.
   - The multiply tape is four wires shorter. Q stays at 1278 because the
     divide traversal and the square still reach the budgeted peak
     (`SUB4_PP_PEAK` = 1278), and the replay ladders are sized to that
     budget. See [peak-qubits-and-budgets](../concepts/peak-qubits-and-budgets.md).
2. **Tail nonce** (`SUB4_PINGPONG_TAIL_NONCE` default in `build()`,
   `src/point_add/mod.rs`): 950027083 → 48000070891.

## Why it is still correct, and what it risks

Depth is a truncation. A multiply input whose walk needs more than 696 rounds
to reach the (±1, ±1) fixed point ends with a wrong product and dirty walk
registers: a **classical** failure, usually with phase and ancilla garbage
too. Nothing else changes. The base's notes put the multiply 696 ↔ 700
difference at about 2 λ, which makes a clean nonce several times rarer. The
shipped nonce `48000070891` draws a clean set: 0 classical, 0 phase and
0 ancilla failures. Two later submissions, `def24be` and
[`a9af194`](a9af194.md), are nonce-only rerolls of this exact circuit. See
[nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

The only change is the multiply walk's iteration count, which is
iteration/threshold tuning.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 7ca0559 -- src/point_add`. The base is the git
   parent. `git diff --ignore-cr-at-eol 7ca0559 36f6ca0 -- src/point_add` is
   4 lines in 2 files.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line
   endings. It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 36f6ca0 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `SUB4_*`
   environment variables set. Expect:
   - 1278 qubits
   - 919,793 average Toffoli (rounded)
   - score 1,175,495,454
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `48000070891` and an identical op
stream. Any other change needs a new nonce hunt.
