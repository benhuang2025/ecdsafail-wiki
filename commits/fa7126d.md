## Summary

This is the same move as the author's [`9798bc9`](9798bc9.md), one frontier
later. The frontier line had again moved on without the author's enhanced
`constprop.rs`. That line now held three more changes:

- the `v[0]` and `y[0]` loans of [`f8d23a9`](f8d23a9.md), worth 1164 qubits;
- the lane-0 cswap elision of [`a47dc6e`](a47dc6e.md);
- `LUD_EXTRA_FOLD_MIN_G=16`, from [`f265bb1`](f265bb1.md).

This commit takes that tree and puts back the enhanced constant-propagation
pass, which has a fixpoint loop, self-inverse pair cancellation and affine
equal/complementary-control detection. The pass's file is byte-identical to
the one in `b02b354` and `9798bc9`. A new tail nonce is added.

Relative to `a47dc6e`, the pass removes 367 more average Toffoli
(1,412,443 → 1,412,076). Relative to the smallest-diff base `9798bc9`, the patch
is the other contestants' three changes, with −1 qubit and −1,057 Toffoli in all.

## What changed and why it saves qubits and Toffoli

Against `9798bc9`, the diff contains only levers already described in other
notes:

1. **Even-`v[0]` and GCD-`y[0]` loans** (`trailmix_ludicrous/gcd.rs`, see [f8d23a9](f8d23a9.md)).
   - `v[0]` is 0 after each step's subtract. It is lent with
     `loan_zero_qubit` around the fused apply step.
   - In `controlled_add_active`, the target's bit 0 is known: 1 after its CX in the
     forward walk (`ForwardKnownOneAfterCx`), and 0 before its CX in the reverse walk
     (`ReverseKnownZeroBeforeCx`). In the reverse walk, the CX is moved after the
     high-bit adder. The wire is lent while that adder runs.
   - `build()` bakes `TLM_PARK_EVEN_V0=1`, `TLM_LOAN_EVEN_V0=1` and `TLM_LOAN_GCD_Y0=1`.
     These loans bring the peak from 1165 to 1164.
2. **Lane-0 cswap elision** (`gcd.rs`, see [a47dc6e](a47dc6e.md)). Both `u`/`v` cswap loops
   start at `j = 1`. Whenever the swap fires, `u[0] = v[0] = 1`, so the lane-0 Fredkin gate
   is the identity. This removes 1,032 Toffoli.
3. **`LUD_EXTRA_FOLD_MIN_G`: 18 → 16** (`mod.rs`, see [f265bb1](f265bb1.md)). The two apply
   `+f` folds with a baked `g = 16` get two extra clean measured carries.
4. **Nonce.** The default `DIALOG_TAIL_NONCE` goes from 1200017123 to 800000341.

The enhanced `trailmix_ludicrous/constprop.rs` is unchanged from the base. See
[b02b354](b02b354.md) for its passes. It runs at the end of
`build_trailmix_ludicrous_ops()`, before the single fan-out rewrite in
`build()`. The note does not break down how many gates it removes on this
stream.

## Why it is still correct, and what it risks

Each component is exact.

- **The loans** depend on the GCD invariants: `u` is odd, and `v` is even after each subtract.
- **The lane-0 elision** depends on `u[0] = v[0] = 1` whenever the swap fires.
- **The fold change** only moves an exact adder's split between measured and chunked carries.
- **The constant, pair and affine rewrites** apply only to provably constant, related or
  cancelling gates.

The combined stream was validated as a whole. Nonce `800000341` gives 0
classical, 0 phase and 0 ancilla failures over all 9,024 shots. The author also
reports that with the pass disabled, the tree reproduces `a47dc6e` exactly. See
[nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

The author's lever is the enhanced constant-propagation pass, re-applied to a
newer tree, so the published label matches the intent. Against the
smallest-diff base, the patch itself is other contestants' loan, elision and
fold levers. The commit is a merge with no new mechanism of its own.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 9798bc9 -- src/point_add`.
   - `git diff --ignore-cr-at-eol 9798bc9 fa7126d -- src/point_add` is 145 changed lines in 2 files.
   - The git parent `a47dc6e` lacks the enhanced pass. Against it, the diff would be
     about 1,180 lines, almost all of it `constprop.rs`.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`. The flag lets the patch apply whether the files use LF or CRLF line endings.
3. **Check the tree.** `git diff --ignore-cr-at-eol fa7126d -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `DIALOG_*`, `TLM_*`, `LUD_*` or `CONSTPROP_*`
   environment variables set. Expect:
   - 1164 qubits
   - 1,412,076 average Toffoli (rounded; 1,412,075.986 before rounding)
   - score 1,643,656,464
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `800000341` and an identical op
stream. Any other change needs a new nonce hunt.
