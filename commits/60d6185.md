## Summary

[`3222da6`](3222da6.md) cut the GCD register widths `SCHED_J2` and the compare
windows `GAP_J2` by 2 bits on the last 128 divsteps (133–260). This commit
applies the same 2-bit cut to the 32 divsteps just before them, 101–132. The
tail is then 2 bits narrower over the last 160 divsteps. It is a pure Toffoli
cut at the same peak: pre-strip CCX+CCZ go 1,372,333 → 1,370,237.

The commit keeps 3222da6's 1150 caps. It does not build on the frontier of the
time, f5ff95b's 1158-qubit trade, which is why it shows a qubit "drop" from
1158 on the leaderboard. The strip was re-mined, this time over 121.6M inputs
rather than 1e9. The narrowing raises λ, the expected number of failing shots
per draw, noticeably: classical failures go from 13.25 to 17.63 per draw.

## What changed and why it saves Toffoli

1. **Width schedule, `src/point_add/trailmix_ludicrous/schedule.rs`.**
   - `SCHED_J2[i]` and `GAP_J2[i]` each drop by 2 at indices 101–132 (32 entries).
     The sums go 35,230 → 35,166 and 10,408 → 10,344.
   - Against `a254a8a`, before any tail narrowing, the profile is now exactly −2
     on every index 101–260.
   - Their difference is unchanged at every index, so the lowest compared bit of
     the `v < u` compare stays put. See [`2aedb45`](2aedb45.md) for why the two
     tables have to move together.
   - Every walk add, compare and cswap at those 32 divsteps runs 2 bits narrower,
     in all four walks. The note's strip-off build: peak 1151 both ways, CCX+CCZ
     1,372,333 → 1,370,237, emitted ops 9,163,279 → 9,143,127. See
     [trailmix-jump-gcd](../concepts/trailmix-jump-gcd.md) and
     [comparator-and-width-truncation](../concepts/comparator-and-width-truncation.md).
2. **Re-mined strip, `src/point_add/deep_strip_keys.rs`.**
   - With the old table, 1,936 keys were discarded by the occupancy check, and
     the rest deleted live gates (4,574 classical mismatches, 141/141 phase).
   - New census: 121,600,000 shots in 11 disjoint shards. It gives 9,678 dead
     keys (9,542 CCX + 136 CCZ) and 2,243 downgrade keys, 11,921 in all. The
     build logs "0 stale keys skipped".
   - A census this shallow over-counts dead gates (see [`2aedb45`](2aedb45.md)'s
     convergence table). The author measured the cost directly: running the
     stripped and unstripped streams on identical inputs and identical
     measurement randomness gave 19 divergences in 5,120,000 shots, so
     Δλ = +0.033 per draw. The previous head's 1e9 strip gave 2 / 5,120,000. See
     [dead-gate-strip](../concepts/dead-gate-strip.md).
3. **Tail nonce:** `SUB4_TAIL_NONCE` default 66014000021257 → 20142451900 in
   `src/point_add/mod.rs`. The caps (`TLM_TARGET_Q`, `TLM_SQUARE_PEAK_CAP`) stay
   at 1150.

## Why it is still correct, and what it risks

- **Width narrowing: probabilistic.** An input that has not shrunk enough by
  divsteps 101–132 loses a high bit when the freed wire is reset. That gives a
  classical failure, and about half the time phase garbage as well; the note
  measured a 45% overlap between the channels.
- Over 16 nonces the note measures classical 17.63 ± 0.91 and phase
  12.00 ± 0.75 batches per draw, against 13.25 / 9.42 for the base. Almost all
  of the rise is the truncation; the shallower strip adds about 0.03. The
  clean-seed density is 9.31e-9, about 4× worse than the base.
- **Strip: empirical**, and measurably not exact, as above.
- The shipped nonce `20142451900` draws a clean set: 9,024 of 9,024 shots, 0
  classical, 0 phase and 0 ancilla failures. The note reproduced the build in a
  second clone with `ops.bin` md5 `57365af103a16e09b1a95a0feac3454f`. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

The only circuit lever is a further per-divstep register and compare width
truncation. Comparator/width truncation.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 3222da6 -- src/point_add`.
   - Do not start from the git parent `f5ff95b`. That is the 1158-cap trade,
     and this commit was built on `3222da6`, as the note says.
   - Against the parent, the diff is 10,387 lines. Besides this commit's
     changes, it would move `TLM_TARGET_Q` and `TLM_SQUARE_PEAK_CAP` from 1158
     back to 1150, which looks like a cap revert this commit never made.
   - Against `3222da6`, `git diff --ignore-cr-at-eol 3222da6 60d6185 -- src/point_add`
     is 6,301 lines in 3 files, almost all of it the key table.
2. **Copy the generated table from the commit:**
   `git checkout 60d6185 -- src/point_add/deep_strip_keys.rs`.
3. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line endings.
4. **Check the tree.** `git diff --ignore-cr-at-eol 60d6185 -- src/point_add`
   should print nothing.
5. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `TLM_*` or
   `SUB4_*` overrides set. Expect:
   - 1151 qubits
   - 1,299,453 average Toffoli (1,299,452.699 before rounding)
   - score 1,495,670,403
   - 0 classical, 0 phase and 0 ancilla failures
6. **Nonce caveat.** The score only reproduces with the nonce `20142451900` and
   an identical op stream. Any other change needs a new nonce hunt and a strip
   re-mine.
