## Summary

This is the same lever as [`a8688f8`](a8688f8.md), applied to the
2002-qubit tree, which still had the old limit of 254. Each Kaliski iteration
swaps `u` and `v_w` under its branch bit at step 3 and swaps them back at
step 9. The boundary-merge fuses step 9 of iteration `k` into step 3 of
iteration `k+1`. It is limited to a prefix where `u ≠ v_w` is guaranteed.

This commit raises the prefix `KAL_CSWAP_UV_MERGE_SAFE_ITERS` from 254 to 256,
which fuses two more boundaries (253 → 254 and 254 → 255). Each fused
boundary deletes one controlled swap of about 100 bits in each of the four
Kaliski walks, for −796 average Toffoli at the same 2002 qubits. The reroll
count changes from 47 to 38. The commit also adds two notes files under
`src/point_add/memory/`, which have no effect on the circuit.

## What changed and why it saves Toffoli

- **`src/point_add/kaliski_state.rs`, `kal_cswap_uv_merge_safe_iters()`: 254 → 256.**
  - Mechanism, in short (see [`a8688f8`](a8688f8.md) and
    [`cef001a`](cef001a.md) for the full description): with the merge on,
    iteration `k` skips its step-9 swap (`uv_merge_out = iter_idx + 1 < safe_iters`),
    carries its swap bit on a `frame` qubit, and iteration `k+1` swaps under
    `a_k ⊕ a_{k+1}` at step 3 (`uv_merge_in = iter_idx < safe_iters`). Step 2's
    comparison is fixed with `l_gt ^= frame_in`, which needs `u ≠ v_w`.
  - At 256, iterations 253 and 254 skip their step-9 swaps, and iterations 254
    and 255 take the merged path.
  - The step-9 swap width is `kal_wtrunc_width(k)` = `256 − ⌊(k − 21)·2/3⌋`
    (K0 = 21 in this tree): 102 bits at `k = 253` and 101 at `k = 254`. After
    the extra step-1 CCX for each merged iteration, that is about 200 Toffoli
    per walk. Four walks (forward and backward for `pair1` and `pair2`) give
    about 800. The measured saving is 796.
- **`src/point_add/mod.rs`, `build()`: the default `KAL_REROLL` goes from 47 to 38.**
  The count of identity `X(tx[0]); X(tx[0])` pairs selects the 9,024-shot
  test draw. The author's screen of `rr = 0..63` found clean draws at 38 and
  47. 38 was chosen.
- **New files `src/point_add/memory/dialog-fold-slack-3-reroll-47.md` and
  `r-small-326-reroll-254.md`.** These are notes from the author's earlier
  experiments (dialog-fold slack 3 and `R_SMALL_THRESHOLD = 326` on an older
  2024-qubit stack). They are not compiled and do not affect the op stream.

## Why it is still correct, and what it risks

- The merge is an exact identity of controlled swaps. The `l_gt ^= frame_in`
  shortcut is wrong only if `u = v_w` at the entry of a merged iteration. With
  gcd 1 that means `(1, 1)`, one step before termination.
- The code proves that a nonzero secp256k1 input needs at least 256 steps to
  terminate. So `(1, 1)` cannot occur at iteration 254. At iteration 255 it
  would need termination in exactly 256 steps, which would require every step
  to halve `u + v` exactly. In practice this extension is exact.
- The author found no clean reroll for 257 in `rr = 0..63`. That is a lottery
  result: the stream still carries other probabilistic truncations (the
  margin-0 width envelope, the slack-0 dialog fold, the carry-tail cut), and
  any op-stream change redraws the inputs those are tested on.
- With `rr = 38`, the full benchmark gives 0 classical, 0 phase and 0 ancilla
  failures over 9,024 shots.

## Classification rationale

The saving comes from fusing two more pairs of controlled swaps across an
iteration boundary, so Fusion → boundary cswap-merge is right. The same lever
appears in [`a8688f8`](a8688f8.md), [`908521d`](908521d.md) and
[`cef001a`](cef001a.md).

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 0435f04 -- src/point_add`. The base is the git parent.
   `git diff --ignore-cr-at-eol 0435f04 cd34b79 -- src/point_add` is 77 lines
   in 4 files, 58 of them in the two new notes files.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line
   endings. It is the complete diff against the base, including the two notes
   files.
3. **Check the tree.** `git diff --ignore-cr-at-eol cd34b79 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `KAL_*`
   or `AFFINE_*` environment variables set. Expect:
   - 2002 qubits
   - 2,576,755 average Toffoli (rounded)
   - score 5,158,663,510
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with `KAL_REROLL = 38` and an identical op stream.
Any other change needs a new reroll search.
