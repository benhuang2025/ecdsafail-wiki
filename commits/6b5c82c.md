## Summary

This is a sell/buy package of two knobs.
- **Sell.** The divide traversal of the ping-pong divider loses four walk
  rounds, `rounds()` 698 → 694. That deletes four walk adds, four walk-back
  adds and four replay cells, the source of the Toffoli saving, and raises λ
  from the convergence tail.
- **Buy.** The endpoint fold window goes from 20 to 26 bits. That makes the
  eight endpoint folds longer, which costs a few dozen Toffoli but removes
  rare carry escapes. 0xrlawrence's λ table in the base's notes priced this
  window at about 34 Toffoli per unit of λ, by far the cheapest λ on the
  board.

Net: −1,396 average Toffoli at the same 1278 qubits. The multiply traversal
stays at 696 rounds.

## What changed and why it saves Toffoli

All in `src/point_add/pingpong_div.rs`.

1. **`rounds()` default: 698 → 694** (`SUB4_PP_ROUNDS`). This is the divide
   depth. `rounds_for(Multiply)` is pinned at 696 and does not move.
   - Each removed round deletes the walk add, the walk-back add and the fused
     replay cell (`replay_halving_round`) of that round.
   - The removed rounds are the last ones, where the fitted width schedule is
     at its floor, so the replay cell is most of the cost: roughly 360
     Toffoli per round.
   - The divide tape gets four wires shorter. Qubits stay at 1278 because the
     replay ladders are sized to the `SUB4_PP_PEAK` budget and the other peak
     owners are unchanged.
   - The new comment calls 694 "the public 694-round depth point" and warns
     that it needs a fresh nonce.
2. **`endpoint_fold_window()` default: 20 → 26** (`SUB4_PP_ENDPOINT_FOLD_WINDOW`).
   - The window counts carry positions above the top bit of the folded
     constant (f or f − 1) in the endpoint folds: `conditional_mod_negate`
     (twice per traversal), `mod_halve_pm` (divide rounds 0 and 1) and
     `mod_double_pm` (multiply rounds 0 and 1). See
     [modular-fold](../concepts/modular-fold.md).
   - Six more positions in each of 8 calls cost a few dozen Toffoli. The new
     doc comment says "about eight executed Toffoli". The base's own notes
     (`memory/11-lambda-walk-and-local-gpu-search.md`) measured 20 → 32 at
     +94 Toffoli for −2.8 λ, about 8 Toffoli per bit, which suggests about 47
     for these 6 bits.
   - The same table shows why the window was not widened further: at 32 the
     terminal fold chain becomes a peak owner and Q rises to 1279. 26 stays
     at 1278.
3. **Tail nonce** (`SUB4_PINGPONG_TAIL_NONCE` default in `build()`,
   `src/point_add/mod.rs`): 68367898080254 → 1400958.

## Why it is still correct, and what it risks

- **Depth is a truncation.** A divide input whose walk needs more than 694
  rounds to reach (±1, ±1) gives a wrong quotient and dirty walk registers: a
  **classical** failure, usually with phase and ancilla garbage too.
- **The wider endpoint window lowers λ.** A fold carry now has to run through
  26 window bits, not 20, to escape (about 2^−26 against 2^−20 per call).
  Escapes give wrong values, which is also the classical channel.
- The net λ is higher than the base's; the four-round cut is worth more λ
  than the window buys back. The shipped nonce `1400958` draws a clean set:
  0 classical, 0 phase and 0 ancilla failures. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

The Toffoli saving comes from removing walk iterations, which is
iteration/threshold tuning. The endpoint widening is a λ buy-back in the
opposite direction, not a saving.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 9805dee -- src/point_add`. The base is the git
   parent. `git diff --ignore-cr-at-eol 9805dee 6b5c82c -- src/point_add` is
   21 lines in 2 files.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line
   endings. It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 6b5c82c -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `SUB4_*`
   environment variables set. Expect:
   - 1278 qubits
   - 918,358 average Toffoli (rounded)
   - score 1,173,661,524
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `1400958` and an identical op
stream. Any other change needs a new nonce hunt.
