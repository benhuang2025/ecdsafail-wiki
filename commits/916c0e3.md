## Summary

[`bc2334a`](bc2334a.md) added a per-call search for the cheapest chunk layout of
two exact controlled adders. The layout had to fit in the scheduled qubit
headroom `k` minus a safety margin of one wire. This commit sets that margin to
0 for the GCD adder only, `TLM_GCD_ADAPTIVE_LAYOUT_MARGIN=0`. With one more wire
allowed, the search can move one more bit out of the chunked part, or save a
chunk, in each of the 48 GCD subtracts that use this path. The author reports 48
fewer emitted Toffoli. The executed average falls by 32. Peak qubits stay at
1166, and the tail nonce was re-hunted.

## What changed and why it saves Toffoli

- `src/point_add/mod.rs`, `build()`: new line
  `set_default_env("TLM_GCD_ADAPTIVE_LAYOUT_MARGIN", "0")`. Before this, the
  variable was unset and `searched_gcd_adaptive_layout()` in
  `trailmix_ludicrous/gidney.rs` used its default `unwrap_or(1)`.
- That search tries every chunk width `c` and every top-part length
  `plain_len`. It rejects a layout unless both:
  - `nchunks + plain_len + margin ≤ k`, so the unchunked top part and the boundary
    carries fit;
  - `nchunks + min(c, chunked_len) + margin ≤ k`, so the widest chunk fits.
  Among the layouts that pass, it keeps the one with the lowest
  `2n + chunked_len + nchunks − 1`. Each chunked bit costs one compare Toffoli in
  the boundary-carry erase, which executes on about half the shots. Each chunk
  costs one boundary-carry Toffoli. A larger usable budget therefore lowers the cost.
- **Why margin 0 is exact accounting.** Look at `emit_adaptive_layout_no_cout`.
  - While chunk `j` runs, the live scratch is `cin0`, the `j` earlier boundary carries,
    and that chunk's `c` internal carries, its own boundary carry included. At the
    last chunk that is `1 + (nchunks − 1) + c`.
  - While the top part runs, the live scratch is `cin0`, the `nchunks` boundary carries
    and `plain_len − 1` internal carries, because there is no carry-out.
  - Both peaks are exactly the left-hand sides with margin 0. So the margin-1 version
    left one wire of the scheduled headroom unused.
- Only GCD subtracts whose baked `GCD_BRANCH` entry is 2 reach this search. That
  is 48 of 1,032 calls. The apply carry-out search keeps
  `TLM_COUT_LAYOUT_MARGIN=1`.
- The default `DIALOG_TAIL_NONCE` goes from 100000004549 to 100000009632 in
  `build()`. The two copies in `configure_ecdsafail_submission_route()` also
  change, but that function is dead on the trailmix route. The comment
  above the knobs is updated to match.

## Why it is still correct, and what it risks

The adder stays exact. Only the chunk geometry changes, and every boundary
carry is still erased by a full-width gated comparison. The only risk is the
peak: `k` must really be the free headroom at each of those 48 calls. The run
measured 1166 qubits, unchanged, so the tighter layouts fit under the existing
high-water mark. The other approximations of the trailmix circuit are untouched. The op stream changed,
so the nonce was re-hunted, and `100000009632` gives 0 classical, 0 phase and 0
ancilla failures over all 9,024 shots. See
[nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

The published label is fold/carry truncation, but nothing is truncated. This is
a tighter qubit budget for an exact chunked adder's layout. That reads as
**Register and Scratch Allocation → scratch/ancilla reuse**, or as the same
windowed carry-block re-layout as its parent, `bc2334a`. The header keeps the
published label.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout bc2334a -- src/point_add`.
   The base is the git parent. `git diff --ignore-cr-at-eol bc2334a 916c0e3 -- src/point_add` is 15 changed lines in 1 file.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`. The flag lets the patch apply whether the files use LF or CRLF line endings.
3. **Check the tree.** `git diff --ignore-cr-at-eol 916c0e3 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `DIALOG_*`, `TLM_*` or `LUD_*`
   environment variables set, because they override the defaults in the source. Expect:
   - 1166 qubits
   - 1,416,071 average Toffoli (rounded; 1,416,070.722 before rounding)
   - score 1,651,138,786
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `100000009632` and an identical op
stream. Any other change needs a new nonce hunt.
