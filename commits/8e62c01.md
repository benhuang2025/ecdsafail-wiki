## Summary

Three exact or nearly exact Toffoli cuts were sitting on different branches
of the 1154-qubit trailmix circuit:

- `2dabd9d` (jackylee0424): the E209 codec change. MERGE25's op-5 product is
  kept and reused, so a 5-control Toffoli becomes 4-control. About −344 T.
- `474c29a` (this author): the apply-cswap is skipped in the last 3 GCD
  steps of both apply passes, and the post-strip fanout closure is re-added.
  About −769 T.
- `9aceb7d` (jackylee0424, the frontier): one exact affine-bridge peephole on
  top of `474c29a`. −1 T.

The frontier `9aceb7d` had the second and third but not the first. This
commit takes `2dabd9d`'s tree and applies `474c29a`'s `mod.rs` changes to
it. Against the base that adds the cswap skips and the closure (−786 T).
Against the frontier it adds E209 back (−344 T) and loses the bridge (+1 T).
Qubits stay at 1154.

## What changed and why it saves Toffoli

Every change is in `src/point_add/mod.rs`; `codec.rs` already has E209 from
the base. The edits are the same ones `474c29a` made to `892b03b`:

1. **`TLM_APPLY_FWD_CSWAP_SKIP_LAST`: "2" → "3"** (both `set_default_env`
   sites) and **`TLM_APPLY_INV_CSWAP_SKIP_LAST`: "1" → "3"**.
   - In `trailmix_ludicrous/gcd.rs`, `apply_fwd_cswap_skip(i)` and
     `apply_inv_cswap_skip(i)` are true for `i + last_n >= ITERS` (261). On
     those steps `apply_step_forward` / `apply_step_reverse` leave out the
     256-wire controlled swap of the payload registers, which costs 256
     Toffoli.
   - Forward apply now skips steps 258–260 instead of 259–260 (−256 T).
     Inverse apply skips 258–260 instead of 260 (−512 T).
   - The swap bit is almost always 0 that late, because the walk has
     converged (`v = 0`, so the subtraction bit and the swap bit are 0). See
     [`474c29a`](474c29a.md) and
     [trailmix-jump-gcd](../concepts/trailmix-jump-gcd.md).
2. **Post-strip fanout closure.** After `apply_deep_strip_identity`, a loop
   reruns `single_ccx_fanout::rewrite_first_target_fanout(ops, 96)` until no
   match is left. It merges `CCX(a,b→t); CX(t→u); CCX(a,b→t)` into
   `CX(t→u); CCX(a,b→u)`. There is no pass-count assert. See
   [dead-gate-strip](../concepts/dead-gate-strip.md).
3. **Tail nonce**: `SUB4_TAIL_NONCE` default 365918044 → 931040453370, with a
   comment recording the result (avg 1,283,787.015 × 1154) and explaining
   that the literal is a Fiat–Shamir search parameter, not a secret.

The E209 change inherited from the base works like this
(see [`2dabd9d`](2dabd9d.md)). `apply_merge25` in
`trailmix_ludicrous/codec.rs` keeps `q = w13·w14` from op 5, fixes it up with
`cx(w14 → q)` after op 17's X on `w13`, and calls
`mcx_clean_k(&[w8, w9, w10, q], w12)` with 4 controls instead of 5. That is
one Toffoli fewer per MERGE25 call. `q` is erased with `hmr` plus a
conditional CZ ([measurement-uncompute](../concepts/measurement-uncompute.md)).

## Why it is still correct, and what it risks

- **E209, the fanout closure and the affine bridge are exact.** The commit
  does not include the bridge, but that only costs its one Toffoli.
- **The cswap skip is probabilistic.** A shot fails, as a classical mismatch,
  if its walk is still running and swaps at step 258 or later, because the
  payload then misses that swap. That is a rare slow-converging input, so
  this adds a little to λ. It is the same risk `474c29a` and `9aceb7d`
  already carried.
- The shipped nonce `931040453370` draws a clean test set: 0 classical,
  0 phase and 0 ancilla failures. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

The only lever this commit adds to the frontier `9aceb7d` is E209, the reuse
of a retained AND product in a scratch ancilla, so it is filed as
scratch/ancilla reuse, like `2dabd9d`. The runner-up is iteration/threshold
tuning: against the diff base `2dabd9d` the code change is the skip-last
knobs, which carry most of the −786 T. Both levers come from earlier
submissions, so the commit is a merge.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 2dabd9d -- src/point_add`.
   - `git diff --ignore-cr-at-eol 2dabd9d 8e62c01 -- src/point_add` is 42
     changed lines in `mod.rs`.
   - Do not start from the git parent `9aceb7d`. Against it the diff is 134
     lines in 2 files: it deletes the affine-bridge splice from `mod.rs` and
     adds the 79-line E209 block to `trailmix_ludicrous/codec.rs`. That makes
     the commit look like a codec change, when the codec change is
     `2dabd9d`'s.
2. **Apply the patch below** from the repo root with
   `git apply --ignore-whitespace`. The flag lets the patch apply whether the
   files use LF or CRLF line endings. It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 8e62c01 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `SUB4_*`
   or `TLM_*` overrides set. Expect:
   - 1154 qubits
   - 1,283,787 average Toffoli (1,283,787.015 before rounding)
   - score 1,481,490,198
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `931040453370` and an identical op
stream. Any other change needs a new nonce hunt.
