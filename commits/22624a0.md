## Summary

Two branches of the 1313-qubit route had each tightened different knobs:

- `02049b8` narrowed the GCD branch comparator to 45 bits.
- `4ef0046` and `587b6d8` narrowed the doubling and fold carry windows to 21.

This commit takes `02049b8` and applies both carry-window cuts on top:
`KAL_DOUBLE_CARRY_TRUNC_W` 22 → 21 (−1,038 Toffoli, four doubling/halving
calls per apply step) and `KAL_FOLD_CARRY_TRUNC_W` 22 → 21 (−518, one fold
per apply call). That is −1,556 Toffoli against `02049b8`. Against the
then-frontier `587b6d8`, the only circuit difference is the comparator at 45
instead of 46, which is worth −876 Toffoli. One nonce was hunted for the
combined stream.

## What changed and why it saves Toffoli

All changes are in `configure_ecdsafail_submission_route()` in
`src/point_add/mod.rs`.

1. **`KAL_DOUBLE_CARRY_TRUNC_W`: 22 → 21.**
   - This is the carry window of the Solinas constant add inside
     `mod_double_inplace_fast`, `mod_halve_inplace_fast`,
     `cmod_double_inplace_lazy` and `cmod_halve_inplace_lazy`.
   - Each apply step calls two of them: double plus K2 conditional double
     going forward, conditional halve plus halve going back. That is 4 × 259 =
     1,036 calls at one Toffoli per carry position. The measured −1,038
     matches [`4ef0046`](4ef0046.md), which made the same cut.
2. **`KAL_FOLD_CARRY_TRUNC_W`: 22 → 21.** This is the carry window of the
   overflow and underflow fold, `y[..73] ± c`, after each chunked apply add or
   subtract. There are 518 calls at one Toffoli per position: −518, as in
   [`587b6d8`](587b6d8.md). See [modular-fold](../concepts/modular-fold.md).
3. **`DIALOG_TAIL_NONCE`: 5005587 → 5000102314.** This reseeds the 9,024 test
   inputs. See [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

`DIALOG_GCD_COMPARE_BITS = 45` is inherited from the base. Every other knob is
the same as in `587b6d8`.

## Why it is still correct, and what it risks

Both carry windows are probabilistic. A truncated constant add is wrong when
the carry out of bit 32 runs through more than `w` consecutive ones above it,
about 2^−22 per call at `w = 21` for random data. A wrong add gives a
classical failure, and garbage when the inverse operation does not undo it.
The 45-bit branch comparator adds its own rare mis-decisions. Stacking all
three raises λ over either parent branch. The shipped nonce 5000102314 draws a
clean set, with 0 classical, 0 phase and 0 ancilla failures over all 9,024
shots in the official run, per the commit comment.

## Classification rationale

All changes cut arithmetic to fewer bits: comparator/width truncation. The two
carry windows alone would fit fold/carry truncation. The commit is mainly a
merge of two lineages' cuts under one nonce.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 02049b8 -- src/point_add`.
   - The git parent is `587b6d8` (anshu4321), from the `4ef0046` line. It
     already has both windows at 21 but keeps `DIALOG_GCD_COMPARE_BITS=46` and
     lacks `02049b8`'s analysis additions.
   - Diffing against the parent (224 lines) shows the comparator change
     together with the whole jump-depth filter addition and two memos from
     `02049b8`, as if this commit wrote them.
   - Against `02049b8`, `git diff --ignore-cr-at-eol 02049b8 22624a0 -- src/point_add`
     is 19 lines in 1 file.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line
   endings. It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 22624a0 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no
   `DIALOG_*` or `KAL_*` environment variables set, because `set_default_env`
   keeps any value already in the environment. Expect:
   - 1313 qubits
   - 1,534,491 average Toffoli (rounded)
   - score 2,014,786,683
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with `DIALOG_TAIL_NONCE=5000102314` and an
identical op stream. Any other change needs a new nonce hunt.
