## Summary

This commit makes no optimization. It only changes the tail nonce in
`src/point_add/mod.rs` (`SUB4_TAIL_NONCE` default in `build()`) from
100388236067 to 20001378531721. The new nonce draws a different clean set of
9,024 test shots, whose average executed Toffoli is 21 lower. The diff touches
only the nonce literal, and the emitted op count is unchanged (9,061,184). For
why a nonce moves the score, see
[nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).
