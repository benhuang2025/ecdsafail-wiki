## Summary

This is the same lever as [`ec0fa98`](ec0fa98.md) and [`58ecf0a`](58ecf0a.md):
the per-step GCD width envelope now shrinks by 1.014 bits per step instead of
1.012. Over 259 steps, the summed active width drops by 72 bits and the summed
branch-comparator width by 32 bits. At about 4 Toffoli per width bit and 1 per
comparator bit, over four transcript passes, that is 4 × (4 × 72 + 32) = 1,280
average Toffoli, the measured saving. Qubits stay at 1319. The tail nonce was
re-hunted. The commit only edits the value. The comments above it still
describe the 1011 → 1012 step.

## What changed and why it saves Toffoli

Both changes are in `configure_ecdsafail_submission_route()` in
`src/point_add/mod.rs`.

1. **`DIALOG_GCD_WIDTH_SLOPE_X1000`: 1012 → 1014.**
   - `dialog_gcd_tobitvector_active_width(step)` =
     `ceil_even(256 − step × slope + 10)`, clamped to [1, 256]. The step's
     conditional swap, gated load, controlled subtract and K2 second-shift
     cascade all run on `u[..aw]` and `v[..aw]`. That is about 4 Toffoli per
     bit per pass (see [`ec0fa98`](ec0fa98.md)).
   - The branch comparator uses `min(46, aw)` bits.
   - Σ aw over 259 steps goes 35,278 → 35,206 (−72). Σ comparator width goes
     11,106 → 11,074 (−32).
   - There are 4 passes: forward and reverse, for each of the two GCD factors
     `dx` and `c = Qx − Rx`. 4 × (4 × 72 + 32) = 1,280.
   - The early steps clamp at 256, so the peak does not move.
2. **`DIALOG_TAIL_NONCE`: 620000849 → 200000008.** This reseeds the 9,024 test
   inputs. See [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Why it is still correct, and what it risks

The envelope truncation is probabilistic. An input whose GCD converges more
slowly than the tighter envelope keeps a set bit above `aw`, and the swap and
subtract ignore that bit. The transcript is then wrong, which shows as a
classical failure plus phase or ancilla garbage. Two notches at once raise λ
more than one. The shipped nonce 200000008 draws a clean set: the run validated
0 classical, 0 phase and 0 ancilla failures over all 9,024 shots.

## Classification rationale

The only circuit change narrows the per-step register widths: comparator/width
truncation.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout c69b6c1 -- src/point_add`. The base is the git parent.
   `git diff --ignore-cr-at-eol c69b6c1 5ad4427 -- src/point_add` is 4 lines in
   1 file.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line
   endings. It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 5ad4427 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no
   `DIALOG_*` or `KAL_*` environment variables set, because `set_default_env`
   keeps any value already in the environment. Expect:
   - 1319 qubits
   - 1,532,997 average Toffoli (rounded)
   - score 2,022,023,043
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with `DIALOG_TAIL_NONCE=200000008` and an identical
op stream. Any other change needs a new nonce hunt.
