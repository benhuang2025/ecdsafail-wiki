## Summary

[`4a90d04`](4a90d04.md) deletes 13,873 CCX from the finished op stream. They
are listed by position in a baked index file and were screened as never
firing. This commit replaces that list with a strict superset of 15,221
positions: all of zuiris's entries plus 1,348 new ones. The circuit and the
deletion code are unchanged. Only the list and the nonce differ.

The new gates are charged on every shot where their condition holds, but their
two controls were never both 1 across about 9.2 M random inputs. Removing them
saves 1,242 average Toffoli at the same 1159 qubits.

## What changed and why it saves Toffoli

1. **New data file `src/point_add/drop_dead_robust_15221.idx`** (generated,
   15,221 lines, one op index per line, on the post-fanout stream).
   - `comm` against `drop_dead_robust_13873.idx` shows that all 13,873 old
     indices are kept and 1,348 are added. The added indices start as early as
     op 4,759.
   - The old file stays in the tree but is no longer read.
2. **`src/point_add/mod.rs`, `build()`.**
   - The drop block's `include_str!` now points at
     `drop_dead_robust_15221.idx`, and its comment is rewritten. The filtering
     loop is unchanged.
   - `DIALOG_TAIL_NONCE` goes from 950803143946 to 1200003967933.
3. **How the 1,348 were found** (author's note).
   - A bit-sliced simulator that reproduces the trusted simulator's per-shot
     evaluation records, for every CCX, the OR over shots of "both controls
     were 1".
   - One 9,024-shot pass flags about 49 k never-fired CCX. Most of them are idle
     only by coincidence on that input set, and deleting them all breaks the
     circuit.
   - Intersecting "never fired" over 1,024 independent random input sets
     (about 9.2 M EC points) leaves a nested, stable core. The sets shrink
     monotonically: V1024 ⊆ V512 ⊆ V256 ….
   - The note gives the reason these gates are idle: "data-dependent mutual
     exclusion" of their two controls, which the static constant-propagation
     pass cannot prove. See [dead-gate-strip](../concepts/dead-gate-strip.md).

## Why it is still correct, and what it risks

- **Empirical.** No proof is given that the 1,348 gates can never fire. If one
  fires on some input, that input becomes a new hard input: a classical
  failure, or a phase failure if the gate sat in a measured-erase recompute.
- The author reports that over many random nonces the extra drops left
  ancilla at 0 and classical at the base straggler floor. So they did not
  visibly increase Lambda.
- **Positional.** The list is only valid for this exact stream. It inherits
  every upstream index from `4a90d04`.
- The shipped nonce `1200003967933` draws a clean set: 9,024 of 9,024 shots,
  with 0 classical, 0 phase and 0 ancilla failures (average 1,364,379.627). It
  was hunted on a 16-machine CPU fleet with a jump-2 GCD plus `f`-fold
  predictor. See [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

The commit only deletes more never-firing gates through the same mechanism,
so dead-gate removal is the right label. It is the empirical kind.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 4a90d04 -- src/point_add`. The base is the git parent.
   `git diff --ignore-cr-at-eol 4a90d04 20b9a1d -- src/point_add` is 15,235
   lines in 2 files. 15,221 of them are the new index file.
2. **Copy the generated index list from the commit:**
   `git checkout 20b9a1d -- src/point_add/drop_dead_robust_15221.idx`.
3. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`. The flag lets the patch apply whether the files use LF or CRLF line endings. It covers
   `mod.rs`.
4. **Check the tree.** `git diff --ignore-cr-at-eol 20b9a1d -- src/point_add`
   should print nothing.
5. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no
   `DIALOG_*`, `TLM_*`, `LUD_*`, `CONSTPROP_*` or `SINGLE_CCX_FANOUT_*`
   environment variables set. Expect:
   - 1159 qubits
   - 1,364,380 average Toffoli (1,364,379.627 before rounding)
   - score 1,581,316,420
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `1200003967933` and an identical op
stream. Any other change needs a new nonce hunt and a regenerated list.
