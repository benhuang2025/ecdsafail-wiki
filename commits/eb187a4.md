## Summary

Two contestants had cut different windows of the same tree `6ee4d14` in
parallel:
- odinfree's [`e5c53dc`](e5c53dc.md) narrowed the replay flag compare from
  25 to 24 bits (−698 Toffoli);
- RealAdii's `37b0c9f` and [`8e8f047`](8e8f047.md) narrowed the replay fold
  window from 56 to 54 bits (−2,810 Toffoli).

This commit has both. Seen from the author's own `e5c53dc`, it adds the
fold-window cut, which saves 2,817 Toffoli. Seen from the frontier `8e8f047`,
it adds the flag-compare cut, which saves 705 Toffoli. Qubits stay at 1320.
The two levers touch different parts of the replay cell and stack almost
exactly. A new tail nonce was hunted for the combined stream.

## What changed and why it saves Toffoli

Both knobs are in `src/point_add/pingpong_div.rs`, and both act on every
fused replay cell (`signed_mod_add_pm_halve_fused` for Divide,
`signed_mod_double_add_pm_fused` for Multiply), about 1,400 cells per shot.

1. **`replay_fold_window()` default: 56 → 54** (`SUB4_PP_REPLAY_FOLD_WINDOW`).
   This is the change in the patch against the base.
   - Each cell adds one of {−f, 0, +f, +2f} into `target[..54]` with
     `fused_fold_maskfree`. It ripples `width − 2` carries, each one
     Toffoli built and measured away, and drops the carry out of the top.
   - Two fewer positions save about 2 Toffoli per cell. See
     [8e8f047](8e8f047.md) for the mechanism and
     [modular-fold](../concepts/modular-fold.md).
2. **`replay_flag_compare()` = 24.** The base already has this value. It
   differs from the git parent, which had 25.
   - The cell's overflow flag is measured out with `hmr(overflow, phase)`.
     Its phase is then repaired by
     `cmp_lt_phase_conditioned(&target[N−24..], &source[N−24..], phase)`,
     which runs only when `phase` = 1.
   - So one bit less is about 0.5 executed Toffoli per cell. See
     [e5c53dc](e5c53dc.md),
     [comparator-and-width-truncation](../concepts/comparator-and-width-truncation.md)
     and [measurement-uncompute](../concepts/measurement-uncompute.md).
3. **Tail nonce** (`SUB4_PINGPONG_TAIL_NONCE` default in `build()`,
   `src/point_add/mod.rs`): 52007 (base) → 60171. The parent had 30008.

## Why it is still correct, and what it risks

Both windows are probabilistic, and they fail on different channels:
- A fold carry escaping the 54-bit window gives a wrong value: a
  **classical** failure, about 2^−21 per cell.
- A tie in the top 24 bits of the flag compare gives a wrong phase repair: a
  **phase** failure, about 2^−24 per cell.

The combined circuit has the λ of both cuts, which is more than either parent
had. The shipped nonce `60171` draws a clean set: 0 classical, 0 phase and
0 ancilla failures. See
[nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

The leaderboard credits this commit for the step from the frontier `8e8f047`,
and that step is a one-bit narrower comparator. So it stays under
comparator/width truncation. Against the base, the visible change is the fold
window (fold/carry truncation), but that lever was RealAdii's, already
credited to `37b0c9f` and `8e8f047`.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout e5c53dc -- src/point_add`.
   - `git diff --ignore-cr-at-eol e5c53dc eb187a4 -- src/point_add` is
     4 lines in 2 files: fold window 56 → 54 and the nonce.
   - The git parent `8e8f047` is equally close (4 lines): there the diff
     shows the flag compare 25 → 24 and the nonce 30008 → 60171 instead.
     Either start reproduces the commit; this note uses `e5c53dc`.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line
   endings. It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol eb187a4 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `SUB4_*`
   environment variables set. Expect:
   - 1320 qubits
   - 942,872 average Toffoli (rounded)
   - score 1,244,591,040
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `60171` and an identical op stream.
Any other change needs a new nonce hunt.
