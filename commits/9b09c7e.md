## Summary

This commit makes no optimization. It only changes the tail nonce in
`src/point_add/mod.rs` (`Q1153_SECOND512_SUBMISSION_NONCE`, which sets
`DIALOG_TAIL_NONCE`) from 840182476601 to 810197699946. The new nonce draws a
different clean set of 9,024 test shots, whose average executed Toffoli is 3
lower. The diff touches only the nonce literal, and the emitted op count is
unchanged (10,203,570). It is the second of three back-to-back rerolls of this
circuit, between [`d17af14`](d17af14.md) and [`4cd1b2f`](4cd1b2f.md). For why
a nonce moves the score, see
[nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).
