## Summary

The author stacks seven gate cuts that are meant to be exact on every input
(the submission note calls them "epsilon = 0"). The largest one is in the
squarer's correction adders. Half of the operand bits of those Cuccaro adders
are known to be |0⟩. For such a bit, the adder's uncompute Toffoli only clears
an AND of two live wires, so it can be replaced by an X-basis measurement plus
a conditional CZ, which costs no Toffoli. The note measures −1,522 for this.
The same trick is applied to the Khattar–Gidney increment (−198). The other
five items skip gates that never fire, or resynthesize one codec gate.

Together these cut about 2,783 emitted Toffoli. They also shift every op index,
so the positional `D2_DEEP_STRIP` from 3f8ce09 no longer lines up, and the
commit turns it off. That strip had removed about 1,855 executed Toffoli, so
the net gain is only −938, at the same 1152 qubits.

## What changed and why it saves Toffoli

The items are listed with the note's own emitted-CCX deltas. All flags are
forced in `build()` (`src/point_add/mod.rs`).

1. **From-zero square-correction adders (`TLM_SQUARE_FROM_ZERO=1`, −1,522).**
   - New in `src/point_add/arith/adder.rs`: `uma_from_zero`, `inv_maj_from_zero`,
     `cuccaro_add_from_zero` and `cuccaro_sub_from_zero`. The adder variants take
     a mask `zero[i]` of operand bits known to be |0⟩ on entry. With an all-false
     mask they emit the same gates as `cuccaro_add` / `cuccaro_sub`.
   - Why it works: in a Cuccaro adder, `maj(x, y, w)` writes the carry into the
     operand bit `w`. If `w` was |0⟩, it then holds exactly `AND(x, y)`. When the
     ripple comes back down, `x` and `y` are restored to the same values, and the
     UMA's first gate `ccx(x, y, w)` only clears that AND. The variant replaces it
     with `hmr(w, m); cz_if(x, y, m)`. The UMA's `cx(w, x)` is then a no-op, so
     only `cx(x, y)` stays. For subtraction, `inv_maj_from_zero` drops both
     trailing CX for the same reason. Each zero bit saves one CCX. See
     [measurement-uncompute](../concepts/measurement-uncompute.md) and
     [adders-and-carries](../concepts/adders-and-carries.md).
   - Where, in `src/point_add/arith/multiply.rs`, `square_corr_forward` and
     `square_corr_inverse`:
     - the add of `a2d = [0, x0, 0, x1, …]` into `prod` uses the mask "even
       index", so n of its 2n operand bits are zero;
     - the subtract of `xext = x ‖ pad` uses the mask "index ≥ n", the zero pad;
     - the add of `a = x[0..n-1] ‖ p1` into the high half masks only the top
       bit, which has no UMA, so it saves nothing (the comment says so).
2. **Forward cswap dead predicate = reverse predicate (`W1155_FWD_EQ_REV=1`, −504).**
   In `trailmix_ludicrous/gcd.rs`, `gcd_forward_cswap_has_structurally_dead_gate`
   now returns `gcd_reverse_cswap_has_structurally_dead_gate(step, bit)`. Before,
   the forward walk skipped only the cswaps in `GCD_FORWARD_CSWAP_REMAINDER_KEYS`.
   The reverse predicate has more: the diagonal rule `step + bit ≥ 265`, its own
   key list and `GCD_REVERSE_CSWAP_DEAD_RANGES`. The author's argument is that
   the reverse walk runs through the same (u, v) states as the forward walk, so a
   u/v cswap gate that is dead in one is dead in the other. Each skipped cswap is
   one Toffoli.
3. **376 more dead shift-ladder gates (E251, −373).** `GCD_SHIFT_DEAD_RANGES`
   in `gcd.rs` gains 376 rows `(12, call, lo, hi)`. Tag 12 is
   `controlled_left_shift`, the controlled one-bit shift ladder of `u`/`v`. A
   row tells it to skip the cswap at bit positions `lo..=hi` of left-shift call
   number `call`. All 376 new rows cover one bit (`lo = hi`). The note calls them
   "audit-recovered", dead for every valid input.
4. **Vented Khattar–Gidney increment (`TLM_KG_INC_VENT=1`, −198).**
   In `trailmix_ludicrous/mcx.rs`, the reverse pass of
   `inc_khattar_gidney_refs_inner` is first planned as a list of steps. Each
   uncompute `ccx(x, y, t)` of an AND-prefix ancilla `t` is checked:
   - if `t` is not touched again, it becomes `mbu_clear_and` (hmr plus a
     conditional CZ, no Toffoli);
   - if the only later use is an `X(t)`, that X is moved in front and the clear is
     measured the same way;
   - otherwise it stays a CCX.
   Vented ancillas are not reset again at the end.
5. **Codec merge resynthesis (E208, −170).** In `trailmix_ludicrous/codec.rs`,
   `apply_merge25` replaces `MERGE25_OPS[18..=26]` with one call to
   `mcx::mcx_clean_k`. Those 9 ops form one 5-control Toffoli,
   `w12 ^= AND(w8, w9, w10, w13, w14)`; the new form uses 7 Toffoli-class gates.
   A multi-controlled X is its own inverse, so the forward and reverse codec use
   the same call. See [trailmix-jump-gcd](../concepts/trailmix-jump-gcd.md) for
   the Triple codec.
6. **Second fanout pass (E275, −13).** After `ccx_final_cancel`, `build()` re-runs
   `single_ccx_fanout::rewrite_first_target_fanout` until it finds no match
   (`SINGLE_CCX_FANOUT_SECOND_PASS=0` turns it off). See
   [dead-gate-strip](../concepts/dead-gate-strip.md) for the identity it uses.
7. **Wider dead-carry band (W1077, −3).** In `trailmix_ludicrous/arith.rs`,
   `cuccaro_call_has_structurally_dead_carry` for calls 12, 25 and 19 goes from
   bits `1..=127` to `0..=127`.

Other edits in `mod.rs`:
- `apply_d2_deep_strip` now runs only if `SUB4_APPLY_D2_STRIP=1`, so it is off.
- The GAP_J2 narrowing of 3f8ce09 is kept, but `SUB4_NO_GAP=1` can turn it off
  (a test switch).
- The tail nonce is `SUB4_TAIL_NONCE`, default 2001891927370 (was 706362233434).

## Why it is still correct, and what it risks

- **Items 1 and 4 are exact.** The measured wire holds exactly the AND that the
  `cz_if` assumes, so the phase cancels on every input. A wrong mask would leave
  a phase error on many shots, and the phase channel would catch it at once.
- **Items 5 and 6 are exact identities** (a resynthesized gate and a proven
  rewrite).
- **Items 2, 3 and 7 are claimed structural facts**, that is, gates dead on
  every input. The note checked them empirically: each item, and the stack,
  gave the same 252 classical mismatches as a control build at a fixed seed, 0
  ancilla garbage, and a clean-batch rate no worse. That is evidence, not a
  proof. A gate that does fire on some input would show up as a classical or
  phase failure on that input.
- Dropping the D2 strip removes an empirical lever, so λ, the expected number
  of failing shots, does not rise.
- The shipped nonce `2001891927370` draws a clean test set: 9,024 of 9,024
  shots, 0 classical, 0 phase and 0 ancilla failures. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

Items 1 and 4, about −1,720 of the roughly −2,783 gross, turn Toffoli
uncomputes into `hmr` plus Clifford repairs. That is measurement uncompute. The
dead-gate skips (items 2, 3 and 7, about −880) are the runner-up,
dead-gate/self-inverse removal.

   `git checkout 5b834ba -- src/point_add/trailmix_ludicrous/gcd.rs`. Its diff is
   382 lines: the 376 new `GCD_SHIFT_DEAD_RANGES` rows (item 3) and the 5-line
   `W1155_FWD_EQ_REV` branch (item 2).

   The flag lets the patch apply whether the files use LF or CRLF line endings.
   It covers the other six files.
4. **Check the tree.** `git diff --ignore-cr-at-eol 5b834ba -- src/point_add`
   should print nothing.
5. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `TLM_*`,
   `SUB4_*` or `W1155_*` overrides set. Expect:
   - 1152 qubits
   - 1,317,390 average Toffoli (1,317,390.325 before rounding)
   - score 1,517,633,280
   - 0 classical, 0 phase and 0 ancilla failures
6. **Nonce caveat.** The score only reproduces with the nonce `2001891927370`
   and an identical op stream. Any other change needs a new nonce hunt.
