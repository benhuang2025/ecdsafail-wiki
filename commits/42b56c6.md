## Summary

This commit makes no optimization. It only changes the tail nonce in
`src/point_add/mod.rs` (`DIALOG_TAIL_NONCE` default in `build()`) from
40000000623 to 3205507. The new nonce draws a different clean set of 9,024
test shots, whose average executed Toffoli is 18 lower. The diff touches only
nonce literals: the three copies in `configure_ecdsafail_submission_route()`,
which only the old dialog route uses, also go from 40000000623 to 3205507. For
why a nonce moves the score, see
[nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Reproduce

From `git checkout 3df690f -- src/point_add`, apply the patch below with
`git apply --ignore-whitespace`. `./benchmark.sh` should give 1164 qubits,
1,380,592 average Toffoli and 0 / 0 / 0 failures.
