## Summary

One constant changes. [`3f534f2`](3f534f2.md) stopped the carry chains of the
five spill-fold Cuccaro adds inside the shift22 helper at `22 + W` bits, with
`W = 41`. This commit sets `W = 33`, so the cut moves from 63 to 55. Each
truncated Cuccaro op costs two Toffoli per carry position, so it saves 16
Toffoli per op. There are 10 ops per shift22 forward/inverse pair and three
pairs, which gives exactly the observed −480. Qubits are unchanged.

## What changed and why it saves Toffoli

- `src/point_add/solinas.rs`, `shift22_spill_carrytail_cut()`: the default of
  `SHIFT22_SPILL_W` goes from 41 to 33, so the cut is `22 + 33 = 55`.
- The cut is used by `cuccaro_add_cut`/`cuccaro_sub_cut` in the `cuccaro_op`
  closure of `mod_shift_left_by_k` and `mod_shift_right_by_k`. Those ops add
  the 22-bit spill into `v_ext[pos..257]` at offsets 0, 4, 6, 10 and 32. They
  compute a full MAJ/UMA ripple for positions `0..=cut` and only XOR the
  addend above.
- An op now costs `2 × 55 = 110` Toffoli instead of 126. That is
  16 × 5 ops × 2 directions × 3 executed pairs = 480. See
  [modular-fold](../concepts/modular-fold.md) and
  [adders-and-carries](../concepts/adders-and-carries.md).
- The comment is updated to record the sweep.

## Why it is still correct, and what it risks

- **Still exact in practice.** Above bit 21 the addend is zero, so a carry is
  dropped only if bits 22…55 of the slice are all ones (or all zeros for the
  subtract op), about 2^-34 per op. A dropped carry gives a wrong product and
  shows up as a classical mismatch.
- **Forward and reverse stay exact inverses**, because both use the same cut.
- **Island.** There is no re-roll knob in this tree, so the test set is a hash
  of the op stream and `W` doubles as the re-roll. The comment says 33 is the
  deepest clean value and 30, 31, 32 and 34 fail. The shipped stream is clean:
  0 classical, 0 phase and 0 ancilla failures. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

A carry chain inside the modular fold is cut shorter, which is fold/carry
truncation. Nothing else changes.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 3f534f2 -- src/point_add`. The base is the git
   parent. `git diff --ignore-cr-at-eol 3f534f2 3ab1c72 -- src/point_add` is
   8 lines in 1 file.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`. The flag lets the patch apply whether the files use LF or CRLF line endings. It is the
   complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 3ab1c72 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `KAL_*`,
   `SHIFT22_*` or `LOWQ_*` environment variables set. Expect:
   - 2309 qubits
   - 2,402,954 average Toffoli (rounded)
   - score 5,548,420,786
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with an identical op stream. There is no re-roll
knob in this tree, so any other change draws a different test set.
