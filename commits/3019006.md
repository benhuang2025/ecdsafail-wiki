## Summary

This commit makes no optimization. It only changes the tail nonce in
`src/point_add/mod.rs` (`TAIL_NONCE` entry of `env_raw()`) from 16778008906 to
17706034936. The new nonce draws a different clean set of 9,024 test shots,
whose average executed Toffoli is 18 lower. The diff touches only the nonce
literal, and the op count is unchanged because the tail is always 96 ops. For
why a nonce moves the score, see
[nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Reproduce

`git apply --ignore-whitespace`. `./benchmark.sh` should give 1251 qubits,
893,473 average Toffoli and 0 / 0 / 0 failures.
