## Summary

One call changes. `mod_add_solinas_ext_product` reduces the 512-bit square
`λ²` into the scratch register `breg`. The last of its six terms, `hi·2^32`,
was added with the slow modular add `mod_add_qq`, whose adders undo their
carries gate by gate (about two Toffoli per bit). This commit uses
`mod_add_qq_fast` instead. Its adders erase their carries by measurement
(about one Toffoli per bit). The four adders in one modular add save 1,024
Toffoli together. The fast adder's extra carry wires stay under the 2708
peak, so qubits are unchanged.

[`b827c9e`](b827c9e.md), by Gajesh2007, made the same edit on a sibling
branch, with the low-scratch variant of the fast add (−1,000). This commit is on
the 666b591 line, which did not have b827c9e.

## What changed and why it saves Toffoli

- `src/point_add/mod.rs`, `mod_add_solinas_ext_product(acc, tmp_ext)`: between
  `mod_shift_left_by_k(hi, 22)` and `mod_shift_right_by_k(hi, 22)`, the call
  `mod_add_qq(b, acc, &hi, p)` becomes `mod_add_qq_fast(b, acc, &hi, p)`.
- In the default circuit this routine runs once per point addition, in
  `square_tx_and_combined_ty_l2minus3qx` (phase `affine_combined_breg_red`).
  It builds `breg = λ² mod p` from the product register `tmp_ext = lo + 2^256·hi`
  by adding `hi·(1 + 2^4 − 2^6 + 2^10 + 2^32)`.
- Both modular adds do the same four steps on 257-bit registers: the operand
  add, `+c` with `c = 2^32 + 977`, `−c` under the no-overflow flag, and a
  comparison that clears the flag.
  - `mod_add_qq` runs each step with the plain Cuccaro adder (`add_nbit_qq`,
    `add_nbit_const`, `csub_nbit_const`) and `cmp_lt_into`. Those undo their
    carry chain with a second Toffoli sweep, about 2 Toffoli per bit.
  - `mod_add_qq_fast` uses `add_nbit_qq_fast`, the loaded-constant fast add,
    and `cmp_lt_into_fast`. Their carries are erased by `hmr` and a Clifford
    `cz_if` fix, about 1 Toffoli per bit. See
    [measurement-uncompute](../concepts/measurement-uncompute.md) and
    [adders-and-carries](../concepts/adders-and-carries.md).
- The −1,024 is 24 more than [`b827c9e`](b827c9e.md)'s −1,000 at the same
  site. That matches the 24-Toffoli premium of the register-free constant
  adders b827c9e used (see [`bc9728a`](bc9728a.md)). Here the constant is
  loaded into a 257-qubit register instead.

**Qubits.** The fast add holds a carry bank of about 256 wires and a loaded
constant register. The slow add held neither. Both fit under the 2708 peak,
which is set in another phase, so the peak is unchanged. See
[peak-qubits-and-budgets](../concepts/peak-qubits-and-budgets.md).

## Why it is still correct, and what it risks

The change is exact on every input. Both functions compute `acc + hi mod p`
with the same steps, and only how the adders clean their carries differs. A
wrong `cz_if` fix in the measured erase would show up as a phase failure.

There is no tail nonce in this era. The 9,024 test inputs are a SHAKE256 hash
of the op stream, so the draw changed. The base's probabilistic Kaliski
settings passed on the new draw with 0 classical, 0 phase and 0 ancilla
failures.

## Classification rationale

The saving comes from erasing carries by measurement instead of a reverse
Toffoli sweep, which is measurement uncompute. Fast-adder reroute was the
runner-up. The census filed b827c9e's near-identical edit as Register and
Scratch Allocation, which fits less well than either.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 666b591 -- src/point_add`. The base is the git
   parent. `git diff --ignore-cr-at-eol 666b591 e33b400 -- src/point_add` is
   2 lines in 1 file.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line endings.
   It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol e33b400 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `KAL_*`,
   `AFFINE_*`, `DUMMY_TOFFOLIS` or other environment overrides set. Expect:
   - 2708 qubits
   - 3,819,957 average Toffoli (rounded)
   - score 10,344,443,556
   - 0 classical, 0 phase and 0 ancilla failures

There is no tail nonce in this era. The 9,024 test inputs are a hash of the
op stream, so the score only reproduces with an identical op stream.
