## Summary

The circuit is 6e9f0af's, with the same risk-ranked strip method. The strip is
re-emitted at a slightly larger risk budget, so the next 96 candidates by risk
are admitted: 59 more deletions and 37 more CX/CZ downgrades. That saves about
78 average Toffoli. The emitted op count drops by the 59 deletions
(9,062,479 → 9,062,420).

The commit is built on 6e9f0af, not on the then-frontier 266b783. So it does
not have jackylee0424's 9-pass post-strip fanout loop, and its gain over the
frontier is only −70 Toffoli (−80,780 score). Most of the author's note is
about measurement: the average executed Toffoli varies with the nonce by
sd ≈ 9.4, so gains of a few Toffoli are nonce luck. And Δλ predictions did not
match the measured clean-seed density.

## What changed and why it saves Toffoli

- **`src/point_add/deep_strip_keys.rs`:** the same 320M-input census header as
  6e9f0af, with 96 key lines added: `DEAD_KEYS` 10,684 → 10,743 and
  `DOWNGRADE_KEYS` 3,051 → 3,088, 13,831 in all. All added keys are CCX
  (kind 13).
  - They come from the same risk ranking ([`6e9f0af`](6e9f0af.md)): each gate is
    priced on an independent oracle census, and gates are admitted in ascending
    risk until a budget is spent. The budget is a little higher here. The note
    does not give the number.
  - The build logs "removed 10743 / 10743 dead; downgraded 3088 / 3088 to CX/CZ;
    0 stale keys skipped".
- **Why it saves Toffoli.** Each deleted gate, and each CCX turned into a CX,
  stops being charged on every shot whose condition holds. See
  [dead-gate-strip](../concepts/dead-gate-strip.md).
- **Tail nonce:** `SUB4_TAIL_NONCE` default 990018471007 → 500008234796 in
  `src/point_add/mod.rs`.

## Why it is still correct, and what it risks

- **Empirical.** Each extra key is a gate that misbehaved rarely, but not
  never, on the oracle census. It adds a little λ, the expected number of
  failing shots per draw. A wrong key shows up as a classical or phase failure
  on the inputs where that gate matters.
- **The note's measurements:**
  - Holding the circuit fixed and varying only the nonce, over 16 draws: mean
    1,292,289.8, sd 9.4, spread 28.9. Both the previous head (1,292,278) and the
    one before it (1,292,286) sit inside that cloud. See
    [scoring-and-validation](../concepts/scoring-and-validation.md).
  - In three cases, Δλ and differential estimates overstated clean-seed density
    by 4–23×. The screen survivor fraction stayed accurate, but P(clean |
    survivor) collapsed through the phase channel. The rule it draws: measure
    clean density on the exact stream before sizing a hunt. For this stream it
    was 1.453e-8, and the winner came after about 70M nonces on 5 GPUs.
  - An abstract interpreter over the final stream found 0 further provably dead
    Toffoli, 0 constant or equal controls, and 0 remaining self-inverse pairs.
- The shipped nonce `500008234796` draws a clean set: 9,024 of 9,024 shots, 0
  classical, 0 phase and 0 ancilla failures. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

A larger empirical dead-gate strip and nothing else: dead-gate/self-inverse
removal.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 6e9f0af -- src/point_add`.
   - Do not start from the git parent `266b783`. Against it, the diff (141 lines)
     would delete that commit's post-strip fanout loop, which this commit never
     had.
   - Against `6e9f0af`, `git diff --ignore-cr-at-eol 6e9f0af ea785b7 -- src/point_add`
     is 98 lines in 2 files: 96 added key lines and the nonce.
2. **Copy the generated table from the commit:**
   `git checkout ea785b7 -- src/point_add/deep_strip_keys.rs`.
3. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line endings.
4. **Check the tree.** `git diff --ignore-cr-at-eol ea785b7 -- src/point_add`
   should print nothing.
5. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `TLM_*` or
   `SUB4_*` overrides set. Expect:
   - 1154 qubits
   - 1,292,208 average Toffoli (1,292,208.289 before rounding)
   - score 1,491,208,032
   - 0 classical, 0 phase and 0 ancilla failures
6. **Nonce caveat.** The score only reproduces with the nonce `500008234796` and an
   identical op stream. Any other change needs a new nonce hunt.
