## Summary

This commit makes no optimization. It only changes the tail nonce in
`src/point_add/mod.rs` (`"TAIL_NONCE"` in `env_raw()`) from 29700148580003 to
29000769323351. The new nonce draws a different clean set of 9,024 test shots,
whose average executed Toffoli is 10 lower (945,942.941 by the submission
note). The diff touches only the nonce literal. `apply_tail_nonce()` writes
the nonce into the `q_target` of the 96 trailing X ops, so the op count is
unchanged by construction, and the q71b recipe and its 450 rewrite rows
(`q71b_rewrite.txt`) are untouched. For why a nonce moves the score, see
[nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

945,943 average Toffoli and 0 / 0 / 0 failures.
