## Summary

The ping-pong divider runs its walk for a fixed number of rounds in each of
its two traversals. The multiply traversal can be a little shorter than the
divide traversal. On this tree it ran `rounds() − 2` = 698 rounds; this
commit takes it to `rounds() − 4` = 696. Two rounds' walk adds, walk-back adds
and replay cells disappear, which saves 736 average Toffoli at the same 1278
qubits. The cost is a slightly higher chance that a multiply walk has not
converged by its last round. [`8d7051b`](8d7051b.md) had moved this knob the
other way (−6 → −2) to buy λ; this commit sells part of that back.

## What changed and why it saves Toffoli

1. **`rounds_for(Multiply)` default: `rounds() − 2` → `rounds() − 4`** in
   `src/point_add/pingpong_div.rs` (`SUB4_PP_ROUNDS_MUL`; `rounds()` = 700).
   - The multiply traversal's walk, replay (`replay_doubling_round`) and
     walk-back each run one step per round, so two fewer rounds delete two
     walk adds, two walk-back adds and two fused replay cells.
   - The removed rounds are the last ones, at the narrow terminal width, so
     the walk adds are cheap. Most of the 736 Toffoli is the two replay cells
     (a 256-bit chunked add, the fold, and their measured-erase repairs),
     about 368 per round.
   - The tape is two wires shorter. Qubits do not drop, because the replay's
     ladders are sized to `SUB4_PP_PEAK` = 1278, and the square ladder is
     unchanged; the wires go to the ladder budget instead. See
     [peak-qubits-and-budgets](../concepts/peak-qubits-and-budgets.md).
2. **Tail nonce** (`SUB4_PINGPONG_TAIL_NONCE` default in `build()`,
   `src/point_add/mod.rs`): 43171001 → 5101174221.

## Why it is still correct, and what it risks

Depth is a truncation. A multiply input whose walk needs its 697th or 698th
round to reach (±1, ±1) now ends with a wrong product and dirty walk
registers, a **classical** failure. The code comment next to the knob prices
one round on one traversal at about +0.05 λ. The 8d7051b note measured a
larger effect for four rounds on its tree (λ 8.94 at −2 against 11.30 at −6).
The shipped nonce `5101174221` draws a clean set: 0 classical, 0 phase and
0 ancilla failures. See [pingpong-division](../concepts/pingpong-division.md)
and [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

The only change is the iteration count of the multiply walk, which is
iteration/threshold tuning.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 787eaa8 -- src/point_add`. The base is the git
   parent. `git diff --ignore-cr-at-eol 787eaa8 70d64f5 -- src/point_add` is
   4 lines in 2 files.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line
   endings. It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 70d64f5 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `SUB4_*`
   environment variables set. Expect:
   - 1278 qubits
   - 924,651 average Toffoli (rounded)
   - score 1,181,703,978
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `5101174221` and an identical op
stream. Any other change needs a new nonce hunt.
