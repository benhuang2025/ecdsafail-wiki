## Summary

This commit takes the dialog-GCD branch comparator one more bit down, from 49
to 48 bits, and re-hunts the tail nonce. One comparator bit is one Toffoli per
call, and there are about 860 calls per shot. The saving is 864 average
Toffoli at the same 1320 qubits.

This is the first of three one-bit steps in a row on this comparator (49 → 48
here, then 48 → 47 in [`6abbe60`](6abbe60.md), and 47 → 46 in
[`2f24e2f`](2f24e2f.md)).

## What changed and why it saves Toffoli

Both changes are default pins in `configure_ecdsafail_submission_route()`,
`src/point_add/mod.rs`.

1. **`DIALOG_GCD_COMPARE_BITS`: 49 → 48.**
   - At each forward GCD step the branch bit `b0_and_b1 = b0 ∧ (u > v)` comes
     from `dialog_gcd_ccx_cmp_gt_truncated_into_width(_hosted)`. That
     comparator only looks at the top `min(COMPARE_BITS, active_width)` bits of
     the step's window.
   - It makes one carry CCX per compared bit. The carries are erased by `hmr`
     plus `cz_if`, which costs no Toffoli.
   - The calls are the forward and reverse transcript passes of both GCD uses,
     on every step whose window is still at least 49 bits wide. That is about
     860 calls, which matches the measured −864.
2. **`DIALOG_TAIL_NONCE`: 675 → 145815044552559.** The 48 `X;X` identity
   pairs at the end of `build_builder()` only reseed the 9,024 test inputs.
   `DIALOG_REROLL` stays at 506906.

## Why it is still correct, and what it risks

- The comparator is wrong when `u` and `v` agree on the top 48 bits of the
  window but differ below. The step then takes the wrong branch, and the
  GCD can fail to converge within 259 steps. That gives a classical failure,
  or phase garbage when the transcript is uncomputed. One bit fewer roughly
  doubles the per-call mis-decision rate.
- The author used a classical GCD pre-filter plus full simulation to find the
  nonce. Nonce 145815044552559 draws a clean set: 9,024 of 9,024 shots, with
  0 classical, 0 phase and 0 ancilla failures. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

A narrower comparator is comparator/width truncation. No runner-up fits.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout c3cbcce -- src/point_add`. The base is the git parent.
   `git diff --ignore-cr-at-eol c3cbcce cf5e390 -- src/point_add` is 4 lines
   in 1 file.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line endings.
   It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol cf5e390 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no
   `KAL_*`, `DIALOG_*` or `SUB4_*` environment variables set, because they
   override the defaults. Expect:
   - 1320 qubits
   - 1,553,603 average Toffoli (rounded)
   - score 2,050,755,960
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `145815044552559` and an identical
op stream. Any other change needs a new nonce hunt.
