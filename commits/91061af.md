## Summary

Two comparators each lose one bit:

- **The GCD branch comparator**, which decides `u > v` in every step, drops from
  46 to 45 bits. It binds on 219 steps in four transcript passes:
  4 × 219 = 876 Toffoli.
- **The apply's overflow-clean comparator**, which erases the overflow flag
  after each modular add or subtract of `x` into `y`, drops from 19 to 18 bits.
  It runs 518 times: 518 Toffoli.

Together they save 1,394 average Toffoli at 1319 qubits. Both are probabilistic
truncations. The tail nonce was re-hunted. The commit only edits the values;
the comments above them are stale.

## What changed and why it saves Toffoli

All changes are in `configure_ecdsafail_submission_route()` in
`src/point_add/mod.rs`.

1. **`DIALOG_GCD_COMPARE_BITS`: 46 → 45.**
   - `b0_and_b1 = v[0] AND (u > v)` is computed by
     `dialog_gcd_ccx_cmp_gt_truncated_into_width_hosted` on the top
     `min(COMPARE_BITS, aw)` bits of the active window (see
     [`e4497a6`](e4497a6.md)).
   - It costs one Toffoli per bit, with its carries cleared by measurement.
   - At slope 1.014 and margin 10, `aw ≥ 46` on 219 of the 259 steps. Forward
     and reverse, for both GCD factors, that is 4 × 219 = 876.
2. **`DIALOG_GCD_APPLY_CLEAN_COMPARE_BITS`: 19 → 18.**
   - After each chunked apply add `y += b0·x`, the overflow bit `acc_ovf` is
     erased by `ccx_cmp_lt_into_fast` on the top 18 bits of the new `y` and
     `x`. After each subtract, `dialog_gcd_clean_truncated_underflow` does the
     same.
   - There is one Toffoli per bit, and there are 259 adds plus 259 subtracts:
     −518. See [`83da96f`](83da96f.md), which made the previous 20 → 19 step,
     and [modular-fold](../concepts/modular-fold.md) for the fold that comes
     just before.
3. **`DIALOG_TAIL_NONCE`: 200000008 → 120002648.** This reseeds the 9,024 test
   inputs. See [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Why it is still correct, and what it risks

Both cuts are probabilistic:

- **Branch comparator.** If `u` and `v` agree on the top 45 bits of the window,
  the step can skip a needed swap, and the subtract then underflows. This gives
  a classical failure, plus phase or ancilla garbage when the reverse pass does
  not mirror the forward one.
- **Overflow-clean comparator.** If the new `y` and `x` agree on the top 18
  bits, the overflow flag is not cleared. This gives ancilla garbage, and phase
  errors downstream.

Each bit removed roughly doubles that comparator's error rate, so λ rises. The
shipped nonce 120002648 draws a clean set: the run validated 0 classical,
0 phase and 0 ancilla failures over all 9,024 shots.

## Classification rationale

Both changes narrow comparators: comparator/width truncation.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 5ad4427 -- src/point_add`. The base is the git parent.
   `git diff --ignore-cr-at-eol 5ad4427 91061af -- src/point_add` is 6 lines in
   1 file.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line
   endings. It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 91061af -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no
   `DIALOG_*` or `KAL_*` environment variables set, because `set_default_env`
   keeps any value already in the environment. Expect:
   - 1319 qubits
   - 1,531,603 average Toffoli (rounded)
   - score 2,020,184,357
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with `DIALOG_TAIL_NONCE=120002648` and an identical
op stream. Any other change needs a new nonce hunt.
