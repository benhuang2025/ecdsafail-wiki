## Summary

This is the same edit as [`7936360`](7936360.md) (45 diff lines here, 44
there), applied to a new stream. `6e9f0af` was built on `d9ef3e9`, which never had jackylee0424's
post-strip fanout loop. This commit adds the loop after `6e9f0af`'s new strip.
The loop runs the exact rewrite `CCX(a,b→t); CX(t→u); CCX(a,b→t)` →
`CX(t→u); CCX(a,b→u)` to a fixed point. It again finds exactly 9 matches, so
9 CCX disappear. The average falls by 8.5 Toffoli (1,292,286.126 →
1,292,277.582), which rounds to −8. Qubits are unchanged.

## What changed and why it saves Toffoli

- **`src/point_add/mod.rs`, `build()`:**
  - After `apply_deep_strip_identity`, while the strip is on, loop
    `single_ccx_fanout::rewrite_first_target_fanout(ops, 96)` until it finds no
    match, logging one witness line per rewrite.
  - Then `assert_eq!(post_strip_fanout_passes, 9, "accepted 6e9f0af post-strip
    target-fanout census drift")`, so a different stream fails the build.
  - The code is identical to 7936360's apart from the assertion message.
- **The rewrite.** Two identical unconditional `CCX(a, b → t)` with only a
  `CX(t → u)` reading `t` between them (and nothing else touching `a`, `b`,
  `t`) equal `CX(t → u); CCX(a, b → u)`. The pair of CCX is replaced by one CCX
  that carries the CX's condition. See [`7936360`](7936360.md) for the exact
  matching rules and [dead-gate-strip](../concepts/dead-gate-strip.md).
- **Why it saves Toffoli.** Each match turns two Toffoli into one, about 1 per
  shot each. The strip had deleted or downgraded the gates that used to block
  these matches.
- **Tail nonce:** `SUB4_TAIL_NONCE` default 990018471007 → 168504092. The note
  says it was found on three RTX 3090s with a GPU filter, then 512- and
  2,048-shot filters, then the full CPU evaluator.

## Why it is still correct, and what it risks

- **The rewrite is exact.** It adds no hard inputs, so λ, the expected number
  of failing shots per draw, is the base's.
- The changed stream draws a new test set. The nonce `168504092` gives a clean
  one: 9,024 of 9,024 shots, 0 classical, 0 phase and 0 ancilla failures. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).
- A gain this small, about 9 Toffoli per shot, is the same size as the
  per-nonce spread of the average. See
  [scoring-and-validation](../concepts/scoring-and-validation.md).

## Classification rationale

Two Toffolis around a fanout CX merge into one: gate/op fusion, as in 7936360.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 6e9f0af -- src/point_add`. The base is the git parent.
   `git diff --ignore-cr-at-eol 6e9f0af 266b783 -- src/point_add` is 45 lines in
   1 file.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line endings.
   It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 266b783 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `TLM_*` or
   `SUB4_*` overrides set. Expect:
   - 1154 qubits
   - 1,292,278 average Toffoli (1,292,277.582 before rounding)
   - score 1,491,288,812
   - 0 classical, 0 phase and 0 ancilla failures
5. **Nonce caveat.** The score only reproduces with the nonce `168504092` and an
   identical op stream. Any other change needs a new nonce hunt, and the
   9-pass assertion will fail if the stream changes.
