## Summary

To find a clean nonce for its windowed final apply chunk,
[`2eab923`](2eab923.md) had loosened several truncation knobs. This commit
takes two of them back:

- The modular double/halve carry window goes from 23 to 22 bits.
- The dialog-GCD width slope goes from 1.004 to 1.005 bits per step.

Both drop high bits that are rarely needed. The tail nonce was re-hunted. The
saving is 1,966 average Toffoli at the same 1320 qubits.

## What changed and why it saves Toffoli

All changes are default pins in `configure_ecdsafail_submission_route()`,
`src/point_add/mod.rs`.

1. **`KAL_DOUBLE_CARRY_TRUNC_W`: 23 → 22.**
   - Every modular double and halve of `y` in the apply loop (the
     unconditional one and the K=2 conditional one) adds or subtracts
     `c = 2^32 + 977`, controlled on the shifted-out bit. It uses
     `cadd_nbit_const_direct_trunc_fast` / `csub_nbit_const_direct_trunc_fast`.
   - Those adders only build carries up to `last = 32 + window`. One bit less
     window removes one carry position, which is 1 CCX, since `c` has no set
     bits above 32. The carries are erased by measurement.
   - At about 1,038 calls per shot, this is about −1,038 Toffoli. That is the
     same step measured in [`c64c03f`](c64c03f.md).
2. **`DIALOG_GCD_WIDTH_SLOPE_X1000`: 1004 → 1005.**
   `dialog_gcd_tobitvector_active_width(step) = ceil_even(256 − step × slope + 10)`.
   One notch narrows step `s` by `0.001 × s` bits, and some late steps lose
   2 bits after rounding. Those steps' cswap and controlled subtract get
   cheaper in every GCD pass. That leaves about −930 for this notch. That is
   more than the ~590 seen for 1.009 → 1.010 in [`8a9d274`](8a9d274.md),
   because rounding to even makes each notch's effect uneven.
3. **`DIALOG_TAIL_NONCE`: 192345092161242 → 188481450290415.** The 48 `X;X`
   identity pairs at the end of `build_builder()` only reseed the 9,024 test
   inputs.

The two parts were not measured separately. Only the total, −1,966, was
measured.

## Why it is still correct, and what it risks

- **Double window.** The truncated adder is wrong when a carry from the low
  33 bits runs through a run of about 23 ones just above bit 32. That is
  about 2^−23 per call. A trigger corrupts the high bits of `y`, which gives a
  classical failure. Double and halve share the window, so they stay exact
  inverses when nothing triggers.
- **Slope.** An input whose GCD registers shrink more slowly than the
  envelope loses a high bit. That gives a classical failure, or phase or
  ancilla garbage on the reverse pass.
- The fold window (24), the comparator (48) and the clean compare (20) keep
  the base's values.
- Nonce 188481450290415 draws a clean set: 9,024 of 9,024 shots, with
  0 classical, 0 phase and 0 ancilla failures. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

Both changes narrow a truncation window: a carry window and a register-width
envelope. The census files this as comparator/width truncation. Fold/carry
truncation would fit the double-window half equally well.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 2eab923 -- src/point_add`. The base is the git parent.
   `git diff --ignore-cr-at-eol 2eab923 db60686 -- src/point_add` is 6 lines
   in 1 file.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line endings.
   It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol db60686 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no
   `KAL_*`, `DIALOG_*` or `SUB4_*` environment variables set, because they
   override the defaults. Expect:
   - 1320 qubits
   - 1,543,821 average Toffoli (rounded)
   - score 2,037,843,720
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `188481450290415` and an identical
op stream. Any other change needs a new nonce hunt.
