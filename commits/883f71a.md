## Summary

This commit makes no optimization. It only changes the tail nonce in
`src/point_add/mod.rs` (`DIALOG_TAIL_NONCE` default in `build()`) from
7000001200 to 82979. The new nonce draws a different clean set of 9,024 test
shots, whose average executed Toffoli is 24 lower. The diff touches only nonce
literals: the three copies in `configure_ecdsafail_submission_route()`, which
the trailmix `build()` never calls, also go from 800457469 to 82979. The
emitted op count is unchanged (10,305,179). For why a nonce moves the score,
see [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Reproduce

From `git checkout 533ef88 -- src/point_add`, apply the patch below with
`git apply --ignore-whitespace`. `./benchmark.sh` should give 1164 qubits,
1,390,952 average Toffoli and 0 / 0 / 0 failures.
