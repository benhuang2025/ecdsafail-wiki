## Summary

This commit copies anupsv's qubit lever from [`7021abe`](7021abe.md) onto the
author's own `df83d16` tree. The x-tail Karatsuba square holds a 258-qubit
register `z1_reg` through its Solinas reduction, where the peak of 1543 sits.
In that window `z1_reg` holds `2·lo·hi < 2^257`, so its top wire is always 0.
The wire is freed for the window and a fresh zero wire is allocated before the
step that can set bit 257 again. The peak drops to 1542 at no Toffoli cost.

`7021abe` had to widen the GCD comparator schedule margin from 5 to 7
(+592 Toffoli) to find a clean reroll island. Here the author found a clean
pair, (17, 56), at margin 5, so the Toffoli count is unchanged and the whole
qubit is profit: 1 × 1,682,159 off the score.

## What changed and why it saves qubits

All changes are in `src/point_add/mod.rs`.

1. **`KARA_FREE_Z1_TOPBIT`** in `squaring_sub_from_acc_karatsuba()`, the same
   code as in `7021abe`:
   - `z1_reg` becomes `mut`. Right after `z1 −= z0; z1 −= z2`, where
     `z1_reg = 2·lo·hi` with `lo, hi < 2^128`, bit 257 is 0 on every branch.
     The code pops that wire and `b.free`s it.
   - The two combine steps that pad `z1_reg` to `3h` bits allocate
     `3h − z1_reg.len()` pad wires instead of `3h − 2(h+1)`, so they still see a
     `3h`-wide operand.
   - The wire stays free through the whole Solinas reduction and the inverse
     `mid −= z1`. Before `z1 += z2` (which can set bit 257), `b.alloc_qubit()`
     takes a fresh zero wire and pushes it back onto `z1_reg`.
   - This lowers the square phase by one qubit. See
     [venting-and-wire-loans](../concepts/venting-and-wire-loans.md) and
     [peak-qubits-and-budgets](../concepts/peak-qubits-and-budgets.md).
2. **`set_default_env("KARA_FREE_Z1_TOPBIT", "1")`** in
   `configure_ecdsafail_submission_route()`, with a comment crediting
   anupsv's `8780d1e` (the submission of `7021abe`).
   `DIALOG_GCD_PA9024_COMPARE_SCHEDULE_MARGIN` stays at 5.
3. **Reroll pair: `DIALOG_REROLL` 40 → 17, `DIALOG_POST_SUB_REROLL` 13 → 56.**
   Identity `X;X` counts that re-draw the 9,024 test inputs without changing
   the circuit (see [`ecbf87b`](ecbf87b.md)).

## Why it is still correct, and what it risks

The free is exact: bit 257 of `2·lo·hi` is 0 for every input, so the wire is
|0⟩ and unentangled when it is reset, and its replacement is also |0⟩. Every
step that reads `z1_reg` sees the same value as in the base.

No approximation changes, but the test set does. The base's approximations
(GCD branch comparator, width envelope, apply-clean compare and the 20-bit
carry-truncated doublings from `df83d16`) must all be right on the new draw.
With the reroll pair (17, 56), 9,024 of 9,024 shots pass with 0 classical,
0 phase and 0 ancilla failures. See
[nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

The qubit comes from shortening one wire's lifetime: it is freed while it is
provably zero and re-allocated when needed. That is ancilla-lifetime /
venting, the same label as the lever's original, `7021abe`.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout df83d16 -- src/point_add`. The base is the git parent.
   `git diff --ignore-cr-at-eol df83d16 46c3e3a -- src/point_add` is 34 lines
   in 1 file.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line endings.
   It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 46c3e3a -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `DIALOG_*`,
   `KAL_*`, `KARA_*` or `ROUND84_*` environment variables set, because
   `set_default_env` keeps any value already in the environment. Expect:
   - 1542 qubits
   - 1,682,159 average Toffoli (rounded)
   - score 2,593,889,178
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the reroll pair `DIALOG_REROLL=17`,
`DIALOG_POST_SUB_REROLL=56` and an identical op stream. Any other change needs
a new reroll search.
