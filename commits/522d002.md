## Summary

The ping-pong walk registers `u` and `v` are always odd, so their bit 0 is
always 1. While the replay runs, it reads only the tape, `coefficient` and
`numerator`, and never touches `u` or `v`. This commit flips `u[0]` and `v[0]`
to |0⟩ with an X gate and hands both wires to the free pool before each
non-terminal replay stretch. The replay's own allocations, such as its carry
ladder, can then reuse them. Afterwards the code takes them back and flips
them back to 1.

The terminal replay batch already did this through its `loan` closure. This
commit extends it to the batch below `r1` and to every interleaved replay
round, in both traversals. The peak drops by one qubit. The gates are the same
except for X gates, so the +12 average Toffoli comes from the new nonce's
test draw, not from extra work.

## What changed and why it saves a qubit

All circuit changes are in `src/point_add/pingpong_div.rs`.

- **Two new helpers.**

  ```
  loan_interleaved_odd_passengers(b, u, v) -> [u[0], v[0]]:
      for q in [u[0], v[0]]:  b.x(q); b.release_clean(q)   # 1 -> 0, back to the pool, no reset
  restore_interleaved_odd_passengers(b, [u0, v0]):
      for q in [v0, u0]:      b.reacquire(q); b.x(q)       # take that index back, 0 -> 1
  ```

  - `release_clean` frees the wire without emitting an `R`, because the X has
    already put it at |0⟩. `reacquire` takes that exact index back out of the
    pool.
  - Any allocation in between may receive the wire, but must return it at
    |0⟩. See [venting-and-wire-loans](../concepts/venting-and-wire-loans.md).
- **Four call sites in `pingpong_mod_mul_div_in_place`**, interleaved plan
  only:
  1. Divide: around the batch of replay rounds `0..r1`, after
     `set_chunks(pick_chunks(…))`.
  2. Divide: around each interleaved `replay_halving_round` in `r1..=r2`.
  3. Multiply: around each interleaved `replay_doubling_round` in `r1..=r2`.
  4. Multiply: around the final batch of replay rounds `0..r1`.
- **Why the peak drops.**
  - Each site is in the peak-binding replay region. There the live set is the
    tape, both coefficient registers, both walk registers and the replay
    cell's ladder.
  - The ladder size is fixed earlier by `pick_chunks`. It is computed from
    the plan's `allowance` formula, not from the live count, so the layout
    and the gates do not change.
  - The two loaned wires are simply reused inside the cell, so the region
    runs two wires lower.
  - The measured peak falls by one, not two, from 1267 to 1266. Some other
    region now binds at 1266. See
    [peak-qubits-and-budgets](../concepts/peak-qubits-and-budgets.md).
- **Tail nonce** (`SUB4_PINGPONG_TAIL_NONCE` default in `build()`,
  `src/point_add/mod.rs`): 8107117281543 → 82505456522172.
- **Toffoli.** No Toffoli is added or removed. Each loan and restore pair adds
  4 X gates. The average executed Toffoli moves by +12 because a new nonce
  draws different test shots, and conditioned repairs execute on different
  shots. This is the same effect as the nonce-only [`a9af194`](a9af194.md).

## Why it is still correct, and what it risks

- **Exact.**
  - Bit 0 of `u` and `v` is 1 on every input, not only on inputs that
    converge. `u = p` and the lifted `v` are odd. Each walk round adds or
    subtracts two odd values, picks the sign so the sum is 2 mod 4, and
    halves it, so the result is odd again. Width trimming only removes top
    bits.
  - The replay rounds do not read or write `u` or `v`. Restoring with
    `reacquire` and X gives back the same value on the same index.
- **How a failure would show.** If a body allocation handed back a loaned
  wire dirty, the restore would leave garbage. That would be a classical or
  ancilla failure, and it would be systematic.
- The shipped nonce draws a clean test set: 9,024 of 9,024 shots, with 0
  classical, 0 phase and 0 ancilla failures. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

Two wires with a known constant value are cleared, lent to the free pool as
scratch for the replay, and restored. No gate is removed. That is
scratch/ancilla reuse, the same pattern as the terminal loan and
[`152fbe0`](152fbe0.md).

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 6752417 -- src/point_add`. The base is the git
   parent. `git diff --ignore-cr-at-eol 6752417 522d002 -- src/point_add` is
   35 lines in 2 files.
2. **Apply the patch below** from the repo root with
   `git apply --ignore-whitespace`. The flag lets the patch apply whether the
   files use LF or CRLF line endings. It is the complete diff against the
   base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 522d002 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `SUB4_*`
   or `TLM_*` environment variables set. The pins from `6752417` are applied
   by `set_default_env` inside `build()`. Expect:
   - 1266 qubits
   - 911,402 average Toffoli (rounded)
   - score 1,153,834,932
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `82505456522172` and an identical op
stream. Any other change needs a new nonce hunt.
