## Summary

This is jackylee0424's post-strip fanout loop again, as in [`7936360`](7936360.md)
and [`266b783`](266b783.md). Every strip re-mine since 266b783 was built
without it, so it is added once more, after `3701581`'s strip. The loop runs
the exact rewrite `CCX(a,b→t); CX(t→u); CCX(a,b→t)` → `CX(t→u); CCX(a,b→u)` to
a fixed point. On this stream it finds exactly 10 matches, so 10 CCX disappear.
The emitted op count goes from 8,961,429 to 8,961,419.

The average falls by 14.9 Toffoli (1,285,673.863 → 1,285,658.939). About 10 of
that is the removed gates; the rest is the new nonce's draw. Qubits are
unchanged.

## What changed and why it saves Toffoli

- **`src/point_add/mod.rs`, `build()`:** after `apply_deep_strip_identity`, while
  the strip is on, loop `single_ccx_fanout::rewrite_first_target_fanout(ops, 96)`
  until it finds no match, logging one witness per rewrite. Then
  `assert_eq!(post_strip_fanout_passes, 10, "3701581 post-strip target-fanout
  census drift")`. The code is the same as 7936360's apart from the count and
  the message.
- **The rewrite** (`single_ccx_fanout.rs`, unchanged). It needs two identical
  unconditional `CCX(a, b → t)`. Between them, `t` may be read only by one
  `CX(t → u)` with `u ∉ {a, b, t}`, and nothing may write `a` or `b`,
  phase-touch `t`, or apply R, Hmr or a swap to any of the three. The pair is replaced by one `CCX(a, b → u)` with the CX's
  condition, inserted after the CX. That saves one Toffoli per match per shot.
  The last 96 ops (the nonce tail) are protected. See [`7936360`](7936360.md)
  for the identity and [dead-gate-strip](../concepts/dead-gate-strip.md).
- **Tail nonce:** `SUB4_TAIL_NONCE` 1003157528363 → 8000230021249. The note
  reports that the base's nonce gives 15 classical / 11 phase failures on the
  rewritten stream, so a new one was needed.
- **File modes:** 24 Python scripts under `src/point_add/memory/repro/` go from
  mode 100755 to 100644. Their contents do not change.

## Why it is still correct, and what it risks

- **The rewrite is exact**, so it adds no hard inputs. λ, the expected number of
  failing shots per draw, is the base's.
- The new nonce `8000230021249` draws a clean set: 9,024 of 9,024 shots, 0
  classical, 0 phase and 0 ancilla failures. The note rebuilt from scratch and
  matched the stream byte for byte. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).
- About 5 of the −15 is island luck. See
  [scoring-and-validation](../concepts/scoring-and-validation.md).

## Classification rationale

Two Toffolis around a fanout CX merge into one: gate/op fusion, as in 7936360
and 266b783.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 3701581 -- src/point_add`. The base is the git parent.
   `git diff --ignore-cr-at-eol 3701581 59f3428 -- src/point_add` changes `mod.rs`
   (46 lines) and the mode of 24 scripts.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line endings.
   It is the complete diff against the base, including the mode changes.
3. **Check the tree.** `git diff --ignore-cr-at-eol 59f3428 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `TLM_*` or
   `SUB4_*` overrides set. Expect:
   - 1154 qubits
   - 1,285,659 average Toffoli (1,285,658.939 before rounding)
   - score 1,483,650,486
   - 0 classical, 0 phase and 0 ancilla failures
5. **Nonce caveat.** The score only reproduces with the nonce `8000230021249` and an
   identical op stream. Any other change needs a new nonce hunt, and the
   10-pass assertion will fail if the stream changes.
