## Summary

The trailmix build runs an exact simplifier, `constprop.rs`, that deletes
pairs of identical Toffolis `CCX(a,b→t) … CCX(a,b→t)` when nothing in between
touches `a`, `b` or `t`. Many such pairs are "blocked": exactly one other
Toffoli in between writes one of the controls. Cancelling a blocked pair is
not exact. It leaves behind a three-way AND that the circuit would have
applied to `t`.

This commit allows cancelling a blocked pair when that leftover three-way AND
is on a short allow-list of 11 wire triples. Each was measured to fire on
almost no inputs (4 to 134 times in 10.5 million shots). Removing these 11
"roots" makes 144 more pairs exactly cancellable, so the pair count goes from
1 to 155. The author measured −308 average Toffoli for about +0.49 λ; on
the shipped test draw the change is −300.

## What changed and why it saves Toffoli

### `src/point_add/trailmix_ludicrous/constprop.rs`

**The residual.** Take a pair `CCX(a,b→t) … CCX(a,b→t)` where the only write
in between to either control is one unconditional `CCX(c,d→a)`. Then

```
t ^= a·b                 # first CCX
a ^= c·d                 # the blocking write
t ^= (a ⊕ c·d)·b         # second CCX
net:  t ^= b·c·d
```

So deleting both CCX is correct exactly when `b·c·d = 0` at the blocking
write. `b` is the "surviving" control (the one not written), and `(b, c, d)`
is the residual triple.

**New table `DEFAULT_CASCADE_TRIPLES`**, 11 sorted qubit triples:
`(9,270,271)`, `(143,271,272)`, `(143,273,274)`, `(271,272,886)`,
`(273,274,915)`, `(274,275,889)`, `(274,275,1088)`, `(274,275,1147)`,
`(530,531,1132)`, `(530,531,1149)`, `(530,531,1150)`.
- The doc comment lists each triple's fire count over 10,485,760 real shots
  and the expected failures per 9,024-shot run, from 4 fires (0.0034) to
  134 fires (0.1153). The total is λ +0.4912, which the comment calls a hunt
  cost of ×1.63.
- Three more roots were measured and left out as λ-inefficient:
  `526:527:1150` (428 fires), `10:526:527` (241) and `529:530:1152` (151).
  Every kept root removes at least 272 ops per unit of λ, every excluded one
  at most 216.
- The comment warns that 1M shots is not enough to rank roots; it
  mis-ranked several.

**New branch in `find_inverse_pairs`.** When a candidate pair is not
cancelled by the exact rule but every other condition holds (same gate,
same condition epoch, target clean, no classical condition, empty condition
stack), the code collects the writes to `a` and to `b` strictly between the
two CCX.
- If there is exactly one such write, it is an unconditional CCX, and it
  targets that control, the code forms the sorted triple
  `(surviving, wc1, wc2)`.
- If the triple is on the allow-list, both CCX are marked killed and recorded
  as a `PairKill`, and `CASCADE_ACCEPT` is logged.
- To support this, the per-wire write-event lists (`wev_q`, `wev_b`) that
  used to be kept only in `straddle` mode are kept whenever cascade is
  active (`track = straddle || cascade_any`).
- Environment switches: `TLM_CASCADE_DISABLE=1` turns it off,
  `TLM_CASCADE_TRIPLES=a:b:c,…` adds triples, and `TLM_CASCADE_TRACE=1` logs
  every candidate root.

**Why it saves so much.** Each accepted root removes two CCX. Removing them
also deletes the obstruction for other pairs nearby, which the exact
predicate then cancels on later iterations of `constprop::run`. The comment
reports `inverse_pairs 1 → 155` and `constprop iters 3 → 16`, and a paired
measurement on identical inputs of exactly −308.000 average executed
Toffoli.

### `src/point_add/mod.rs`

The default `SUB4_TAIL_NONCE` goes from 931040453370 to 1337610097.

### New file `src/point_add/dialog_gcd_classical_filter.rs` (2,181 lines)

A classical nonce prefilter. For each candidate tail nonce it derives the
9,024 Fiat–Shamir inputs, replays the truncated binary-GCD transcript on
both inversion factors in plain arithmetic, and flags a factor as hard on
width overflow, a truncated-comparator mis-decision, non-convergence, or a
number of codec and fold-carry mismatches. The header calls it
"analysis-only tooling". Nothing declares `mod dialog_gcd_classical_filter`,
so it is not compiled into the build and has no effect on the circuit. See
[nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md),
"Hunting".

## Why it is still correct, and what it risks

- **The 11 roots are probabilistic.** On an input where a triple's AND is 1,
  `t` misses a flip of `b·c·d`. That gives a wrong value, a classical
  mismatch, or a phase error. The measured sum is λ +0.49, that is, about one
  extra failing shot per two draws.
- **The 144 follow-on pairs are exact.** They pass the original exact
  predicate once the roots are gone. The comment's point is that the risk
  surface is only the 11 triples.
- **The triples name fixed qubit indices.** Any upstream change that moves
  wires makes the table inert or wrong. Later commits re-measure it
  (`afcc72e`, `0422437`).
- The shipped nonce `1337610097` draws a clean test set: 0 classical,
  0 phase and 0 ancilla failures. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

The saving comes from cancelling pairs of identical CCX, a few of them only
statistically safe. That is dead-gate/self-inverse removal. See the
"Cascade" entry in [dead-gate-strip](../concepts/dead-gate-strip.md). The
prefilter file does not touch the circuit.

   parent. `git diff --ignore-cr-at-eol 8e62c01 f735fd7 -- src/point_add` is
   2,323 changed lines in 3 files, 2,181 of them the new filter file.

   `git checkout f735fd7 -- src/point_add/dialog_gcd_classical_filter.rs`.
   It is hand-written and copied only because it is too large to inline. It
   is not compiled.
3. **Apply the patch below** from the repo root with
   `git apply --ignore-whitespace`. The flag lets the patch apply whether the
   files use LF or CRLF line endings. It covers `constprop.rs` and `mod.rs`.
4. **Check the tree.** `git diff --ignore-cr-at-eol f735fd7 -- src/point_add`
   should print nothing.
5. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `SUB4_*`
   or `TLM_*` overrides set (in particular no `TLM_CASCADE_*`). Expect:
   - 1154 qubits
   - 1,283,487 average Toffoli (rounded)
   - score 1,481,143,998
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `1337610097` and an identical op
stream. Any other change needs a new nonce hunt.
