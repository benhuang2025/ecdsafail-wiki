## Summary

Sky14 moves fold-window bits between payload cells. The Skywalk payload cells
reuse ping-pong's replay cell, whose modular fold works on a truncated slice
of `fold_window` bits. Two pins set that width per cell:

| knob | change | cells (per leg) | direction |
| --- | --- | --- | --- |
| `HEO_PIN_PP_FOLD_PROFILE` band `25:` | −2 → −3 | ticks 354–365 (12) | sell, one bit narrower |
| `HEO_PIN_PP_FOLD_PROFILE` band `0:` | −4 → −5 | ticks 374 to the end, less the terminal cell (17–18) | sell, one bit narrower |
| `HEO_PIN_PP_FOLD_WIDEN` | 68 → 112 | ticks 37–59 (23) | buy, one bit wider |

The sells remove more window bits than the buy adds. The author priced the
buy to give back the λ the sells spend, so λ stays flat while Toffoli falls.
The SAT rewrite table is re-mined for the new op stream (54 → 58 rows). The
net is −38 Toffoli at 1174 qubits.

## What changed and why it saves Toffoli

All circuit changes are pins in `install_skywalk_submission_recipe()`,
`src/point_add/mod.rs`. The `HEO_PIN_` prefix overrides the head's pinned
`PP_FOLD_PROFILE` / `PP_FOLD_WIDEN`.

**How a payload cell's fold window is set** (`pingpong.rs` and
`heo_carry.rs`, unchanged):

- `cell_div` / `cell_mul` compute `proxy = h7::proxy_round(esw)`: the first
  ping-pong round whose `PP_WIDTH_SCHEDULE` width is at most the tick's width
  in the fixed proxy envelope `env_front07_R393_clamp.txt`.
- The window is `h7::fold_window(proxy, mul)` =
  `PP_REPLAY_FOLD_WINDOW(_MUL)` (54 for both legs) + `fold_offset(proxy)`.
  `cell_div` / `cell_mul` then add the per-cell `dX` from `HEO_CELL_WINDOWS`
  (`windows_full_safe_mulB64.tsv`, nonzero on many cells); the window values
  below are before that shift, which this commit does not change.
- `fold_offset(round)` = `band_at(PP_FOLD_PROFILE, policy_width(round))` +
  1 if `round < PP_FOLD_WIDEN`.
  - `policy_width(round)` is `PP_WIDTH_SCHEDULE[round]`.
  - `band_at` picks the first `width:offset` band whose lower bound is at or
    below that width, so the table is read widest first.
- The source comment above `fold_shape()` explains the shape: the fold
  "drops the carry off the top of its slice", and the escape rate collapses
  once the walk is narrower than about 45 bits. So late cells can afford a
  narrower window at the same per-cell error. `PP_FOLD_WIDEN` is the
  separate "level" knob: a block of leading rounds carries one extra bit.
- See [modular-fold](../concepts/modular-fold.md) for the fold itself.

**The edits.** The tick ranges below are my mapping of each band through the
proxy envelope and the pinned width schedule.

1. **`HEO_PIN_PP_FOLD_PROFILE`: `38:0,32:-1,25:-2,19:-4,0:-4` →
   `38:0,32:-1,25:-3,19:-4,0:-5`.**
   - Walk width 25–31 (ticks 354–365 on both legs): window 52 → 51.
   - Walk width 0–18 (ticks 374 to the last tick): window 50 → 49. The last
     cell of each leg (division tick 392, multiply tick 391) is not affected.
     It is replaced by `pingpong::terminal_pair` with its own
     `TERMINAL_FW = 50`.
   - Bands 32–37 and 19–24 keep their offsets.
2. **`HEO_PIN_PP_FOLD_WIDEN`: 68 → 112.**
   - Proxy rounds 68–111 now also get +1. On the proxy envelope these are
     ticks 37–59 (proxy rounds 68–110; round 111 does not occur), whose
     window goes 54 → 55 on both legs.
   - Ticks 0–36 (proxy rounds below 68) already had the bit.
3. **Cost per bit.**
   - Each window bit is one more stage of the fold's truncated carry chain,
     so it is worth about one Toffoli per cell on every shot.
   - The sells cover about 59 cells over the two legs and the buy covers 46.
   - The submission note prices them alone at −83 T (sell) and +46 T (buy),
     and the package at −37 T without rows. The buy's +46 T over 46 cells
     fits the one-Toffoli-per-bit estimate.
4. **SAT rewrite rows: `sky13_rewrite.txt` (54 rows) → `sky14_rewrite.txt`
   (58 rows).**
   - The code comment calls them "58 square rows re-proved by SAT on the
     sky14 op stream".
   - Comparing the files, 16 rows name the same wires as a sky13 row, all at
     an index shift of −434. The other 42 are new.
   - The loader is unchanged. It finds one global shift under which every
     row names an unconditioned CCX, then replaces each CCX with its CX
     chain. See [dead-gate-strip](../concepts/dead-gate-strip.md).
   - Four more rows are worth about −4 Toffoli.
   - `sky13_rewrite.txt` stays in the tree, unused.
5. **Tail nonce**: `TAIL_NONCE` goes from 13001751969103 to 14000222169933.

## Why it is still correct, and what it risks

- **The sells** about double the escape rate of the fold on those cells. An
  escaped carry is dropped, so the register ends up wrong by `2^W`: a wrong
  field element, which shows up as a **classical** failure (or as ancilla
  garbage if the inverse pass cannot clean up).
- **The buy** about halves the escape rate on 23 early cells per leg.
- The submission note gives the package's paired-nonce λ change as +0.003
  and the final λ as 19.261 ± 0.032, inside the 19.5 limit that the code
  comment cites.
- The rewrite rows are exact on reachable states if their proofs hold. The
  build only asserts that each row still names its CCX.
- The shipped nonce `14000222169933` draws a clean island: 0 classical,
  0 phase and 0 ancilla failures. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

Both levers change the width of a truncated fold carry chain: fold/carry
truncation, like [`03d9ecd`](03d9ecd.md), which used the same two knobs. The
runner-up was comparator/width truncation, the label of the other sky
packages, but no compare width changes here.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 1c185d1 -- src/point_add`. The base is the git
   parent. `git diff --ignore-cr-at-eol 1c185d1 cc530e2 -- src/point_add` is
   70 lines in 2 files.
2. **Copy the new rewrite table from the commit:**
   `git checkout cc530e2 -- src/point_add/skywalk_data/sky14_rewrite.txt`.
   It holds the 58 SAT rows described above.
3. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line
   endings. It covers `mod.rs`.
4. **Check the tree.** `git diff --ignore-cr-at-eol cc530e2 -- src/point_add`
   should print nothing.
5. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh`. `build()` clears
   the process environment and then installs the pinned recipe, so `HEO_*`,
   `GO_*`, `SKY_*`, `PP_*` and `SUB4_*` overrides have no effect. Do not set
   them anyway. Expect:
   - 1174 qubits
   - 944,609 average Toffoli (rounded)
   - score 1,108,970,966
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `14000222169933` and an identical op
stream. [`b997d0a`](b997d0a.md) keeps this circuit and only re-rolls the
nonce.
