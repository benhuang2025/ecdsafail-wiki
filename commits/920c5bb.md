## Summary

Each round of the ping-pong coefficient replay erases three bits by
measurement: the two carries between the three chunks of its 256-bit add, and
the cell's overflow flag. After each `hmr` the phase is repaired by a
comparison of only the top `k` bits of two registers. This commit makes those
comparisons narrower: 25 → 24 bits at the chunk boundaries and 28 → 26 bits
for the flag. A compare bit costs one Toffoli on the roughly half of shots
where the repair runs, so the saving is about 2 executed Toffoli per replay
cell, 2,798 in total. Qubits are unchanged.

The commit also adds two tuning knobs, `SUB4_PP_ROUNDS` and
`SUB4_PP_WIDTH_RESCALE`. Both are off by default and do not change the
shipped op stream.

## What changed and why it saves Toffoli

All circuit changes are in `src/point_add/pingpong_div.rs`.

1. **`replay_chunk_compare()` default: 25 → 24** (`SUB4_PP_REPLAY_CHUNK_COMPARE`).
   - `add_chunked_measured` splits the replay's 256-bit add into
     `chunk_bounds(256, REPLAY_CHUNK = 96)`, which is three chunks of 86, 85
     and 85 bits, with a carry wire between neighbouring chunks.
   - After the add, each of the two boundary carries is measured out with
     `b.hmr(carry, phase)`. Then
     `cmp_lt_phase_conditioned(b, &acc[hi−k..hi], &addend[hi−k..hi], phase)`
     applies the phase `(−1)^[sum < addend]` on the chunk's top `k` bits. The
     carry out of a chunk equals `[sum < addend]` over that chunk, so this
     cancels the phase the measurement left.
   - The compare runs under `push_condition(phase)`: `k` CCX on the forward
     pass, and an `hmr`/`cz_if` inverse with no Toffoli. So one bit less saves
     one Toffoli on about half the shots, per boundary.
2. **`replay_flag_compare()` default: 28 → 26** (`SUB4_PP_REPLAY_FLAG_COMPARE`).
   - In the Divide cell `signed_mod_add_pm_halve_fused` (and its Multiply
     twin), the overflow flag of the add is measured out with
     `b.hmr(overflow, phase)`. The repair is
     `cmp_lt_phase_conditioned(b, &target[N−k..], &source[N−k..], phase)`, the
     same conditioned top-`k` compare. The flag is not recomputed; only its
     phase is repaired.
3. **Arithmetic check.** About 1,404 fused cells run (rounds 2..703 in each of
   the two traversals). Each saves 2 × 1 chunk bits + 2 flag bits, at about
   0.5 executed Toffoli per bit, so about 1,404 × 2 = 2,808 Toffoli. The
   measured change is −2,798. See
   [comparator-and-width-truncation](../concepts/comparator-and-width-truncation.md)
   and [measurement-uncompute](../concepts/measurement-uncompute.md).
4. **Dormant scaffolding, no effect on the default stream.**
   - `ROUNDS` becomes `ROUNDS_DEFAULT = 704`, read through a new
     `rounds()` that honours `SUB4_PP_ROUNDS`. `value_walk` and
     `value_walk_back` loop to `rounds()`. Unset, it is still 704.
   - `width_round_index(round)` rescales the `value_width` schedule to a
     shorter depth only if `SUB4_PP_WIDTH_RESCALE` is set. Unset, it returns
     `round`.
   - The self-test assertion `value_width(ROUNDS − 1) == 8` is relaxed to
     `≥ 8`.
   - Later commits use `SUB4_PP_ROUNDS` to cut the walk depth (for example
     [`be0c8bc`](be0c8bc.md)).
5. **Tail nonce** (`SUB4_PINGPONG_TAIL_NONCE` default in `build()`,
   `src/point_add/mod.rs`): 6273 → 20136.

## Why it is still correct, and what it risks

The values are unchanged: the chunked add itself is exact, and only the
phase repairs are approximate. A truncated compare decides `sum < addend` from
the top `k` bits. It is wrong when those bits tie, about 2^−k per call, and then
the phase repair is wrong on that shot. So these changes add **phase**
failures (twice the per-call rate at the boundaries, four times at the flag),
which raises λ. The shipped nonce `20136` draws a clean set: 0 classical,
0 phase and 0 ancilla failures. See
[nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

The only changes on the default path are two narrower comparator windows, so
the commit is comparator/width truncation. The new rounds and rescale knobs
are unused scaffolding.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 8cdc0e6 -- src/point_add`. The base is the git
   parent. `git diff --ignore-cr-at-eol 8cdc0e6 920c5bb -- src/point_add` is
   43 lines in 2 files.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line
   endings. It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 920c5bb -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `SUB4_*`
   environment variables set (in particular not `SUB4_PP_ROUNDS` or
   `SUB4_PP_WIDTH_RESCALE`). Expect:
   - 1320 qubits
   - 948,501 average Toffoli (rounded)
   - score 1,252,021,320
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `20136` and an identical op stream.
Any other change needs a new nonce hunt.
