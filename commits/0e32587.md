## Summary

This is the same qubit saving as saucegodbased's [`b60eec2`](b60eec2.md),
which the author's later trees had reverted. The bulk Kaliski iteration
allocated a qubit `f1`, set it to |1⟩, and used it only as the always-on
control of one classically conditioned CZ in STEP 5. Replacing that CZ with a
conditioned single-qubit Z (`B::z_if`, already in `builder.rs` since
[`c8e508f`](c8e508f.md)) makes `f1` unnecessary. `f1` was live across STEP 4,
where the circuit peaks, so the peak drops by one, to 2309. The Toffoli count
is unchanged, because the removed gates were an X pair and a CZ.

## What changed and why it saves qubits

`src/point_add/kaliski_walk.rs`, `kaliski_iteration_bulk_prefix3()`:
- At the top, `let f1 = b.alloc_qubit(); b.x(f1);` is removed, along with its
  comment.
- STEP 5's measured uncompute of `add_f` goes from
  `b.hmr(add_f, sm); b.cz_if(f1, b_f, sm);` to
  `b.hmr(add_f, sm); b.z_if(b_f, sm);`. In the simulator, `cz_if(c, q, m)`
  flips the phase when `m & c & q`, and `z_if(q, m)` when `m & q`. With
  `c = f1 = 1` the two are the same.
- At the end, `b.x(f1); b.free(f1);` is removed.

Unlike [`b60eec2`](b60eec2.md), this version does not add a dummy
`alloc_qubit(); free()` pair to emit a stand-in `R` op. That pair never mattered
for correctness: a reset of a |0⟩ qubit adds no phase. Here the op stream (and
so the hashed test draw) simply changes, and the new draw is clean.

The peak phase is the bulk iteration's STEP 4, the fused controlled subtract
and add with its 256-wide temporary. Every wire live there counts toward the
circuit's high-water mark, so removing `f1` lowers the peak by one. See
[peak-qubits-and-budgets](../concepts/peak-qubits-and-budgets.md).

## Why it is still correct, and what it risks

The change is exact. `f1` held |1⟩ for its whole life, so the CZ and the Z
apply the same phase on every basis state, and the measured uncompute of
`add_f` stays phase-clean (see
[measurement-uncompute](../concepts/measurement-uncompute.md)). Nothing
probabilistic is added.

The new op stream draws a new hashed test set, because there is no tail nonce
in this era. The draw is clean: 0 classical, 0 phase and 0 ancilla failures.
The circuit's existing empirical knobs (W-TRUNC margin 20, iteration counts,
the bulk and R_SMALL thresholds) all passed on it unchanged. The average
Toffoli is identical to the base, as expected, since no Toffoli was touched.

## Classification rationale

The published label is ancilla-lifetime / venting. The effect is that a wire
is no longer live at the peak. The same edit in [`b60eec2`](b60eec2.md) is
filed as Constant Propagation and Classical Specialization → host-derived /
classical specialization, because the mechanism replaces a qubit known to be
|1⟩ with that classical knowledge. Either label fits, but the two filings of
identical code are inconsistent.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 6da9882 -- src/point_add`. The base is the git
   parent. `git diff --ignore-cr-at-eol 6da9882 0e32587 -- src/point_add` is
   10 lines in 1 file.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`. The flag lets the patch apply whether the files use LF or CRLF line endings. It is the
   complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 0e32587 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `KAL_*`,
   `POINT_ADD_*` or `BY_*` environment variables set. Expect:
   - 2309 qubits
   - 3,015,004 average Toffoli (rounded)
   - score 6,961,644,236
   - 0 classical, 0 phase and 0 ancilla failures

There is no tail nonce in this era: the test set is a hash of the op stream,
so the score only reproduces with an identical op stream.
