## Summary

The Kaliski inverse swaps its GCD pair `(u, v_w)` under a control bit in
STEP 3 and STEP 9 of every iteration. Each swapped bit costs one Toffoli.
Those swaps still ran at the provable width (`n`, then `2n − iter`), while
the subtract and compare of the same registers had already been cut to the
much narrower empirical envelope (W-TRUNC). This commit cuts the swaps to the
W-TRUNC width plus one bit. Swapping two bits that are both 0 does nothing, so
the high part of each swap was wasted work. The saving is about 210,000
Toffoli, the biggest single step of the day.

The commit also puts the constant-subtract carry-tail window back from 36 to
49 bits. That costs about 8,000 Toffoli and is probably there to land a clean
test island. Net: −202,662 average Toffoli at the same 2309 qubits.

## What changed and why it saves Toffoli

1. **UV-CSWAP truncation**, new in `src/point_add/kaliski_state.rs`:
   - `kal_uv_cswap_trunc_enabled()`: on unless `KAL_UV_CSWAP_TRUNC=0`.
   - `kal_uv_cswap_extra_margin()`: `KAL_UV_CSWAP_MARGIN`, default 1.
   - `kal_uv_cswap_width(iter, n, invariant)` returns
     `min(invariant, kal_wtrunc_width(iter, n) + 1)`. With the base's settings
     (`K0 = 26`, margin 3), `kal_wtrunc_width` is
     `min(n, n − ⌊(iter − 26)·2/3⌋ + 3)`.
2. **Where it is used**, `src/point_add/kaliski_walk.rs`. The (u, v_w) swap
   width is replaced by `kal_uv_cswap_width(...)` at four sites:
   - `kaliski_iteration_bulk_prefix3`: STEP 3 (`uv_width_step3`, including the
     merged STEP-9-plus-STEP-3 swap) and STEP 9 (`uv_width_step9`);
   - `kaliski_iteration_bulk_prefix3_backward`: the reverse STEP 9 and
     reverse STEP 3.

   `BULK_PREFIX_SAFE_ITERS = 400` covers all 399 and 397 iterations of the
   two inversions, so every iteration of every run uses these bodies.
3. **Why it saves Toffoli.** `cswap` in `compare.rs` is `CX, CCX, CX`, so one
   Toffoli per bit. The gap between the old and the new width grows with the
   iteration. At iteration 200 it is 256 − 144 = 112 bits, and at iteration
   300 it is 212 − 78 = 134 bits. Summed over about 1,600 forward and backward
   iterations, this removes about 210,000 Toffoli. The author's note puts the
   swaps at about 27% of all Toffoli before this change.
4. **Carry-tail window back to 49**, `kal_carrytail_w()`: 36 → 49. The comment
   above it still describes 36. That makes `csub_nbit_const_direct_fast`
   compute 13 more borrow bits per call, about +13 Toffoli × 611 calls ≈
   +7,900. It reverts [`a97b4e9`](a97b4e9.md) to the value of
   [`0be8d11`](0be8d11.md). The commit does not say why. The likely reason is
   that this value gave a clean island together with the swap change.

## Why it is still correct, and what it risks

A swap of two bits that are both 0 is the identity. So the truncated swap is
exact on any input where `u` and `v_w` have no nonzero bit above the cut. The
bet is the same one W-TRUNC already makes for the subtract and compare of
the same registers, with one extra bit of slack. An input that breaks the swap
cut would almost surely break the STEP-4 subtract too, so this adds very
little new risk. If it does fail, a high bit is left unswapped, the GCD state
is wrong, and the run shows a classical mismatch. The same width function is
used in the forward swap and in its backward mirror, so the two stay
consistent.

The code comment records the island search. There is no nonce in this era.
`KAL_UV_CSWAP_MARGIN = 1` is clean. Margin 0 had a single straggler (1
classical mismatch). Margins 2 to 5 failed, on hard inputs that came in with
the new draw. A 3M-trial model puts the worst gap between the true bit length
and the W-TRUNC base at +3 bits (at iteration 371). So margin 1 is below the
"provably clean" margin of about 4, and it is accepted on the island alone.
This draw is clean: 0 classical, 0 phase and 0 ancilla failures. See
[nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

The saving comes from narrowing a loop to the empirical width of its
registers, which is comparator/width truncation. The carry-tail revert is a
side change and costs Toffoli.

   - 2309 qubits

score only reproduces with an identical op stream. Any other change draws a new
island.
