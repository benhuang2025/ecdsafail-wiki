## Summary

Two truncation windows in the ping-pong replay each lose one bit:

- **The replay fold window** (`REPLAY_FOLD_WINDOW`, 54 → 53). Every replay
  cell folds a multiple of f = 2³² + 977 into the low 54 bits of its target
  and drops any carry that leaves that slice. One bit less is one carry, about
  one Toffoli, per cell.
- **The chunk-boundary compare** (`REPLAY_CHUNK_COMPARE`, 21 → 20). Each
  replay add is split into chunks, and every carry between chunks is measured
  out and phase-repaired by a top-bits compare. One bit less is about half a
  Toffoli per boundary.

Together they save 2,549 average Toffoli at the same 1278 qubits. The two
cuts fail on different channels. The fold costs only classical λ and the
compare costs only phase λ, so neither eats the other's margin. A new nonce
was hunted.

## What changed and why it saves Toffoli

Both knobs are in `src/point_add/pingpong_div.rs`.

1. **`replay_fold_window()` default: 54 → 53** (`SUB4_PP_REPLAY_FOLD_WINDOW`).
   - Both fused cells, `signed_mod_add_pm_halve_fused` (Divide) and
     `signed_mod_double_add_pm_fused` (Multiply), call
     `fused_fold_maskfree(&target[..replay_fold_window()], …)`, which adds the
     selected value from {−f, 0, +f, +2f} through `width − 2` carries and
     drops the carry out of the top.
   - The window is an absolute slice length here. Each carry is one CCX, and
     each is erased by `hmr` + `cz_if`.
   - With about 1,394 cells (divide 700 rounds, multiply 698), one position
     less is about 1,394 Toffoli.
   - The same knob also shortens the sparse endpoint recovery chain
     (`cadd_per_position_controls_trunc(…, replay_fold_window() − 2)`), which
     runs once per walk-back. See [modular-fold](../concepts/modular-fold.md).
2. **`replay_chunk_compare()` default: 21 → 20** (`SUB4_PP_REPLAY_CHUNK_COMPARE`).
   - In `add_chunked_measured_with`, each boundary carry is erased by
     `hmr(carry, phase)` and repaired with
     `cmp_lt_phase_conditioned(&acc[hi−k..hi], &addend[hi−k..hi], phase)`,
     `k = min(REPLAY_CHUNK_COMPARE, chunk width)`. The compare runs only when
     `phase` = 1, so a bit costs about 0.5 executed Toffoli per boundary.
   - In this tree the chunk layout is chosen per round against the peak
     budget (`chunk_layout`), so the number of wide boundaries varies by
     round. The comment in `plan()` gives one per cell in the batch replay
     and one or two in the interleaved rounds.
   - The same window caps the exact leading chunk that `chunk_layout` may
     use, and it applies to the square's chunked adds too.
   - The remaining ~1,150 Toffoli of the measured total come from this knob.
     See [comparator-and-width-truncation](../concepts/comparator-and-width-truncation.md).
3. **Tail nonce** (`SUB4_PINGPONG_TAIL_NONCE` default in `build()`,
   `src/point_add/mod.rs`): 31163008 → 43171001.

## Why it is still correct, and what it risks

- **Fold window.** A carry escapes the 53-bit slice about 2^−20 times per
  cell, which leaves a wrong field element: a **classical** failure.
- **Chunk compare.** A tie in the top 20 bits of a wide chunk gives a wrong
  phase repair: a **phase** failure, about 2^−20 per wide boundary. Repairs of
  leading chunks no wider than the window compare the whole chunk and stay
  exact.
- Both raise λ. The shipped nonce `43171001` draws a clean set: 0 classical,
  0 phase and 0 ancilla failures. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

Both levers are truncations of the same kind. Fold/carry truncation is the
primary label because the fold window is the larger of the two savings
(about 1,394 of the 2,549 Toffoli). Comparator/width truncation is the close
runner-up.

   parent. `git diff --ignore-cr-at-eol d631017 787eaa8 -- src/point_add` is
   6 lines in 2 files.

   The flag lets the patch apply whether the files use LF or CRLF line
   endings. It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 787eaa8 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `SUB4_*`
   environment variables set. Expect:
   - 1278 qubits
   - 925,387 average Toffoli (rounded)
   - score 1,182,644,586
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `43171001` and an identical op
stream. Any other change needs a new nonce hunt.
