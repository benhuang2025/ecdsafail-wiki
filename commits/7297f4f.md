## Summary

According to the author's comments, the 1542 peak had three co-binders, and
all three must drop for the peak to fall: the x-tail square's Solinas reduction, its half-squares `z0 = lo²` and
`z2 = hi²`, and the GCD apply pass. This commit lowers each by at least one
qubit:

- Row 0 of each half-square is the widest row. Its add now runs in two
  windowed blocks, so only about half its carry wires are live at once.
- After the Karatsuba combine, `z1_reg = 2·lo·hi` is even, so its bit 0 is
  freed through the Solinas reduction.
- The apply add's chunk split moves from bit 78 to 79, one more bit in the
  lower chunk.

The peak becomes 1541. It costs +260 Toffoli for the windowed boundary
compares and +798 for the wider apply boundary compare, +1,058 in all. That is
less than the about 1,091 Toffoli one qubit is worth here (1,681,207 / 1541),
so the score drops by 50,829.

## What changed and why it saves qubits

All changes are in `src/point_add/mod.rs`.

1. **`KARA_Z02_ROW0_WINDOWED=1`**, new functions
   `schoolbook_square_symmetric_row0_windowed` and its `_inverse`.
   - `schoolbook_square_symmetric(x, tmp_ext)` squares a 128-bit half. Row `i`
     builds a temporary `row` of width `n − i + 1` (the diagonal bit `x_i` and
     the cross products `x_i·x_j`, `j > i`) and adds it into `tmp_ext[2i..]`
     with `cuccaro_add_fast`. That adder holds one carry wire per bit. Row 0 is
     the widest: a 130-bit add (129-wire row plus a pad), with about 129 carry
     wires live next to the row. See
     [squaring-and-karatsuba](../concepts/squaring-and-karatsuba.md).
   - The new functions are line-for-line copies, except that row `i = 0` uses
     `cuccaro_add_fast_windowed(row_padded, slice, c_in, 2)` (the inverse uses
     `cuccaro_sub_fast_windowed`). Every other row is unchanged.
   - `cuccaro_add_fast_windowed` (already in the file) splits the add into
     blocks `[0, 65)` and `[65, 130)`. Block 0 is added with a 1-bit extension
     `cout` that catches its carry-out, which then feeds block 1 as carry-in.
     So only about 65 carry wires are live at a time. After both blocks, `cout`
     is cleared exactly by `cmp_lt_into_fast(acc[..65], a[..65], cout)`, since
     the low part of the sum is below the low part of the addend exactly when a
     carry left it.
   - The selection is made in `squaring_sub_from_acc_karatsuba()` for both
     `z0` and `z2` and for both inverse squares, 4 calls in all. Each call adds
     one 65-bit boundary compare, about 65 Toffoli: 4 × 65 = 260.
   - This takes the half-square phases below the Solinas window. The early
     windowed adders of this era are covered in
     [adders-and-carries](../concepts/adders-and-carries.md), which also
     has the background on measured carries.
2. **`KARA_FREE_Z1_LOBIT=1`** in `squaring_sub_from_acc_karatsuba()`.
   - After the combine `mid += z1`, `z1_reg = 2·lo·hi`, which is even, so bit 0
     is 0. The new code calls `z1_reg.remove(0)` and frees that wire.
   - At the start of `r84k_inv_combine`, before `mid −= z1`, a fresh zero wire
     is inserted back at index 0.
   - This stacks with `KARA_FREE_Z1_TOPBIT` (bit 257, freed earlier, see
     [`7021abe`](7021abe.md)). The Solinas reduction then holds 256 of
     `z1_reg`'s 258 wires, one fewer than in the base. See
     [venting-and-wire-loans](../concepts/venting-and-wire-loans.md).
3. **`DIALOG_GCD_APPLY_CHUNKED_F_CUT`: 78 → 79** in
   `configure_ecdsafail_submission_route()`.
   - The apply pass's controlled add and subtract split their 257-bit
     accumulator at `F_CUT`. The upper chunk holds about 2 × (256 − F_CUT)
     scratch qubits (gated addend and carry lane), so one more bit in the lower
     chunk frees two qubits. That takes the apply phases from 1542 to 1540,
     below the new 1541 floor. See [`40574d3`](40574d3.md).
   - The lower chunk's carry is cleared by an exact compare of the low `F_CUT`
     bits, one Toffoli per bit, once in the add and once in the subtract per
     GCD step: 1 × 2 × 399 = +798 Toffoli.
4. **Reroll pair: `DIALOG_REROLL` 14 → 23, `DIALOG_POST_SUB_REROLL` 4 → 11.**
   Identity `X;X` counts that re-draw the 9,024 test inputs without changing
   the circuit (see [`ecbf87b`](ecbf87b.md)).

260 + 798 = 1,058, the measured change.

## Why it is still correct, and what it risks

All three levers are exact. The windowed add computes the same sum as the full
add, and its boundary carry is cleared by a full compare of the low 65 bits.
Bit 0 of `2·lo·hi` is 0 for every input, so freeing that wire and inserting a
fresh zero later leaves every value unchanged. The chunk split is exact at any
cut. See [peak-qubits-and-budgets](../concepts/peak-qubits-and-budgets.md) for
why all co-binders had to move.

Only the test set changes. With the reroll pair (23, 11), all existing
approximations are right on the new draw: 9,024 of 9,024 shots pass with
0 classical, 0 phase and 0 ancilla failures. See
[nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

The new code is the windowed row-0 add, which splits a carry chain into blocks
so fewer carry wires are live at once. That is windowed carry/shift blocks.
The low-bit free (ancilla lifetime) and the F_CUT move (chunk rebalancing) are
the runner-up labels. They are needed to make the peak actually fall, but they
are small.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 47f30d4 -- src/point_add`. The base is the git parent.
   `git diff --ignore-cr-at-eol 47f30d4 7297f4f -- src/point_add` is 133 lines
   in 1 file.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line endings.
   It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 7297f4f -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `DIALOG_*`,
   `KAL_*`, `KARA_*` or `ROUND84_*` environment variables set, because
   `set_default_env` keeps any value already in the environment. Expect:
   - 1541 qubits
   - 1,682,265 average Toffoli (rounded)
   - score 2,592,370,365
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the reroll pair `DIALOG_REROLL=23`,
`DIALOG_POST_SUB_REROLL=11` and an identical op stream. Any other change needs
a new reroll search.
