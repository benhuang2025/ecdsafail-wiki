## Summary

This is the same kind of cut as the author's [`f0c1c42`](f0c1c42.md) 19
minutes earlier, made stronger and on an older base. Each jump-GCD step
decides the `u`/`v` swap from only the top `GAP_J2[i]` bits. This commit lowers
every entry of the 258-step `GAP_J2` table by 1 bit, and by 3 bits where the
entry is 48 or more (98 steps), 454 bits in all. `f0c1c42` cut the wide
entries by 2.

It starts from `d11bdbb`, so it does not include `662e267`'s classical `3·ox`
step. Even so, it scores below `f0c1c42`: the extra 98 bits of compare saved
more than that step did. Net −1,494 average Toffoli at 1159 qubits. The
tail nonce was re-hunted (by an automated proof-gated pipeline, per the
submission note).

## What changed and why it saves Toffoli

- `src/point_add/trailmix_ludicrous/schedule.rs`, `GAP_J2` (258 entries):
  - entries below 48: −1 (160 steps, for example 24 → 23 at step 0);
  - entries of 48 or more: −3 (98 steps, indices 112–218, for example
    56 → 53).
  - The table is then no longer monotone at the end of the wide band (for
    example 48, 47 → 45, 46 around step 218). Nothing requires it to be.
- `src/point_add/mod.rs`, `build()`: `DIALOG_TAIL_NONCE` 200001456973 →
  550000025725.

**Mechanism** (as in [`f0c1c42`](f0c1c42.md)). `gcd.rs` uses
`cmp_eff = min(GAP_J2[i], SCHED_J2[i])` as the width of the swap compare in
`forward_gcd_jump` (`controlled_swap_decision_lt_truncated`, about one Toffoli
per bit) and in `reverse_gcd_jump` (`swap_decision_uncompute_vented`, the
`hmr` phase repair, on about half the shots). Both GCD calls of the point
addition use it, so each bit saves about 3 Toffoli. 454 bits × about 3.3 gives
the measured 1,494. See [trailmix-jump-gcd](../concepts/trailmix-jump-gcd.md)
and [comparator-and-width-truncation](../concepts/comparator-and-width-truncation.md).

## Why it is still correct, and what it risks

- **Probabilistic.** The swap is mis-decided iff `u` and `v` agree on all of
  the top `GAP_J2[i]` bits of the active width
  (`SCHED_J2[i] − bitlen(u ⊕ v) ≥ GAP_J2[i]`). Three fewer bits make that
  about 8 times as likely at each of the 98 wide steps, so Lambda rises more
  than for `f0c1c42`.
- A wrong swap gives a wrong inverse or product, a classical failure; a wrong
  phase repair in the reverse pass is a phase failure.
- The shipped nonce 550000025725 draws a clean set: 9,024 of 9,024 shots pass,
  with 0 classical, 0 phase and 0 ancilla failures, per the author's stock
  `./benchmark.sh` run.

## Classification rationale

As for `f0c1c42`: the published label is iteration/threshold tuning, for a
per-step threshold schedule. The change narrows a truncated comparator, so
comparator/width truncation is the close runner-up.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout d11bdbb -- src/point_add`.
   - Do not start from the git parent `f0c1c42`. This commit was built on
     `d11bdbb` and lacks `662e267`'s classical `3·ox` step.
   - Against the parent, the diff is 358 lines in 5 files. It would delete
     `662e267`'s `classical_times3_mod_q`, `mod_add_exact`, the `bit_*`
     helpers and the test builders, and lower the wide `GAP_J2` entries by one
     more bit.
   - Against `d11bdbb`, `git diff --ignore-cr-at-eol d11bdbb 5f3a0e3 -- src/point_add`
     is 24 lines in 2 files.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`. The flag lets the patch apply whether the files use LF or CRLF line endings. It is the
   complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 5f3a0e3 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no
   `DIALOG_*`, `TLM_*`, `LUD_*`, `CONSTPROP_*` or `TRACE_*` environment
   variables set, because they override the defaults in `build()`. Expect:
   - 1159 qubits
   - 1,379,217 average Toffoli (rounded)
   - score 1,598,512,503
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `550000025725` and an identical op
stream. Any other change needs a new nonce hunt.
