## Summary

At 1500 qubits the peak was a tie between two places. One was the GCD
transcript's branch-bit comparator (`tobitvector_branch_bits` and its
reverse). The other was the apply pass's chunked add and subtract.

The comparator allocated a fresh carry lane (up to about 60 wires) on top of
the live GCD state, plus one dead `cmp` wire that the fused path never used.
This commit runs the comparator on borrowed carries taken from the part of
the compressed transcript log that has not been written yet, and drops the
dead wire. The Toffoli count is unchanged.

With the comparator out of the way, the apply add's chunk split moves from
bit 99 to 116, freeing 2 × 17 = 34 qubits. The peak falls to 1466, where the
GCD body itself binds. The only cost is the wider exact boundary compare:
17 × 2 × 399 = 13,566 Toffoli, about 400 Toffoli per qubit.

## What changed and why it saves qubits

All changes are in `src/point_add/mod.rs`.

1. **`DIALOG_GCD_BRANCH_BITS_HOST_COMPARATOR=1`**: a hosted branch comparator.
   - In each transcript step
     (`emit_dialog_gcd_compressed_sidecar_tobitvector_steps_block_lifecycle`
     and its `_reverse_` twin), the fused branch-bit path writes
     `b0_and_b1 ^= b0 AND (u > v)` with a top-`compare_bits` comparator,
     `dialog_gcd_ccx_cmp_gt_truncated_into_width`. That calls
     `ccx_cmp_lt_into_fast`, which allocates `c_in` plus `n` carry wires
     (`n = compare_bits`, up to 59) and clears them by measurement.
   - New `dialog_gcd_ccx_cmp_gt_truncated_into_width_hosted` takes an optional
     borrowed slice. If the slice has at least `n + 1` wires, it calls the new
     `ccx_cmp_lt_into_fast_borrowed_carries`, which emits the same gate
     sequence on the borrowed `c_in` and `carries` and returns them to |0⟩
     through its `hmr` + `cz_if` sweep. If the slice is too short, it falls
     back to the self-allocating comparator.
   - The slice is `dialog_gcd_compressed_sidecar_future_carry_slice(compressed_log, step, active_width)`:
     the compressed-log blocks after the current 3-step block. In the forward
     pass they have not been written yet, so they are |0⟩. The step's
     controlled subtract already borrowed the same slice for its own carries,
     so the call is moved up from the subtract to before the branch bits.
   - **Dead wire removed.** The base allocated `let cmp = b.alloc_qubit()` at
     the top of every step and freed it at the end. The fused path never
     touched it, but it was still live at the branch-bit instant. The
     allocation now happens only in the non-fused branch.
   - Together these take the branch-bit phases well below the apply phases,
     per the author's comment. See
     [venting-and-wire-loans](../concepts/venting-and-wire-loans.md).
2. **`DIALOG_GCD_APPLY_CHUNKED_F_CUT`: 99 → 116.**
   - The apply pass's controlled add and subtract split the 257-bit
     accumulator at `F_CUT`. The upper chunk holds about 2 × (256 − F_CUT)
     scratch qubits, so 17 more bits in the lower chunk free 34 qubits. See
     [`40574d3`](40574d3.md).
   - The author's comment says 116 is the smallest cut at which the apply
     phases meet the next floor, the `materialized_*_body` GCD-body tier at
     1466. Beyond it the peak stays at 1466 and Toffoli keeps rising. See
     [peak-qubits-and-budgets](../concepts/peak-qubits-and-budgets.md).
   - Cost: the exact compare that clears the lower chunk's carry is 17 bits
     wider, once in the add and once in the subtract per step, over 399 steps:
     17 × 2 × 399 = 13,566 Toffoli. That is exactly the measured change, so
     the hosted comparator is Toffoli-neutral.
3. **Reroll pair: `DIALOG_REROLL` 15 → 16, `DIALOG_POST_SUB_REROLL` 25 → 0.**
   Identity `X;X` counts that re-draw the 9,024 test inputs without changing the
   circuit (see [`ecbf87b`](ecbf87b.md)).

## Why it is still correct, and what it risks

Both levers are exact. The hosted comparator computes the same truncated
`u > v` as before, so its accuracy is unchanged. Its borrowed wires must be
|0⟩ on entry, and they are returned to |0⟩ by the measured uncompute. If the
future-log slice were ever not clean (for example in the reverse pass, where
the borrowed region must already have been cleared), the result would be
wrong. That would show up as classical mismatches or as phase or ancilla
garbage. The run shows none. The chunk split is exact at any cut.

Only the test set changes. With the reroll pair (16, 0), all existing
approximations are right on the new draw: 9,024 of 9,024 shots pass with
0 classical, 0 phase and 0 ancilla failures. See
[nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

The main lever reuses an idle, clean region (the unwritten transcript log) as
the comparator's scratch instead of allocating new wires. That is
scratch/ancilla reuse. The F_CUT move is the usual chunk rebalance that turns
the freed headroom into a lower peak.
