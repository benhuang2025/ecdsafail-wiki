## Summary

In each divstep, the jump-GCD walk does a controlled `v −= u`. This add works
mod 2^n and gives the caller no carry-out. It is built as a chain of chunks,
and each chunk's carry-out feeds the next chunk's carry-in. The last chunk
still computed a carry-out, which nothing read. The adder then paid a
compute-AND, a vent and a capped measured erase just to clear it again. This
commit stops producing that carry. It is an exact, source-level removal, and it
also takes about 95,000 ops out of the stream (9,057,301 → 8,962,060).

Because the stream changed, the strip was re-mined. It is still priced as the
union of failing inputs at λ budget 4.0. The admission is now "true greedy":
the marginal coverage of the remaining candidates is re-evaluated after every
admission. The new table has 11,110 deletions and 3,302 downgrades, fewer than
the base's 17,278 keys, because the stream it is mined on is different and
smaller. The note does not split the saving between the two levers. Together:
−1,489 average Toffoli at the same 1154 qubits.

## What changed and why it saves Toffoli

1. **`src/point_add/trailmix_ludicrous/gidney.rs`, `controlled_hybrid_add_varchunk_gated_refs()`.**
   - This is the chunked controlled adder that `gcd.rs::controlled_add_active`
     reaches through `controlled_hybrid_add_capped_branch`. With the default
     `TLM_GCD_RESELECT_LAYOUT=1` that function ignores the schedule's branch and
     calls `controlled_hybrid_add_knob_capped_refs`, which picks this adder
     whenever its cost model beats the adaptive one. It is used for the walk's
     controlled add or subtract of `u` into `v`.
   - Chunk `j` reads only `carries[j − 1]`. On the `direct` path
     (`TLM_DIRECT_VARCHUNK=1`, set in `mod.rs`), the last chunk is now built with
     `cout = None`. `controlled_clean_add_threaded` then uses `n_inner = s − 1`,
     and the top bit takes its no-carry branch. The forward CCX, the boundary
     CCX and the vent for that bit all disappear. The compute-AND and its
     measured uncompute go away as a pair.
   - The erase loop now runs over the carries that were actually produced
     (`carries.len()`). So the last chunk's `controlled_erase_carry_gated_capped`
     is gone as well. That erase was an `hmr` plus a phase-conditioned compare
     over up to `PAD = 20` top bits, run on about half the shots.
   - The legacy vented path still needs a carry per chunk and is unchanged.
   - Why it is exact: the add is mod 2^n, so its top sum bit is `a ⊕ b ⊕ c_in`
     whether or not the carry-out is formed. See
     [adders-and-carries](../concepts/adders-and-carries.md) and
     [measurement-uncompute](../concepts/measurement-uncompute.md).
   - Where it applies: every divstep that takes this path, in all four GCD
     walks. See [trailmix-jump-gcd](../concepts/trailmix-jump-gcd.md).
2. **`src/point_add/deep_strip_keys.rs`, re-mined.**
   - The header: "UNION max-coverage admission, TRUE GREEDY v4
     randomized-order-swept". Ranking used a 320M-pair census (seed 20260803),
     pricing an independent 320M-pair census (seed 314159265), and events came
     from 32M pairs. Pre-strip the stream has 1,353,338 CCX+CCZ. Risk is
     3.999888 against a budget of 4.000.
   - `DEAD_KEYS` 13,056 → 11,110 and `DOWNGRADE_KEYS` 4,222 → 3,302. The build
     logs "11,110/11,110 dead removed, 3,302/3,302 downgraded, 0 stale keys".
   - The rule differs from [`ed4b529`](ed4b529.md)'s. ed4b529 priced union
     coverage once, against the empty set. Here the marginal new-failure count
     of each remaining candidate is updated after each admission. See
     [dead-gate-strip](../concepts/dead-gate-strip.md).
3. **`src/point_add/mod.rs`:** tail nonce `SUB4_TAIL_NONCE` 200321420125 →
   1001707183656.

## Why it is still correct, and what it risks

- **The carry drop is exact.** The removed value was never read, so no output or
  phase changes on any input. It also removes a capped compare that could, on
  rare ties, mis-repair the phase. If anything that lowers the risk.
- **The strip is empirical**, at the same union-priced budget of 4.0 as the base.
- **On the nonce:** the note says the average executed Toffoli varies over a band
  about 13,000 wide across tail nonces, and that this nonce sits toward the
  unfavourable end. It was the first clean nonce found: 1 in 5,136 candidates
  from a classical-only GPU prefilter, then confirmed on the trusted CPU
  evaluator.
- The shipped nonce `1001707183656` draws a clean set: 9,024 of 9,024 shots, 0
  classical, 0 phase and 0 ancilla failures. The note reproduced it on fresh
  trees with no environment set. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

Both levers remove gates: an unread carry at the source level (exact), and a
re-selected census strip. That is dead-gate/self-inverse removal.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout ed4b529 -- src/point_add`.
   - The git parent `6909d15` is a repository merge commit ("Merge pull request
     #17 … blacksmith-benchmark-action"). Its `src/point_add` is identical to
     `ed4b529`'s, so either works.
   - `git diff --ignore-cr-at-eol ed4b529 258b25f -- src/point_add` is 5,732 lines
     in 3 files, almost all of it the key table.
2. **Copy the generated table from the commit:**
   `git checkout 258b25f -- src/point_add/deep_strip_keys.rs`.
3. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line endings.
   It covers `gidney.rs` and `mod.rs`.
4. **Check the tree.** `git diff --ignore-cr-at-eol 258b25f -- src/point_add`
   should print nothing.
5. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `TLM_*` or
   `SUB4_*` overrides set. Expect:
   - 1154 qubits
   - 1,286,612 average Toffoli (1,286,611.658 before rounding)
   - score 1,484,750,248
   - 0 classical, 0 phase and 0 ancilla failures
6. **Nonce caveat.** The score only reproduces with the nonce `1001707183656` and
   an identical op stream. Any other change needs a new nonce hunt and a strip
   re-mine.
