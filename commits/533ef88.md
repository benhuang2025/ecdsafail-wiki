## Summary

This commit makes no optimization. It only changes the tail nonce in
`src/point_add/mod.rs` (`DIALOG_TAIL_NONCE` default in `build()`) from
1200006462 to 7000001200. The new nonce draws a different clean set of 9,024
test shots, whose average executed Toffoli is 11 lower. The diff touches only
the nonce literal, and the emitted op count is unchanged. For why a nonce
moves the score, see
[nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).
