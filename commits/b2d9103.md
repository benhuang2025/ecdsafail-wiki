## Summary

The point addition runs a fixed sequence of phases on `x` and `y`:
`coord_x_sub`, `coord_y_sub`, `divide`, `coord_add3x`, `square`, `multiply`,
`coord_y_sub_final` and `coord_rsub_final`. Each coordinate add or subtract
ends with its own modular fold, which adds `f = 2^32 + 977` into a low slice of
`f_slice() = 33 + FOLD_GUARD = 58` bits when the 256-bit add wrapped. The
divider's first and last steps on the same registers also fold by `f`: the
walk's round-0 lift and its reverse, and the replay's round 0 and round 1.

This commit fuses each such neighbouring pair into one operation. The two
corrections are selected constants in the same low window, so a single
per-position ladder can add their sum. There are seven sites, controlled by
five new pins (`PP_J_XFUSE`, `PP_J_YFUSE`, `PP_J_AFUSE`, `PP_J_RFUSE` and
`PP_J_SEED1`). Each site removes one truncated ladder of about 58 positions
and adds a few ANDs, which works out to 361 average Toffoli in total, or about
52 per site. Qubits are unchanged. No window, compare width or round count
moves.

## What changed and why it saves Toffoli

Most of the new code is in a new file, `src/point_add/j_fuse.rs` (379 lines).
The hooks are in `classical.rs`, `pingpong.rs` and `build_point_add()` in
`mod.rs`. `builder.rs` gains `phase_name()`, so that `round0_reverse` can tell
which traversal it is in. Background on the fold is in
[modular-fold](../concepts/modular-fold.md).

### 1. `PP_J_YFUSE`, divide side: `coord_y_sub` + replay round 0 → `y ← (y − oy)/2`

- **Before:**
  - `coord_sub` ran `mod_sub_vented`: a ripple, then a fold of the borrow by
    `f` (a 58-bit ladder), then an erase compare.
  - Later, the divide replay's round 0, `mod_halve_pm(y)`, subtracted
    `parity·f` over 58 bits and rotated down.
- **After:** `classical::coord_sub_halve` calls `j_fuse::mod_sub_halve`.
  - After the ripple, `y` holds `D = y − oy + c·2^256`, where `c` is the
    borrow. The value mod p is `s = D − c·f`, and its parity is
    `par = D0 XOR c`.
  - Halving needs `s − par·f`. So one ladder subtracts `k·f` with
    `k = c + par ∈ {0, 1, 2}`. The ladder is `f_slice + 1` bits wide, because
    `2f` is one bit wider than `f`.
  - It needs one CCX for `k == 2` (`b2 = c AND par`), which is then measured
    out (`hmr` plus `cz_if`).
  - `c` is erased by the usual top-bit compare, `ERASE_COMPARE = 24` bits.
    Then the register rotates down, and `par` lands on the top wire as in
    `finish_halving`.
- `replay_halving_round` skips round 0 when YFUSE is on.

### 2. `PP_J_YFUSE`, multiply side: replay round 0 + `coord_y_sub_final` → `y ← 2y − oy`

- **Before:** the multiply replay's round 0, `mod_double_pm`, rotated up and
  folded the overflow `o` by `f`. Then `coord_sub` subtracted `oy` with its own
  fold.
- **After:** `classical::coord_double_sub` calls `j_fuse::mod_double_sub`.
  - It rotates up with `o` on its own wire, then subtracts `oy` with borrow
    `c`.
  - The result needs `(c − o)·f`, which is one `add_f_window` of `f_slice`
    bits controlled by `o XOR c`, inside a complement sandwich on `o`.
  - `o XOR c` is the parity of `r + oy`, so it is erased with CX gates. `c` is
    erased by the same 24-bit top compare.
- `replay_doubling_round` skips round 0 when YFUSE is on.

### 3. `PP_J_XFUSE`: `coord_x_sub` + the divide walk's round-0 lift

- **Before:**
  - `coord_sub(x, ox)` folded its borrow.
  - Then the divide's `round0_forward` made `x` odd with a lift. The lift adds
    one selected constant from the arms {f, h+1, h, 0} (`h = (f−1)/2`) over an
    `f_slice` ladder (`round0_correction`).
- **After:**
  - `coord_sub_keep` (`mod_sub_keep_borrow`) stops after the ripple. It
    leaves `D = x − ox mod 2^256` in `x` and the borrow `c` live, and stashes
    `(c, ox)` in `X_CARRY`. The true denominator is `a = D − c·f`.
  - The divide's `round0_forward` finds the stash and calls the new
    `round0_forward_fused`. This computes `a0 = D0 XOR c` and
    `a1 = D1 XOR (c AND NOT D0)` (one AND).
  - The new `round0_correction_fused` relabels the four lift arms by `c`. The
    arms are still over the magnitudes {f, h+1, h, 0}, and the ladder is still
    `f_slice` wide. The coordinate fold is gone.
  - `erase_x_carry` then erases `c` with the same predicate `mod_sub_vented`
    used: `[~D_top < ox_top]` on the top 24 bits. It loads `ox`'s top bits into
    24 temporary qubits for this. That happens in round 0, far from the peak.

### 4. `PP_J_AFUSE` and `PP_J_RFUSE`: walk-back round 0 + the next coordinate op

- **Before:**
  - `round0_reverse`, the walk-back's last step, shifted `x` back up and added
    a selected `{f, 2f}` correction over an `f_slice + 1` ladder.
  - The next coordinate op then folded its own carry over `f_slice`. That op is
    `coord_add3x` after the divide and `coord_rsub_final` after the multiply.
- **After:**
  - `round0_reverse` checks `defer_r0_reverse(phase_name())`. That is true in
    `pp_div_walkback` with AFUSE and in `pp_mul_walkback` with RFUSE. In those
    cases it only does the shift and sets the three high bits. It then stashes
    `(a0, !a1)` with `stash_r0`.
  - `coord_add3x` and `coord_rsub` call `take_r0()`. If there is a stash, they
    run `mod_add_r0fused` or `mod_rsub_r0fused` instead of `mod_add` or
    `mod_rsub_vented_loaded`.
  - Those functions ripple-add, then add or subtract the selected magnitude
    `(a0 + c)·f` or `(2 − a0 − c)·f`, which is one of {0, f, 2f}. This is one
    `selected_f_or_2f` ladder of `f_slice + 1` bits. It uses one CCX for the
    `2f` arm, measured out.
  - Then `a0` and `!a1` are erased. Each one is recomputed from the low two
    bits of the result using `f ≡ 1 (mod 4)`. The second bit needs one
    majority AND (`xor_low_maj`, one CCX, measured out). Finally the carry is
    erased by the 24-bit top compare.

### 5. `PP_J_SEED1`: replay round 1's seed + its halving or doubling

- **Before:**
  - The divide's round 1 seeded `t ← ±s`. It did this with CX gates plus a
    conditional subtract of `f − 1` over `f_slice` (`seed_round_one`).
  - Then `mod_halve_pm` subtracted `par·f` over `f_slice`.
- **After:** `j_seed_halve` does both in one ladder.
  - It subtracts `M = sign·(f−1) + par·f`, which is one of {0, f−1, f, 2f−1},
    over `f_slice + 1` bits.
  - `par` is the seeded value's bit 0, which is known before either
    correction, because `f − 1` is even.
  - It needs one CCX for `pab = sign AND par`, measured out.
  - `j_seed1_controls` shares one control wire per distinct
    (`f−1`, `f`, `2f−1`) bit pattern.
- The multiply's `j_double_unseed` is the exact inverse shape. It adds
  `o·f + sign·(f−1)` in one ladder, then undoes the seed's CX gates.

### 6. Nonce

## Why it is still correct, and what it risks

- **The algebra is exact.** Each fused ladder adds exactly the sum of the two
  corrections it replaces. The selector bits (`k`, `a0`, `!a1`, `par`, `o XOR c`)
  are erased exactly, either with CX gates or with one measured-out AND (see
  [measurement-uncompute](../concepts/measurement-uncompute.md)).
- **No new approximation is added.** The fused ladders keep the
  `FOLD_GUARD = 25` bits of headroom above their constant, which is the same
  truncation as before. They are `f_slice + 1` wide where the constant can
  reach `2f`. Each site now has one truncated ladder instead of two, so it has
  one dropped-carry chance instead of two. The borrow and carry erasures use
  the same 24-bit top compare on the same bits, because no ladder reaches the
  top 24 bits. See [comparator-and-width-truncation](../concepts/comparator-and-width-truncation.md).
- **One negligible edge.** In `mod_double_sub`, the comment notes that the
  borrow predicate and the top compare's threshold differ only for
  `r + oy ∈ [p, 2^256)`. That is a slice of about 2^-223 of the inputs.
- A wrong fold would give a wrong field element (a classical failure). A wrong
  selector erase would leave phase or ancilla garbage.
- The shipped nonce `28949644005` draws a clean test set: 9,024 of 9,024 shots
  pass, with 0 classical, 0 phase and 0 ancilla failures. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

Every lever merges two adjacent arithmetic operations, each with its own
correction ladder, into one ladder. That is gate/op fusion. The runner-up was
modular-fold strength reduction, but the fold itself is not computed more
cheaply. It is shared across an operation boundary.

+//! subtractions with the replay's round-0 halving / doubling.
+//!
+//! Divide: the replay's round 0 is `y <- y/2 (mod p)` and is the first thing
+//! that touches `y` after `coord_y_sub`. Both are folded into one
+//! `y <- (y - oy)/2 (mod p)`: the subtraction's borrow `c` and the halving's
+//! parity `par` select ONE correction `k*f`, `k = c + par in {0,1,2}`, in a
+//! single per-position ladder one bit wider than `f_slice` (the same shape as
+//! `round0_reverse`).  `par` leaves on the top wire exactly as in
+//! `finish_halving`; `c` is erased with the unchanged top-bit compare.
+//!
+//! Multiply: the replay's round 0 is `y <- 2y (mod p)` and is the last thing
+//! that touches `y` before `coord_y_sub_final`.  Both become one
+//! `y <- 2y - oy (mod p)`: the doubling's overflow `o` and the borrow `c`
+//! select one `(c - o)*f` correction (`o` a complement sandwich around one
+//! `f_slice` fold).  `o ^ c` is the parity of `r + oy`, so it is erased with
+//! CX gates; `c` is `[r + oy >= 2^256]`, the unchanged top-bit compare.

+/// `acc <- (acc - value)/2 (mod p)`.
+pub fn mod_sub_halve(circ: &mut Builder, value: &[QubitId], acc: &[QubitId]) {
+    let n = acc.len();
+    assert_eq!(n, N);
+    assert_eq!(value.len(), n);
+    let before = circ.i35_cost();
+    circ.x_all(acc);
+    let c = circ.alloc_qubit();
+    ripple_add(circ, value, acc, None, Some(c));
+    // acc = ~D with D = y - oy + c*2^256.
+    let a = circ.alloc_qubit();
+    circ.cx(acc[0], a);
+    circ.x(a); // a = D0 = (k odd)
+    let par = circ.alloc_qubit();
+    circ.cx(a, par);
+    circ.cx(c, par); // par = D0 ^ c: parity of s = D - c*f
+    let b2 = circ.alloc_qubit();
+    circ.ccx(c, par, b2); // k == 2
+    let g = circ.alloc_qubit();
+    circ.cx(a, g);
+    circ.cx(b2, g); // k != 0
+    // Position 0: acc0 = ~a, addend a: sum 1, carry 0.
+    circ.cx(a, acc[0]);
+    let width = f_slice() + 1;
+    let fc = f();
+    let controls: Vec<Option<QubitId>> = (1..width)
+        .map(|i| match (fc.bit(i), fc.bit(i - 1)) {
+            (false, false) => None,
+            (true, false) => Some(a),
+            (false, true) => Some(b2),
+            (true, true) => Some(g),
+        })
+        .collect();
+    cadd_const_per_position_trunc(circ, &acc[1..width], &controls);
+    circ.cx(b2, g);
+    circ.cx(a, g);
+    circ.free(g);

+    circ.free_bit(m);
+    circ.free(b2);

+    circ.cx(c, a);

+    circ.free(c);

+        circ.swap(acc[i], acc[i + 1]);
+    }
+    circ.cx(par, acc[n - 1]);
+    circ.cx(acc[n - 1], par);
+    circ.free(par);
+    if trace() {

+    }

+/// `acc <- 2*acc - value (mod p)`.
+pub fn mod_double_sub(circ: &mut Builder, value: &[QubitId], acc: &[QubitId]) {
+    let n = acc.len();
+    assert_eq!(n, N);
+    assert_eq!(value.len(), n);
+    let before = circ.i35_cost();
+    let o = circ.alloc_qubit();
+    circ.swap(acc[n - 1], o);
+    for i in (0..n - 1).rev() {
+        circ.swap(acc[i], acc[i + 1]);
+    }
+    // acc = A = 2y mod 2^256, A0 = 0; o = 2y >> 256.
+    circ.x_all(acc);
+    let c = circ.alloc_qubit();
+    ripple_add(circ, value, acc, None, Some(c));
+    // acc = w = ~D, D = A - oy + c*2^256; 2y - oy == D + (o - c)*f (mod p).
+    // In the complemented frame that is w += (c - o)*f.
+    let width = f_slice();
+    circ.cx(o, c); // c = o ^ c: a correction is due
+    for &q in &acc[..width] {
+        circ.cx(o, q);
+    }
+    add_f_window(circ, c, acc, width, false);
+    for &q in &acc[..width] {
+        circ.cx(o, q);
+    }
+    // r = ~acc satisfies 2y = r + oy + (o - c)*p, so e = o ^ c = r0 ^ oy0,
+    // which is ~acc0 ^ value0.  Wire c holds e; XOR it into o (o becomes the
+    // borrow) and clear wire c with the parity itself.
+    circ.cx(c, o);
+    circ.cx(acc[0], c);
+    circ.x(c);
+    circ.cx(value[0], c);
+    circ.free(c);
+    // o = borrow = [r + oy >= 2^256] = [~r < oy] (threshold p when e = 1:
+    // the two differ only for r + oy in [p, 2^256)).
+    let k = erase_compare();
+    erase_with_compare(circ, o, &acc[n - k..], &value[n - k..], None);
+    circ.free(o);
+    circ.x_all(acc);
+    if trace() {

+    }

+    let pab = circ.alloc_qubit();
+    circ.ccx(sign, par, pab);
+    let width = f_slice() + 1;
+    let fm1 = f_minus_one();
+    let two_f_m1 = f().wrapping_add(f_minus_one());
+    let (controls, wires) = j_seed1_controls(circ, sign, par, pab, fm1, f(), two_f_m1, width);
+    // Subtract M = sign*(f-1) + par*f in the complement frame. Position 0:
+    // ~T0_0 = !par plus M_0 = par is 1 with no carry.
+    circ.x_all(&target[..width]);
+    circ.cx(par, target[0]);
+    cadd_const_per_position_trunc(circ, &target[1..width], &controls);
+    circ.x_all(&target[..width]);
+    j_seed1_release(circ, sign, par, pab, wires);
+    let m = circ.alloc_bit();
+    circ.hmr(pab, m);
+    circ.cz_if(sign, par, m);
+    circ.free_bit(m);
+    circ.free(pab);
+    finish_halving(circ, target, par);
+    if env_flag("PP_J_TRACE") {
+        eprintln!("J_SEEDHALVE {}", circ.i35_cost() - before);
+    }
+}
+
+/// Exact inverse shape of [`j_seed_halve`]: `target <- 2*target (mod p)`, then
+/// the seed's conditional negation undone, leaving `target` clear.
+fn j_double_unseed(circ: &mut Builder, sign: QubitId, source: &[QubitId], target: &[QubitId]) {
+    let before = circ.i35_cost();
+    let o = start_doubling(circ, target);
+    // target = 2z mod 2^256 with bit 0 clear; add M = o*f + sign*(f-1).
+    let pab = circ.alloc_qubit();
+    circ.ccx(o, sign, pab);
+    let width = f_slice() + 1;
+    let two_f_m1 = f().wrapping_add(f_minus_one());
+    let (controls, wires) = j_seed1_controls(circ, o, sign, pab, f(), f_minus_one(), two_f_m1, width);
+    // Position 0: 0 + M_0 = o, no carry.
+    circ.cx(o, target[0]);
+    cadd_const_per_position_trunc(circ, &target[1..width], &controls);
+    j_seed1_release(circ, o, sign, pab, wires);
+    let m = circ.alloc_bit();
+    circ.hmr(pab, m);
+    circ.cz_if(o, sign, m);
+    circ.free_bit(m);
+    circ.free(pab);
+    circ.cx(target[0], o);
+    circ.free(o);
+    for i in (0..N).rev() {
+        circ.cx(sign, target[i]);
+        circ.cx(source[i], target[i]);
+    }
+    if env_flag("PP_J_TRACE") {
+        eprintln!("J_DOUBLEUNSEED {}", circ.i35_cost() - before);
+    }
+}
