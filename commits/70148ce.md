## Summary

Two Skywalk packages had branched from the same tree, `82c849b`:
- dysnasia's sky8 ([`4ea960f`](4ea960f.md)): wider envelopes, `HEO_SPLIT_K` 21,
  per-cell compare shifts, and new SAT rewrite rows;
- TongchenShen-zdxlz's [`800ba12`](800ba12.md): `HEO_MB_SKIP2` and one fewer
  chunk-compare bit in the narrowest band.

This commit puts the two together. Read as an edit of sky8, it does four
things:
1. It adds 800ba12's two levers. Skipping the multiply batch's route at
   t = R − 2 removes a 256-bit controlled swap, and the chunk shape loses one
   more bit below walk width 25.
2. It shrinks sky8's `GO_CELLB` sell from division ticks 150–155 to 153–155,
   which buys a little λ back.
3. It switches the SAT rewrite rows off, because their op indices no longer
   match the merged stream. That gives back about 67 Toffoli.
4. It re-hunts the nonce.

The net is −355 Toffoli against sky8 and −76 against 800ba12, at 1174 qubits.

## What changed and why it saves Toffoli

All circuit changes are in `install_skywalk_submission_recipe()` and `build()`,
`src/point_add/mod.rs`:

1. **`HEO_MB_SKIP2 = 1`** (new pin, from 800ba12).
   - In the multiply leg's trailing batch (`heo_carry.rs`, the loop
     `for t in (k.r2m..r).rev()`), the payload route at `t + 2 == r` is
     skipped: `if !(k.mb_skip2 && t + 2 == r) { route(c, s, sig, &del) }`.
   - The route is a controlled swap of the 256-bit `Sig` / `Del` pair on the
     tape bit `s`, so it costs about 256 CCX.
   - The code comment says the route is the identity there except on walks
     that park exactly at tick R. It mirrors the division leg's `HEO_DB_SKIP2`,
     which was already on. See [`800ba12`](800ba12.md) and
     [dead-gate-strip](../concepts/dead-gate-strip.md).
2. **`HEO_PIN_PP_CHUNK_SHAPE`: `64:0,38:1,25:-3,0:-4` → `64:0,38:1,25:-3,0:-5`**
   (from 800ba12).
   - `chunk_compare(round)` in `pingpong.rs` adds the offset of the first band
     whose start is at or below `policy_width(round)`. The last band covers
     walk widths below 25.
   - For Skywalk cells, `round` is the proxy round from the fixed proxy
     envelope. Widths below 25 are the cells at ticks 366 to the end.
   - Those cells' chunk-boundary carry erases (hmr plus a phase-conditioned
     top-k compare) get one bit narrower. This is a sell.
3. **`GO_CELLB`: `div:150-155:-1` → `div:153-155:-1`**.
   - `go_cell_delta` adds the delta to dB, the boundary-compare shift of the
     division cell at that tick (see [`4ea960f`](4ea960f.md) for the
     mechanism).
   - Ticks 150–152 get their bit back, which is wider and costs a few Toffoli.
     Ticks 153–155 keep the sell. This is a λ buy-back, to pay for the two
     sells above.
4. **SAT rewrite rows switched off.** The whole `SKY_REWRITE` block in
   `build()` is replaced by a comment: "Existing Sky8 rewrite rows are tied to
   its original op stream. This hybrid keeps the original CCX until new
   reachable-state proofs exist."
   - The rows are keyed to op indices. The loader only allows one rigid
     shift for all of them, and both changes above move ops locally, so the
     sky8 rows would no longer match.
   - Each row had removed one Toffoli that runs on every shot, so dropping all
     67 costs about 67 Toffoli.
   - `sky8_p7f_rewrite.txt` stays in the tree, unused.
5. **Tail nonce**: `TAIL_NONCE` goes from 8000042289598 to 281300476413435.

The commit also adds back the sky5 envelope files `sky5_env_div_gN.d.35.txt`
and `sky5_env_mul_gN.m.35.txt` (from 800ba12's tree). Nothing reads them:
`heo.rs` still compiles in the sky8 `iA.100` envelopes.

Rough accounting (my estimate; the benchmark gives no per-lever split):
- 800ba12 was −375 against sky5 after dropping 57 rows. If MB_SKIP2 saves
  the full 256, the shape bit is worth about 175.
- Here, MB_SKIP2 plus the shape is about −430, dropping 67 rows is about
  +67, and the `GO_CELLB` buy-back costs a few Toffoli.
- That is consistent with the measured −355.

## Why it is still correct, and what it risks

- **MB_SKIP2** is λ-priced. On a walk that parks exactly at tick R, the
  skipped swap was needed, and the payload comes out wrong. That shows up as a
  **classical** failure.
- **The narrower last chunk band** raises the top-k tie error of those
  boundary erases. A wrong compare leaves a wrong phase, so it shows up as a
  **phase** failure.
- **The GO_CELLB change** only removes error.
- **Dropping the rewrite rows** is exact: the original CCX are kept.
- All of sky8's other levers (the `HEO_SPLIT_K` 21 sell and the envelope,
  `GO_CELLF` and `FOLD_WIDEN` 68 buys) are kept unchanged.
- The shipped nonce `281300476413435` draws a clean island: 0 classical,
  0 phase and 0 ancilla failures. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

Against the frontier it beat (`800ba12`), the new content is sky8's compare
package: `HEO_SPLIT_K`, the per-cell shifts and the envelopes. Together with
the extra chunk-shape bit, that is comparator/width truncation.

The runner-up is dead-gate/self-inverse removal. Measured against sky8 alone,
the largest single piece is `HEO_MB_SKIP2`. That idea is 800ba12's, though,
and it is credited there.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 4ea960f -- src/point_add`.
   - Do not start from the git parent `800ba12`. That is TongchenShen-zdxlz's
     tree, built on sky5.
   - Against the parent, the diff is 950 lines in 7 files. It would look like
     this commit wrote the whole sky8 package: `go_cell_delta` in
     `heo_carry.rs`, the `iA.100` envelope switch in `heo.rs`, the two
     envelope tables, `HEO_SPLIT_K` / `GO_CELLF` / `FOLD_WIDEN`, and the unused
     `sky8_p7f_rewrite.txt`. It would also show the sky5 rewrite table being
     deleted.
   - Against `4ea960f`, `git diff --ignore-cr-at-eol 4ea960f 70148ce -- src/point_add`
     is 831 lines in 3 files. 787 of those lines are the two unused sky5
     envelope files coming back.
2. **Copy the two unused envelope tables from the commit:**
   `git checkout 70148ce -- src/point_add/skywalk_data/sky5_env_div_gN.d.35.txt src/point_add/skywalk_data/sky5_env_mul_gN.m.35.txt`.
   These are sky5's `esw ead` envelopes. Nothing in this build reads them.
3. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line
   endings. It covers `mod.rs`.
4. **Check the tree.** `git diff --ignore-cr-at-eol 70148ce -- src/point_add`
   should print nothing.
5. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh`. `build()` clears
   the process environment and then installs the pinned recipe, so `HEO_*`,
   `GO_*`, `SKY_*`, `PP_*` and `SUB4_*` overrides have no effect. Do not set
   them anyway. Expect:
   - 1174 qubits
   - 945,473 average Toffoli (rounded)
   - score 1,109,985,302
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `281300476413435` and an identical op
stream. Any other change needs a new nonce hunt.
