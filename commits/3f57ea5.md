## Summary

This commit makes no optimization. It only changes the tail nonce in
`src/point_add/mod.rs` (`SUB4_PINGPONG_TAIL_NONCE` default in `build()`) from
660000097677 to 79297. The new nonce draws a different clean set of 9,024 test
shots, whose average executed Toffoli is 2 lower. Ignoring line endings, the
diff touches only that literal; the raw diff is much larger only because six
files under `src/point_add`, `mod.rs` among them, switched line endings. For
why a nonce moves the score, see
[nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

939,024 average Toffoli and 0 / 0 / 0 failures.
