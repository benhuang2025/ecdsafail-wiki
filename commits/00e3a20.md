## Summary

This continues [`541bd85`](541bd85.md). Each step of the dialog GCD (see
[`cddd5df`](cddd5df.md)) decides whether to swap `u` and `v` from a compare of
only the top `DIALOG_GCD_COMPARE_BITS` bits of the live slices. This commit
lowers the window from 74 to 72 bits, which saves 10,016 average Toffoli at the
same 1698 qubits. The reroll count stays at 2. The new op stream happens to
draw a clean test set with it.

## What changed and why it saves Toffoli

- **`src/point_add/mod.rs`, `configure_ecdsafail_submission_route()`:
  `DIALOG_GCD_COMPARE_BITS` 74 → 72.**
  - The compare is `cmp_lt_into` on the top `k = min(72, w(s))` bits of
    step `s`'s active width `w(s)`. It costs 2 Toffoli per bit, and it is
    computed and uncomputed in each step, in each of the four GCD passes per
    shot.
  - With the margin-37 width schedule, the sum over the 399 steps of
    `min(k, w(s))` falls from 26,816 to 26,190. 16 × 626 = 10,016, exactly
    the measured saving.

## Why it is still correct, and what it risks

- This is a truncation. If the two slices agree on their top 72 bits, the swap
  decision can be wrong, `v −= u` goes negative, and the GCD does not finish
  at `(1, 0)`. A failure would show as a classical mismatch with ancilla and
  phase garbage.
- The author reports that 72 is the lowest clean value at this reroll: 71
  fails. The full benchmark at 72 gives 0 classical, 0 phase and 0 ancilla
  failures over 9,024 shots. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

A comparator window is narrowed, so this is comparator/width truncation.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 541bd85 -- src/point_add`. The base is the git parent.
   `git diff --ignore-cr-at-eol 541bd85 00e3a20 -- src/point_add` is 2 lines
   in 1 file.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line
   endings. It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 00e3a20 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no
   `DIALOG_GCD_*` or `ROUND*` environment variables set. Expect:
   - 1698 qubits
   - 2,432,870 average Toffoli (rounded)
   - score 4,131,013,260
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with `DIALOG_GCD_REROLL = 2` and an identical op
stream. Any other change needs a new reroll search.
