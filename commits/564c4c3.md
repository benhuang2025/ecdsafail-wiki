## Summary

This is the third step of the dialog-GCD compare tightening, after
[`541bd85`](541bd85.md) (75 → 74) and [`00e3a20`](00e3a20.md) (74 → 72). Each
GCD step decides whether to swap `u` and `v` from a compare of only the top
`DIALOG_GCD_COMPARE_BITS` bits. This commit lowers the window from 72 to 68,
which saves 20,320 average Toffoli at the same 1698 qubits. The reroll count
stays at 2.

## What changed and why it saves Toffoli

- **`src/point_add/mod.rs`, `configure_ecdsafail_submission_route()`:
  `DIALOG_GCD_COMPARE_BITS` 72 → 68.**
  - The compare is `cmp_lt_into` on the top `min(k, w(s))` bits of each
    step's active width. It costs 2 Toffoli per bit, and it is computed and
    uncomputed in each of the 399 steps of all four GCD passes. That is 16
    Toffoli per bit per step for each shot.
  - The sum over steps of `min(k, w(s))` falls from 26,190 to 24,920.
    16 × 1,270 = 20,320, exactly the measured saving.
  - See [`cddd5df`](cddd5df.md) for the step structure.

## Why it is still correct, and what it risks

- A narrower compare makes a wrong swap decision more likely when `u` and `v`
  agree on their top bits. The walk then goes negative and does not finish at
  `(1, 0)`, which shows as a classical mismatch with garbage.
- The author's sweep at this reroll found 67, 69 and 70 failing, with 1 to 4
  classical mismatches on the 9,024-shot set. 68 passes. Failure is not
  monotone in the width, because every change of the width also changes the
  op stream and therefore the drawn inputs.
- At 68, the full benchmark gives 0 classical, 0 phase and 0 ancilla failures.
  See [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

A comparator window is narrowed, so this is comparator/width truncation.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 00e3a20 -- src/point_add`. The base is the git parent.
   `git diff --ignore-cr-at-eol 00e3a20 564c4c3 -- src/point_add` is 2 lines
   in 1 file.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line
   endings. It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 564c4c3 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no
   `DIALOG_GCD_*` or `ROUND*` environment variables set. Expect:
   - 1698 qubits
   - 2,412,550 average Toffoli (rounded)
   - score 4,096,509,900
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with `DIALOG_GCD_REROLL = 2` and an identical op
stream. Any other change needs a new reroll search.
