## Summary

The peak sits in the ping-pong replay and walk cells, where the tape, both
coefficient registers, the walk registers and a carry ladder are all live.
This commit removes temporaries from those cells without removing any
arithmetic:

- an adder's last carry is written straight into the top output bit;
- the fold's operand is held in one of its own selector wires;
- Clifford-derived flags (`plus_f`, `sign_and_parity`, `odd_correction`,
  `sign_xor_add`) are parked in a live wire or cleared and rebuilt around the
  fold;
- comparator top stages become pure phase gates, so their last carry wire and
  Toffoli disappear.

With the cells narrower, the peak budgets go from 1273 to 1267. In the square,
the Karatsuba sum `a + b` now lives in the input's own high half, which frees
128 wires there. That room is spent on exact full-width square adds.

Several Toffoli knobs move the other way, to buy back Lambda (the expected
number of failing test shots) and to absorb the tighter ladders: a wider chunk
compare, one more multiply round, the width repair switched back on, and a
smaller ladder budget. Net: −6 qubits for +2,372 Toffoli. At this size one
qubit is worth about 720 Toffoli of score (916,615 / 1267), so the trade pays.

## What changed and why it saves qubits

### 1. Builder: `release_clean` (`src/point_add/mod.rs`)

`B::free(q)` is now `r(q)` followed by the new `B::release_clean(q)`.
`release_clean` returns a wire to the free pool **without** emitting a reset.
The caller must already have restored the wire to |0⟩ with ordinary gates. It
is used for `odd_correction` below. See
[venting-and-wire-loans](../concepts/venting-and-wire-loans.md).

### 2. Last carry written into the output (`pingpong_div.rs`)

A ripple's final carry is only ever XORed into the top sum bit. The new
terminal stage at position `n−2` writes `ccx(source[i], target[i], target[n−1])`
plus CX fix-ups directly, instead of computing a carry wire and CXing it in.
The Toffoli count is unchanged, one carry wire disappears, and so does its
measured erasure. See [adders-and-carries](../concepts/adders-and-carries.md).

- `signed_add_wrapping_sigma` (walk add): `alloc_qubits(n − 1)` → `n − 2`.
- `signed_add_wrapping_sigma_split` (walk add split at `low`): the high chunk
  keeps `high − 1` carries instead of `high`.
- `fused_fold_maskfree` (the replay fold): `num_carries` goes from
  `width − 2` to `width − 3`.

### 3. Temporaries parked in live wires (`pingpong_div.rs`)

None of these change any Toffoli. They only shorten lifetimes.

- **`fused_fold_maskfree`**: the `operand` wire, which held the XOR of the
  position's selectors, is gone. The XOR is accumulated into `selectors[0]`
  itself and undone before the next position.
- **`signed_mod_add_pm_halve_fused`** (divide replay cell):
  - `plus_f = parity ⊕ sign ⊕ minus_f` is held **in the `parity` wire** across
    the fold, then parity is restored with two CXs.
  - `sign_and_parity` equals `parity ⊕ not_sign_and_parity`, so it is cleared
    with two CXs and freed before the fold. It is re-allocated and rebuilt
    with two CXs for the `and_uncompute` of `plus_2f`.
  - Two wires fewer across the fold's carry ladder.
- **`signed_mod_double_add_pm_fused`** (multiply replay cell):
  - `plus_f = add_out ⊕ doubled_out ⊕ minus_f` is held in the `add_out` wire.
  - `odd_correction` is cleared after `first_carry` is built and released with
    `release_clean`, then rebuilt for the uncompute.
  - `sign_xor_add` is freed right after `routed` is built and rebuilt for the
    final `and_uncompute`.
  - Three wires fewer across the fold.
- **`mod_halve_pm`** (replay rounds 0 and 1) calls the new
  `csub_nbit_const_direct_trunc_fast_dead_low_ctrl_low0_host` in
  `arith/const_arith.rs`. `parity` is an exact copy of `target[0]`, so applying
  the bit-0 subtraction first leaves `target[0]` at |0⟩, and that wire then
  hosts the final borrow. One borrow wire fewer.

### 4. Phase-only comparator tops

Each of these comparators runs as a phase oracle: it computes a borrow
chain, applies a phase from the top borrow, and uncomputes. The top borrow is
`maj(q, a, x) = q·a ⊕ q·x ⊕ a·x`, so its phase `(−1)^maj` is exactly
`CZ(q,a)·CZ(q,x)·CZ(a,x)`. The last CCX and its wire are never built. See
[measurement-uncompute](../concepts/measurement-uncompute.md).

- **`cmp_lt_phase_conditioned`** (`arith/compare.rs`). This is the truncated
  compare that repairs the phase of each replay chunk-boundary carry after it
  is measured out (`add_chunked_measured`).
  - Old: one clean `c_in` wire plus `n` carries, and `n` CCX.
  - New: `n − 1` carries and `n − 1` CCX. `u[0]` itself serves as the first
    control, since after the first CX it holds the value the old code copied
    into `c_in`.
  - Two wires and one Toffoli fewer per call. The call sits inside
    `push_condition(phase)`, so the Toffoli only executes on shots where the
    measured bit is 1, about half.
  - `cmp_lt_phase_conditioned_with_cin_borrowed_carries`, used by
    `arith/multiply.rs`, gets the same top.
- **The split walk add's boundary compare** (`signed_add_wrapping_sigma_split`).
  - Old: `cmp_lt_phase_conditioned` over `target[..low]` / `source[..low]`.
  - New: an inline compare over bits `2..low`, with `source[1]` as the live
    carry-in and the 3-CZ top. On the forward walk `target[0] = 1`, and on the
    walk-back `target[1:0] = 10`. In both cases `source[0] = 1`, so the borrow
    out of the low two positions is exactly `source[1]`.
  - The new unit test `sigma_split_low_two_compare_reduction_is_exact` checks
    this identity for widths 3 to 10.
  - Three CCX and four wires fewer per split.
- **Trailmix modular add/sub** (`trailmix_ludicrous/arith.rs` and
  `comparator.rs`). `controlled_lt_msbs_conditional` and
  `controlled_add_carry_msbs_conditional` called
  `compare_geq_chunked_middle` into an `lt_flag` wire and applied Z or CZ to
  it. They now call the new `compare_geq_chunked_middle_complement_phase`. It
  applies the omitted final carry `ci ⊕ (a & b)` as a phase directly: Z and CZ
  when uncontrolled, or Z, CZ and one CCZ when controlled. No flag wire is
  used. These helpers serve the `mod_add` / `mod_sub` family that the affine
  shell (`ec_add.rs`) uses.
- **Square overflow repair** (`clear_overflow_phase` in `product_register.rs`):
  same idea. It uses `compare_geq_cin_middle` with a callback that applies
  `neg`, `Z(carry_in)` and `CZ(a,b)`, so the `flag` wire is gone.

### 5. The square (`trailmix_ludicrous/square/product_register.rs`)

- **Karatsuba sum in place.** `square_sub` used to build `sum = y_lo + y_hi`
  in a fresh 129-wire register at the start. Now it adds `y_lo` into
  `y[h..]` plus one new carry wire, **after** branches A and B, and subtracts
  it back after branch C. That frees 128 wires during the square, and the sum
  is no longer live during branches A and B. See
  [squaring-and-karatsuba](../concepts/squaring-and-karatsuba.md).
- **`SQUARE_CHUNK_MIN`: 200 → `usize::MAX`**, also pinned by env. Every
  square add now uses the exact full-width ladder (`hybrid_add_adaptive`)
  instead of the chunked adder with measured, truncated boundary repairs. The
  wider ladders fit in the 128 freed wires. This removes the boundary
  repairs' Toffoli and their Lambda.
- **`tri_corr`.** The correction "subtract `x`, then subtract
  `~(x mod 2^(m−1))` at offset `m`" is now one full-width subtraction of the
  concatenation `x ‖ ~x_low`, because the two operands occupy disjoint bit
  ranges. The complemented copy is built with CX and X gates. This removes
  one (m−1)-Toffoli ladder per correction.
- **`apply_shifted_full_term`** (new). `apply_shift_full` uses it, and so
  does `apply_shift_half` for a 256-bit product. `apply_shift_half` uses an
  inline copy of the same rotation for the 258-bit cross-square.
  - For `value·2^shift mod p`, the wrapped high limb contributes `f·high`.
  - Old: `mod_add_top` of the low part, then `apply_f` of the high limb with
    all five NAF terms of `f`.
  - New: rotate the high limb into the vacated low positions, so its unit
    term rides in the main `mod_add_top`. Only the other four NAF terms are
    added separately (`apply_f_without_unit`).
  - This drops one windowed add per call.

### Where the qubits and Toffoli come from

- **Qubits.** Items 2 to 4 shrink the replay and walk cells' own temporaries
  by several wires at the moment the ladder is live. `PEAK` and `WALK_PEAK`
  are then lowered by 6, so the ladders do not grow back into the freed
  room. The square frees 128 wires and spends them on full-width ladders, so
  it stays under the new cap.
- **Toffoli.** Several pieces save Toffoli: the phase-only tops, the shorter
  split compare, `tri_corr`, the rotated folds, the exact square adds and
  `FOLD_WINDOW_MUL`. Several pieces add Toffoli: `CHUNK_COMPARE` +2 on every
  boundary repair, one more multiply round, the width repair, and more chunks
  under a ladder budget 6 wires smaller. The net is +2,372. The commit gives
  no per-item measurements.

## Why it is still correct, and what it risks

- **Exact.** All the parking, terminal-carry and phase-only changes compute
  the same function:
  - Each parked value is a Clifford function of wires that do not change
    while it is parked.
  - Each phase-only top applies exactly `(−1)^maj`.
  - The split compare's bit-2 start is a proved identity, with a unit test.
  - The in-place sum, `tri_corr` and the rotated fold are exact identities.
  - `SQUARE_CHUNK_MIN = usize::MAX` replaces approximate chunked square adds
    with exact ones, which lowers Lambda.
- **Probabilistic.** These knobs change existing approximations:
  - `CHUNK_COMPARE` 22, the extra multiply round and the width repair all
    lower Lambda.
  - `FOLD_WINDOW_MUL` 53 and the smaller ladder budgets (more truncated
    boundary repairs) raise it.
- **How failures would show.**
  - A wrong parked value would be a classical or ancilla failure, and would
    be systematic.
  - A wrong phase-only top would be systematic phase garbage.
  - A truncated repair that misfires is a rare phase failure.
- The shipped nonce draws a clean test set. The code comment says it was
  "verified by the optimized and reference evaluators over all 9,024 shots",
  with 0 classical, 0 phase and 0 ancilla failures. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

All of the score gain comes from qubits (−6), while Toffoli goes up. The
qubits come from hosting temporaries in wires that are already live or
provably restorable: the output's top bit, a selector, `parity`, `add_out`,
`target[0]` and the input's high half. That is scratch/ancilla reuse. The
runner-up was measurement uncompute or gate fusion, for the phase-only
comparator tops, but those mostly save wires here too, and their Toffoli
saving is more than offset by the Lambda knobs.
