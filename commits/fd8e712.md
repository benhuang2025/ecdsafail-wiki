## Summary

The new 1466-qubit frontier [`92a247e`](92a247e.md) was built on `250774e`,
so it lacked two Toffoli cuts that other contestants had already shipped on
older trees. This commit re-applies both:

- The GCD runs 398 steps instead of 399, the lever of [`7c29f79`](7c29f79.md).
- The branch comparator is capped at 58 bits instead of 59, the lever of
  [`fe29b53`](fe29b53.md) and [`47f30d4`](47f30d4.md).

Dropping the last step saves 2,090 Toffoli here. That is 34 more than in
`7c29f79`, because the frontier's wider apply split, F_CUT = 116, made every
step's boundary compares 2 × 17 bits wider. The comparator cap saves
4 × 238 = 952. Together that is 3,042 Toffoli, with qubits unchanged. A new
reroll pair, (52, 28), draws a clean test set for the combined stream.

## What changed and why it saves Toffoli

All changes are in `configure_ecdsafail_submission_route()` in
`src/point_add/mod.rs`:

1. **`DIALOG_GCD_ACTIVE_ITERATIONS`: 399 → 398.**
   - Every dialog-GCD step loop (`for step in 0..dialog_gcd_active_iterations()`)
     loses its last step. These are the forward and reverse transcript passes
     and both GCD pairs' apply passes.
   - Step 398 has a 2-bit active width, so its cost is mostly the apply pass's
     full-width controlled modular add and subtract on the Bézout registers.
   - `7c29f79` measured 2,056 Toffoli for that step at F_CUT = 99. At 116, each
     of the step's two chunk-boundary compares is 17 bits wider, giving
     2,056 + 34 = 2,090.
   - The compressed log still needs ⌈398/3⌉ = 133 five-qubit blocks, so no
     qubits change.
2. **`DIALOG_GCD_COMPARE_BITS`: 59 → 58.**
   - `dialog_gcd_compare_bits_for_step` returns
     `min(SCHEDULE[step] + 5, active_width, DIALOG_GCD_COMPARE_BITS)`. The cap
     binds on steps 54 to 318, all below 398, so the summed width drops by
     238 bits (20,010 → 19,772).
   - The branch comparator `ccx_cmp_lt_into_fast` costs one Toffoli per bit
     (it is now the hosted variant from `92a247e`, with the same gates). It
     runs four times per step (forward and reverse transcript, both GCD pairs):
     4 × 238 = 952 Toffoli.
3. **Reroll pair: `DIALOG_REROLL` 16 → 52, `DIALOG_POST_SUB_REROLL` 0 → 28.**
   Identity `X;X` counts that re-draw the 9,024 test inputs without changing
   the circuit (see [`ecbf87b`](ecbf87b.md)).

2,090 + 952 = 3,042, the measured change.

## Why it is still correct, and what it risks

Both cuts are probabilistic:

- An input whose GCD needs a 399th step ends with an unfinished transcript,
  and its inverse comes out wrong (a classical failure).
- An input whose `u` and `v` agree on their top 58 active bits at some
  affected step can take the wrong branch. That gives a classical failure, or
  phase or ancilla garbage if the uncompute no longer mirrors the forward
  pass.

Both raise λ. The reroll pair (52, 28) draws a test set with no such input:
9,024 of 9,024 shots pass with 0 classical, 0 phase and 0 ancilla failures.
See [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md) and
[comparator-and-width-truncation](../concepts/comparator-and-width-truncation.md).

## Classification rationale

Most of the saving (2,090 of 3,042) comes from the step count, so
iteration/threshold tuning fits. The comparator cap would be comparator/width
truncation on its own, which is the runner-up.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 92a247e -- src/point_add`. The base is the git parent.
   `git diff --ignore-cr-at-eol 92a247e fd8e712 -- src/point_add` is 14 lines
   in 1 file.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line endings.
   It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol fd8e712 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `DIALOG_*`,
   `KAL_*`, `KARA_*` or `ROUND84_*` environment variables set, because
   `set_default_env` keeps any value already in the environment. Expect:
   - 1466 qubits
   - 1,729,241 average Toffoli (rounded)
   - score 2,535,067,306
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the reroll pair `DIALOG_REROLL=52`,
`DIALOG_POST_SUB_REROLL=28` and an identical op stream. Any other change needs
a new reroll search.
