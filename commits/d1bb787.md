## Summary

This commit changes one constant on the author's own 1278-qubit tree. Outside
the per-round replay cells, the ping-pong divider has a handful of "endpoint"
modular operations: the halvings of replay rounds 0 and 1, the doublings of
multiply rounds 0 and 1, and the two conditional negations that canonicalise
the result in each traversal. Each folds the constant f = 2³² + 977 (or f − 1)
into the low bits with a truncated carry chain whose length is
`highest_set_bit(f) + ENDPOINT_FOLD_WINDOW`. This commit shortens the window
from 28 to 20 positions. Eight such calls run per shot, and 8 fewer
positions in each save 82 average Toffoli. Qubits are unchanged.

## What changed and why it saves Toffoli

1. **`endpoint_fold_window()` default: 28 → 20** in
   `src/point_add/pingpong_div.rs` (`SUB4_PP_ENDPOINT_FOLD_WINDOW`).
   - In this generation the window counts positions **above** the top set
     bit of the folded constant. The comment above the knob says the carry
     chain is `min(n − 2, highest_set_bit(c) + window)` long, so 20 means a
     chain of about 32 + 20 positions instead of 32 + 28.
   - It is passed as the window argument of
     `csub_nbit_const_direct_trunc_fast` / `cadd_nbit_const_direct_trunc_fast`
     in three helpers that run by default:
     - `conditional_mod_negate`, which subtracts f − 1 under `control`: twice
       per traversal, once on each coefficient register.
     - `mod_halve_pm`, which subtracts f when the target is odd, then
       halves: replay rounds 0 and 1 of the divide traversal.
     - `mod_double_pm`, which doubles, then adds f when the shifted-out top
       bit was set: rounds 0 and 1 of the multiply traversal.
     - The unfused fallback `signed_mod_add_pm` also reads it, but it runs
       only under `SUB4_PINGPONG_UNFUSED_INVERSE`.
   - That is 8 calls per shot. Each removed position is one carry of a
     controlled constant adder, about one Toffoli, so 8 positions × 8 calls ≈
     64, against the measured −82 (the controlled chain costs a little more
     than one Toffoli per position). See
     [modular-fold](../concepts/modular-fold.md).
   - These chains are short-lived and are not at the peak, so qubits stay at
     1278.
2. **Tail nonce** (`SUB4_PINGPONG_TAIL_NONCE` default in `build()`,
   `src/point_add/mod.rs`): 660000097677 → 810000185473.

## Why it is still correct, and what it risks

Each fold is approximate. The constant's carry escapes the chain only if it
runs through all 20 window positions above bit 32, about 2^−20 per call. Then
the register is off by 2^(chain length), a wrong field element and a
**classical** failure. With about 8 calls per shot, the added λ is small
(about 8 × 9,024 × 2^−20 ≈ 0.07 failing shots per draw), which is why the
window could drop 8 bits at once. The replay cells' own fold windows are
unchanged. The shipped nonce `810000185473` draws a clean set: 0 classical,
0 phase and 0 ancilla failures. See
[nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

The only circuit change is a shorter fold carry window, which is
fold/carry truncation.

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout f836a70 -- src/point_add`.

   - Against the parent the diff is 211 lines in 4 files. It deletes that
     tree's `cadd/csub_nbit_const_direct_trunc_fast_dead_low` helpers from
     `arith/const_arith.rs` and their call sites, moves `plan()` back from
     r1 292 / r2 608 / peak 1276 to 298 / 613 / 1278, and sets
     `SQUARE_LADDER` back from 246 to 248.
   - Against `f836a70`, `git diff --ignore-cr-at-eol f836a70 d1bb787 -- src/point_add`
     is 4 lines in 2 files.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line
   endings. It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol d1bb787 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `SUB4_*`
   environment variables set. Expect:
   - 1278 qubits
   - 938,944 average Toffoli (rounded)
   - score 1,199,970,432
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `810000185473` and an identical op
stream. Any other change needs a new nonce hunt.
