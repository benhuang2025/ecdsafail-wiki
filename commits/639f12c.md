## Summary

Each dialog-GCD walk step does a controlled subtract (or add) of one work
register into the other. The adder is the "fast" Cuccaro form. Each carry
goes on its own borrowed scratch wire, costs one Toffoli, and is erased by
measurement. That needs `body_len − 1` carry wires on top of the
`body_len` gated-load wires. In the forward walk this scratch is what sets
the 1313-qubit peak.

This commit runs the top 4 carry stages as plain in-place Cuccaro instead:
`MAJ` keeps the carry in the gated source wire itself, and `UMA` undoes it.
That needs no carry wire, but costs one extra Toffoli per stage. The
scratch shrinks by 4 wires, so the peak drops from 1313 to 1309. The
extra cost is 4 Toffoli per walk step, +4,120 in total. The score falls
because 4/1313 = 0.30% fewer qubits outweighs 4,120/1,512,823 = 0.27% more
Toffoli.

## What changed and why it saves qubits

All changes are in `src/point_add/mod.rs`.

1. **New knob `DIALOG_GCD_SELECTED_BODY_GATE_SUFFIX_CARRIES`** (default 0,
   now pinned to 4), read by `dialog_gcd_selected_body_gate_suffix_carries(n)`.
   The value is clamped to `n − 2`, so the folded-out stage-0 carry always
   keeps a borrowed lane.
2. **`cuccaro_add_fast_borrowed_carries_no_cin` and
   `cuccaro_sub_fast_borrowed_carries_no_cin`.** These are the no-carry-in
   adders of the selected walk body (`DIALOG_GCD_SELECTED_BODY_NOCIN=1`).
   With `borrowed = (n − 1) − suffix`:
   - Stages `1..borrowed` are unchanged. Each one writes its carry into
     `carries[i]` with one CCX. The reverse sweep erases it with `hmr` and a
     `cz_if` phase fix, which costs no Toffoli (see
     [measurement-uncompute](../concepts/measurement-uncompute.md)).
   - Stages `borrowed..n−1` are new. The forward sweep uses
     `maj(a[i−1], acc[i], a[i])` (subtract: `inv_uma`), which leaves the
     carry in `a[i]`. The reverse sweep uses `uma(a[i−1], acc[i], a[i])`
     (subtract: `inv_maj`), which writes the sum bit and restores `a[i]`.
     `MAJ` and `UMA` each cost one CCX. So such a stage costs 2 Toffoli
     instead of 1, and needs no carry wire. See
     [adders-and-carries](../concepts/adders-and-carries.md).
   - `a` here is the gated copy of the source register (`ctrl ∧ src`) that
     the body loads into scratch, so overwriting it in place is safe.
     These are the "gated source lanes" of the code comment.
   - The assertion becomes `carries.len() >= borrowed`.
3. **Scratch sizing.** The new helpers are
   `dialog_gcd_selected_body_nocin_carry_need(len) = len − 1 − suffix` and
   `dialog_gcd_selected_body_nocin_scratch_need(len) = len + carry_need`.
   They replace the hard-coded `2·body_len − 1` and `body_len − 1` in three
   places:
   - `dialog_gcd_controlled_sub_selected`
   - `dialog_gcd_controlled_add_selected`
   - `dialog_gcd_build_composite_scratch`, which sizes the composite scratch
     pool of each walk step
   The pool is 4 wires smaller on every step whose body is wide enough.
4. **Pins in `configure_ecdsafail_submission_route()`**: the new knob is set
   to `4`, and `DIALOG_TAIL_NONCE` goes from 45100002269 to 264497.

**Why the peak falls by exactly 4.** The comment says the change "drops the
three tobitvector binders to the round84 floor at 1309q". The forward-walk
(`tobitvector`) phases were the co-binders at 1313, and their peak includes
the full composite scratch. Four fewer carry wires lowers all three at once.
Some other phase, at 1309, then becomes the binder, so a fifth suffix stage
would cost Toffoli without lowering the peak (see
[peak-qubits-and-budgets](../concepts/peak-qubits-and-budgets.md)).

**Toffoli.** 4 extra CCX per walk-step body. The measured +4,120 is
1,030 bodies, about 258 steps × 4 walks (forward and reverse walk of the two
divisions).

## Why it is still correct, and what it risks

The change is exact. In-place Cuccaro and the measured-carry adder compute
the same sum, and both return every scratch wire, and the borrowed `a`
lanes, to their entry value on every input. The Toffoli and qubit counts
do not depend on the input, and λ does not change. The nonce was re-hunted
only because the op stream changed. The new nonce `264497` was screened by
the author's CUDA K=2 classical filter and then confirmed by the trusted
evaluation: 9,024 of 9,024 shots, with 0 classical, 0 phase and 0 ancilla
failures. If the in-place stages were wrong, `a` would not be restored. That
would show up as ancilla garbage, and also as a classical mismatch. See
[nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

The commit moves the top of an adder from one adder form (measured carries
on borrowed wires) to another (in-place MAJ/UMA). That fits fast-adder
reroute. Its purpose is to save qubits, not Toffoli; it actually spends
Toffoli. So Register and Scratch Allocation → scratch/ancilla reuse would
also have been a reasonable label, and arguably a better one.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 76fdaf2 -- src/point_add`. The base is the git
   parent.
   - `git diff --ignore-cr-at-eol 76fdaf2 639f12c -- src/point_add` lists 420
     files. Only `mod.rs` changes in content: 57 insertions and 15
     deletions.
   - All 420 files, including `mod.rs`, also change mode from 100755 to
     100644. Half of them (210) are macOS `._*` AppleDouble files.
   - The patch below covers `mod.rs`, including its mode line. The other mode
     changes do not affect the build, and the check ignores them.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line endings.
3. **Check the tree.** `git diff --ignore-cr-at-eol 639f12c -- src/point_add`
   should show only mode changes, and no content lines.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no
   `KAL_*` or `DIALOG_*` environment variables set. Expect:
   - 1309 qubits
   - 1,516,943 average Toffoli (rounded)
   - score 1,985,678,387
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with `DIALOG_TAIL_NONCE=264497` and an identical
op stream. Any other change needs a new nonce hunt.
