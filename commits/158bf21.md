## Summary

q71b leaves the circuit as built unchanged. It adds 73 rows to the
post-build rewrite table. Each row names one CCX in the q71a op stream whose
target bit, at that point, always equals a parity (XOR) of other live wires.
The CCX is replaced by a chain of CX gates that computes the same parity.

The author found them with a census of live linear spans at every CCX site:

- 72 are ripple-carry carries equal to "the XOR of their operand bits and a
  live sum bit";
- 2 are single-control copies, one of which was already a q71a row.

Each row removes one Toffoli on every shot. By the submission notes, the
16,384-nonce mean fell from 946,018.00 (q71a) to 945,945.06, about −73 T. The
clean nonce lands 68 lower at the same 1171 qubits.

## What changed and why it saves Toffoli

1. **`skywalk_data/q71a_rewrite.txt` (377 rows) → `q71b_rewrite.txt` (450 rows).**
   - All 377 q71a rows are kept with the same op indices, and 73 rows are
     added.
   - A row reads `widx c1 c2 t cst w1,w2,…|-`. The loader in `build()` does
     the following:
     1. It finds the unique global index shift under which every row names
        an unconditioned CCX with those controls and target. Here the shift
        is 0, because the stream is the q71a stream.
     2. It replaces that CCX by `CX(w_i → t)` for each listed wire, plus
        `X(t)` when `cst = 1`.
   - Rows are spliced from the highest index down, so adding rows does not
     move the others.
   - The 73 new rows lie between ops 4,670,856 and 5,208,176, the op range
     where the earlier tables' square rows also sit. 34 have `cst = 0` and 39 have `cst = 1`. Their CX chains have
     1 to 25 terms.
   - See [dead-gate-strip](../concepts/dead-gate-strip.md) for the
     mechanism, and [adders-and-carries](../concepts/adders-and-carries.md)
     for why a ripple carry can collapse to a parity once a sum bit is live.
2. **`mod.rs`.**
   - The `include_str!` switches to `q71b_rewrite.txt`.
   - The q71a block comment and the `SKY_REWRITE` comment are updated to
     "450 rewrite rows … q71a's 377 plus 73 exact ripple-carry rows".
3. **Cleanup.** The two unused tables copied from jackylee0424's `3161bd2`,
   `cap1173_bridge_room_profile_v2.txt` and `q1173_exact_rows.txt`, are
   deleted. Nothing read them.
4. **Tail nonce:** `TAIL_NONCE` goes from 28000421609163 to 29700148580003.

## Why it is still correct, and what it risks

- The author calls the 73 rows exact. On 400 CRN-paired nonces the λ
  difference was "+0.0000 +- 0.0000".
- The build only asserts that each row still names its CCX. It does not
  re-check the linear relation. A wrong row would leave a wrong bit on the
  states where the relation fails, which shows up as a **classical** or
  **phase** failure.
- The other rows are q71a's 377, including its 59 census rows that the
  author measured at 1 fail in 16M shots.
- The submission note gives λ = 19.387 ± 0.032 on 16,384 nonces (est + 2 SE
  19.452), measured on a different nonce range from q71a's 19.333.
- The shipped nonce `29700148580003` draws a clean island: 0 classical,
  0 phase and 0 ancilla failures. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

The saving comes from offline proof that certain CCX targets are linear
functions of live wires, applied by a host-side table. That is the same
kind of change as the earlier SAT-row commits such as
[`0642f52`](0642f52.md): host-derived / classical specialization. The
runner-up was dead-gate/self-inverse removal, but no gate is deleted
outright. Each CCX becomes a CX chain.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 05161d3 -- src/point_add`. The base is the git
   parent. `git diff --ignore-cr-at-eol 05161d3 158bf21 -- src/point_add` is
   235 lines in 4 files: `mod.rs`, the renamed table with 73 added rows, and
   the two deleted tables.
2. **Delete the two unused tables** with the `rm` command under Patch below.
3. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line
   endings.
4. **Check the tree.** `git diff --ignore-cr-at-eol 158bf21 -- src/point_add`
   should print nothing.
5. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh`. `build()` clears
   the process environment and then installs the pinned recipe, so `HEO_*`,
   `GO_*`, `SKY_*`, `PP_*` and `SUB4_*` overrides have no effect. Do not set
   them anyway. Expect:
   - 1171 qubits
   - 945,953 average Toffoli (rounded)
   - score 1,107,710,963
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `29700148580003` and an identical op
stream. [`a1e2b66`](a1e2b66.md) keeps this circuit and only re-rolls the
nonce.
