## Summary

In the dialog-GCD walk, `u` starts as the odd prime `p`, and it is only ever
replaced by `v` when `v` is odd. So bit 0 of `u` is 1 at every step, for every
input. This commit uses that fact in two places in each walk step. The
conditional swap of `u[0]` with `v[0]` only fires when both bits are 1, so it
is skipped. The gated load `gated[0] = ctrl AND u[0]` becomes `gated[0] = ctrl`,
a CX instead of a CCX. Each saves one Toffoli per step, so the saving is
2 × 399 steps × 4 walks = 3,192 Toffoli. Qubits are unchanged. The author
reports that the same fastpath was on an older 1698-qubit line (`73f81cc`) and
had been lost.

## What changed and why it saves Toffoli

Background on the walk step is in [8316db1](8316db1.md):

```
b0 = v[0];  b0_and_b1 = b0 AND (u > v, truncated)
cswap(b0_and_b1, u[..w], v[..w])
if b0: v -= u        # gated = b0 AND u, then v -= gated
v >>= 1
```

Changes, all in `src/point_add/mod.rs`:

- New switch `dialog_gcd_odd_u_lowbit_fastpath_enabled()`
  (`DIALOG_GCD_ODD_U_LOWBIT_FASTPATH`), set to `"1"` in
  `configure_ecdsafail_submission_route()`.
- **Bit-0 swap skipped.** In the six walk variants'
  `cswap(b0_and_b1, u_i, v_i)` loops (raw, compressed-sidecar and
  compressed-block-lifecycle; forward and reverse), lane `i = 0` is skipped
  when the switch is on. Only the block-lifecycle pair runs on the submission
  route. A `cswap` costs one Toffoli.
- **Bit-0 gated load becomes a CX.** In `dialog_gcd_controlled_sub_selected`
  and `dialog_gcd_controlled_add_selected`, the load loop
  `ccx(ctrl, subtrahend[i], gated[i])` becomes `cx(ctrl, gated[0])` for
  `i = 0`. The subtrahend (or addend) is `u`, so `ctrl AND u[0] = ctrl`.
- The clear loop is unchanged. It still runs `hmr(gated[0])` and
  `cz_if(ctrl, u[0], m)`, which is correct because the value is the same.
- Count: 2 Toffoli per step × 399 steps × 4 walks (forward and reverse, in
  both the quotient and the multiply) = 3,192, exactly the measured drop.
- `DIALOG_REROLL` 0 → 9 to find a clean test draw for the new op stream.

## Why it is still correct, and what it risks

This is exact, not a statistical assumption, whatever the commit comment says
about the "reachable verifier support".
- `u` is loaded with `p`, which is odd.
- `u` changes only through the swap. The swap is controlled by
  `b0_and_b1 = v[0] AND (...)`, so it happens only when `v` is odd, and `u`
  becomes that odd value.
- The subtraction and the shift change only `v`.

So `u[0] = 1` at every swap and load, in both the forward walk and the reverse
walk, which retraces the same states. It holds even on inputs where a
truncated comparator picks the wrong branch. With `u[0] = v[0] = 1` whenever
the swap fires, swapping bit 0 is the identity, and `ctrl AND u[0] = ctrl`.

The change adds no failure mode. The reroll was rescanned only because the op
stream changed, which re-draws the test set for the base's existing
approximations. The shipped reroll 9 draws 0 classical, 0 phase and 0 ancilla
failures.

## Classification rationale

The gates are removed because a qubit's value is known in advance (`u[0] = 1`),
which is constant propagation. The census label "host-derived / classical
specialization" fits. A runner-up would be an exact peephole (see
[dead-gate-strip](../concepts/dead-gate-strip.md)). The fact is proved from the
algorithm, not mined from samples.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout b6d6f41 -- src/point_add`. The base is the git
   parent. `git diff --ignore-cr-at-eol b6d6f41 075c0c6 -- src/point_add` is
   57 lines in 1 file.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line endings.
   It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 075c0c6 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no
   `DIALOG_*`, `KAL_*`, `KARA_*` or `ROUND84_*` environment variables set.
   Expect:
   - 1572 qubits
   - 1,746,797 average Toffoli (rounded)
   - score 2,745,964,884
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with `DIALOG_REROLL = 9` and an identical op
stream. Any other change needs a new reroll scan.
