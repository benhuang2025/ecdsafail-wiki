## Summary

This commit makes no optimization. It only changes the tail nonce in
`src/point_add/mod.rs` (`DIALOG_TAIL_NONCE` default in `build()`) from
333000003142 to 888000000775. The new nonce draws a different clean set of
9,024 test shots, whose average executed Toffoli is 20 lower. The diff touches
only nonce literals: the three copies in
`configure_ecdsafail_submission_route()`, which the trailmix `build()` never
calls, also go from 333000003142 to 888000000775. The emitted op count is
unchanged (10,674,109). For why a nonce moves the score, see
[nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Reproduce

From `git checkout 764afda -- src/point_add`, apply the patch below with
`git apply --ignore-whitespace`. `./benchmark.sh` should give 1166 qubits,
1,416,017 average Toffoli and 0 / 0 / 0 failures.
