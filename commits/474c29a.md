## Summary

The trailmix GCD applies each step's decisions to a pair of 256-bit payload
registers. One part of that update is a full-width controlled swap
("apply-cswap") on the step's swap bit, which costs 256 Toffoli. In the last
few of the 261 steps almost every walk has already converged, so the swap bit
is 0 and the swap does nothing.

The base already skipped the apply-cswap in the last 2 steps of the forward
apply and the last 1 step of the inverse apply. This commit skips it in the
last 3 steps of both. That removes 3 more 256-Toffoli swaps, 768 Toffoli in
all, at the price of a few more inputs on which a needed swap is missing. The
commit also puts back the post-strip fanout closure. The net saving is 769
average Toffoli at 1154 qubits.

## What changed and why it saves Toffoli

1. **`TLM_APPLY_FWD_CSWAP_SKIP_LAST`: "2" → "3"**, and
   **`TLM_APPLY_INV_CSWAP_SKIP_LAST`: "1" → "3"**, set with
   `set_default_env` in `src/point_add/mod.rs`. The forward knob is set in two
   places, `configure_q1153_second512_submission_defaults()` (which runs first
   and wins) and `build()`. Both change.
   - The knobs are read in `src/point_add/trailmix_ludicrous/gcd.rs`.
     `apply_fwd_cswap_skip(i)` and `apply_inv_cswap_skip(i)` return true when
     `i + last_n >= ITERS`, which here is `ITERS = 261`.
   - When they return true, `apply_step_forward` and `apply_step_reverse`
     leave out the loop `for j in 0..256 { cswap(swp, x_reg[j], y_reg[j]) }`.
     Each `cswap` is CX, CCX, CX, so one skipped step saves 256 Toffoli on
     every shot.
   - Forward apply (used in the multiply phase): skipped steps go from
     {259, 260} to {258, 259, 260}, one more step, −256 T.
   - Inverse apply (used in the λ division): skipped steps go from {260} to
     {258, 259, 260}, two more steps, −512 T.
   - Why the swap is idle there: the walk swaps only when the subtraction
     bit `b = v[0]` is 1 and `v < u`. Once the walk has converged (`v = 0`),
     `b` is 0 and so is the swap bit. See
     [trailmix-jump-gcd](../concepts/trailmix-jump-gcd.md).
2. **Post-strip fanout closure re-added** in `build()`, `mod.rs`. After
   `apply_deep_strip_identity`, a loop runs
   `single_ccx_fanout::rewrite_first_target_fanout(ops, 96)` until it finds no
   more matches. It merges `CCX(a,b→t); CX(t→u); CCX(a,b→t)` into
   `CX(t→u); CCX(a,b→u)`. This is the closure from `59f3428`, here without
   its pass-count assert, because the comment expects the larger strip to
   expose more than 10 matches. The note measures it at about 8 Toffoli
   (paired over 64 nonces). See
   [dead-gate-strip](../concepts/dead-gate-strip.md).
3. **Tail nonce**: default `SUB4_TAIL_NONCE` 902265393175 → 906027526784.

The two parts add up to about −776 T before island noise; the run measured
−769.

## Why it is still correct, and what it risks

- **The skip is probabilistic.** The walk itself is unchanged: it still
  computes the swap bit at steps 258–260 and swaps `u` and `v` when needed.
  Only the payload misses the swap. A shot is wrong when its walk is still
  running at step 258 or later and swaps there. Then the payload, and so the
  output point, is wrong, which shows up as a classical mismatch. The concept
  page quotes a non-convergence rate of 2.839×10⁻⁴ of inputs at 258 steps,
  which bounds how often a walk is still running that late. So the skip adds
  a small amount to λ.
- **The fanout closure is exact** on every input.
- The commit was built on the author's own `892b03b`, not on the frontier
  `2dabd9d`, so it does not contain `2dabd9d`'s exact MERGE25 product reuse
  (E209). `8e62c01` later combines the two.
- The shipped nonce `906027526784` draws a clean test set: 0 classical,
  0 phase and 0 ancilla failures. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

Almost all of the saving is a threshold knob: how many final steps of the
apply pass may drop the swap, priced by how rarely the walk is still active
there. That is iteration/threshold tuning. The fanout closure is a small
secondary gate fusion.

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 892b03b -- src/point_add`.
   - `git diff --ignore-cr-at-eol 892b03b 474c29a -- src/point_add` is 31
     changed lines in `mod.rs`.
   - Do not start from the git parent `2dabd9d`. Against it the diff is 110
     lines in 2 files, and 79 of them remove jackylee0424's E209 change from
     `trailmix_ludicrous/codec.rs`, which this commit never had.
2. **Apply the patch below** from the repo root with
   `git apply --ignore-whitespace`. The flag lets the patch apply whether the
   files use LF or CRLF line endings. It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 474c29a -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `SUB4_*`
   or `TLM_*` overrides set. The knobs use `set_default_env`, so an exported
   `TLM_APPLY_*_CSWAP_SKIP_LAST` would win over them. Expect:
   - 1154 qubits
   - 1,284,147 average Toffoli (rounded)
   - score 1,481,905,638
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `906027526784` and an identical op
stream. Any other change needs a new nonce hunt.
