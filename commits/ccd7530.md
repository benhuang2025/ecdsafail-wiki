## Summary

After [`233a44c`](233a44c.md) the 2025-qubit peak sat in the Solinas fold of
pair1's first multiply. There, the shift22 step (`hi · 2^22 mod p`) and the
position-32 modular add each allocate a clean scratch register about 257
qubits wide. This commit swaps both for the existing "dirty-borrow" versions.
These run Gidney-style venting adders with two clean qubits plus a borrowed
register in an arbitrary state, and restore that register afterwards. The
borrowed register is `lo`, the low half of the 512-bit product. It is live
but not read again until the multiply is uncomputed.

With that transient gone, the peak moves to other phases. Two knobs are
re-tuned to follow it:

- the affine square's fast-row ceiling `mfw` goes from 243 to 234;
- the W-TRUNC prefix `K0` goes from 20 to 21, to find a clean draw.

`KAL_REROLL` goes from 43 to 3. The result is 19 fewer qubits for 15,180 more
Toffoli.

## What changed and why it saves qubits

1. **`SHIFT22_FOLD_DIRTY` (new, default on)** in
   `mod_mul_write_into_zero_acc_schoolbook_lowscratch_fold`,
   `src/point_add/mul_schoolbook.rs`. This is the pair1 first multiply
   (`pair1_mul1_write_into_zero_acc` → low-scratch schoolbook).
   - Before: `mod_shift_left_by_k(hi, 22)`, `mod_add_qq(acc, hi)` (position 32),
     `mod_shift_right_by_k`. The plain shift22 allocates a `padded` register of
     up to 257 qubits for each spill-fold add. `mod_add_qq` builds loaded
     constant registers for its `+c` / conditional `−c`. On top of the 972
     carrier + init, the 512-qubit `tmp_ext` and the 256-qubit `acc`, this
     reached 2025.
   - After: `mod_shift_left_by_k_dirty(hi, 22, &lo)`,
     `mod_add_qq_dirty(acc, hi, &lo)`, `mod_shift_right_by_k_dirty(…, &lo)`
     (existing functions in `solinas.rs` and `modular.rs`).
     - The spill folds go through `shift22_spill_op_dirty`. With the default
       `SHIFT22_COLLAPSE`, these are two ops: `m = spill · 977` (32 bits) added
       at position 0, and `spill` added at position 32.
     - The `+c` and conditional `−c` steps use
       `venting::iadd_dirty_2clean_classical` and
       `venting::cisub_dirty_2clean_classical`. These are classical-constant
       adders that need two clean qubits and `n − 2` dirty qubits, and leave
       the dirty qubits as they found them.
   - `lo = tmp_ext[0..256]` was consumed read-only by the earlier `lo` add and
     is not touched again until `schoolbook_mul_into_addsub_lsx_inverse`. So
     it can be lent as the dirty donor. See
     [venting-and-wire-loans](../concepts/venting-and-wire-loans.md).
   - Cost: the venting adders run at full width with no carry-tail truncation
     and cost more Toffoli than the clean adders they replace.
2. **`AFFINE_SQUARE_RECOMPUTE_MFW`: 243 → 234** (`mul_affine.rs`).
   - In the affine squares of `233a44c`, rows wider than `mfw` use the slow
     in-place Cuccaro, which needs no carry register. That is now rows
     `i < 23` instead of `i < 14`.
   - The comment says 234 is the largest value (fewest slow rows) that keeps
     the affine square transient at the new floor. That floor is pair2's
     Kaliski `kal_bulk_step4`. 230 also reaches it but costs about 3.7k more
     Toffoli.
3. **`kal_wtrunc_k0()`: 20 → 21** (`kaliski_state.rs`). The W-TRUNC envelope
   starts one iteration later, so the clipped loops are one bit wider at two
   of every three iterations. This costs Toffoli. The comment says it was
   needed because the new stream had no clean margin-0 draw at `K0 = 20` for
   `rr` 0–80, and `K0 = 21` is cheaper than raising the margin to 1. The
   margin comment is extended to say the same.
4. **`KAL_REROLL`: 43 → 3** (`mod.rs`). The comment above it still describes
   `rr = 43`.

The author puts the trade at about +15k Toffoli for −19 qubits. The note does
not split the +15,180 between the venting adders, the 9 extra slow rows and
`K0`. At 2006 qubits one qubit is worth about 2,575,683 / 2006 ≈ 1,284
Toffoli of score, so −19 qubits is worth about 24.4k Toffoli and the trade
pays.

## Why it is still correct, and what it risks

- **The dirty borrow is exact if the donor is disjoint and restored.** The
  venting adders compute the same sums as the clean ones and return `lo` to
  its entry value, so the later multiply uncompute still reads the right
  product. The comment in `233a44c` warns that the same dirty fold is unsound
  in the affine recompute path on this layout (1–5 classical mismatches). Here
  it is used only in pair1's multiply, where `lo` is provably idle.
- **The shift22 here is no longer truncated.** The dirty path does not use
  the `SHIFT22_CARRYTAIL_W` window, so this one site is exact.
- **`K0 = 21` is a loosening** of the W-TRUNC truncation, so it is safer than
  the base. `mfw` only chooses between two exact adders.
- **Island.** The shipped `rr = 3` draws a clean set: 0 classical, 0 phase and
  0 ancilla failures over 9,024 shots. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

The qubit saving comes from replacing two clean scratch registers with a loan
of an idle live register, which is ancilla-lifetime / venting. `mfw` and `K0`
are re-tunes that follow the moved peak and the new draw.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 233a44c -- src/point_add`.
   - Do not start from the git parent `61bdeb0`. That is antojoseph's line on
     the same base, and this commit does not contain it.
   - Against the parent, the diff is 175 lines in 8 files. It would revert
     `R_SMALL` 326 → 321, the dialog-fold slack 3 → 4 and the shift22 window
     35 → 37, and delete three `memory/*.md` notes files.
   - Against `233a44c`, `git diff --ignore-cr-at-eol 233a44c ccd7530 -- src/point_add`
     is 50 lines in 4 files.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`. The flag lets the patch apply whether the files use LF or CRLF line endings. It is the
   complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol ccd7530 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `KAL_*`,
   `AFFINE_*`, `SHIFT22_*` or `LOWQ_*` environment variables set. Expect:
   - 2006 qubits
   - 2,575,683 average Toffoli (rounded)
   - score 5,166,820,098
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with `KAL_REROLL = 3` and an identical op stream.
Any other change needs a new re-roll search.
