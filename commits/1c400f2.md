## Summary

Each Kaliski run (pair 1: 399 iterations, pair 2: 398) starts with a "bulk
prefix" of iterations that use a cheaper body,
`kaliski_iteration_bulk_prefix3`. That body skips the `v == 0` termination
test and the running flag `f`. The base used the bulk body for the first 394
iterations of both runs. This commit raises the prefix to 398 for pair 1 and
396 for pair 2. Only the last generic iteration of pair 1, and the last two of
pair 2, remain. The six iterations that switch body each save about 120
Toffoli in both the forward and the backward run, 1,444 in all. Qubits are
unchanged.

## What changed and why it saves Toffoli

- `src/point_add/mod.rs`, `bulk_prefix_caps(pair)`:
  - The pair-1 default (used when no `KAL_BULK3_*` or `KAL_PAIR1_BULK3_*` env
    override is set) goes from `forward = backward = 394` to 398.
  - A new, matching block for `KalPair::Pair2` (when no `KAL_BULK3_*` or
    `KAL_PAIR2_BULK3_*` override is set) sets `forward = backward = 396`.
    Before, pair 2 fell through to `BULK_PREFIX_SAFE_ITERS = 394`, which is
    unchanged.
- In `kaliski_forward_with_coeff_caps` and `kaliski_backward_caps`, iteration
  `i < cap` runs the bulk body and its mirror. The generic `kaliski_iteration`
  pays for:
  - STEP 0: `with_eq_zero_fast` over the low `2n − i` bits of `v_w`. At
    `i ≈ 395` that is about 117 bits, so about 117 Toffoli. It sets
    `m_i ^= f·[v_w = 0]` and then `f ^= m_i`.
  - `f`-controlled forms of STEP 1, 2 and 4: one extra CCX for `f·u[0]`, one
    for `f·l_gt`, and `mcx2_polar(f, b_f)` for the add flag.

  The bulk body drops STEP 0 and uses a constant `|1⟩` in place of `f`.
  Pair 1 converts iterations 394 to 397 and pair 2 converts 394 and 395, so
  6 iterations × 2 runs × about 120 Toffoli ≈ 1,444.

See [`a16788e`](a16788e.md) for the loop structure.

## Why it is still correct, and what it risks

From the bulk body's code, on an input that has already reached
`(u, v_w) = (1, 0)`:
- it sets `a_f = 0`, `m_i = u[0]·¬v_w[0] = 1` and `b_f = 1`, so the add flag
  `¬b_f` is 0, and no swap or add happens;
- `v_w` (zero) is halved and `r` is doubled, exactly as the generic body does
  with `f = 0`;
- the only difference is the recorded `m_i` (1 instead of 0), and the bulk
  backward mirror undoes that consistently.

What the bulk body cannot do is clear `f`. Only a generic iteration does that,
when it sees `v_w = 0` at entry. Both before and after this commit, the last
iteration of each run is generic. So the requirement is the same: every input
must have terminated before the last iteration starts, which is the loop-length
bet of [`a16788e`](a16788e.md). If one has not, `f` is freed while still 1,
and `u`, `s` are freed with the wrong values. That shows up as ancilla failures
and a wrong `λ`.

The extension therefore does not appear to add a new failure mode. Even so,
the code's comments treat high bulk caps as risky ("phase cliff"). The values
398 and 396, rather than the whole loop, suggest the author searched for caps
whose re-rolled test draw stayed clean. The submission note is only the word
`benchmark.json`.

There is no tail nonce in this era. The 9,024 test inputs are a SHAKE256 hash
of the op stream, and the base's other bets (loop length and
`R_SMALL_THRESHOLD = 326`, see [`9bd0748`](9bd0748.md)) must survive the new
draw. They do: the run passed with 0 classical, 0 phase and 0 ancilla
failures. See [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

The commit moves the iteration at which the cheaper bulk body hands over to
the generic body. That is iteration/threshold tuning.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 81ff75b -- src/point_add`. The base is the git
   parent. `git diff --ignore-cr-at-eol 81ff75b 1c400f2 -- src/point_add` is
   16 lines in 1 file.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line endings.
   It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 1c400f2 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `KAL_*`,
   `AUDIT_*`, `DUMMY_TOFFOLIS` or other environment overrides set. Expect:
   - 2708 qubits
   - 3,810,390 average Toffoli (rounded)
   - score 10,318,536,120
   - 0 classical, 0 phase and 0 ancilla failures

There is no tail nonce in this era. The 9,024 test inputs are a hash of the
op stream, so the score, and the clean draw, only reproduce with an identical
op stream.
