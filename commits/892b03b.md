## Summary

The strip table of [`3701581`](3701581.md) stops at its risk budget ("Risk
1.239700 (budget 1.24)"), not because it runs out of candidates. The author
argues that budget was priced too pessimistically. It treats "no classical
mismatch" and "no phase garbage" as independent events and multiplies their
probabilities. But a shot that fails classically usually fails in phase too,
so that is one bad shot, not two.

Over 64 random nonces on the base, the author measured 15.95 classical bad
shots and 11.25 phase bad shots per draw. 8.06 of them were both, so the union
is 19.14. Counting each bad shot once, the grind is far cheaper than the
product model says. That leaves room to admit more gates. A fresh 10M-shot
census found 832 candidates the table did not contain: 461 never-firing gates
to delete, and 371 gates with a redundant control to downgrade to CX. Together
they save 756 average Toffoli for a measured +0.53 bad shots per draw. The
appended keys are applied by the existing strip code, unchanged.

## What changed and why it saves Toffoli

- **`src/point_add/deep_strip_keys.rs`:** 832 key lines appended, none removed.
  The header is unchanged.
  - `DEAD_KEYS` 11,741 → 12,202 (+461) and `DOWNGRADE_KEYS` 3,674 → 4,045 (+371).
  - The census is 10M shots, recording per CCX/CCZ:
    - `fired`, the OR of `cond & q(c1) & q(c2)`;
    - `bad1` / `bad2`, for one control being redundant;
    - the summed `popcount(cond)` the gate is charged.
  - The build logs "0 stale keys skipped; 12,202 dead removed / 4,045
    downgraded to CX/CZ".
- **Measured on 64 paired nonces** (Δ avg T, Δλ_union in bad shots per draw):

  | variant | Δ avg T | Δλ_union |
  |---|---:|---:|
  | 371 downgrades only | −317.5 | −0.391 ± 0.79 (not measurably costly) |
  | 461 deletions only | −436.0 | +1.344 ± 0.77 |
  | both (shipped) | −756.1 | +0.531 ± 0.72 |

  - Going further up the same curve (gates that fire 1–5 times in 10M) keeps
    paying 350–480 avg T per unit of λ with no knee. So the best stopping point
    is simply the grind budget.
  - See [dead-gate-strip](../concepts/dead-gate-strip.md) and
    [scoring-and-validation](../concepts/scoring-and-validation.md).
- **`src/point_add/trailmix_ludicrous/gidney.rs`, `emit_adaptive_layout_no_cout()`.**
  It gains the same "drop the unread last-chunk carry-out" option that
  [`258b25f`](258b25f.md) added to the varchunk adder. It only applies when
  `plain_len == 0` and `TLM_ADAPTIVE_FINAL_NO_COUT=1`. Nothing sets that
  variable, so the shipped circuit does not use it.
- **`src/point_add/mod.rs`:** tail nonce `SUB4_TAIL_NONCE` 1003157528363 →
  902265393175.
- **File modes:** 24 scripts under `src/point_add/memory/repro/` go from 100755 to
  100644, as in [`59f3428`](59f3428.md). Their contents do not change.

## Why it is still correct, and what it risks

- **Empirical.** The 832 keys are "a priced risk purchase, not a proof of
  deadness". A deeper census would reclassify some of them. A wrong key shows up
  as a classical mismatch or phase garbage on the inputs where that gate
  matters.
- **Hunt pricing on this exact stream:** survivor fraction 5.467e-6,
  P(clean | survivor) 3.133e-4, so clean density is 1.713e-9. Two clean nonces
  were found, and the cheaper one shipped (1,284,915.786 against 1,284,919.122).
  Before grinding, the author checked that the GCD prefilter's CPU twin never
  rejected a nonce the trusted simulator accepted, over 24 nonces. The
  prefilter models the ideal circuit, not the census drops.
- The shipped nonce `902265393175` draws a clean set: 9,024 of 9,024 shots, 0
  classical, 0 phase and 0 ancilla failures. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

A larger empirical dead-gate strip; the `gidney.rs` option is off. That is
dead-gate/self-inverse removal.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 3701581 -- src/point_add`.
   - The note says the work is based on `f87c292` (= `3701581`), not on the head
     of the time.
   - The git parent `5b95ac2` is a repository merge commit whose `src/point_add`
     equals the frontier `c24c306`. Against it, the diff would delete
     jackylee0424's 10-pass post-strip fanout loop from `mod.rs`, which this
     commit never had. The note says it left those 15 average Toffoli
     unclaimed on purpose.
   - Against `3701581`, `git diff --ignore-cr-at-eol 3701581 892b03b -- src/point_add`
     is 857 lines: 832 key lines, the nonce, the dormant `gidney.rs` option and
     24 mode changes.
2. **Copy the generated table from the commit:**
   `git checkout 892b03b -- src/point_add/deep_strip_keys.rs`.
3. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line endings.
   It covers `mod.rs`, `gidney.rs` and the mode changes.
4. **Check the tree.** `git diff --ignore-cr-at-eol 892b03b -- src/point_add`
   should print nothing.
5. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `TLM_*` or
   `SUB4_*` overrides set. Expect:
   - 1154 qubits
   - 1,284,916 average Toffoli (1,284,915.786 before rounding)
   - score 1,482,793,064
   - 0 classical, 0 phase and 0 ancilla failures
6. **Nonce caveat.** The score only reproduces with the nonce `902265393175` and an
   identical op stream. Any other change needs a new nonce hunt.
