## Summary

[`9bd0748`](9bd0748.md) set one global `R_SMALL_THRESHOLD = 326`. Below it,
each Kaliski iteration doubles `r` (forward) or halves it (backward) with a
free wire rotation, and above it with a Solinas modular double or halve of
about 255 Toffoli. This commit makes the threshold depend on the Kaliski run
and the direction. Pair 1's backward run now uses 327, and the other three
runs keep 326. The backward iteration 326 of pair 1 becomes free, a saving of
exactly 255 Toffoli. Qubits are unchanged.

## What changed and why it saves Toffoli

All edits are in `src/point_add/mod.rs`.

- **New constant `R_SMALL_THRESHOLD_PAIR1_BK = 327`**, next to
  `R_SMALL_THRESHOLD = 326`.
- **New enum `KalPass { Forward, Backward }`** and a new function
  `r_small_threshold_for(pair, pass)`, which replaces `r_small_threshold()`.
  - The default is 327 for `(Pair1, Backward)` and 326 otherwise.
  - Env overrides, from weakest to strongest: `KAL_R_SMALL_THRESHOLD`, then
    `KAL_R_SMALL_THRESHOLD_FWD` / `_BK`, then `KAL_PAIR{1,2}_R_SMALL_THRESHOLD`,
    then `KAL_PAIR{1,2}_R_SMALL_THRESHOLD_FWD` / `_BK`.
- **`BulkPrefixCaps` gains a `pair` field**, set by `bulk_prefix_caps(pair)`
  and `cleanup_bulk_prefix_caps(pair)`. That way the loop drivers know which
  run they belong to.
- **Plumbing.** Each loop driver (`kaliski_forward_with_coeff_caps`,
  `kaliski_backward_caps`, the `_alias_v_w_caps` pair and the `_prescaled_kind`
  pair) computes the threshold once and passes it as a new `r_small_threshold`
  argument to the four iteration bodies. The bodies compare `iter_idx` with
  the argument instead of calling the global function.
- `env_usize` moves above the new code. It is unchanged.

In the backward bodies (`kaliski_iteration_backward`,
`kaliski_iteration_bulk_prefix3_backward`), `iter_idx < r_small_threshold`
selects `mod_halve_no_corr(r)`, a 0-Toffoli rotation down one place. Otherwise
the code runs the inverse of the Solinas double, with a carry chain. Pair 1's
backward loop now takes the free branch at `iter_idx = 326`, which saves one
255-Toffoli chain.

## Why it is still correct, and what it risks

Forward and backward now disagree at iteration 326 of pair 1. Forward still
runs `mod_double_inplace_fast(r)`: it moves the top bit of `r` into an
overflow qubit and adds `c` under it. Backward undoes that step with a plain
rotation, which is a correct inverse only if the overflow bit was 0, that is,
if `r < 2^255` at forward iteration 326. That is the same condition a forward
threshold of 327 would need. As [`9bd0748`](9bd0748.md) explains, it holds
for every input whose Kaliski run is still active at that iteration, and
fails on inputs that converge earlier.

If the condition fails, forward has already produced the correct `λ`. Only the
backward run goes wrong, so pair 1 does not return to its zero state. That
shows up as ancilla failures, and possibly phase errors, rather than as a
classical mismatch.

There is no tail nonce in this era. The 9,024 test inputs are a SHAKE256 hash
of the op stream. The draw for this op stream passes with 0 classical, 0
phase and 0 ancilla failures. Why only pair 1's backward run moved is not
documented (the commit has no submission note). Most likely moving the other
runs to 327 changed the draw onto one that failed.

## Classification rationale

The commit moves the iteration at which a cheaper body takes over, in one of
the four Kaliski runs. That is iteration/threshold tuning.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 9bd0748 -- src/point_add`. The base is the git
   parent. `git diff --ignore-cr-at-eol 9bd0748 a444668 -- src/point_add` is
   106 lines in 1 file.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line endings.
   It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol a444668 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `KAL_*`,
   `DUMMY_TOFFOLIS` or other environment overrides set. Expect:
   - 2708 qubits
   - 3,839,689 average Toffoli (rounded)
   - score 10,397,877,812
   - 0 classical, 0 phase and 0 ancilla failures

There is no tail nonce in this era. The 9,024 test inputs are a hash of the
op stream, so the score, and the clean draw, only reproduce with an identical
op stream.
