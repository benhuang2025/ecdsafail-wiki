## Summary

Each trailmix GCD step decides whether to swap `u` and `v` by comparing their
top bits, using a carry chain over that window. A baked per-call table,
`CMP_K`, says how many of the window's top bits use "held" carries: fresh
ancillas, uncomputed by measurement at no Toffoli cost. The other bits use an
in-place Cuccaro MAJ chain, whose uncompute costs a second Toffoli per bit.

This commit adds 4 to every `CMP_K` entry. Four more bits per compare take
the cheap path, which costs four extra transient qubits during that compare.
The comparison result is unchanged, so this is exact. It saves 350 average
Toffoli against its base at the same 1166 qubits, because the compares are
not at the peak. The tail nonce was re-hunted.

## What changed and why it saves Toffoli

- `src/point_add/trailmix_ludicrous/mod.rs`, `next_cmp_k()`: returns the next
  `CMP_K` entry plus 4. When the schedule is exhausted it still returns
  `usize::MAX`.
- How `k` is used (`trailmix_ludicrous/comparator.rs`, unchanged):
  - `controlled_swap_decision_lt_truncated` (the forward swap decision) and
    `swap_decision_uncompute_vented` (its measured uncompute) both pass
    `ck = next_cmp_k()` to `compare_geq_chunked_middle(a, b, flag, body, k)`.
  - That function works on the top-window operands (`GAP_J2[i]` bits) and
    clamps `k` to the window width `n`.
  - The bottom `n − k` bits run an in-place Cuccaro MAJ chain with one live
    carry. That is 1 CCX forward, and the reverse UMA costs another CCX.
  - The top `k` bits each get a fresh carry qubit (1 CCX forward). On the
    reverse each one is erased with `hmr` and `cz_if_bit`, at no Toffoli
    cost.
- So each extra held bit saves one CCX per compare and adds one live qubit
  while the compare runs. The submission note gives no per-call count, but
  the measured effect is −350 average Toffoli. The forward decision runs on
  every shot. The vented uncompute runs under the `hmr` condition, so on about
  half the shots. See [measurement-uncompute](../concepts/measurement-uncompute.md)
  and [adders-and-carries](../concepts/adders-and-carries.md).
- `src/point_add/mod.rs`, `build()`: `DIALOG_TAIL_NONCE` default `"6147"` →
  `"28265"`, and the comment is updated.

## Why it is still correct, and what it risks

- **Exact.** Both carry layouts compute the same `a ≥ b` over the same top
  window. The approximation that does exist, comparing only the top
  `GAP_J2[i]` bits, is unchanged, so the hard inputs are the base's.
- **Peak.** The cost is up to 4 extra qubits during each compare. The run
  still peaks at 1166, so the swap compares had at least that much headroom
  below the peak.
- **Nonce.** Nonce `28265` gives 0 classical, 0 phase and 0 ancilla failures
  over all 9,024 shots, with no environment overrides. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

The published label is comparator/width truncation. The comparator's window
does not change, though. The change spends spare qubit headroom on a cheaper,
exact carry layout. "Budget/headroom retune" fits the diff better, as in the
fold-vent commits [`a9ac507`](a9ac507.md) and [`fd89e69`](fd89e69.md).
Comparator/width truncation is the nearest existing type. The header keeps
the published label.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout ab1b2d6 -- src/point_add`.
   - Do not start from the git parent `fd89e69` (jieyilong). That tree holds
     the `LUD_EXTRA_FOLD_*` fold-vent knob, and this commit was not built on
     it.
   - Against the parent, the diff is 52 lines in 2 files, and it would delete
     that knob.
   - Against `ab1b2d6`, `git diff --ignore-cr-at-eol ab1b2d6 75851e6 -- src/point_add`
     is 11 lines in 2 files.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`. The flag lets the patch apply whether the files use LF or CRLF line endings.
3. **Check the tree.** `git diff --ignore-cr-at-eol 75851e6 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no
   `LUD_*`, `TRAILMIX_*`, `DIALOG_*` or `TLM_*` environment variables set. Expect:
   - 1166 qubits
   - 1,422,266 average Toffoli (1,422,265.574 before rounding)
   - score 1,658,362,156
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `28265` and an identical op stream.
Any other change needs a new nonce hunt.
