## Summary

The author's previous commit [`b8ce940`](b8ce940.md) added a family of
switches that skip one controlled swap which only ever exchanges two zero
wires, but it switched the skip on only in the apply phase. This commit flips
the master switch, so the same skip now also runs in the GCD walk
(`tobitvector`), forward and reverse. The code was already in the tree; the
diff is one renamed default and the nonce.

Each GCD walk step does an optional second right shift of `v` (the K=2 "jump"),
built as a cascade of controlled swaps. Its last swap exchanges the top two
wires of the shifted window, which are both 0. Skipping it saves one Toffoli
per walk step. There are four walk passes of 260 steps per shot, so about
1,040 Toffoli; the measured saving is 1,029. Qubits are unchanged, and the
change is exact.

## What changed and why it saves Toffoli

1. **`src/point_add/mod.rs`, `configure_ecdsafail_submission_route()`.**
   - `set_default_env("DIALOG_GCD_SKIP_ZERO_EDGE_APPLY_CSHIFT", "1")` becomes
     `set_default_env("DIALOG_GCD_SKIP_ZERO_EDGE_CSHIFT", "1")`.
   - In `rounds/dialog/compressed.rs`, `dialog_gcd_skip_zero_edge_cshift_enabled()`
     reads that variable and turns on all four skips:
     `..._tobit_fwd_...`, `..._tobit_rev_...`, `..._apply_double_...` and
     `..._apply_halve_...` (the last two were already on).
   - `DIALOG_TAIL_NONCE`: 700000459112 → 800002627594.
2. **What the newly enabled skips do.** Both live in the K=2 branch of the
   block-lifecycle walk.
   - Forward walk, `emit_dialog_gcd_compressed_sidecar_tobitvector_steps_block_lifecycle`,
     phase `dialog_gcd_compressed_block_tobitvector_shift`:
     - `dialog_gcd_shift_right_assuming_even(v_shift)` rotates the window
       `v_shift = v[..shift_width]` down by one with plain swaps. `v` is even
       here, so the 0 in `v[0]` lands in the top wire of the window.
     - `s2 = NOT v[0]` records whether `v` is still even.
     - The conditional second shift runs `cswap(s2, v_shift[i], v_shift[i+1])`
       for `i = 0..pairs−1`, with `pairs = shift_width − 1`.
     - When `s2 = 1`, `v[0]` is 0 and that 0 travels up one place per swap. At
       the last swap, `i = pairs − 1`, the lower wire holds the travelling 0
       and the top wire holds the 0 put there by the first rotation. The swap
       exchanges 0 with 0. When `s2 = 0`, a controlled swap does nothing.
     - New code: `if dialog_gcd_skip_zero_edge_tobit_fwd_cshift_enabled() && i + 1 == pairs { continue; }`.
   - Reverse walk, `emit_dialog_gcd_compressed_sidecar_tobitvector_steps_reverse_block_lifecycle`,
     phase `..._tobitvector_reverse_unshift`: the mirror loop runs the swaps in
     reverse order, so its *first* swap is the same zero pair. It is skipped
     under `..._tobit_rev_cshift_enabled()`.

**Why it saves Toffoli.** Each `cswap` is `CX; CCX; CX`, one Toffoli, and runs
on every shot. The point addition uses the dialog GCD twice (in-place multiply
and division). Each use runs a forward walk and a reverse walk of 260 steps,
so 4 × 260 = 1,040 swaps go. The measured average falls by 1,029, which also
includes the shift from the new nonce's test draw.

## Why it is still correct, and what it risks

The skipped swap is the identity on every input that reaches it, so the change
is exact. The zero in the top wire comes from the "v is even" invariant of the
walk (every step's subtraction leaves `v` even), not from a width assumption.
If an input ever broke that invariant, the base circuit would already be wrong,
because the first rotation `..._shift_right_assuming_even` relies on it too.

The op stream changed, so the tail nonce was re-hunted. The shipped nonce
`800002627594` draws a clean set: 9,024 of 9,024 shots, with 0 classical,
0 phase and 0 ancilla failures. See
[nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

The change removes gates that act on known-zero wires and have no effect,
which is dead-gate removal, the same label as [`b8ce940`](b8ce940.md). There is
no runner-up.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout b8ce940 -- src/point_add`. The base is the git parent.
   `git diff --ignore-cr-at-eol b8ce940 7822c37 -- src/point_add` is 4 lines in
   1 file.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line endings.
   It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 7822c37 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no
   `DIALOG_*`, `KAL_*` or `ROUND84_*` environment variables set, because they
   override the route defaults. Expect:
   - 1285 qubits
   - 1,381,126 average Toffoli (rounded)
   - score 1,774,746,910
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with `DIALOG_TAIL_NONCE=800002627594` and an
identical op stream. Any other change needs a new nonce hunt.
