## Summary

This commit makes no optimization. It only changes the tail nonce in
`src/point_add/mod.rs` (`DIALOG_TAIL_NONCE` default in `build()`) from
800457469 to 1200006462. The new nonce draws a different clean set of 9,024
test shots, whose average executed Toffoli is 26 lower. The diff touches only
the nonce literal, and the emitted op count is unchanged. The git parent
[`3b05e0a`](3b05e0a.md) is the same circuit under nonce 16581. For why a nonce
moves the score, see
[nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).
