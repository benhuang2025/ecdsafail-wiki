## Summary

This continues the multiply-depth sweep of [`7b3469b`](7b3469b.md) and
[`5c23d45`](5c23d45.md), on the author's newer tree `cc82b18`. The ping-pong
multiply traversal goes from `rounds() − 4 = 696` rounds to
`rounds() − 5 = 695`, while the divide stays at 700. One walk round, one
replay cell and one walk-back round fewer save 383 average Toffoli. Qubits
stay at 1278. The cost is a little more exposure to multiply walks that
need the extra round.

## What changed and why it saves Toffoli

1. **`rounds_for(PingPongDirection::Multiply)`** in
   `src/point_add/pingpong_div.rs`: the default of `SUB4_PP_ROUNDS_MUL` goes
   from `rounds() − 4` to `rounds() − 5`.
   - All three stages of the multiply traversal (walk, replay, walk-back)
     loop to `rounds_for(direction)`, so each loses its last round.
   - Most of the saving is the dropped 256-bit replay cell. The walk and
     walk-back adds of the last round are at the narrowest walk width.
   - **Qubits.** In `cc82b18`, `plan()` has checkpoints `r1 = 298`,
     `r2 = 613` and cap `SUB4_PP_PEAK = 1278`. The replay ladders are sized to
     the room under that cap, so a shorter tape does not lower Q. See
     [pingpong-division](../concepts/pingpong-division.md) and
     [peak-qubits-and-budgets](../concepts/peak-qubits-and-budgets.md).
2. **Tail nonce** (`src/point_add/mod.rs`): the default
   `SUB4_PINGPONG_TAIL_NONCE` goes from 45448000021 to 910000024466.

## Why it is still correct, and what it risks

- **Depth is a truncation.** An input whose multiply walk needs more than
  695 rounds to reach `(±1, ±1)` gives a wrong product and dirty walk
  registers. That shows as classical and ancilla failures.
- The `rounds_for` comment prices one round on one traversal at about
  +0.05 λ.
- The shipped nonce `910000024466` draws a clean test set: 0 classical,
  0 phase and 0 ancilla failures. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).
- [`03c9c5b`](03c9c5b.md) later re-rolls only this commit's nonce, for −11 T.

## Classification rationale

Cutting a fixed round count against a measured convergence rate is
iteration/threshold tuning.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout cc82b18 -- src/point_add`. The base is the git
   parent. `git diff --ignore-cr-at-eol cc82b18 4417b24 -- src/point_add` is
   4 changed lines in 2 files.
2. **Apply the patch below** from the repo root with
   `git apply --ignore-whitespace`. The flag lets the patch apply whether the
   files use LF or CRLF line endings. It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 4417b24 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `SUB4_*`
   environment variables set (in particular no `SUB4_PP_ROUNDS_MUL`). Expect:
   - 1278 qubits
   - 939,393 average Toffoli (rounded)
   - score 1,200,544,254
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `910000024466` and an identical op
stream. Any other change needs a new nonce hunt.
