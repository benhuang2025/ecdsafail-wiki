## Summary

This re-applies josusanmartin's 58 → 57 cut from [`975b73f`](975b73f.md) to
the 1466-qubit frontier. Each dialog-GCD step decides `u > v` from only the
top few bits of the two registers. Lowering the global cap on that comparison
from 58 to 57 bits removes one bit from each of the 254 steps where the cap
binds. The comparison runs four times per step at one Toffoli per bit, so the
saving is 4 × 254 = 1,016 Toffoli. Qubits are unchanged. The reroll pair was
re-searched to (3, 32).

## What changed and why it saves Toffoli

Both changes are in `configure_ecdsafail_submission_route()` in
`src/point_add/mod.rs`:

1. **`DIALOG_GCD_COMPARE_BITS`: 58 → 57.**
   - `dialog_gcd_compare_bits_for_step` returns
     `min(SCHEDULE[step] + 5, active_width, DIALOG_GCD_COMPARE_BITS)`. With the
     baked 399-entry `DIALOG_GCD_PA9024_COMPARE_SCHEDULE`, margin 5 and
     `DIALOG_GCD_WIDTH_MARGIN=27`, the cap binds on steps 53 to 320. All of
     these are inside the 398 active steps, so the summed width drops by
     254 bits (19,772 → 19,518).
   - The branch comparator (the hosted `ccx_cmp_lt_into_fast_borrowed_carries`
     from [`92a247e`](92a247e.md)) costs one Toffoli per bit, with carries
     cleared by `hmr` + `cz_if`. It runs in the forward and reverse transcript
     passes of both GCD pairs: 4 × 254 = 1,016 Toffoli.
2. **Reroll pair: `DIALOG_REROLL` 52 → 3, `DIALOG_POST_SUB_REROLL` 28 → 32.**
   Identity `X;X` counts that re-draw the 9,024 test inputs without changing the
   circuit (see [`ecbf87b`](ecbf87b.md)).

## Why it is still correct, and what it risks

The truncated comparison is approximate. When `u` and `v` agree on their top
57 active bits it can give the wrong `u > v`. The step then takes the wrong
branch and the transcript no longer matches the true GCD. That shows as a
classical failure, or as phase or ancilla garbage if the uncompute no longer
mirrors the forward pass. One bit fewer roughly doubles the per-step risk on
the 254 affected steps.

The reroll pair (3, 32) draws a clean set: 9,024 of 9,024 shots pass with
0 classical, 0 phase and 0 ancilla failures. See
[nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

The only circuit change is a narrower, approximate comparator, so
comparator/width truncation fits.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout fd8e712 -- src/point_add`. The base is the git parent.
   `git diff --ignore-cr-at-eol fd8e712 14b84f1 -- src/point_add` is 12 lines
   in 1 file.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line endings.
   It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 14b84f1 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `DIALOG_*`,
   `KAL_*`, `KARA_*` or `ROUND84_*` environment variables set, because
   `set_default_env` keeps any value already in the environment. Expect:
   - 1466 qubits
   - 1,728,225 average Toffoli (rounded)
   - score 2,533,577,850
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the reroll pair `DIALOG_REROLL=3`,
`DIALOG_POST_SUB_REROLL=32` and an identical op stream. Any other change needs
a new reroll search.
