## Summary

Against the author's own `cc82b18`, the only circuit change is a shorter
multiply traversal: `ROUNDS_MUL` goes from `rounds() − 4` to `rounds() − 6`,
so the multiply walk runs 694 rounds instead of 696. Two rounds' walk adds,
walk-back adds and replay cells disappear, which saves 750 average Toffoli at
1278 qubits.

The frontier at the time was jackylee0424's `f615c6b`, which had the same
`rounds() − 6` but had also lowered every peak budget to reach 1277 qubits.
This commit keeps the round cut and puts the budgets back to 1278. The
arithmetic says that is better: at equal depth, the 1277-qubit layout costs
939,783 − 939,026 = 757 more Toffoli, while one qubit is only worth about
939,026 / 1277 ≈ 735 Toffoli of score. So 1278 × 939,026 beats
1277 × 939,783 by 27,663.

## What changed and why it saves Toffoli

1. **`rounds_for(Multiply)` default: `rounds() − 4` → `rounds() − 6`** in
   `src/point_add/pingpong_div.rs` (`SUB4_PP_ROUNDS_MUL`; `rounds()` = 700).
   - The multiply traversal walks for 694 rounds and records 694 tape signs.
     Its replay (`replay_doubling_round`) and walk-back run one step per
     round. The divide traversal keeps all 700 rounds.
   - Each round removed is one walk add, one walk-back add and one fused
     replay cell (a 256-bit chunked add plus fold plus measured-erase
     repairs). Two rounds account for the −750.
   - The tape gets two wires shorter. Qubits do not drop, because the peak is
     set by `SUB4_PP_PEAK` = 1278 and `SQUARE_LADDER` = 248, which are
     unchanged from the base. The ladder budgets simply absorb the freed
     wires. See [peak-qubits-and-budgets](../concepts/peak-qubits-and-budgets.md).
2. **Tail nonce** (`SUB4_PINGPONG_TAIL_NONCE` default in `build()`,
   `src/point_add/mod.rs`): 45448000021 → 660000097677.

## Why it is still correct, and what it risks

Depth is a truncation. A multiply input whose walk needs its 695th or 696th
round to reach (±1, ±1) now ends with a wrong product and dirty walk
registers, a **classical** failure that usually also leaves ancilla and phase
garbage. The code comment next to the knob prices one round on one traversal
at about +0.05 λ, so this adds about 0.1 λ. Everything else is the base
circuit. The shipped nonce `660000097677` draws a clean set: 0 classical,
0 phase and 0 ancilla failures. See
[pingpong-division](../concepts/pingpong-division.md) and
[nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

Against the author's line the only new circuit content is two fewer walk
iterations, which is iteration/threshold tuning. Against the frontier the
commit is a revert of a budget cut, not a new mechanism.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout cc82b18 -- src/point_add`.
   - Against `cc82b18`, `git diff --ignore-cr-at-eol cc82b18 f836a70 -- src/point_add`
     is 4 lines in 2 files.
   - Do not start from the git parent `f615c6b`. Against it the diff is
     23 lines in 3 files, and it undoes jackylee0424's budget cut:
     `SUB4_PP_PEAK` 1277 → 1278, `SUB4_PP_R1` 295 → 298 (with its comment)
     and `SQUARE_LADDER` 247 → 248.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line
   endings. It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol f836a70 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `SUB4_*`
   environment variables set. Expect:
   - 1278 qubits
   - 939,026 average Toffoli (rounded)
   - score 1,200,075,228
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `660000097677` and an identical op
stream. Any other change needs a new nonce hunt.
