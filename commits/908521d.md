## Summary

This is the same lever as [`a8688f8`](a8688f8.md) and [`cd34b79`](cd34b79.md),
pushed much further. Each Kaliski iteration swaps `u` and `v_w` under its
branch bit at step 3 and back at step 9. The boundary-merge fuses step 9 of
iteration `k` into step 3 of iteration `k+1`, but only inside a prefix where
`u ≠ v_w`. Those two commits moved the prefix by one or two iterations, inside
the range where `u ≠ v_w` is guaranteed. This commit moves it from 254 to 329,
75 boundaries at once, well past that range.

That deletes 75 controlled swaps of 52 to 102 bits from each of the four
Kaliski walks, for −22,600 average Toffoli at the same 2006 qubits. In return
the merge is now probabilistic: an input that reaches `u = v_w` before
iteration 329 takes a wrong branch. The reroll count `KAL_REROLL` changes from
3 to 5 so the test draw contains no such input.

The commit was built on the 2006-qubit tree `ccd7530`, not on the 2002-qubit
frontier. The Toffoli saving was large enough to beat that frontier anyway.

## What changed and why it saves Toffoli

- **`src/point_add/kaliski_state.rs`, `kal_cswap_uv_merge_safe_iters()`: 254 → 329.**
  - Mechanism (see [`a8688f8`](a8688f8.md) for the full description):
    iteration `k` skips its step-9 swap when `k + 1 < safe_iters`, and carries
    its swap bit `a_k` on a `frame` qubit. Iteration `k+1` swaps under
    `a_k ⊕ a_{k+1}` at step 3, and corrects its step-2 comparison with
    `l_gt ^= frame_in`. That correction is right only if `u ≠ v_w`.
  - With 329, the step-9 swaps of iterations 253 through 327 are deleted.
    Each is `min(2n − k, kal_wtrunc_width(k))` bits wide, which with `K0 = 21`
    goes from 102 bits at `k = 253` down to 52 at `k = 327`. The sum is 5,775
    Toffoli per walk, minus one extra step-1 CCX for each merged iteration.
    Four walks (forward and backward for `pair1` and `pair2`) give about
    22,800. The measured saving is 22,600.
- **`src/point_add/mod.rs`, `build()`: the default `KAL_REROLL` goes from 3 to 5.**
  The count of identity `X(tx[0]); X(tx[0])` pairs selects the 9,024-shot
  test draw. 5 gives a clean draw for this stream. The added comment says 330
  had no clean reroll.

## Why it is still correct, and what it risks

- The fusion of the swaps is exact. The approximation is the
  `l_gt ^= frame_in` shortcut. With gcd 1, `u = v_w` means `(1, 1)`, the
  state one step before termination.
- A nonzero input needs at least 256 Kaliski steps to terminate (proved in
  the `bulk_prefix_safe_iters` comment), so iterations below about 255 are
  safe. Between 255 and 328 they are not: the inversion pairs run 399 and 397
  iterations, and an input whose walk finishes before iteration 329 passes
  through `(1, 1)` inside the merged range. On such an input the step-2
  branch is wrong, the walk diverges, and λ comes out wrong. That would show as
  a classical mismatch, with phase and ancilla garbage from the backward walk.
- Such fast-finishing inputs are rare, and the `rr = 5` draw contains none.
  The author validated it with the full benchmark: 0 classical, 0 phase and
  0 ancilla failures over 9,024 shots. [`cef001a`](cef001a.md) later pushed
  the same knob to 331 with a different reroll.

## Classification rationale

The published label is Dead-Code and Redundancy Elimination →
dead-gate/self-inverse removal. The diff is the same boundary cswap-merge
lever as [`cd34b79`](cd34b79.md) and [`cef001a`](cef001a.md), which the census
files as Fusion → boundary cswap-merge. The deleted swaps are not dead on
their own. They are made redundant by being fused into the next iteration's
swap. Fusion → boundary cswap-merge is the better fit.

     is 14 lines in 2 files.

   The flag lets the patch apply whether the files use LF or CRLF line
   endings. It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 908521d -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `KAL_*`
   or `AFFINE_*` environment variables set. Expect:
   - 2006 qubits
   - 2,553,083 average Toffoli (rounded)
   - score 5,121,484,498
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with `KAL_REROLL = 5` and an identical op stream.
Any other change needs a new reroll search.
