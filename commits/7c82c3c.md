## Summary

This is one more step of the author's width-envelope re-fit
([1eae277](1eae277.md)). The dialog-GCD width `256 − slope·step + margin`
keeps margin 10, and its slope goes from 0.984 to 0.990 bits per step. The
extra 0.006 bits per step builds up to about 1.5 bits by the last step. After
rounding to even, the later steps lose 2 bits each, 192 bits per walk in
total. Each step-bit costs 4 Toffoli in the K=2 walk, plus capped comparator
bits. The saving is 3,376 Toffoli, exactly what the width formula predicts.
Qubits are unchanged. A new tail nonce was found.

## What changed and why it saves Toffoli

`src/point_add/mod.rs`, `configure_ecdsafail_submission_route()`:

- `DIALOG_GCD_WIDTH_SLOPE_X1000`: 984 → 990.
- `DIALOG_TAIL_NONCE`: 65110790329263 → 16096474301152.

`dialog_gcd_width_slope()` reads the slope as `X1000 / 1000`, and
`dialog_gcd_tobitvector_active_width(step)` uses it. The width bounds four
loops in each walk step, each about 1 Toffoli per bit: the branch `cswap`, the
gated load, the subtract or add body, and the K=2 conditional-shift cascade.
It also caps the branch comparator at `min(74, active_width)`. See
[01260e8](01260e8.md).

Replaying the formula over the 259 steps, the summed width per walk goes from
36,208 to 36,016 bits (−192). The summed comparator width goes from 17,252 to
17,176 (−76). Per walk that is 4 × 192 + 76 = 844 Toffoli. The four walks give
3,376, the measured drop. The last step's width goes from 14 to 12 bits. The
peak is set by the apply chunked add, so it stays at 1390.

## Why it is still correct, and what it risks

The steeper slope assumes a faster average shrink of `max(bitlen u, bitlen v)`
in the K=2 walk. The late steps lose the most margin, and that is where an
input that converges slowly would run past the envelope. Such an input loses
live high bits, and its walk fails: a classical mismatch, and ancilla garbage
after the reverse walk.

The shipped nonce `16096474301152` draws a test set with 0 classical, 0 phase
and 0 ancilla failures over all 9,024 shots. See
[nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

The submission note's first line repeats the stale "margin 14 / slope 986"
text. Its validation line gives the real values, 10 and 990.

## Classification rationale

A narrower per-step register width is comparator/width truncation.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 1eae277 -- src/point_add`. The base is the git
   parent. `git diff --ignore-cr-at-eol 1eae277 7c82c3c -- src/point_add` is
   4 lines in 1 file.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line
   endings. It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 7c82c3c -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no
   `DIALOG_*` or `KAL_*` environment variables set, because
   `set_default_env` only fills in unset variables. Expect:
   - 1390 qubits
   - 1,547,007 average Toffoli (rounded)
   - score 2,150,339,730
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with `DIALOG_TAIL_NONCE=16096474301152` and an
identical op stream. Any other change needs a new nonce hunt.
