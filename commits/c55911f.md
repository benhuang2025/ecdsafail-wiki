## Summary

This is the first accepted commit of the contest. It changes one number: the
default of the `DUMMY_TOFFOLIS` padding knob goes from 10,000 to 9,000. The
padding is a block of self-cancelling Toffoli pairs that the organisers put at
the end of the circuit so the acceptance pipeline could be tested with
trivial submissions. Removing 1,000 pairs removes exactly 2,000 executed
Toffoli per shot and changes nothing else. The commit went through the
acceptance plumbing but was never scored; the leaderboard starts at
[`6f7c159`](6f7c159.md), which ships the same tree.

## What changed and why it saves Toffoli

- `src/point_add/mod.rs`, `build()`: the default of `DUMMY_TOFFOLIS` goes
  from `10_000` to `9_000`.

The padding block sits at the end of `build()`, after the point addition has
produced its outputs:

```rust
let n: usize = std::env::var("DUMMY_TOFFOLIS")
    .ok()
    .and_then(|v| v.parse::<usize>().ok())
    .unwrap_or(9_000);
if n > 0 {
    let a = tx[0];
    let bq = ty[0];
    let c = b.alloc_qubit();        // fresh ancilla, |0>
    for _ in 0..n {
        b.ccx(a, bq, c);
        b.ccx(a, bq, c);            // CCX is self-inverse: the pair is the identity
    }
    b.free(c);
}
```

- Each unit is a pair of identical Toffolis on the same three wires, so the
  pair cancels exactly whatever the control values are, and `c` ends at |0⟩.
- The trusted simulator (`src/sim.rs`) adds a CCX to the executed-Toffoli
  tally whenever its classical condition is true, without looking at the
  controls. These gates are unconditional, so every unit costs exactly
  **2 executed Toffoli on every shot**, and the average moves by exactly 2
  per unit. See [scoring-and-validation](../concepts/scoring-and-validation.md)
  and, for why paid-but-useless gates cost anything,
  [dead-gate-strip](../concepts/dead-gate-strip.md).
- The ancilla `c` is allocated after the arithmetic has freed its scratch, so
  it never reaches the peak. Qubits stay at 2715.
- The source comment calls the block a "noise-injection knob for harness
  sensitivity tests". The scored numbers later confirm the arithmetic: 9,000
  units give 3,960,753 ([`6f7c159`](6f7c159.md)) and 0 units give 3,942,753
  ([`f43a73e`](f43a73e.md)), a difference of 18,000 = 2 × 9,000.

## Why it is still correct, and what it risks

The change is exact. The pairs are the identity on every input, so the
point-addition arithmetic, its outputs and its peak are untouched. Only the
number of identity pairs differs. There is no risk to any validation channel:
the ancilla is reset clean, no phase is produced, and the outputs are
unchanged.

There is no tail nonce in this era. The 9,024 test inputs are a SHAKE256 hash
of the op stream, so this change re-draws them. The circuit passed with the
new draw, as the identical scored tree [`6f7c159`](6f7c159.md) shows.

## Classification rationale

The published label puts the four pre-leaderboard padding commits in their own
"Unscored bootstrap" group. The change is a pure padding change, the same as
the three scored "DUMMY_TOFFOLIS padding change" rows under Neutral /
Mechanical. It removes gates that do nothing, so it could also be read as
dead-gate removal, but the gates were placed deliberately as padding, not as
a by-product of the arithmetic.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 62ae3d0 -- src/point_add`. The base is the git parent,
   the contest's initial commit. `git diff --ignore-cr-at-eol 62ae3d0 c55911f -- src/point_add`
   is 2 lines in 1 file.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line endings.
   It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol c55911f -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no
   `DUMMY_TOFFOLIS` or other environment overrides set. The commit was never
   scored. The same tree, scored as [`6f7c159`](6f7c159.md), gives:
   - 2715 qubits
   - 3,960,753 average Toffoli (rounded)
   - score 10,753,444,395
   - 0 classical, 0 phase and 0 ancilla failures

There is no tail nonce in this era. The 9,024 test inputs are a hash of the
op stream, so the score only reproduces with an identical op stream.
