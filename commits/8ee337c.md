## Summary

Point addition needs `λ = (y2 − y1) / (x2 − x1) mod p`. Since 897dda2 the
frontier computed that division, and the matching multiply, with the
ping-pong binary-division walk: about 700 fixed rounds, one tape bit per round.

This commit swaps the walk for **GCD Skywalk**, a reversible form of Stein's
binary GCD. Each step halves whichever rail is even and replaces the other
rail by a signed difference. It records one of three legal symbols (a trit),
and five trits are packed into 8 qubits. The walk needs 393 ticks for the
divide and 392 for the multiply, instead of about 700 rounds. The field
payload rides the same trajectory in a sum/difference pair `(Sig, Del)`, using
ping-pong's own replay cells.

The shorter history lowers the peak from 1250 to 1174 qubits. Every tick also
pays a full-width Fredkin row on the rails and a 256-wire controlled swap on
the payload, so Toffoli rises by 57,048 (6.4%). The product still falls by
605,000 against the base: 1174/1250 = 0.939 for qubits, 946,250/889,202 =
1.064 for Toffoli, net 0.99946.

## What changed and why it saves qubits

The new walk is explained in [skywalk-gcd](../concepts/skywalk-gcd.md). This
section says where each piece lives and what the shipped build switches on.

### Routing: `src/point_add/mod.rs` (in the patch)

- New `install_skywalk_submission_recipe()`, called first in `build()`. It sets
  about 100 process variables. The ones that select the architecture are:
  - `HEO_WALK=1` and `HEO_SCHEDULE=carry`: `build_point_add()` now calls
    `heo::divide(circ, y, x)` in phase `divide` and `heo::multiply(circ, y, x)`
    in phase `multiply`, instead of `pingpong::divide` / `multiply`.
  - `HEO_SEED=base`, `HEO_CARRY_SEED=fd`, `HEO_LT0=1`, `HEO_BW=inv`,
    `HEO_LT0_MUL=1`: the fused "FD" start frame (below).
  - `HEO_PIN_PP_WALK_MAX_QUBITS=1174`: the live-qubit cap that every chunked
    ladder is sized under. This is where the new peak is set.
  - `HEO_ENVELOPE`, `HEO_ENVELOPE_MUL`, `HEO_PROXY_ENVELOPE`,
    `HEO_CELL_WINDOWS`, `K3B_CELL_OVR`: point at the data files below. The
    loaders only test that the variable is set. The file contents are compiled
    in with `include_str!`, so the path value itself is never read.
  - 26 `HEO_PIN_<NAME>` entries. `env_raw()` now first asks
    `heo::pinned_override(name)`, which returns `HEO_PIN_<NAME>` whenever
    `HEO_WALK` is set. These re-pin ping-pong knobs that the payload cells
    still read, for example `HEO_PIN_FOLD_GUARD=21`,
    `HEO_PIN_PP_FOLD_WIDEN=64`, `HEO_PIN_PP_CHUNK_SHAPE=64:0,38:1,25:-3,0:-4`,
    `HEO_PIN_ERASE_COMPARE=25`, `HEO_PIN_SQ_ASM_TAIL=20`, a new
    `HEO_PIN_PP_WIDTH_SCHEDULE` and new `I12_*`, `I35_*`, `I41_ROUNDS` profiles.
  - Unpinned names fall through to `heo::passthrough()`, which reads the
    process environment. So with this recipe, any `SUB4_*`, `PP_*`, `HEO_*`,
    `GO_*` or similar variable left in the shell changes the circuit.
- The base's three pin blocks (pkgFdP + stk2, pkgN2, r6a_dpark) are removed.
  Their keys move back into the alphabetical list or into the recipe.
- `TAIL_NONCE`: 29190082163 → 2748956028.
- New post-pass `mabsorb::absorb(ops)` when `HEO_MABSORB=1` (set). It moves an
  X-basis measurement in front of the last X-type writes to its target and turns
  each such `CCX` into a `CZ` conditioned on the outcome. It is exact and saves
  one Toffoli per rewritten CCX.
- New helper `go_slice(key, round, dir)`: per-round ±bit offsets read from
  `GO_<KEY>` strings `lo-hi:dir:delta`. Pinned here: `GO_JLB=616-698:m:-1`
  (joint low-fold bits) and `GO_PRB=631-698:-1` (prebias retain bits).

### New file `src/point_add/heo.rs` (829 lines, copied)

- The environment overlay (`research_on`, `enabled`, `pinned_override`,
  `passthrough`, per-cell `CELL_PINS`).
- `config()` / `config_mul()`: parse the per-tick envelope, one `esw ead` line
  per tick (swap width and add width, sign bit included). `rounds()` is the
  number of lines: 393 for the divide, 392 for the multiply.
- The reference rail tick `fwd_tick` / `rev_tick`, ported gate for gate from
  the author's Python model. It sets `c = R1[0]`, Fredkin-swaps `R1[i] ↔ R2[i]`
  on `c` for `i ≥ 1`, takes `E/2 = R1[1..]` as a free relabel, and adds or
  subtracts `E/2` into `R2` with a Gidney adder whose carries are erased by
  `hmr` plus `cz_if`. The documented cost is `(esw − 1) + (ead − 1)` CCX per
  tick. `resize()` trims a rail by CX-ing its top wire with the wire below and
  freeing it, which is only valid if the top wire is a sign copy. That is the
  envelope's promise.
- The reference payload cells: `cell_fwd` calls ping-pong's division replay
  cell `add_halve` at `h7::proxy_round(esw[t])`, the first ping-pong round whose
  policy width is ≤ the rail width, then `route()`, which is 256 `cswap`s
  (256 CCX) controlled by the sign-flip bit `s`. `cell_rev` is the mirror,
  using `double_add`.
- The simple `fused` schedule and the `3dpp` / `pmd` seeds. They are not used:
  the recipe selects `carry`, which `divide()` / `multiply()` hand straight to
  `carry::divide` / `carry::multiply`.

### New file `src/point_add/heo_carry.rs` (3,244 lines, copied)

The production schedule (`HEO_SCHEDULE=carry`), included as `heo::carry`.

- **`CarryCfg`** reads every `HEO_*` switch. The ones the recipe sets:
  `r2d = 375` and `r2m = 370` (where the divide and multiply legs switch
  between fused ticks and a batch), `zone = 1`, `loan_both`, `rail_max = 257`,
  `db_skip`, `db_skip2`, `lr1`, `div_lifo_n = 1`, `mulb_lifo_n = 2`,
  `head_lifo_n = 2`, `div_partial`, `mulb_partial`, `div_early_p3`, `o0_dec`,
  `o0m`. Defaults used: `r1m = 190`, `split_k = 24`. `mb_skip2` exists but is
  left off here (800ba12 turns it on).
- **FD seed** (`fd_seed`, `fd_seed_at`). Instead of `(R1, R2) = (d + p, d)`,
  the rails start at `X = (d − b·p)/2` and `Y = d − (1 − b)·p + X`, with
  `b = d[0]`. This folds the first halving into the seed. `o_0 = NOT(X_sign ⊕
  X[254])` is read off the rails. `fd_payload_div` builds the payload class
  from `(N, 2N)` with one route and two conditional negations.
- **Rail ticks** `forward_tick` / `reverse_tick`, built on `fama_fwd` /
  `fama_rev` and `rail_add` with chunked carry splits. Forward splits use
  `SplitMode::Defer`: boundary carries are measured out at once, and their phase
  is repaired by the mirror pass. Multiply walk-back splits use the windowed
  `Approx` mode (`HEO_SPLIT_K`).
- **Tape** (`Tape`, `Group`). Each tick leaves `(typ, s)` on two raw wires.
  `pack3` folds three letters (6 wires) into 5 with
  `codec_synth::pack_compatible_shared` (3 CCX plus an `hmr` cleanup). `pack5`
  folds two more letters (4 wires) in with `pair_pack`, so a group of five
  letters sits on 8 wires. Groups are unpacked as the batch or the walk-back
  reaches them.
- **Codec shares.** With `HEO_CARRY_CODEC=1`, on the multiply forward pass the
  product `h2·typ3` that the rail add already computed is kept for one tick and
  replaces pack3's first CCX. With `HEO_REVERSE_CARRY_CODEC=1`, on the divide
  walk-back the unpack keeps that product and hands it to the reverse rail add
  as its first carry. Each share saves one CCX.
- **Divide leg** (`divide`):
  - Ticks `t < 375` run rail tick → codec pack → `cell_div` → `route`. With
    `HEO_CELL_INSIDE=1` the cell runs inside the rail tick, before the add.
  - Ticks 375..392 run rails only.
  - Then the terminal loan (`loan`, after `park_orient`, because the walk may
    park in either orientation), the trailing batch of cells 375..392 with the
    group codec, the endpoint `Del ^= Sig` (0 CCX, because `Sig == Del` at
    park), unloan, and the full reverse walk that restores the denominator.
  - The batch skips the route at `t = R − 1` (`db_skip`) and at `t = R − 2`
    (`db_skip2`).
- **Multiply leg** (`multiply`): rails-only forward walk with codec packing,
  loan, `Del = Sig`, the trailing batch of inverse cells 391..370 (route, then
  `cell_mul`), unloan, rails-only reverse, the fused walk-back for ticks
  369..190, the head batch of inverse cells 189..1, the FD payload inverse
  (`fd_payload_div_inv`), and the last reverse ticks.
- **Cells** `cell_div` / `cell_mul` call ping-pong's `add_halve` /
  `double_add` at the proxy round, with three per-cell adjustments:
  `HEO_PROXY_ENVELOPE` takes the proxy from a fixed envelope;
  `HEO_CELL_WINDOWS` adds `(dB, dF, dX)` to the chunk-boundary compare, the flag
  compare and the fold window of cell `(leg, t)`; `K3B_CELL_OVR` applies
  per-cell pin overrides keyed by the cell's call index.

### Why fewer qubits and more Toffoli

- **Qubits.** The peak is the replay plateau, where the history, the two
  256-bit payload registers and the rails are live together. Skywalk keeps
  about 393 × 8/5 ≈ 629 history wires, against ping-pong's one wire per round
  over about 700 rounds. That is my estimate; the submission note only says "a
  shorter total history". The ladders are then fitted under the new 1174 cap.
- **Toffoli.** Each tick pays a Fredkin row of about `esw − 1` CCX on the
  rails as well as the add, and each payload cell pays a 256-CCX route on top
  of ping-pong's cell. The note sums it up: "Skywalk pays additional routing
  per step, but performs many fewer steps."

## Why it is still correct, and what it risks

- **Exact parts.** The rail tick is exact while the envelope holds. The codecs
  are exact on the valid trit support. The FD seed is exact except for a
  2^-220 sliver in `o_0`. The endpoint `Del ^= Sig` is exact once the walk has
  parked. `mabsorb` is exact.
- **Probabilistic parts.**
  - Fixed depth: a walk that has not parked by tick 393 (392) gives a wrong
    quotient, a classical failure.
  - The envelope: a rail value wider than its `esw` / `ead` makes `resize`
    free a wire that is not a sign copy. That leaves ancilla garbage or a wrong
    result.
  - The payload cells inherit ping-pong's truncated chunk-boundary, flag and
    fold windows, here moved per cell by `windows_full_safe_mulB64.tsv`. A
    wrong `hmr` phase repair shows up as a phase failure.
  - The `HEO_FIT_K = 24` windows on the room-fitted adds, and the windowed
    multiply split repair (`HEO_SPLIT_K = 24`).
  - `db_skip2` drops the divide batch's route at `t = R − 2`. That route is the
    identity unless the walk parks exactly at tick R with `s_{R−2} = 1`.
- The note states a "limiting contract": later work on this circuit must keep
  its Lambda below 19.5 on 9,024 shots and must not cut rounds. Lambda is the
  expected number of failing shots per test draw. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).
- The shipped nonce `2748956028` draws a clean set: 9,024 of 9,024 shots, with
  0 classical, 0 phase and 0 ancilla failures.

## Classification rationale

The division and multiply primitive is replaced by a different GCD recurrence
with a new history encoding, while the affine-add shell stays the same. That is
Algorithmic Substitution → inversion/division algorithm swap, the type created
for the ping-pong swap [`897dda2`](897dda2.md). The trit codec, the FD fusions
and the measurement-absorption pass ride along, but none of them would exist
without the new walk.

+//! K3a measurement absorption: an exact, generic op-stream post-pass (`K3A_MABSORB=1`; off = byte-identical).
+//!
+//! An X-basis measurement turns every X-type write into its target into a phase:
+//! `CCX(a,b,t); ...; Hmr(t)->m` equals `Hmr(t)->m'` placed BEFORE the write, the write replaced by
+//! `CZ(a,b) if m'`, and `m <- m'` where the old `Hmr` stood.  It holds whenever `t` is never READ between the
+//! write and the measurement (it may be XOR-written: `X` -> `Neg if m'`, `CX(c,t)` -> `Z(c) if m'`,
+//! `CCX(a,b,t)` -> `CZ(a,b) if m'`), because the measurement's phase kick `(-1)^(m*t_final)` factorises over
+//! the writes and each factor is applied with the operands' values AT THAT WRITE.  `t` is |0> after the moved
+//! measurement, which is what the old one left.  Each rewritten CCX saves one Toffoli.
+//!
+//! Scope (conservative): every write in the window and both measurements sit at condition depth 0 and carry
+//! no per-op condition; the new bit `m'` is fresh (bits are unscored).
+use crate::circuit::{BitId, Op, OperationType as K, QubitId, NO_BIT, NO_QUBIT};

+        }
