## Summary

This is the first commit on the leaderboard. The organisers had renamed the
benchmark (`b807023`, which only touches `benchmark.json`) and put the
`DUMMY_TOFFOLIS` padding back to 10,000 (`e8ce2c9`, undoing
[`ca1bf33`](ca1bf33.md)'s 9,000). This submission
lowers the padding default from 10,000 to 9,000 on that tree. The padding is a
block of self-cancelling Toffoli pairs at the end of the circuit, so removing
1,000 pairs removes exactly 2,000 executed Toffoli per shot, and nothing else
changes. The resulting tree is byte-identical to the bootstrap commits
[`c55911f`](c55911f.md) and [`ca1bf33`](ca1bf33.md).

## What changed and why it saves Toffoli

- `src/point_add/mod.rs`, `build()`: against the git parent `e8ce2c9`, the
  default of `DUMMY_TOFFOLIS` goes from `10_000` to `9_000`. Against the base
  `c55911f` nothing changes.
- The block, at the end of `build()` after the point addition, runs `n` times
  `ccx(tx[0], ty[0], c); ccx(tx[0], ty[0], c)` on a fresh ancilla `c`, then
  frees `c`. Each pair is the identity, because CCX is self-inverse. The
  trusted simulator charges every unconditional CCX on every shot without
  looking at its controls, so each unit costs exactly 2 average Toffoli. The
  ancilla is allocated after all scratch is gone, so it never sets the peak.
  The code is quoted in [`c55911f`](c55911f.md).
- The arithmetic checks out against the leaderboard: 9,000 units give
  3,960,753 here, and 0 units give 3,942,753 at [`f43a73e`](f43a73e.md),
  a difference of 18,000 = 2 × 9,000.
- See [scoring-and-validation](../concepts/scoring-and-validation.md) and
  [dead-gate-strip](../concepts/dead-gate-strip.md).

## Why it is still correct, and what it risks

The change is exact. The removed gates were identity pairs, so outputs,
ancilla cleanliness, phase and peak qubits are those of the organisers'
circuit. The run passed with 0 classical, 0 phase and 0 ancilla failures.
There is no tail nonce in this era. The 9,024 test inputs are a SHAKE256 hash
of the op stream, so changing the padding re-draws them, but the arithmetic is
the same on every input.
