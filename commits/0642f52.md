## Summary

[`82c849b`](82c849b.md) added a post-pass that replaces some Toffoli gates by
CNOT chains. Each replacement is listed as one row in a table and is proven
exact offline with a SAT solver. This commit adds 11 more rows, so the table
grows from 57 to 68. Each row removes one unconditioned CCX, so the circuit
loses exactly 11 Toffoli on every shot. Nothing else in the circuit changes.

The score's average Toffoli fell by 15.95, not 11. The remaining ~5 comes from
the new nonce, which draws a different set of 9,024 shots. The note's means
over many nonces fall by exactly 11.0, from about 945,927.5 to about 945,916.5.

## What changed and why it saves Toffoli

- **New table `src/point_add/skywalk_data/sky6_z11_rewrite.txt`** (68 rows,
  copied). It is `sky5_ycd_rewrite.txt` plus 11 rows, and the old file is
  deleted.
  - A row is `widx c1 c2 t cst w1,w2,…`. It means that the unconditioned
    `CCX(c1, c2 → t)` at op index `widx` of the final op stream can become
    `CX(w1 → t), CX(w2 → t), …`, plus `X(t)` if `cst = 1`. That is valid
    because, on every reachable state at that point,
    `c1·c2 = w1 ⊕ w2 ⊕ … ⊕ cst`.
  - Op indices refer to the stream before any rewrite. The loader applies the
    rows in descending index order, so earlier splices do not move later
    ones.
  - The 11 new rows:
    - op 17,124: `17124 512 772 516 0 772`, so the product equals wire 772
      alone. The note places it between the FD seed and the y-sub ladder.
    - nine rows at ops 4,766,150 to 5,196,829, with 1 to 41 CX each;
    - op 8,926,749: `8926749 1054 904 970 0 904`, inside the multiply's FD
      payload.
  - The note says each candidate came from a "whole-program span census" of
    sky5. It was screened on millions of random shots and then proved exact by
    a SAT check over the exact op stream. Only proved rows are used.
- **`src/point_add/mod.rs`**:
  - The `SKY_REWRITE` block in `build()` now does
    `include_str!("skywalk_data/sky6_z11_rewrite.txt")`. The loader is
    unchanged: it finds the unique rigid shift under which every row names its
    CCX, asserts each match, and splices in the CX chain. See
    [`82c849b`](82c849b.md) for the loader.
  - Comments say sky6.
  - `TAIL_NONCE`: 5000500937876 → 6000441753949.

Each removed gate was a real, always-executed CCX, so the saving is exactly
one Toffoli per row on every shot. The CX chains cost nothing in the score.

## Why it is still correct, and what it risks

- **Exact.** Each rewrite is an identity on the reachable state space, proved
  offline. The note confirms that, paired against sky5 on the same shots, the
  classical, phase and ancilla failure counts are identical, and ΔT is exactly
  −11.0. Lambda is unchanged: the note reports 17.848 ± 0.031 on 16,384
  nonces.
- **Fragile to any upstream change.** The rows are keyed to op positions and
  wire numbers. If a later change shifts the stream non-rigidly, the build
  panics at the unique-shift assert. A row is only valid together with the
  computation around it, so the rows must be re-proved, not re-indexed.
  [`800ba12`](800ba12.md), which builds on sky5, drops the whole block for this
  reason.
- The shipped nonce `6000441753949` draws a clean set: 9,024 of 9,024 shots,
  with 0 classical, 0 phase and 0 ancilla failures. The average is 945,907.931
  Toffoli.

## Classification rationale

The saved Toffolis come from facts about wire values at specific points. A
solver derives those facts on the host, and they are baked into the build as
data. That is host-derived / classical specialization. The runner-up is
dead-gate removal: each rewrite strength-reduces a CCX whose nonlinearity is
provably absent, much like the dead-gate strip.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 82c849b -- src/point_add`. The base is the git parent.
   `git diff --ignore-cr-at-eol 82c849b 0642f52 -- src/point_add` is 19 changed
   lines in 2 files: the table rename with 11 added rows, and `mod.rs`.
2. **Copy the new rewrite table from the commit:**
   `git checkout 0642f52 -- src/point_add/skywalk_data/sky6_z11_rewrite.txt`.
   It is generated data (68 rows), described above.
3. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line endings.
   It edits `mod.rs` and deletes the old `sky5_ycd_rewrite.txt`.
4. **Check the tree.** `git diff --ignore-cr-at-eol 0642f52 -- src/point_add`
   should print nothing.
5. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh`. `build()` clears
   the process environment, but keep `SUB4_*`, `PP_*`, `HEO_*`, `GO_*` and
   `SKY_*` unset anyway. Expect:
   - 1174 qubits
   - 945,908 average Toffoli (945,907.931 before rounding)
   - score 1,110,495,992
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `6000441753949` and an identical op
stream. Any other change needs a new nonce hunt and re-proved rewrite rows.
