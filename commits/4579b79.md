## Summary

[`d6eed9a`](d6eed9a.md) put its shifted-low square reroute on the risk-2.5
strip table, because 900M nonces on the risk-3.0 table had found no clean
draw. This commit goes back to the risk-3.0 table, byte-identical to the one in
[`5265674`](5265674.md), and searches a new, disjoint range of nonces. After
171M nonces it found a clean one.

The risk-3.0 table has 253 more deletions and 116 more CX/CZ downgrades.
Applied to this stream, it saves 312.25 more average Toffoli (−313 after
rounding). The arithmetic is unchanged. The table was mined on the stream
before the reroute, so 251 dead keys are again discarded as stale.

## What changed and why it saves Toffoli

- **`src/point_add/deep_strip_keys.rs`:** replaced by the risk-3.0 table:
  `DEAD_KEYS` 12,290 → 12,543 and `DOWNGRADE_KEYS` 3,807 → 3,923, the same file
  as 5265674.
  - The build logs "251 keys discarded because tuple occupancy changed; removed
    12292 / 12543 dead; downgraded 3923 / 3923 to CX/CZ".
  - The same 251 keys go stale as on the 2.5 table, so all 253 extra deletions
    and 116 extra downgrades take effect. Emitted ops drop by 253, to 9,058,065.
  - See [`6e9f0af`](6e9f0af.md) for the risk-ranked admission rule and
    [dead-gate-strip](../concepts/dead-gate-strip.md) for the mechanism.
- **`src/point_add/trailmix_ludicrous/square.rs`.**
  - A comment explains why the shifted-low branch still allocates 128 unused
    pad wires: "Removing these unused pads makes 4,486 keys stale". Freeing them
    would change which qubit ids later gates get, and with that the strip keys'
    operand tuples.
  - `shifted128_low_miter()` now restores `TLM_SQUARE_NO_VENT_REDUCE` and
    `TLM_SQUARE_VENT_SHIFTED` when it returns, through a drop guard. It is still
    not called by the build.
- **`src/point_add/mod.rs`:** tail nonce `SUB4_TAIL_NONCE` 58000098603199 →
  60000115034108.
- **`src/point_add/memory/repro/__pycache__/`:** 12 more Python bytecode files,
  not part of the circuit.

## Why it is still correct, and what it risks

- **Empirical.** Per [`7726431`](7726431.md)'s ladder, budget 3.0 adds about
  2.3 expected failing shots per random draw, against 1.9 at 2.5. On this stream
  the author's earlier courts found no clean draw in 900M nonces.
  - The only 8,192-shot survivor failed at shot 8,756, which the accepted parent
    also fails under the same seed.
- **The final court.** It searched 171,000,000 nonces in four disjoint ranges.
  There were 967 GPU hits; 600 passed 512 shots, 156 passed 2,048, 1 passed
  8,192, and that one also passed 9,024.
- The shipped nonce `60000115034108` draws a clean set: 9,024 of 9,024 shots, 0
  classical, 0 phase and 0 ancilla failures. The author verified the rebuilt
  stream by its decoded canonical hash. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

The only circuit change is a larger empirical strip: dead-gate/self-inverse
removal.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout d6eed9a -- src/point_add`. The base is the git parent.
   `git diff --ignore-cr-at-eol d6eed9a 4579b79 -- src/point_add` is 399 lines in
   15 files: 369 added key lines, the `square.rs` and nonce edits, and 12 binary
   `.pyc` files.
2. **Copy the generated table and the bytecode files from the commit:**
   `git checkout 4579b79 -- src/point_add/deep_strip_keys.rs src/point_add/memory`.
   The `.pyc` files are binary, so a text patch cannot carry them.
3. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line endings.
   It covers `mod.rs` and `square.rs`.
4. **Check the tree.** `git diff --ignore-cr-at-eol 4579b79 -- src/point_add`
   should print nothing.
5. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `TLM_*` or
   `SUB4_*` overrides set. Expect:
   - 1154 qubits
   - 1,289,081 average Toffoli (1,289,081.341 before rounding)
   - score 1,487,599,474
   - 0 classical, 0 phase and 0 ancilla failures
6. **Nonce caveat.** The score only reproduces with the nonce `60000115034108` and
   an identical op stream. Any other change needs a new nonce hunt.
