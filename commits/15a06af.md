## Summary

The second bootstrap commit. It lowers the default of the `DUMMY_TOFFOLIS`
padding knob from 9,000 to 8,000. The padding is a block of self-cancelling
Toffoli pairs at the end of the circuit, put there by the organisers to test
the acceptance pipeline. Removing 1,000 pairs removes exactly 2,000 executed
Toffoli per shot and changes nothing else. The commit was accepted but never
scored. The organisers later reset the knob to 10,000 (`db48f66`, "reset
dummy"), so this value never reached a scored tree.

## What changed and why it saves Toffoli

- `src/point_add/mod.rs`, `build()`: the default of `DUMMY_TOFFOLIS` goes
  from `9_000` to `8_000`.
- The block runs `n` times `ccx(tx[0], ty[0], c); ccx(tx[0], ty[0], c)` on a
  fresh ancilla `c` after the point addition is finished. Each pair is the
  identity, because CCX is self-inverse, but the simulator charges both gates
  on every shot. One unit therefore costs exactly 2 average Toffoli and no
  qubit. The code is quoted in [`c55911f`](c55911f.md).
- See [scoring-and-validation](../concepts/scoring-and-validation.md) for how
  executed Toffoli are counted, and
  [dead-gate-strip](../concepts/dead-gate-strip.md) for why gates that do
  nothing are still paid for.

## Why it is still correct, and what it risks

The change is exact. Only the number of identity pairs differs, so outputs,
ancilla cleanliness, phase and peak qubits are those of the base. There is no
tail nonce in this era. The 9,024 test inputs are a SHAKE256 hash of the op
stream, so the draw changed, but the arithmetic is the same on every input.

## Classification rationale

The commit is one of the four pre-leaderboard padding commits, which the
census puts in their own "Unscored bootstrap" group. Had it been scored, it
would be a "DUMMY_TOFFOLIS padding change" under Neutral / Mechanical, like
[`6f7c159`](6f7c159.md).

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout c55911f -- src/point_add`. The base is the git parent.
   `git diff --ignore-cr-at-eol c55911f 15a06af -- src/point_add` is 2 lines
   in 1 file.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line endings.
   It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 15a06af -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no
   `DUMMY_TOFFOLIS` or other environment overrides set. The commit was never
   scored. By the padding arithmetic (3,942,753 for the unpadded circuit, see
   [`f43a73e`](f43a73e.md), plus 2 × 8,000), expect:
   - 2715 qubits
   - 3,958,753 average Toffoli
   - score 10,748,014,395
   - 0 classical, 0 phase and 0 ancilla failures

There is no tail nonce in this era. The 9,024 test inputs are a hash of the
op stream, so the score only reproduces with an identical op stream.
