## Summary

zuiris's positional dead-CCX strip ([`4a90d04`](4a90d04.md), extended in
[`20b9a1d`](20b9a1d.md)) ran on the 1159-qubit tree. This commit brings the
same mechanism to the author's 1156-qubit tree, [`cde752d`](cde752d.md). The
lists are tied to op positions, so zuiris's list cannot be reused. The commit
ships a new list of 14,361 never-firing CCX positions, generated for this
exact stream.

It also makes two circuit changes first, and the list is specific to them:
- **The K1 apply-add skip.** In the last GCD iteration, the apply step's
  controlled modular add (forward) or subtract (inverse) is dropped.
- **The quantum `3·ox` coordinate step.** The shell switches back from the
  classical form to the original quantum form, `coord_add3x_orig`.

The net is −14,996 average Toffoli at the same 1156 qubits. Most of it is the
strip.

## What changed and why it saves Toffoli

1. **Dead-CCX drop** (`src/point_add/mod.rs`, end of `build()`, after the
   single-CCX fanout loop).
   - The same filter as `4a90d04`: parse indices, keep only the ops whose
     position is not listed.
   - Two new switches: `DROP_DEAD_ROBUST_DISABLE=1` turns it off (needed to
     screen for the list), and `DROP_DEAD_IDX_FILE=<path>` reads another list
     instead of the baked one.
   - **New data file `src/point_add/dead_k1_nocoord3x.idx`** (generated). It has
     an `idx` header line, then 14,361 indices from 4,759 to 10,107,105.
   - Per the author's note, the gates were found by screening the drop-disabled
     stream over about 9 M inputs and keeping those that never fired
     (`cond & c1 & c2 == 0` on every shot).
   - Each removed CCX was charged but did nothing. See
     [dead-gate-strip](../concepts/dead-gate-strip.md).
2. **K1 apply-add skip** (`gcd.rs`, new `apply_add_skip(i, fwd)`, default
   `TLM_APPLY_ADD_SKIP_LASTK=1`).
   - When `i + 1 >= ITERS`, `apply_step_forward` skips its
     `controlled_mod_add_k(sub, x, y)` and `apply_step_reverse` skips its
     `controlled_mod_sub_vented(sub, x, y)`.
   - That step is GCD iteration 257, the first forward-apply step and the last
     inverse-apply step. Each skipped call is a full 256-bit controlled add
     with its `+f` fold and truncated compare-erase.
   - The `next_cout_k()` / `next_ffg()` schedule cursors are still advanced,
     so later calls keep their schedule values.
   - It is a no-op whenever `subtracted = 0` at step 257, which holds whenever
     the GCD finished earlier. The new switches `TLM_APPLY_ADD_SKIP_FWD` and
     `TLM_APPLY_ADD_SKIP_INV` can set the two directions separately. They are
     not set.
3. **`3·ox` step back to the quantum form** (`ec_add.rs`, `ec_add`, phase
   `tlm_coord_add3x`).
   - The call changes from `coord_add3x` to `coord_add3x_orig`.
   - `coord_add3x` derives `3·ox mod q` with free classical-bit ops and does
     one exact `mod_add_exact`.
   - `coord_add3x_orig` loads `ox` into a 257-qubit temp, then runs
     `mod_add`, `mod_double`, `mod_add` and `mod_double_reverse`.
   - By the code's own comment, the quantum form emits more Toffoli (about 754
     against 326). It also makes three more `add_f_window` calls, which moves
     every later `+f` call index, and with it the per-call reserve overrides, by
     3.
   - The commit adds `arith::advance_ffg_call_index(n)` and calls it with 3 at
     the end of the classical `coord_add3x`, to keep those indices aligned. But
     the shipped path no longer calls `coord_add3x`, so this only matters for
     the next commit, [`27d4627`](27d4627.md), which switches back.
   - The note gives no reason for the switch. The list's name,
     `dead_k1_nocoord3x`, records that it was screened on this variant.
4. **Nonce:** `DIALOG_TAIL_NONCE` 9600006009245 → 9500055003049.

## Why it is still correct, and what it risks

- **The strip is empirical.** A listed CCX that fires on an unscreened input
  makes that input hard: a classical failure, or a phase failure inside a
  measured-erase recompute. The list is positional, so it is valid only for
  this stream.
- **The K1 add skip is probabilistic.** It breaks inputs whose binary GCD
  still subtracts at iteration 257. The tail stack of `cde752d` (the `s2`-zero
  and cswap skips) already gives up the same class of inputs, so this adds
  little new risk.
- The quantum `3·ox` path is the circuit's original form, with its usual
  truncated `+f` windows.
- The author hunted the island with the drop on. The shipped nonce
  `9500055003049` draws a clean set: 9,024 of 9,024 shots, with 0 classical,
  0 phase and 0 ancilla failures. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

Almost all of the saving comes from deleting never-firing gates, so
dead-gate removal is the right label. The K1 add skip is a smaller
probabilistic tail truncation. The `3·ox` switch costs Toffoli.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout cde752d -- src/point_add`.
   - Do not start from the git parent `20b9a1d`. That is the 1159-qubit
     `f6ce76d` lineage, with zuiris's and mpjunior92's drop lists. This commit
     was built on the author's 1156-qubit `cde752d`.
   - Against the parent, the diff (44,368 lines) would delete both of their
     index files and undo the whole 1156 stack.
   - Against `cde752d`, `git diff --ignore-cr-at-eol cde752d 6c0769f -- src/point_add`
     is 14,467 lines in 5 files. 14,362 of them are the new index file.
2. **Copy the generated index list from the commit:**
   `git checkout 6c0769f -- src/point_add/dead_k1_nocoord3x.idx`.
3. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`. The flag lets the patch apply whether the files use LF or CRLF line endings. It covers
   the four source files.
4. **Check the tree.** `git diff --ignore-cr-at-eol 6c0769f -- src/point_add`
   should print nothing.
5. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no
   `DIALOG_*`, `TLM_*`, `LUD_*`, `CONSTPROP_*`, `SINGLE_CCX_FANOUT_*` or
   `DROP_DEAD_*` environment variables set. Expect:
   - 1156 qubits
   - 1,366,238 average Toffoli (rounded)
   - score 1,579,371,128
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `9500055003049` and an identical op
stream. Any other change needs a new nonce hunt and a regenerated list.
