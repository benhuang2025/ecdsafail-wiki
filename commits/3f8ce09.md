## Summary

Each divstep of the trailmix jump-GCD decides whether to swap `u` and `v` with
a truncated comparison `v < u` over the top `GAP_J2[i]` bits. This commit
compares 2 fewer bits on every divstep below 200, in all four GCD walks. The
author found that the comparator window has slack only in the early divsteps,
where `u` and `v` almost never agree on their top bits. From about divstep 200
on there is no slack, so those steps are left alone. The submission note
measures −568.6 executed Toffoli for this, against a control build that
reproduces the base byte for byte.

Narrowing the comparator shifts every later op index, so the base's positional
dead-CCX strip (M-60, 2,101 indices) no longer lines up. The commit switches it
off and ships a freshly mined positional strip, `D2_DEEP_STRIP`, with 1,999
indices. It also adds an exact CCZ self-inverse cancellation pass. The net
change is −396 Toffoli at the same 1152 qubits.

## What changed and why it saves Toffoli

1. **Comparator window, `src/point_add/trailmix_ludicrous/gcd.rs`.**
   - New `cmp_window(i, current_n)` replaces the inline
     `(GAP_J2[i] as usize).min(current_n).max(1)` in both `forward_gcd_jump` and
     `reverse_gcd_jump`. `current_n = SCHED_J2[i]` is the live width of `u` and
     `v` at divstep `i`.
   - The window is passed as `k` to `controlled_swap_decision_v_lt_u`, which
     calls `comparator::controlled_swap_decision_lt_truncated`. That computes the
     swap flag `s = subtracted AND (v < u)` from the top `k` bits of `v` and `u`
     only. Fewer bits means fewer Toffoli in each comparator.
   - With `TLM_GAP_J2_DELTA = d > 0`, the window becomes `max(1, base − d)` for
     divsteps `LO ≤ i < HI`, where `base` is the old window. With
     `TLM_GAP_J2_TRUNC_ONLY=1` a step is narrowed only if `GAP_J2[i] < current_n`,
     that is, only where the compare was already a truncation, not an exact
     full-width compare.
   - `build()` in `src/point_add/mod.rs` forces `TLM_GAP_J2_TRUNC_ONLY=1`,
     `TLM_GAP_J2_DELTA=2`, `TLM_GAP_J2_LO=0` and `TLM_GAP_J2_HI=200`.
   - In the shipped `schedule.rs` (`ITERS = 258`), `GAP_J2[i] < SCHED_J2[i]` holds
     for all 200 divsteps 0–199. For example step 1 goes from 25 bits to 23, and
     step 199 from 53 to 51. Step 0 takes its swap flag from `subtracted`
     directly, so it has no comparator. The narrowing therefore applies to
     divsteps 1–199 in each of the four walks (forward and reverse, in both
     `tlm_inverse` and `tlm_forward_multiply`).
   - The forward and reverse walks call the same `cmp_window`, so the reverse
     walk recomputes exactly the swap flag that the forward walk wrote. That is
     required for the reverse walk to erase it. See
     [trailmix-jump-gcd](../concepts/trailmix-jump-gcd.md) and
     [comparator-and-width-truncation](../concepts/comparator-and-width-truncation.md).
2. **Strip swap, `src/point_add/mod.rs`.**
   - `build()` forces `M60_DISABLE=1`, which turns off `apply_m60_dead_t10`.
     M-60 was a list of 2,101 op indices into the base's post-fanout stream. The
     code comment says it "would misalign here", since the narrower comparators
     move every later index.
   - New `apply_d2_deep_strip()` deletes the 1,999 op indices in the new
     generated file `src/point_add/d2_deep_strip.rs` (`D2_DEEP_STRIP: [usize; 1999]`).
     Its header says the indices point into the *final* emitted stream, after
     fanout, the CCZ cancel and the CCX final cancel. It says the gates were
     verified never to fire over 1e8 random inputs (seeds 909, 1111, 2222 and
     3333). Unlike M-60, the new pass does not assert that each index is a CCX.
   - The submission note explains why the census depth matters. The marginal
     gates fire at about 1e-6, so strips mined from 5e5–1e6 inputs looked clean
     and then dropped the clean-batch rate from 0.85 to 0.33. See
     [dead-gate-strip](../concepts/dead-gate-strip.md).
3. **Exact CCZ cancel, `trailmix_ludicrous/constprop.rs`.**
   - New `ccz_straddle_cancel(ops)`. Two CCZ on the same unordered triple, under
     the same classical condition and condition epoch, cancel if all three qubits
     are net-restored between them. Net-restored means `control_net_restored`
     proves each qubit's computational-basis value is the same at both CCZ.
     CCZ·U·CCZ = U then holds exactly, in value and phase.
   - It runs by default from the new `ccz_self_inverse_cancel()` wrapper in
     `mod.rs` (`TLM_CCZ_SELF_INVERSE_CANCEL=0` turns it off). `constprop` becomes
     `pub(crate)` in `trailmix_ludicrous/mod.rs` so `mod.rs` can call it.
   - `mod.rs` also keeps an unused prototype, `ccz_self_inverse_cancel_conservative`,
     marked `dead_code`.
4. **CCX final cancel, added but off.** `constprop::ccx_final_cancel` re-runs
   `find_inverse_pairs` on the final stream. It returns the ops unchanged unless
   `TLM_CCX_FINAL_CANCEL=1`, which nothing in the tree sets. It has no effect on
   the shipped circuit.
5. **Post-pass order and nonce.** The tail of `build()` becomes
   `apply_m60_dead_t10` (disabled) → `ccz_self_inverse_cancel` →
   `ccx_final_cancel` (off) → `apply_d2_deep_strip` → `apply_tail_nonce(ops, 706362233434)`.
   - The trailmix builder still emits the 96-X identity tail from
     `DIALOG_TAIL_NONCE = 9000624727621`.
   - The new `apply_tail_nonce` then rewrites only the `q_target` of those 96 X
     ops, to encode the new nonce 706362233434. That is the nonce that counts.
     See [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Why it is still correct, and what it risks

- **Comparator narrowing: probabilistic.** A truncated `v < u` is wrong when
  `u` and `v` agree on all compared top bits. The walk then takes the wrong
  swap and the GCD transcript is wrong, which shows up as a classical failure,
  usually with phase garbage as well. The author's claim is that in divsteps
  below 200 the extra 2 bits never decided a compare. The note says the error
  rate at a fixed seed did not change ("error-neutral"), and that narrowing all
  divsteps uniformly "destroys the circuit".
- **D2 strip: empirical.** A gate that would fire on an input outside the 1e8
  census gives a wrong output or phase on that input. The list is positional,
  so it is valid only for exactly this op stream. Any upstream edit makes it
  delete the wrong ops, and nothing checks for that.
- **CCZ cancel: exact.** It removes only pairs that it proves are the identity.
- The shipped nonce `706362233434` draws a clean test set: 0 classical, 0
  phase and 0 ancilla failures. The note warns that the per-nonce spread of the
  average executed Toffoli is about 14.5 (1 SD), so its measurements are paired
  over 36–48 nonces.

## Classification rationale

The note credits about −569 Toffoli to the comparator narrowing, more than the
whole net −396, so the strip swap and the CCZ cancel are slightly negative
together. The main lever is the narrower comparator window, which makes this
comparator/width truncation. The runner-up is dead-gate/self-inverse removal,
for the D2 strip and the CCZ cancel.
