## Summary

In this era the slope λ comes from a reversible binary GCD (the "dialog GCD").
Its two apply passes do, per GCD step, one controlled modular add (product
pass) and one controlled modular subtract (quotient pass). Each leaves an overflow (or underflow) bit that must be
cleared, and the circuit clears it with a comparison of only the top `k` bits
of two registers. This commit makes `k` 19 instead of 20. One comparator bit
costs one Toffoli, the clean runs twice per step, and there are 399 steps, so
the saving is 2 × 399 = 798 Toffoli. Qubits are unchanged. The Fiat–Shamir
reroll pair was re-searched because the op stream changed.

## What changed and why it saves Toffoli

All circuit changes are in `configure_ecdsafail_submission_route()` in
`src/point_add/mod.rs`, which sets the route's knobs with `set_default_env`.

1. **`DIALOG_GCD_APPLY_CLEAN_COMPARE_BITS`: 20 → 19.**
   - `dialog_gcd_apply_clean_compare_bits()` reads it (falling back to
     `DIALOG_GCD_COMPARE_BITS` if unset). It sets `compare_start = N − k`.
   - With `DIALOG_GCD_APPLY_CHUNKED_F_BLOCKS=2`,
     `DIALOG_GCD_RAW_APPLY_TRUNCATED_CLEAN=1` and
     `DIALOG_GCD_MEASURED_APPLY_SUB=1`, the apply pass runs
     `dialog_gcd_cmod_add_materialized_pseudomersenne_chunked` and
     `dialog_gcd_cmod_sub_materialized_pseudomersenne_chunked`. Each computes
     `acc ± ctrl·a` into a 257-bit extended register, then folds the spill
     bit `acc_ovf` back with the pseudo-Mersenne constant `c = 2^256 − p`
     (see [modular-fold](../concepts/modular-fold.md)).
   - `acc_ovf` must then be erased. For the add, a wrap happened exactly when
     the reduced result is smaller than the addend, so the phase
     `..._overflow_clean` runs
     `ccx_cmp_lt_into_fast(acc[N−k..], a[N−k..], ctrl, acc_ovf)`. For the
     subtract, `dialog_gcd_clean_truncated_underflow` runs the mirrored compare
     on the same top `k` bits.
   - `ccx_cmp_lt_into_fast` spends one CCX per bit on its carry chain plus one
     for the output, and clears its carries by measurement (`hmr` + `cz_if`,
     see [measurement-uncompute](../concepts/measurement-uncompute.md)). So it
     costs `k + 1` Toffoli. One bit fewer saves one Toffoli per call.
   - Per GCD step there is one add (the product pair) and one subtract (the
     quotient pair), and `DIALOG_GCD_ACTIVE_ITERATIONS=399`:
     2 × 399 = 798 Toffoli, exactly the measured change.
2. **Reroll pair: `DIALOG_REROLL` 2 → 6, `DIALOG_POST_SUB_REROLL` 10 → 28.**
   These are identity `X;X` counts emitted in `build_builder()` before and just
   after `Px −= Qx; Py −= Qy`. They change the op-stream bytes, and so the
   9,024 test inputs, without changing the circuit (see [`ecbf87b`](ecbf87b.md)).
   This era has no tail nonce; the pair plays that role.
3. **Comments only.** The long comments on the round763 compressor lever
   (`round763_compress_lever_enabled`, `emit_dialog_gcd_round763_compressor`
   and its inverse, and the `set_default_env` line) are shortened. The lever
   itself, `DIALOG_GCD_ROUND763_COMPRESS_LEVER=1`, was already on in the base.
4. **New file `src/point_add/memory/2026-06-02-round763-applyclean19-stack.md`**,
   the author's log. It describes stacking "the round763 lever" and
   apply-clean 19 onto `3bd3aa5`; against this commit's actual base `8117d98`,
   only the apply-clean change is new. The log records which old reroll
   islands failed (4/15, 6/3, 0/23, 1/0, 3/18) and the validated 6/28.

## Why it is still correct, and what it risks

The add, the fold and the stored result are exact; only the erasure of the
overflow bit is approximate. The top-`k` compare gives the wrong answer when
`acc` and `a` agree on all top `k` bits but the full comparison differs, about
2^-k per call for random values. Going from 20 to 19 bits roughly doubles that
chance across the 798 calls. When it happens, `acc_ovf` is left at 1 when it is
freed, which the evaluator sees as phase or ancilla garbage; the classical
output is unaffected.

The reroll pair (6, 28) draws a test set with no such input: 9,024 of 9,024
shots pass with 0 classical, 0 phase and 0 ancilla failures at 1567 qubits
(peak in `round84_fused_square_xtail_dx_sub_lam_square_lowq`, per the author's
log). See [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

The only circuit change is a narrower cleanup comparator, so comparator/width
truncation fits. The reroll change comes with every circuit change in this era
and is not a separate lever.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 8117d98 -- src/point_add`. The base is the git parent.
   `git diff --ignore-cr-at-eol 8117d98 006e38b -- src/point_add` is 65 lines
   in 2 files (one of them the new memory log).
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line endings.
   It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 006e38b -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `DIALOG_*`,
   `KAL_*` or `ROUND84_*` environment variables set, because `set_default_env`
   keeps any value already in the environment. Expect:
   - 1567 qubits
   - 1,685,515 average Toffoli (rounded)
   - score 2,641,202,005
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the reroll pair `DIALOG_REROLL=6`,
`DIALOG_POST_SUB_REROLL=28` and an identical op stream. Any other change needs
a new reroll search.
