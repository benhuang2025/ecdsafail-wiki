## Summary

This commit moves two truncation knobs in opposite directions.

- The GCD width envelope gets steeper: `DIALOG_GCD_WIDTH_SLOPE_X1000` goes from
  1005 to 1008. The working window is then 2 bits narrower on 42 steps between
  126 and 257, which saves 1,408 Toffoli.
- The apply-phase fold window goes back from 23 to 24 bits, undoing `af0f90a`'s
  lever. That costs 518 Toffoli.

The net change is −890 Toffoli at the same 1390 qubits. The author's note says
this combination had the densest clean-island signal of the candidates they
were searching. Giving back the fold bit lowers λ, which pays for the steeper
slope.

## What changed and why it saves Toffoli

**Background.** The circuit is the dialog-GCD route (`emit_dialog_gcd_raw_pa`
in `src/point_add/mod.rs`). Two calls each run a reversible binary GCD on
(u, v) = (p, factor): the quotient dy/dx and the product with c = ox − Rx. Each
call has a forward pass, an apply pass and a reverse pass. [98416e4](98416e4.md)
lists one GCD step and the width formula
`active_width(step) = clamp(2·⌈(256 − step·SLOPE/1000 + MARGIN)/2⌉, 1, 256)`,
with `MARGIN` = 9 here. [af0f90a](af0f90a.md) explains the fold window.

**The changes in `configure_ecdsafail_submission_route()`:**

1. **`DIALOG_GCD_WIDTH_SLOPE_X1000`: 1005 → 1008.**
   - Because of the even rounding, the window becomes 2 bits narrower at
     42 steps: the even steps 126 to 200 (140 → 138 at step 126) and the odd
     steps 251 to 257 (8 → 6 at step 257). Elsewhere it is unchanged.
   - Per bit-step, the four GCD passes cost about 4 × 4 = 16 Toffoli for the
     cswap, subtract or add, and K=2 halving.
   - The comparator adds 4 more when the window is at or below the 72-bit
     comparator cap (`DIALOG_GCD_COMPARE_BITS = 72`). That is true for the last
     8 of the 42 steps.
   - 34 × 2 × 16 + 8 × 2 × 20 = 1,408 Toffoli saved.
2. **`KAL_FOLD_CARRY_TRUNC_W`: 23 → 24.**
   - Each apply-step fold `cadd_nbit_const_direct_trunc_fast(acc[..73], c, acc_ovf, w)`
     gets one more carry position, which is one more Toffoli.
   - There are 259 apply steps in each of 2 GCD calls, so this costs 518.
   - The comment above the knob still describes the 24 → 23 tightening. It was
     not updated.
3. **`DIALOG_TAIL_NONCE`**: 189322128207780 → 22011802698611.

The net is −1,408 + 518 = −890, exactly the measured change.

## Why it is still correct, and what it risks

Both knobs are probabilistic truncations.

- A steeper slope cuts the top bits of any input whose GCD registers have not
  shrunk as fast as the envelope assumes. This notch narrows steps from 126 on,
  where the 1004 → 1005 notch only reached steps 202 to 248. A failure
  makes the GCD wrong, which is a classical failure.
- Widening the fold window from 23 to 24 halves that lever's small failure rate,
  about 2^-(w+1) per firing fold.

The trade is about where the hard inputs land, not a proof. The shipped nonce
`22011802698611` draws a clean set: 0 classical, 0 phase and 0 ancilla failures
over all 9,024 shots.

## Classification rationale

The saving comes from the narrower GCD window, which is comparator/width
truncation. The fold-window change goes the other way. It spends a little
Toffoli to make the island easier to find.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout b84d15c -- src/point_add`. The base is the git parent.
   `git diff --ignore-cr-at-eol b84d15c f0e2891 -- src/point_add` is 6 changed
   lines in 1 file.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line endings.
   It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol f0e2891 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no
   `DIALOG_*`, `KAL_*`, `KARA_*` or `ROUND84_*` environment variables set.
   `set_default_env` only fills variables that are unset. Expect:
   - 1390 qubits
   - 1,529,503 average Toffoli (rounded)
   - score 2,126,009,170
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `22011802698611` and an identical op
stream. Any other change needs a new nonce hunt.
