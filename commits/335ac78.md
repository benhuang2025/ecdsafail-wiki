## Summary

[075c0c6](075c0c6.md) used the fact that `u` is always odd in the dialog-GCD
walk to drop the bit-0 swap and the bit-0 gated-load Toffoli. This commit
takes the same fact one step further, into the controlled subtract `v -= b0·u`
itself. Bit 0 of that subtraction is always `1 − 1` or `0 − 0`, so its result
is known and it never borrows. Bit 0 can therefore be set with one CX, and the
measured Cuccaro subtractor can start at bit 1, one bit shorter. The reverse
walk's controlled add gets the same treatment. One Toffoli is saved per step
per walk: 399 × 4 = 1,596. Qubits are unchanged.

## What changed and why it saves Toffoli

Background on the walk step is in [8316db1](8316db1.md), and on the odd-`u`
invariant in [075c0c6](075c0c6.md).

`src/point_add/mod.rs`, `dialog_gcd_controlled_sub_selected` (forward walk,
`acc = v`, `subtrahend = u`, `ctrl = b0`), with the switch
`DIALOG_GCD_ODD_U_LOWBIT_FASTPATH = 1` that is already on:

- `body_start = 1`. The gated load runs `ccx(ctrl, subtrahend[i], gated[i])`
  only for `i ≥ 1`, so `gated[0]` is no longer written. In the base it was
  written with a CX.
- A new `cx(ctrl, acc[0])` replaces bit 0 of the subtraction. At this point
  `acc[0] = v[0] = b0 = ctrl`: `b0` was copied from `v[0]`, and the swap keeps
  bit 0 because both bits are 1 when it fires. Also `subtrahend[0] = u[0] = 1`.
  So the low bit of `v − ctrl·u` is `ctrl ⊕ ctrl = 0`, and there is no borrow
  into bit 1.
- The measured subtractor (`sub_nbit_qq_fast_borrowed_carries`) now runs on
  `gated[1..w]` / `acc[1..w]`, with `body_len − 1` borrowed carries. That is
  one CCX fewer.
- The `hmr` + `cz_if` clear loop runs for `i ≥ 1` only.

`dialog_gcd_controlled_add_selected` (reverse walk, the inverse operation)
gets the mirror change:

- After `unshift`, `acc[0] = 0`. The walk's subtraction always leaves `v`
  even (odd − odd, or no subtraction when `v` is even), and the shift rotation
  puts that 0 back at bit 0.
- `addend[0] = u[0] = 1`, so bit 0 of `v + ctrl·u` is `ctrl` and does not
  carry. It becomes `cx(ctrl, acc[0])`, and the adder starts at bit 1.

Count: one CCX per step per walk. 399 steps × 4 walks = 1,596 Toffoli, exactly
the measured drop.

Other edits:
- `DIALOG_REROLL` 9 → 1 and `DIALOG_POST_SUB_REROLL` 10 → 12. These are the
  two identity `X;X` pads that pick the Fiat–Shamir draw.
- A comment update.
- A new memory note, `src/point_add/memory/2026-06-02-lowbit-body-skip.md`,
  with the same reasoning and the validation commands.

## Why it is still correct, and what it risks

This is exact on every input. Both facts it relies on hold by construction:
- `u` is odd, as shown in 075c0c6.
- `v[0]` equals `b0` before the subtraction, and `v` is even after it.

Neither fact depends on the truncated comparator or on the width envelope
being right. The comments speak of "reachable GCD states", but no sampling is
involved.

No new failure mode is added. The reroll pair was rescanned only because the
op stream changed. The shipped pair (1, 12) draws 0 classical, 0 phase and 0
ancilla failures. If the bit-0 reasoning were wrong, `v` would be off by one
in its low bit, the walk would diverge, and the result would be classical
mismatches and ancilla garbage on many shots.

## Classification rationale

Gates are removed because a bit's value is known from the algorithm. That is
constant propagation, and it extends 075c0c6's change of the same kind. The
runner-up would be an exact peephole on the adder.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 36dcf6b -- src/point_add`. The base is the git
   parent. `git diff --ignore-cr-at-eol 36dcf6b 335ac78 -- src/point_add` is
   137 lines in 2 files, one of them the new memory note.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line endings.
   It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 335ac78 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no
   `DIALOG_*`, `KAL_*`, `KARA_*` or `ROUND84_*` environment variables set.
   Expect:
   - 1571 qubits
   - 1,745,201 average Toffoli (rounded)
   - score 2,741,710,771
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with `DIALOG_REROLL = 1`,
`DIALOG_POST_SUB_REROLL = 12` and an identical op stream. Any other change
needs a new reroll scan.
