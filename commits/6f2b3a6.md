## Summary

Sky20 narrows the payload cells' fold window by one bit in two more places:

| knob | change | sites | direction |
| --- | --- | --- | --- |
| `HEO_PIN_PP_FOLD_PROFILE` | band `19:-4` → `19:-5` (walk widths 19–24) | cells at ticks 366–373, both legs (8 per leg) | sell, 1 bit |
| `HEO_PIN_PP_FOLD_WIDEN` | 128 → 112: proxy rounds 112–127 lose their +1 | cells at ticks 60–69, both legs (10 per leg) | sell, 1 bit |

That is about 36 cell-bits over the two legs. The SAT rewrite table is
re-proved on the new stream (62 → 61 rows). The net is −46 Toffoli at 1174
qubits. The author reports λ up 0.117, the largest single λ spend of the
sky17–sky20 run.

## What changed and why it saves Toffoli

All circuit changes are pins in `install_skywalk_submission_recipe()`,
`src/point_add/mod.rs`. The tick ranges are my mapping through the proxy
envelope and the pinned width schedule.

1. **`HEO_PIN_PP_FOLD_PROFILE`: `56:0,38:-1,32:-1,25:-5,19:-4,0:-5` →
   `56:0,38:-1,32:-1,25:-5,19:-5,0:-5`.**
   - Walk widths 19–24 (ticks 366–373) go from offset −4 to −5, so their
     fold window loses one bit. Now every band below width 32 sits at −5.
   - The `fold_shape` doc comment measures the escape rate at walk width 21
     at 0.074 of the flat rate. So the error per window bit there is small.
   - About one Toffoli per cell per bit. See
     [modular-fold](../concepts/modular-fold.md) and the sky14 note
     [`cc530e2`](cc530e2.md) for how `fold_offset` reads the table.
2. **`HEO_PIN_PP_FOLD_WIDEN`: 128 → 112.**
   - Proxy rounds 112–127 lose the +1 that `fold_offset` gives rounds below
     `PP_FOLD_WIDEN`. On the proxy envelope they are ticks 60–69 (rounds
     113–127 occur).
   - These ticks are in the flat region, where an escape costs the full
     rate. This is probably the sell that costs most of the λ. The note does
     not price the two pins separately.
   - With sky18 ([`f79a8d1`](f79a8d1.md)) this undoes all of sky15's
     112 → 144 buy.
3. **SAT rewrite rows: `sky19_rewrite.txt` (62 rows) → `sky20_rewrite.txt`
   (61 rows).**
   - The commit comment says "61 SAT-proven rows re-proved on this op stream".
   - In the file, 21 rows name the same wires as a sky19 row at an index
     shift of −328. The row at op 16,991, near the start of the stream, is
     unchanged.
   - One fewer row is about +1 Toffoli.
   - The loader is unchanged. See
     [dead-gate-strip](../concepts/dead-gate-strip.md). `sky19_rewrite.txt`
     stays in the tree, unused.
4. **Tail nonce**: `TAIL_NONCE` goes from 19001981683038 to 20001517057646.

## Why it is still correct, and what it risks

- **Both pins are fold truncations.** Each about doubles the escape rate of
  the affected cells' folds. A dropped carry leaves a wrong field element,
  which shows up as a **classical** failure.
- The submission note gives λ 19.348 ± 0.032 on 16,384 nonces (est + 2 SE
  19.412), against 19.231 for sky19, inside the 19.5 limit that the code
  comment cites.
- The rewrite rows are exact on reachable states if their proofs hold. The
  build asserts only that each row still names its CCX.
- The shipped nonce `20001517057646` draws a clean island: 0 classical,
  0 phase and 0 ancilla failures. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

Both levers narrow the payload cells' fold windows: fold/carry truncation,
like sky14, sky15 and sky18. There was no close runner-up.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout cf13eba -- src/point_add`. The base is the git
   parent. `git diff --ignore-cr-at-eol cf13eba 6f2b3a6 -- src/point_add` is
   73 lines in 2 files.
2. **Copy the new rewrite table from the commit:**
   `git checkout 6f2b3a6 -- src/point_add/skywalk_data/sky20_rewrite.txt`.
   It holds the 61 SAT rows described above.
3. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line
   endings. It covers `mod.rs`.
4. **Check the tree.** `git diff --ignore-cr-at-eol 6f2b3a6 -- src/point_add`
   should print nothing.
5. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh`. `build()` clears
   the process environment and then installs the pinned recipe, so `HEO_*`,
   `GO_*`, `SKY_*`, `PP_*`, `TLM_*` and `SUB4_*` overrides have no effect. Do
   not set them anyway. Expect:
   - 1174 qubits
   - 943,831 average Toffoli (rounded)
   - score 1,108,057,594
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `20001517057646` and an identical op
stream. [`d6dd7ef`](d6dd7ef.md) keeps this circuit and only re-rolls the
nonce.
