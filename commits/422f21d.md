## Summary

The trailmix square computes `λ²` as three half-width integer squares
(`A = lo²`, `B = hi²`, `C = (lo+hi)²`). Each one used a triangular
schoolbook. For every row `i` it computed the AND products `x_i·x_j` into a
row register with one CCX each, added the row into the product with a
hybrid adder, and erased the ANDs.

This commit routes every one of those squares (forward and reverse) through
a new `square_addsub_vented`. Row `i` adds `+x[i+1..]` to the product when
`x_i = 1` and `−x[i+1..]` when `x_i = 0`, with no controlled gates. A short
fix-up at the end turns the sum of those signed rows into exactly `x²`.
Each row is one uncontrolled adder whose carries are borrowed from the
product's still-zero top bits and erased by measurement. A row therefore
costs about one Toffoli per cross product, instead of an AND plus an add per
cross product.

Two route knobs also change. The CCX fan-out rewrite is turned back on, and
the forward-apply cswap skip goes back to the last 2 GCD steps. The rest of
the 6,111-line diff deletes comments, unused files and legacy routes. Net:
43,467 fewer average Toffoli at the same 1152 qubits (−3.19%). The nonce was
re-hunted (193806910775884).

## What changed and why it saves Toffoli

1. **Signed-row square** (`src/point_add/arith/multiply.rs`, new functions;
   used from `trailmix_ludicrous/square.rs`).
   - `symmetric_square_into_prod` now allocates the full `2n`-qubit `prod`
     up front and calls `arith::square_addsub_vented(x, prod)`.
     `symmetric_square_into_prod_reverse` calls
     `square_addsub_vented_inverse` and frees `prod`. The switch
     `square_addsub_enabled()` is hard-wired to `true`.
   - The old AND-row loop is kept only behind the probe/local switches:
     `TLM_SQUARE_ADDSUB_LOCAL`, `TLM_SQUARE_ADDSUB_SKIP_C` and
     `TLM_SQUARE_ADDSUB_PROBE`, none of which is set.
   - **Rows.** For `i = 0..n−2`, with `m = n−1−i`, the call is
     `controlled_add_subtract_vented_borrowed(x[i+1..n], prod[2i+1 .. 2i+m+2], ctrl = x_i, carries = prod[2i+m+2 .. 2i+2m+2])`.
     - It X-flips `ctrl`, then XORs it into the padded addend and into a
       carry-in qubit. So it adds `X_i = Σ_{j>i} x_j 2^{j−i−1}` when
       `x_i = 1`, and adds `~X_i + 1 = −X_i` (two's complement) when
       `x_i = 0`. Both cases use the same uncontrolled adder
       `cuccaro_add_fast_borrowed_carries`.
     - That adder computes its `m` carries with one CCX each into the
       borrowed wires, which are the not-yet-written top of `prod` and are
       still |0⟩. In the reverse sweep it erases them with `hmr` plus
       `cz_if`, at zero Toffoli. A row therefore costs `m` Toffoli, one per
       cross product `x_i x_j`, and needs no extra qubits.
   - **Algebra.** Summed over the rows, the effect is
     `Σ_i (2x_i − 1) Σ_{j>i} x_j 2^{i+j} = 2Σ_{i<j} x_i x_j 2^{i+j} − Σ_{i<j} x_j 2^{i+j}`.
     The first term is the cross-term part of `x²`. The second simplifies to
     `−Σ_j x_j 4^j + Σ_j x_j 2^j`.
   - **Fix-up** (`square_corr_forward`). It adds the interleaved diagonal
     `Σ x_i 2^{2i+1}`, which supplies the missing `+2Σ x_i 4^i`, and
     subtracts `x`. It then adds `x[0..n−1]` plus one into the high half
     `prod[n..2n]` and flips the top bit, which repairs the borrows that the
     per-row subtractions dropped above each row's slice. These are three
     ordinary Cuccaro adds of about `2n` bits, a small fixed cost per
     square. `square_corr_inverse` and `square_addsub_vented_inverse` run
     the whole thing backwards.
   - **Comparison with the old row.** The old row was `m` CCX for the ANDs,
     plus a hybrid add of about `m + 2` bits (`add_into` → `hybrid_add_adaptive`),
     plus measured AND erasure. Per cross product that is one AND plus about
     one or two adder Toffoli, against one now. The squares cover about
     24,500 cross products per direction (`C`: 129 bits, `A` and `B`: 128
     bits each), and each is built and unbuilt.
   - **Self-test.** `arith::square_addsub_selftest::run()`
     (`TLM_SQ_SELFTEST=1`, with `TLM_SQ_SELFTEST_BIG=1` for more batches)
     does three things: it checks `prod = x²` bit-exactly against classical
     arithmetic, exhaustively for `n ≤ 6` and on random inputs for `n` up
     to 129; it checks that forward plus inverse drains `prod` and every
     ancilla to 0 with no phase; and it prints the CCX counts of the old and
     new squares (`SQ_TOF`).
2. **Fan-out rewrite back on** (`mod.rs`).
   - `SINGLE_CCX_FANOUT_DISABLE` changes from `"1"` to `"0"`, in both
     `configure_q1153_second512_submission_defaults()` and the later
     `build()` default. `build()` checks for `== "1"`, so the loop over
     `single_ccx_fanout::rewrite_first_target_fanout(ops, 96)` runs again.
   - It had been off since [`da51a48`](da51a48.md), where the positional
     drop lists needed an unchanged stream. With the call-keyed skips of
     [`6dafa07`](6dafa07.md), it can run again.
   - The rewrite merges `CCX(a,b→t); CX(t→u); CCX(a,b→t)` into
     `CX(t→u); CCX(a,b→u)`, which saves one CCX per match. See
     [dead-gate-strip](../concepts/dead-gate-strip.md).
3. **`TLM_APPLY_FWD_CSWAP_SKIP_LAST`: 1 → 2.**
   - [`d44cad3`](d44cad3.md) had set 1 in the configure function. Now both
     sites say 2, so `gcd.rs::apply_fwd_cswap_skip` again skips the 256
     controlled swaps of the last two forward-apply steps.
   - This removes 256 CCX per forward apply, assuming the swap bit of the
     second-to-last GCD step is always 0.
4. **Extra Cuccaro dead range** (`trailmix_ludicrous/arith.rs`, `cuccaro_call_has_structurally_dead_carry`).
   - The new arm `12 | 25 => (1..=127).contains(&bit)` skips carries 1–127
     of Cuccaro calls 12 and 25, the same pattern as the existing call 19.
   - `TLM_CUCCARO_SKIP_STRUCTURAL_DEAD_CALLS = 1` is now also set in the
     configure function. It was already on through the later `build()`
     default.
5. **Clean-up with no effect on the shipped stream.**
   - Comments and doc comments are stripped from 25 files. A
     comment-insensitive comparison shows no code change in 21 of them.
   - Deleted files: `dialog_gcd_classical_filter.rs` (the CPU reference of
     the GPU nonce prefilter), `island_search.rs`, and the four unused
     `.idx` drop lists.
   - New diagnostics: a peak-owner census (`B0_WIN_LO` / `B0_WIN_HI` /
     `B0_PHASE`), `TLM_TIMELINE_DUMP`, `TRACE_TLM_CCX`, `DUMP_PHASE_BOUNDS`
     and `TLM_SQ_TRACE`.
   - `TLM_SEED_PERTURB` appends `k` DebugPrint ops to re-roll the
     Fiat–Shamir seed without changing gates. It is unset.
   - An unused "straddle" inverse-pair cancellation in `constprop.rs`
     (`TLM_CONSTPROP_STRADDLE`), and a fix to its nonce-verifier snapshot.
   - `install_q1153_submission_defaults()` no longer overwrites an already
     set `TLM_TARGET_Q`. It is still 1152.

The commit does not split the −43,467 between items 1–4. Item 1 is by far the
largest. Item 3 also saves a few hundred, item 2 an unmeasured amount.

## Why it is still correct, and what it risks

- **Exact.** The signed-row square is an exact integer identity. Its
  self-test checks the value bit-exactly and checks that the inverse drains
  to zero with no phase. The borrowed carry wires are `prod` bits that are
  provably |0⟩ when a row runs, and they are returned to |0⟩ by HMR plus the
  conditional-CZ phase fix. The fan-out rewrite is an exact identity.
- **Probabilistic.**
  - The last-two-steps cswap skip assumes the GCD has converged by step 256
    of 258. A slower input gives a wrong product, a classical failure.
  - The new Cuccaro dead range is an empirical skip in the style of
    `6dafa07`.
  - The square no longer calls `hybrid_add_adaptive`. Any call-indexed skip
    keyed to primitives that the old square used could therefore now point
    at different gates. The validated run shows that the shipped tables
    still only hit gates that are dead on the test draw.
- The submission note's "value-exact" refers to the 0/0/0 run, not to the
  probabilistic parts above.
- The shipped nonce `193806910775884` draws a clean set: 9,024 of 9,024
  shots, 0 classical, 0 phase and 0 ancilla failures, average 1,320,762.912
  Toffoli (submission note). See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

The published label is Fusion → boundary cswap-merge. It probably reflects
items 2 and 3: the CCX fan-out merge, and the cswap skip at the last GCD
steps. The diff shows that the saving comes almost entirely from rewriting
the squarer's partial-product scheme (item 1). That is a multiplier/squarer
swap (Algorithmic Substitution), with measurement uncompute as its enabling
trick. The header keeps the published label.
