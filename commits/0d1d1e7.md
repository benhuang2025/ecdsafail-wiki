## Summary

This commit changes one constant and the tail nonce. Each step of the
dialog-GCD apply does a controlled modular add or subtract. That leaves an
overflow flag, which is erased by measurement and then phase-repaired with a
comparison of the top `k` bits of the two operands. This commit sets the
default `k` back to 19. It had been 19 until [`8cd8104`](8cd8104.md) widened
it to 20 to land that commit's nonce. One comparator bit costs one Toffoli,
and the repair runs only on about half the shots, so the saving is about half
a Toffoli per add or subtract: −242 average Toffoli. Qubits are unchanged.

## What changed and why it saves Toffoli

- `src/point_add/mod.rs`, `configure_ecdsafail_submission_route()`:
  - `DIALOG_GCD_APPLY_CLEAN_COMPARE_BITS`: 20 → 19.
  - Both `DIALOG_TAIL_NONCE` lines: 9800070235165 → 30000009780549. Only the
    first line takes effect.
- The knob is read by `dialog_gcd_apply_clean_compare_bits()` in
  `rounds/dialog/config.rs`, through
  `dialog_gcd_special_clean_compare_bits_from_env` in `rounds/dialog/mod.rs`.
  - It is the default width for every apply step. The exceptions are the
    steps listed in `DIALOG_GCD_SPECIAL_OVERFLOW_CLEAN_STEP_BITS`
    (`113:21,131:21,142:22,187:23,205:22,210:21`) and
    `…_UNDERFLOW_CLEAN_STEP_BITS` (`42:22,91:22,118:22,149:21`).
- The compare is used in `dialog_gcd_cmod_add_materialized_pseudomersenne_chunked`
  (overflow) and in `dialog_gcd_clean_truncated_underflow` (underflow, for the
  `sub` twin).
  - With `DIALOG_GCD_SPECIAL_CLEAN_CONDITIONAL_REPLAY=1`, the circuit runs
    `hmr(acc_ovf, phase)`, and then, under `phase`,
    `cmp_lt_phase_conditioned_with_cin(acc[256−k..], a[256−k..], c_in = 0, ctrl, phase)`.
  - This recovers the flag's value from the top `k` bits only. It costs
    `k` CCX on the shots where `phase = 1`. See
    [measurement-uncompute](../concepts/measurement-uncompute.md) and
    [comparator-and-width-truncation](../concepts/comparator-and-width-truncation.md).

## Why it is still correct, and what it risks

- **The compare is a truncation.** The submission note calls it
  "value-exact": "the dropped high bit is provably 0 there". That is not right.
  - The compare drops the *low* bits and their borrow into the window. It
    returns the wrong flag when the top 19 bits of `acc` and `a` tie and the
    ignored low part would have decided the result.
  - That happens with probability about 2^-19 per call, twice the rate at
    20 bits.
  - A wrong flag gives a wrong phase repair. That shows up as a phase failure.
- The shipped nonce `30000009780549` draws a clean set: 9,024 shots, 0
  classical, 0 phase and 0 ancilla failures. The author found it with a CPU
  classical GCD prefilter followed by `eval_circuit`. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).
- **The submission note's figures do not match the leaderboard.** The note
  reports 1,404,654.191 average Toffoli and a score of 1,701,035,994. The
  leaderboard records 1,404,664 and 1,701,048,104. Use the leaderboard
  numbers.

## Classification rationale

The only circuit change is a narrower truncated comparator, so the label is
comparator/width truncation. The nonce change comes with every circuit
change and is not a separate lever.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout cf3c6f1 -- src/point_add`. The base is the git
   parent. `git diff --ignore-cr-at-eol cf3c6f1 0d1d1e7 -- src/point_add` is
   6 lines in 1 file.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line
   endings. It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 0d1d1e7 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with none of the
   route's variables (`DIALOG_*`, `SQUARE_*`, `KAL_*`, `KARA_*`, `ROUND84_*`,
   `R84_*`) set, because `set_default_env` only fills unset variables. Expect:
   - 1211 qubits
   - 1,404,664 average Toffoli (rounded)
   - score 1,701,048,104
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `30000009780549` and an identical op
stream. Any other change needs a new nonce hunt.
