## Summary

Since [`cea9f5f`](cea9f5f.md), `build()` ends with one application of a gate
identity: `CCX(a,b→t); CX(t→u); CCX(a,b→t)` is replaced by `CX(t→u); CCX(a,b→u)`.
That merges two Toffoli into one, but only at the first site found. This commit
calls the same checked rewrite in a loop until it finds no more sites. On this
stream it applies 66 times instead of once. That gives 65 fewer emitted ops and
65 fewer emitted CCX. The average executed Toffoli falls by 88, which includes
the change of nonce draw. Peak qubits stay at 1164.

## What changed and why it saves Toffoli

- `src/point_add/mod.rs`, `build()`, after `build_trailmix_ludicrous_ops()`, which already
  includes the constant-propagation pass:
  - **Old.** It made one call to `single_ccx_fanout::rewrite_first_target_fanout(ops, 96)`,
    then `assert_eq!(ops.len() + 1, input_ops)`.
  - **New.** It loops `rewrite_first_target_fanout(ops.clone(), 96)`. Each `Ok` replaces
    the stream and increments `fanout_passes`. The first `Err`, meaning no match is
    left, ends the loop.
  - It asserts `fanout_passes >= 1` and prints `SINGLE_CCX_FANOUT: SUMMARY … passes=N`.
- **The identity.** If `t` holds `x` before the first CCX and `p = a·b`, the old sequence
  gives:
  - `t = x ⊕ p`;
  - then `u ^= x ⊕ p`;
  - then `t = x`.
  The new sequence gives `u ^= x`, then `u ^= p`. Both leave `t = x` and `u ^= x ⊕ p`. Two
  CCX become one.
- **Validity check** (`single_ccx_fanout.rs`, unchanged). Dependency epochs check that,
  between the two CCX, nothing writes `a` or `b`, nothing but the one CX blocker uses `t`
  as a control, nothing puts a phase on `t`, and nothing measures, resets or swaps the
  three wires. The
  blocker's target must not be `a`, `b` or `t`. Condition-stack changes are barriers. The
  replacement CCX takes the blocker's `c_condition`.
- **Why one pass was not enough.** Each call returns after its first rewrite. Running it
  again finds the next site, and a rewrite can also create a new match. The 66 passes
  rescan the 10.6 M-op stream each time, which costs only build time.
- The author reports 1,688 Toffoli removed by constant propagation, 66 fan-out passes and
  10,659,958 emitted ops.
- **Nonce.** The default `DIALOG_TAIL_NONCE` goes from 800000341 to 800006524.

See [dead-gate-strip](../concepts/dead-gate-strip.md), section "Target-fanout
closure", for this rewrite and its later uses.

## Why it is still correct, and what it risks

Each application is an exact gate identity on every basis input. It changes no
phases, because it only reorders XOR contributions into `u`. The epoch check
makes sure that the commutations it needs are legal. The loop applies the same
checked step repeatedly, so the result is exact too. The last 96 ops, the nonce
tail, are checked byte-for-byte on each pass.

The op stream changed, so the nonce was re-hunted. `800006524` gives 0
classical, 0 phase and 0 ancilla failures over all 9,024 shots. See
[nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

Two Toffoli are merged into one by a gate identity, which is gate/op fusion. The
runner-up is Dead-Code and Redundancy Elimination, because the rewrite is a
post-pass peephole of the same kind as the constant-propagation pass.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout fa7126d -- src/point_add`.
   The base is the git parent. `git diff --ignore-cr-at-eol fa7126d 12c7337 -- src/point_add` is 38 changed lines in 1 file.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`. The flag lets the patch apply whether the files use LF or CRLF line endings.
3. **Check the tree.** `git diff --ignore-cr-at-eol 12c7337 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `DIALOG_*`, `TLM_*`, `LUD_*` or `CONSTPROP_*`
   environment variables set. Expect:
   - 1164 qubits
   - 1,411,988 average Toffoli (rounded; 1,411,987.834 before rounding)
   - score 1,643,554,032
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `800006524` and an identical op
stream. Any other change needs a new nonce hunt.
