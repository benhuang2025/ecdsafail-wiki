## Summary

This commit makes no optimization. It only changes the tail nonce in
`src/point_add/mod.rs` (`SUB4_PINGPONG_TAIL_NONCE` default) from 68001243769
to 57002259501. The new nonce draws a different clean set of 9,024 test shots,
whose average executed Toffoli is 3 lower. The diff touches only the nonce
literal, and the emitted op count is unchanged (12,972,785). For why a nonce
moves the score, see [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).
