## Summary

This commit changes one threshold of the knob from [`a9ac507`](a9ac507.md).
`LUD_EXTRA_FOLD_MIN_G` goes from 24 to 23, so `FFG_G` entries equal to 23 also
get one extra clean carry in their `+f` fold. Only 2 of the 516 entries are
23, so the arithmetic change is tiny: the submission note counts 14 fewer
emitted ops. The measured average drops by 23 Toffoli at 1166 qubits, but
most of that is probably the new nonce's test draw rather than the two folds.

## What changed and why the score moves

- `src/point_add/mod.rs`, `build()`:
  - `LUD_EXTRA_FOLD_MIN_G` default `"24"` → `"23"`;
  - `DIALOG_TAIL_NONCE` default `"40003939"` → `"100012904"`;
  - the comment is updated.
  - The same two values change in `configure_ecdsafail_submission_route()`.
    That function belongs to the dialog route, which `build()` no longer
    calls, so those lines have no effect.
- `load_schedule()` in `trailmix_ludicrous/mod.rs` (unchanged since a9ac507)
  adds `LUD_EXTRA_FOLD_VENTS = 1` to every `FFG_G` entry in
  `[MIN_G, MAX_G]`, capped at 53.
  - The baked `FFG_G` has exactly two entries equal to 23, so this commit
    turns two apply-step `+f` folds from `g = 23` into `g = 24` clean carries.
  - `add_f_window_hybrid` runs that many carries as a clean chain with
    measured uncompute, and the rest with the costlier graduated chunked
    adder. One bit moves from the chunked suffix into the clean prefix. See
    [modular-fold](../concepts/modular-fold.md).
- **Why the measured drop is larger than two folds.** The average executed
  Toffoli depends on which 9,024 inputs the nonce draws, because many Toffoli
  run only on some measurement outcomes. Two slightly cheaper folds are worth
  a few Toffoli at most. The note's figure of 1,422,562.776 → 1,422,539.842
  (−22.9) mixes that saving with the draw-to-draw variation of the new nonce.
  See [scoring-and-validation](../concepts/scoring-and-validation.md).

## Why it is still correct, and what it risks

- **Exact.** Both adder layouts give the same value, so no hard input is
  added. The two folds take one more transient qubit, and the peak stays at
  1166.
- **Nonce.** Nonce `100012904`, found with the GPU prefilter and confirmed by
  full local validation, draws a clean set: 0 classical, 0 phase and 0
  ancilla failures over 9,024 shots. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

The published label is fold/carry truncation. As in a9ac507, nothing is
truncated: an exact adder layout is changed so that it uses one more clean
carry. Most of the score gain looks like nonce variation, so "Verifier Search
→ nonce/island reroll" is a close alternative. The header keeps the published
label.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout a9ac507 -- src/point_add`. The base is the git
   parent. `git diff --ignore-cr-at-eol a9ac507 fd89e69 -- src/point_add` is
   12 lines in 1 file.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`. The flag lets the patch apply whether the files use LF or CRLF line endings.
3. **Check the tree.** `git diff --ignore-cr-at-eol fd89e69 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no
   `LUD_*`, `TRAILMIX_*`, `DIALOG_*` or `TLM_*` environment variables set. Expect:
   - 1166 qubits
   - 1,422,540 average Toffoli (1,422,539.842 before rounding)
   - score 1,658,681,640
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `100012904` and an identical op
stream. Any other change needs a new nonce hunt.
