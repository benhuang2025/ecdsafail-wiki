## Summary

The jump-GCD stores its transcript in a base-5 codec. Each "Triple" window
packs three divstep symbols into 7 qubits, and part of that packing is a fixed
gate list, `NORMALIZER_OPS`. Entry 34 of that list (counting from 0) is
`CCX(w6, w10 → w9)`, and entry 35 is `CX(w10 → w9)`. This commit turns entry 34
into a second
`CX(w10 → w9)`, so the two entries cancel.

That is valid if `w6 = 1` on every reachable codec state where `w10 = 1`. Then
the CCX always acts like the CX. The normalizer runs once per Triple window
when the forward walk encodes it, and once when the reverse walk decodes it.
There are 86 Triple windows per walk and two GCD phases, so 86 × 2 × 2 = 344
CCX are removed. That matches the measured −344 Toffoli exactly. The
submission note only says the nonce was refreshed; the codec edit is not
mentioned.

## What changed and why it saves Toffoli

- **`src/point_add/trailmix_ludicrous/codec.rs`, `NORMALIZER_OPS`:** entry
  34 `(2,6,10,9)` → `(1,10,9,0)`.
  - The tuples are `(kind, a, b, c)`, applied by `apply_op_off` with offset 6:
    label `k` (written `wk` here) is wire `w[k − 6]` of the 11-wire window. Kind 0 is `X(a)`, kind 1 is `CX(a → b)`, kind 2 is `CCX(a, b → c)`.
  - So `CCX(w6, w10 → w9)` becomes `CX(w10 → w9)`. Entry 35 is already
    `CX(w10 → w9)`, and the pair is now the identity. Both CX gates are still
    emitted, but they cost no Toffoli.
- **Where it runs.** `compress_3sym` applies `NORMALIZER_OPS` forward after
  `compress_2sym_fast`, and `compress_3sym_reverse` applies it backward when
  decoding. Each Triple window is encoded once in a forward walk and decoded
  once in the matching reverse walk, in both `tlm_inverse` and
  `tlm_forward_multiply`. See [trailmix-jump-gcd](../concepts/trailmix-jump-gcd.md)
  for the codec.
- **Why it saves Toffoli.** Each removed CCX is unconditional, so it saved 1
  Toffoli on every shot.
- **Tail nonce:** `SUB4_TAIL_NONCE` default 500008234796 → 198386112 in
  `src/point_add/mod.rs`.

## Why it is still correct, and what it risks

- **The claim is a reachability fact.** It needs `w10 = 1 ⇒ w6 = 1` at that
  point of the normalizer, for every symbol triple the walk can produce. The
  commit gives no proof.
- **A violation would be loud.** Only 5³ = 125 symbol triples are reachable,
  and each walk encodes 86 windows. So a violating state would hit many of the
  9,024 test shots, not a rare few. The build passes with 0 / 0 / 0.
- **Later evidence.** [`7726431`](7726431.md) re-applied this edit and tested the
  six other CCX entries of the table with either control dropped. All twelve
  variants gave 7,159–9,024 classical mismatches and 141/141 phase garbage.
  That is what a false claim looks like, and this entry does not do it.
- **Strip interaction.** The edit changes one CCX operand tuple per window.
  7726431 reports "0 stale keys skipped" with the edit applied, so the strip
  table still lines up.
- The shipped nonce `198386112` draws a clean set: 0 classical, 0 phase and 0
  ancilla failures. See [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

A CCX whose extra control is redundant on reachable states is removed, which
is a redundant-gate removal, like the strip's CX/CZ downgrades. Dead-gate /
self-inverse removal. [`37ab267`](37ab267.md) undid the edit by accident, and
7726431 re-applied it.

5. **Nonce caveat.** The score only reproduces with the nonce `198386112` and an
   identical op stream. Any other change needs a new nonce hunt.
