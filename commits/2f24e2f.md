## Summary

This commit takes the dialog-GCD branch comparator from 47 to 46 bits and
re-hunts the tail nonce. One comparator bit costs one Toffoli per call, and
there are about 876 calls per shot. The saving is 876 average Toffoli at the
same 1320 qubits.

It is the third one-bit step in a row on this knob by the same author, after
[`cf5e390`](cf5e390.md) (49 → 48) and [`6abbe60`](6abbe60.md) (48 → 47). The
46-bit value matches the one zuiris shipped in [`5ad23b1`](5ad23b1.md) on a
different tree.

## What changed and why it saves Toffoli

Both changes are default pins in `configure_ecdsafail_submission_route()`,
`src/point_add/mod.rs`.

1. **`DIALOG_GCD_COMPARE_BITS`: 47 → 46.**
   - The branch bit `b0_and_b1 = b0 ∧ (u > v)` of each forward GCD step comes
     from `dialog_gcd_ccx_cmp_gt_truncated_into_width(_hosted)`. That
     comparator compares only the top `min(COMPARE_BITS, active_width)` bits
     of the step's window.
   - It makes one carry CCX per bit and erases the carries by `hmr` plus
     `cz_if`, which costs no Toffoli. One bit fewer saves 1 Toffoli on each
     call.
   - The calls are the forward and reverse transcript passes of both GCD uses,
     on every step whose window is at least 47 bits wide.
2. **`DIALOG_TAIL_NONCE`: 256973122702329 → 100874459447525.** The 48 `X;X`
   identity pairs at the end of `build_builder()` only reseed the 9,024 test
   inputs.

## Why it is still correct, and what it risks

- The comparator mis-decides a branch when `u` and `v` agree on the top 46
  bits of the window but differ below. The GCD can then fail to converge in
  259 steps, which gives a classical failure, or phase garbage when the
  transcript is uncomputed.
- Each bit removed roughly doubles that rate, so clean nonces get rarer.
- Nonce 100874459447525 draws a clean set: 9,024 of 9,024 shots, with
  0 classical, 0 phase and 0 ancilla failures. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

A narrower comparator is comparator/width truncation. No runner-up fits.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 6abbe60 -- src/point_add`. The base is the git parent.
   `git diff --ignore-cr-at-eol 6abbe60 2f24e2f -- src/point_add` is 4 lines
   in 1 file.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line endings.
   It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 2f24e2f -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no
   `KAL_*`, `DIALOG_*` or `SUB4_*` environment variables set, because they
   override the defaults. Expect:
   - 1320 qubits
   - 1,552,451 average Toffoli (rounded)
   - score 2,049,235,320
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `100874459447525` and an identical
op stream. Any other change needs a new nonce hunt.
