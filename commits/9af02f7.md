## Summary

The author's note calls this a nonce refresh. The diff shows a real circuit
change: it carries over jieyilong's inverse-apply cswap skip from
[`6ba606a`](6ba606a.md) (only the `gcd.rs` apply hunks, not the 1157-qubit
retarget). The 256-wire controlled swap in the inverse direction's last apply
step is dropped. On every input the circuit gets right, that step's swap flag
is 0, so the swap does nothing.

The base is the frontier `c07bf74`, which is gopikannappan's `f8e215b` square
tree with a rerolled nonce. The skip saves 256 Toffoli. The measured drop is
244, because the new nonce draws a slightly costlier set. Qubits stay at 1159.
The commit also compiles in an island-search tool module, which emits no ops.

## What changed and why it saves Toffoli

**`src/point_add/trailmix_ludicrous/gcd.rs`**

- `apply_step_reverse`, the apply step of the inverse direction
  `y ← y·x⁻¹` that computes `λ`:
  - its `cswap(swp, x_reg[j], y_reg[j])` loop over 256 bits is now skipped when
    `TLM_APPLY_INV_FIRST_CSWAP_SKIP=1` and `i + 1 == ITERS`;
  - it is also skipped when `TLM_APPLY_INV_LAST_CSWAP_SKIP=1` and `i == 0`,
    but that knob is not set.
  - A third new knob, `TLM_APPLY_INV_FIRST_SUB_SKIP`, would return before the
    final `y −= x`. It is also not set.
- `apply_step_forward`: the existing first-step skip
  (`TLM_APPLY_FWD_FIRST_CSWAP_SKIP`, from [`5c34dd1`](5c34dd1.md)) is
  rewritten as `skip_first || skip_last`. The new `TLM_APPLY_FWD_LAST_CSWAP_SKIP`
  is not set, so the forward stream is unchanged.

**Why the skipped swap is the identity.**
- In the inverse direction, `forward_gcd_jump` calls `apply_step_reverse` for
  `i = 0 … ITERS−1`. So `i = ITERS−1 = 257` is the *last* apply step, even
  though the knob says "first". Its swap flag is
  `swp = subtracted AND (v < u)`.
- A GCD that finishes needs `v = 0` after this step. Then either nothing is
  subtracted (`swp = 0`), or `v = u = 1` (`v < u` false, so `swp = 0`).
- So `swp = 1` happens only on inputs whose GCD has not converged in 258
  steps, which the base already gets wrong. One `cswap` is `cx; ccx; cx`, so
  this saves 256 Toffoli. See [trailmix-jump-gcd](../concepts/trailmix-jump-gcd.md).

**`src/point_add/mod.rs`**
- `build()`: new default `TLM_APPLY_INV_FIRST_CSWAP_SKIP=1`.
  `DIALOG_TAIL_NONCE` goes from 2801645198 to 720036076906.
- `pub mod island_search;` compiles `src/point_add/island_search.rs`, which
  was already in the tree but not declared.
  - It is CPU nonce-hunting tooling. It builds the op stream once, pre-absorbs
    everything but the 96-op tail into SHAKE256, and screens candidate nonces
    with the classical GCD prefilter.
  - It is driven by an ignored test and is not called from `build()`.

**`src/point_add/dialog_gcd_classical_filter.rs`**:
`body_carry_trunc_width_fast`, `cswap_width` and `shift_width` become
`pub(crate)` so `island_search` can use them. There is no circuit effect.

## Why it is still correct, and what it risks

- The skip changes no input that the base gets right, by the argument above.
  No scratch wire depends on the swap, so a mistake could only show up as a
  classical failure (wrong `λ`) or a phase failure in later measured erasures.
- The author reports 10,135,771 emitted ops. The new nonce `720036076906`
  draws a clean set: 9,024 of 9,024 shots, with 0 classical, 0 phase and
  0 ancilla failures. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

256 gates that act as the identity on every passing input are removed. That is
dead-gate removal, and the census label is right. It is not a nonce-only
change, although the submission note says the cswap skip was "already present
in this worktree". It was not present in the base `c07bf74`.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout c07bf74 -- src/point_add`. The base is the git
   parent. `git diff --ignore-cr-at-eol c07bf74 9af02f7 -- src/point_add` is
   48 lines in 3 files.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`. The flag lets the patch apply whether the files use LF or CRLF line endings. It is the
   complete diff against the base. `src/point_add/island_search.rs` is
   unchanged and is already in the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 9af02f7 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no
   `DIALOG_*`, `TLM_*`, `LUD_*` or `CONSTPROP_*` environment variables set,
   because they override the defaults in `build()`. Expect:
   - 1159 qubits
   - 1,377,960 average Toffoli (1,377,959.696 before rounding)
   - score 1,597,055,640
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `720036076906` and an identical op
stream. Any other change needs a new nonce hunt.
