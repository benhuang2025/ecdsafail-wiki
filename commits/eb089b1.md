## Summary

`src/point_add/mod.rs` (`DIALOG_TAIL_NONCE` default in `build()`) from
800447829 to 600002572. The new nonce draws a different clean set of 9,024
test shots, whose average executed Toffoli is 8 lower. The diff touches only
the nonce literal, and the emitted op count is unchanged. For why a nonce
moves the score, see
[nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).
