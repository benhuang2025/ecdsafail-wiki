## Summary

The circuit is 258b25f's. Only the dead-gate strip table and the nonce change.
Strip candidates come in two kinds:
- *event* gates misbehaved at least once in the event census, so their risk is
  measured;
- *no-event* gates never misbehaved, so their risk is only an estimate from an
  independent census.

The previous table admitted both kinds against one summed budget. The author
calls that a winner's-curse trap: a no-event gate looks cheap exactly when its
estimate happens to come out low. The note measured that about five such keys
had used 3.435 of the old table's priced risk while saving almost nothing.

This commit caps the no-event group at a small allowance (`NO_EVENT_CAP`) and
gives the rest of the budget to event gates, whose coverage is measured. The
five expensive keys leave and 1,008 new keys enter: 11,741 deletions and 3,674
downgrades. That is −938 average Toffoli at the same 1154 qubits. The author
also scored all five clean nonces found, not just the first, and shipped the
cheapest.

## What changed and why it saves Toffoli

- **`src/point_add/deep_strip_keys.rs`, re-selected.**
  - The header: "Deep strip, COMPOSED geometry (head + R6), TRUE GREEDY v5 cap
    6.0, no-event floored at 0.40 … order=rand2. Census 320000000 seed
    20260803/320000000 seed 314159265; events 32000000 seed 777000777. Risk
    1.239700 (budget 1.24)". The previous header read "Risk 3.999888 (budget
    4.000)".
  - The census streams are the same. Only the admission rule changes: true
    greedy as in [`258b25f`](258b25f.md), plus the no-event cap. The note does
    not define the header's "cap 6.0" or the 0.40 floor further.
  - Diff: 5 keys removed (3 `DEAD_KEYS`, 2 `DOWNGRADE_KEYS`) and 1,008 added.
    `DEAD_KEYS` 11,110 → 11,741 and `DOWNGRADE_KEYS` 3,302 → 3,674.
  - The build logs "11,741 / 11,741 dead removed, 3,674 / 3,674 downgraded to
    CX/CZ, 0 stale keys skipped". Emitted ops are 8,961,429, which is 631 fewer
    than the base: the net added deletions.
- **Why it saves Toffoli.** More deleted or CX-downgraded gates means fewer
  Toffoli charged per shot. See [dead-gate-strip](../concepts/dead-gate-strip.md).
- **`src/point_add/mod.rs`:** tail nonce `SUB4_TAIL_NONCE` 1001707183656 →
  1003157528363.

## Why it is still correct, and what it risks

- **Empirical.** The note claims the new table both saves more Toffoli and has
  a lower failure rate for the same budget, because the five removed keys
  carried most of the old table's priced risk. That rests on the census risk
  model and is not proven.
- **The hunt.** A classical-only GPU prefilter gave 8,985 candidates across two
  geometries. The trusted CPU evaluator found five clean ones, 1 in 1,797. This
  geometry's best is the shipped nonce. The other geometry's three survivors
  scored 1,484,731,784 to 1,484,750,248.
- The shipped nonce `1003157528363` draws a clean set: 9,024 of 9,024 shots, 0
  classical, 0 phase and 0 ancilla failures, at 1,285,673.863 average Toffoli.
  The score uses the rounded average:
  round(1,285,673.863) × 1154 = 1,483,667,796. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

A re-selected empirical dead-gate strip and nothing else: dead-gate/self-inverse
removal.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 258b25f -- src/point_add`. The base is the git parent.
   `git diff --ignore-cr-at-eol 258b25f 3701581 -- src/point_add` is 1,024 lines in
   2 files: the key table and the nonce.
2. **Copy the generated table from the commit:**
   `git checkout 3701581 -- src/point_add/deep_strip_keys.rs`.
3. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line endings.
4. **Check the tree.** `git diff --ignore-cr-at-eol 3701581 -- src/point_add`
   should print nothing.
5. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `TLM_*` or
   `SUB4_*` overrides set. Expect:
   - 1154 qubits
   - 1,285,674 average Toffoli (1,285,673.863 before rounding)
   - score 1,483,667,796
   - 0 classical, 0 phase and 0 ancilla failures
6. **Nonce caveat.** The score only reproduces with the nonce `1003157528363` and an
   identical op stream. Any other change needs a new nonce hunt.
