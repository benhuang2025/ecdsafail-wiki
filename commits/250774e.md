## Summary

At 1542 qubits two places co-bound the peak. One was the x-tail Karatsuba
square, where wide transient registers (adder carry lanes and a loaded
256-qubit constant) sit on top of the live `tmp_ext` (512) and `z1_reg` (258).
The other was the GCD apply pass. This commit removes the square's transients
with three exact rewrites:

- The `z0 = lo²` square borrows its carry lane from the still-empty `z2` half
  of `tmp_ext`.
- The `z2 = hi²` square uses the ancilla-free Cuccaro adder.
- The Solinas modular adds and subtracts add their constant with a
  dirty-ancilla adder instead of a loaded constant register.

With the square no longer binding, the apply add's chunk split can move from
bit 78 all the way to 99, which takes 42 qubits off the apply pass. The peak
falls from 1542 to 1500.

The cost is +36,558 Toffoli. At about 1,100 Toffoli per qubit, 42 qubits are
worth about 46,000 Toffoli, so the score still drops by 15.8 M.

## What changed and why it saves qubits

All changes are in `src/point_add/mod.rs`. Two new knobs are turned on and
`F_CUT` is raised in `configure_ecdsafail_submission_route()`.

### 1. `KARA_Z02_LOWQ=1`: no fresh carry lane in the half-squares

In `squaring_sub_from_acc_karatsuba()`:

- `schoolbook_square_symmetric(x, slice)` adds each row with
  `cuccaro_add_fast`, which allocates one carry wire per bit (about 129 for
  row 0) and clears them by measurement. While `z0` and `z2` are built,
  `tmp_ext` (512) and `z1_reg` (258) are both live, so that lane was on the
  peak. See [squaring-and-karatsuba](../concepts/squaring-and-karatsuba.md).
- **`z0` (forward and inverse): hosted carries.** The new
  `schoolbook_square_symmetric_hosted(x_lo, tmp_ext[0..2h], host)` and its
  `_inverse` are copies that call `cuccaro_add_fast_borrowed_carries` /
  `cuccaro_sub_fast_borrowed_carries` with `host = tmp_ext[2h..4h]`.
  - When `z0` is computed, `z2` has not been written yet, so that slice is
    all zero. In the inverse, `z2` has just been uncomputed, so it is zero
    again.
  - The borrowed-carry adder needs a clean lane and returns it clean
    (measured uncompute). So the Toffoli count is the same as the fast square,
    and no new wires are allocated. See
    [venting-and-wire-loans](../concepts/venting-and-wire-loans.md).
- **`z2` (forward and inverse): ancilla-free adder.** It calls the existing
  `schoolbook_square_symmetric_lowq` / `_lowq_inverse`, which use
  `cuccaro_add` / `cuccaro_sub`. These are MAJ/UMA ripples that hold the carry
  in the operand itself, so they need no carry lane, but they cost two Toffoli
  per bit instead of one. Row `i` adds `n − i + 2` bits, so the extra cost is
  about 8,383 Toffoli per pass, about 16,770 for forward plus inverse (my
  count from the code).

### 2. `KARA_SOL_MOD_VENT=1`: vented Solinas corrections

- The Solinas reduction's `mod_sub` and `mod_add` closures now pick the new
  `mod_sub_qq_vent` / `mod_add_qq_vent`. The mid-subtract of the `2^32` term,
  which used to call `mod_sub_qq` directly, now goes through the closure too.
  That is six calls.
- `mod_add_qq` computes `acc + a` in 257 bits, adds `c = 2^256 − p`, takes the
  top bit as a flag, conditionally subtracts `c` back, then clears the flag
  with `cmp_lt_into(acc, a)`. Its constant add (`add_nbit_const`,
  `csub_nbit_const`) loads `c` into a fresh 256-qubit register. That register
  was a peak transient. See [modular-fold](../concepts/modular-fold.md).
- `mod_add_qq_vent` follows the same steps, but adds and subtracts `c` with
  `venting::iadd_dirty_2clean_classical` and `cisub_dirty_2clean_classical`.
  These are Gidney's constant adders that need only 2 clean wires and borrow
  the operand `a_ext` as dirty scratch, which they return unchanged.
  `mod_sub_qq_vent` is written out as the explicit gate reverse, because
  `emit_inverse` cannot reverse measurement-based venting. The flag is still
  cleared with the full `cmp_lt_into`.
- The doc comment on `iadd_dirty_2clean_classical` in `venting.rs` still says
  "correctness is INCOMPLETE … LEAKS PHASE". The body already merges the
  carry-xor targets that the comment says are missing, and the submission
  validates with no phase failures, so the comment appears stale.
- The residual cost, about 3,000 Toffoli over the six calls, is the
  dirty-ancilla adder's roughly 3n Toffoli against the cheaper loaded-constant
  add. This is inferred from the totals, not counted.

### 3. `DIALOG_GCD_APPLY_CHUNKED_F_CUT`: 78 → 99

- The apply pass's controlled add and subtract split their 257-bit
  accumulator at `F_CUT`. The upper chunk `[F_CUT, 257)` holds about
  2 × (256 − F_CUT) scratch qubits (the gated addend and a carry lane), so 21
  more bits in the lower chunk free 42 qubits: 1542 → 1500. See
  [`40574d3`](40574d3.md).
- The lower chunk's carry is cleared by an exact compare of the low `F_CUT`
  bits at one Toffoli per bit, once in the add and once in the subtract per
  GCD step: 21 × 2 × 399 = 16,758 Toffoli.

### 4. Reroll pair: `DIALOG_REROLL` 17 → 15, `DIALOG_POST_SUB_REROLL` 56 → 25

Identity `X;X` counts that re-draw the 9,024 test inputs without changing the
circuit (see [`ecbf87b`](ecbf87b.md)).

Total: 16,758 + about 16,770 + about 3,030 = 36,558.

## Why it is still correct, and what it risks

Every rewrite is exact:

- The hosted adder computes the same sum and returns the borrowed `z2` slice
  to zero.
- The ancilla-free Cuccaro computes the same sum.
- The vented modular add computes `(acc + a) mod p` with the same flag logic
  and returns `a_ext` unchanged.
- The chunked apply add is exact at any cut.

See [peak-qubits-and-budgets](../concepts/peak-qubits-and-budgets.md) for why
both co-binders had to drop. The one thing that relies on validation alone is
the dirty-ancilla adder, whose own doc comment doubts it (see above). Any
phase leak from it would show as phase garbage, and none appears.

The test set changes. With the reroll pair (15, 25), all existing
approximations are right on the new draw: 9,024 of 9,024 shots pass with
0 classical, 0 phase and 0 ancilla failures. See
[nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

Every lever lowers the number of wires live at the peak: by borrowing a clean
region as a carry lane, by venting a constant add onto dirty wires, by
dropping a carry lane, or by rebalancing chunk scratch. All of them add
Toffoli, so this is ancilla-lifetime / venting, not a reduction in work.
