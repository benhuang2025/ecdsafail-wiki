## Summary

The circuit is unchanged. The commit lowers the default of the
`DUMMY_TOFFOLIS` padding knob from 9,000 to 8,690. The padding is a block of
self-cancelling Toffoli pairs at the end of the circuit, so removing 310 pairs
removes exactly 620 executed Toffoli per shot. The odd value 8,690 looks
chosen to beat the frontier by a small margin rather than to remove the
padding outright, which [`f43a73e`](f43a73e.md) did a few hours later.

## What changed and why it saves Toffoli

- `src/point_add/mod.rs`, `build()`: the default of `DUMMY_TOFFOLIS` goes
  from `9_000` to `8_690`.
- The block, at the end of `build()` after the point addition, runs `n` times
  `ccx(tx[0], ty[0], c); ccx(tx[0], ty[0], c)` on a fresh ancilla `c`. Each
  pair is the identity, because CCX is self-inverse. The simulator charges
  every unconditional CCX on every shot, so each unit costs exactly 2 average
  Toffoli: 310 × 2 = 620, which matches the leaderboard (3,960,753 →
  3,960,133). The code is quoted in [`c55911f`](c55911f.md).
- See [scoring-and-validation](../concepts/scoring-and-validation.md) and
  [dead-gate-strip](../concepts/dead-gate-strip.md).

## Why it is still correct, and what it risks

The change is exact. Only the number of identity pairs differs, so outputs,
ancilla cleanliness, phase and peak qubits are those of the base. The run
passed with 0 classical, 0 phase and 0 ancilla failures. There is no tail
nonce in this era. The 9,024 test inputs are a SHAKE256 hash of the op stream,
so the draw changed, but the arithmetic is the same on every input.

## Classification rationale

The only edit is the padding constant: Neutral / Mechanical, "DUMMY_TOFFOLIS
padding change".

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 6f7c159 -- src/point_add`. The base is the git parent.
   `git diff --ignore-cr-at-eol 6f7c159 ed34c00 -- src/point_add` is 2 lines
   in 1 file.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line endings.
   It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol ed34c00 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no
   `DUMMY_TOFFOLIS` or other environment overrides set. Expect:
   - 2715 qubits
   - 3,960,133 average Toffoli (rounded)
   - score 10,751,761,095
   - 0 classical, 0 phase and 0 ancilla failures

There is no tail nonce in this era. The 9,024 test inputs are a hash of the
op stream, so the score only reproduces with an identical op stream.
