## Summary

After [`92a247e`](92a247e.md), the 1466 peak was set by the GCD body: the
controlled subtract (or add) inside each transcript step. That subtract loads
`ctrl & subtrahend` into a "gated" register. It hosts that register on the
unwritten tail of the compressed transcript log, but only when the tail is
long enough for both the carries and the whole gated register. Otherwise it
allocates the gated register fresh, all of it.

This commit makes the hosting partial. Whatever part of the gated register
fits in the tail is hosted, and only the rest is allocated. It also stops
allocating one unused wire. The body phase drops below the apply pass. The
apply add's chunk split then moves from bit 116 to 126, freeing 2 × 10 = 20
qubits. The peak falls to 1446, where the branch-bit comparator and the apply
pass co-bind.

The hosting is Toffoli-neutral. The only cost is the wider exact boundary
compare: 10 × 2 × 398 = 7,960 Toffoli, about 400 per qubit.

## What changed and why it saves qubits

All changes are in `src/point_add/mod.rs`.

1. **New helper `dialog_gcd_materialized_body_gated_register(b, body_len, borrowed_carries)`**,
   used by `dialog_gcd_controlled_sub_selected` and
   `dialog_gcd_controlled_add_selected` (the materialized GCD-body subtract and
   its reverse-pass add).
   - Context: each transcript step does `v −= ctrl·u` on the `n`-bit active
     registers (`n = dialog_gcd_tobitvector_active_width(step)`). It loads
     `gated[i] = ctrl & subtrahend[i]` with CCX, subtracts with
     `sub_nbit_qq_fast_borrowed_carries` (carries borrowed), and clears
     `gated` by `hmr` + `cz_if`. With `DIALOG_GCD_ODD_U_LOWBIT_FASTPATH=1`,
     bit 0 is handled by one CX, so the body covers indices 1 to `n − 1`:
     `body_len = n − 1`.
   - `borrowed_carries` is `dialog_gcd_compressed_sidecar_future_carry_slice`.
     It returns the compressed-log blocks after the current one, which are
     still |0⟩, up to `2n − 1` wires.
   - **Old rule (all or nothing).** If the slice had at least `2n − 1` wires,
     `gated` was `slice[n−1 .. 2n−1]`. Otherwise `b.alloc_qubits(n)`
     allocated all `n` wires fresh, including `gated[0]`, which the
     fast-path body never uses.
   - **New rule.** `carry_need = body_len − 1` wires of the slice go to the
     carries, as before. Then `hosted = min(slice.len() − carry_need, body_len)`
     wires of `gated` come from the rest of the slice, and only
     `body_len − hosted` are allocated. `gated` now has exactly `body_len`
     entries, indexed from `body_start`, so the dead bit-0 wire is gone.
   - Where it matters (my reading of the slice lengths, with 133 five-qubit
     log blocks and the base's width envelope): the slice is shorter than
     `2n − 1` only in the late steps, from about step 366 on, where little log
     is left after the current block. There the old code allocated up to 26
     fresh wires (`n = 26` at step 366). The new code hosts all or nearly all
     of them. That lowers the `materialized_*_body` phase, which was the
     binder. See [venting-and-wire-loans](../concepts/venting-and-wire-loans.md).
2. **`DIALOG_GCD_APPLY_CHUNKED_F_CUT`: 116 → 126.**
   - The apply pass's controlled add and subtract split the 257-bit
     accumulator at `F_CUT`. The upper chunk holds about 2 × (256 − F_CUT)
     scratch qubits, so 10 more bits in the lower chunk free 20 qubits. The
     comment says this drops the route to the 1446 branch/apply co-binder. See
     [`40574d3`](40574d3.md) and
     [peak-qubits-and-budgets](../concepts/peak-qubits-and-budgets.md).
   - Cost: the exact compare that clears the lower chunk's carry is 10 bits
     wider, once in the add and once in the subtract per GCD step, over the
     398 active steps: 10 × 2 × 398 = 7,960 Toffoli, exactly the measured
     change.
3. **Reroll: `DIALOG_REROLL` 52 → 1** (`DIALOG_POST_SUB_REROLL` stays 28).
   Identity `X;X` counts that re-draw the 9,024 test inputs without changing the
   circuit (see [`ecbf87b`](ecbf87b.md)).

## Why it is still correct, and what it risks

Both levers are exact. The gated register holds the same values whether its
wires are hosted or fresh. The hosted wires are |0⟩ on entry, because they are
future log blocks not yet written. They are returned to |0⟩ by the
`hmr` + `cz_if` clear, before that log block is written. The CCX loads and the
subtract are the same gates, so Toffoli is unchanged. The chunk split is exact
at any cut. A mistake in the slice bookkeeping (overlapping carries and gated
wires, or a slice that is not clean) would show up as classical mismatches or
as phase or ancilla garbage. The run shows none.

Only the test set changes. With the reroll pair (1, 28), all existing
approximations are right on the new draw: 9,024 of 9,024 shots pass with
0 classical, 0 phase and 0 ancilla failures. See
[nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

The lever reuses an idle clean region (the unwritten transcript log) for
more of the body's scratch instead of allocating fresh wires. That is
scratch/ancilla reuse, like `92a247e`. The F_CUT move turns the headroom into
a lower peak.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout fd8e712 -- src/point_add`.
   - The git parent is `14b84f1` (10d9e, comparator cap 57). Diffing against it
     (145 lines) would also show `DIALOG_GCD_COMPARE_BITS` going back from 57
     to 58. This commit was built on the author's own `fd8e712`.
   - `git diff --ignore-cr-at-eol fd8e712 8ab5f90 -- src/point_add` is 135
     lines in 1 file.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line endings.
   It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 8ab5f90 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `DIALOG_*`,
   `KAL_*`, `KARA_*` or `ROUND84_*` environment variables set, because
   `set_default_env` keeps any value already in the environment. Expect:
   - 1446 qubits
   - 1,737,201 average Toffoli (rounded)
   - score 2,511,992,646
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the reroll pair `DIALOG_REROLL=1`,
`DIALOG_POST_SUB_REROLL=28` and an identical op stream. Any other change needs
a new reroll search.
