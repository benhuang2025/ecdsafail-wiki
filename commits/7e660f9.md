## Summary

Each step of the dialog GCD (see [`cddd5df`](cddd5df.md)) compares `u` and `v`
on their top `k = 72` bits. The base did this with `cmp_lt_into`, a ripple of
MAJ gates followed by an inverse MAJ sweep, which costs 2 Toffoli per bit.

This commit adds `cmp_lt_into_measured`. It records each bit's carry in a
fresh ancilla on the way up and erases those ancillas by X-basis measurement
on the way down, so the compare costs 1 Toffoli per bit. The compare runs
twice per step in all four GCD passes, so halving it saves 209,520 average
Toffoli. The qubit peak stays at 1698. The change is exact, and with it the
reroll count can go from 2 to 0.

## What changed and why it saves Toffoli

All changes are in `src/point_add/mod.rs`.

- **New `cmp_lt_into_measured(b, u, v, flag)`**, which computes
  `flag ^= (u < v)` and restores `u` and `v`.
  - It allocates `c_in` and an `n`-qubit `cr` register, and complements `u`.
  - Forward sweep, per bit:
    `cx(u[i], v[i]); cx(u[i], u[i−1]); ccx(u[i−1], v[i], cr[i]); cx(cr[i], u[i])`.
    This is the same carry chain as the MAJ sweep, but the carry-generate term
    goes into its own ancilla `cr[i]`. The top bit `u[n−1]` then holds
    `u < v` and is copied into `flag` with a CX.
  - Backward sweep: the exact gate-reverse of the forward sweep, except that
    each `ccx` into `cr[i]` is replaced by `hmr(cr[i], m)` and
    `cz_if(u[i−1], v[i], m)`. That is the measured uncompute: measure in the X
    basis, and fix the phase with a CZ on the two control bits if the outcome
    is 1. It costs 0 Toffoli.
  - So the total is `n` Toffoli instead of `2n`. It is the same structure as
    the `cmp_lt_into_fast` and `cuccaro_add_fast` already in the file. See
    [measurement-uncompute](../concepts/measurement-uncompute.md).
- **`dialog_gcd_cmp_gt_truncated_into_width()`** calls
  `cmp_lt_into_measured` when `DIALOG_GCD_MEASURED_CMP=1`, and `cmp_lt_into`
  otherwise.
- **`configure_ecdsafail_submission_route()`** sets
  `DIALOG_GCD_MEASURED_CMP = 1`, and changes `DIALOG_GCD_REROLL` from 2 to 0.
  With 0, the reroll loop of [`541bd85`](541bd85.md) emits nothing.
- **Saving.** Each step computes and uncomputes the compare, in each of four
  GCD passes, on `min(72, w(s))` bits. The old cost was `16·Σ min(72, w(s))` =
  16 × 26,190 = 419,040. Halving it saves 209,520, exactly the measured
  saving.
- **Qubits.** The extra `cr` register (up to 72 qubits) is live only during
  the compare. That happens before the 256-bit `gated` register of the same
  step is allocated, so the peak does not change.

## Why it is still correct, and what it risks

- The new compare implements the same map as `cmp_lt_into` for every input.
  The measured uncompute is exact, because at the moment of each `hmr` the
  controls `u[i−1]` and `v[i]` hold their compute-time values. If it were
  wrong, it would show as phase garbage.
- The compare width (72) and the other truncations of the route are
  unchanged, so the risk profile is the base's. The change re-rolls the test
  inputs, and the plain stream with no padding (`rr = 0`) draws a clean set:
  0 classical, 0 phase and 0 ancilla failures over 9,024 shots.

## Classification rationale

A Toffoli uncompute sweep is replaced with measurement plus a classically
controlled CZ. That is Uncompute Strategy → measurement uncompute.

3. **Check the tree.** `git diff --ignore-cr-at-eol 7e660f9 -- src/point_add`
