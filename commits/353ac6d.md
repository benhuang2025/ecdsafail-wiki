## Summary

Each dialog-GCD step works only on the low `active_width(step)` bits of `u`
and `v`, a linear envelope `256 − step × slope + margin`. Earlier commits had
tuned only the margin. This one sets the slope for the first time, from its
built-in default 0.7075 to 0.708 bits per step. The envelope then sits up to
0.2 bits lower by the last step, and after rounding to an even width, 19 of
the 396 steps lose 2 bits. That saves 512 average Toffoli at the unchanged
1355-qubit peak. The first reroll count was re-searched for the new op
stream.

## What changed and why it saves Toffoli

Both changes are in `configure_ecdsafail_submission_route()` in
`src/point_add/mod.rs`:

1. **New `set_default_env("DIALOG_GCD_WIDTH_SLOPE_X1000", "708")`.**
   - `dialog_gcd_width_slope()` reads this variable divided by 1000. Unset,
     it returns `0.5 × 1.415 = 0.7075`. It is used in
     `dialog_gcd_tobitvector_active_width(step)`:
     `ideal = 256 − step × slope + margin` (margin 26 here), rounded **up**
     to an even number and clamped to [1, 256].
   - A steeper slope lowers `ideal` by `0.0005 × step`, at most 0.2 bits at
     step 395. That only matters where it crosses an even boundary: 19 steps
     (65, 113, 130, …, 390) drop from one even width to the next, 2 bits
     each, so 38 bit-steps in total.
   - Each bit-step costs about 3 Toffoli per pass (controlled swap, gated
     load and subtract carry), in four passes (forward and reverse, for each
     of the two GCD calls): 38 × 3 × 4 = 456. On the late steps where the
     width is below the comparator width, the comparator shrinks with it, by
     14 bits in total: 14 × 4 = 56. 456 + 56 = 512, the measured saving.
   - The peak is not affected, because early steps clamp at 256 bits.
2. **Reroll: `DIALOG_REROLL` 291150 → 101019.** `DIALOG_POST_SUB_REROLL`
   stays at 503292; the author swept only the first count. These are counts
   of identity `X;X` pairs that re-seed the 9,024 Fiat–Shamir test inputs
   without changing the circuit. See
   [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Why it is still correct, and what it risks

The envelope is an empirical bound, not a proof. The submission note cites a
binary-GCD degree bound from the literature as the reason a steeper slope
should be safe, but the circuit's own safety still rests on the test draw.
An input whose `u` or `v` is still wider than `active_width(step)` at one of
the 19 tightened steps loses its top bits. Its transcript then goes wrong,
which shows up as classical failures (and as phase or ancilla garbage if the
reverse pass no longer mirrors the forward one). The change is small, so λ
rises only a little.

The shipped pair (101019, 503292) is clean: 0 classical, 0 phase and 0
ancilla failures over all 9,024 shots, per the author. See
[comparator-and-width-truncation](../concepts/comparator-and-width-truncation.md).

## Classification rationale

The only circuit change narrows the registers on some GCD steps, which is
comparator/width truncation. The reroll change is the usual companion.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout da42ce2 -- src/point_add`. The base is the git
   parent. `git diff --ignore-cr-at-eol da42ce2 353ac6d -- src/point_add` is
   13 lines in 1 file.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line
   endings. It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 353ac6d -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no
   `DIALOG_*` environment variables set, because `set_default_env` keeps any
   value already in the environment. Expect:
   - 1355 qubits
   - 1,778,555 average Toffoli (rounded)
   - score 2,409,942,025
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with `DIALOG_REROLL=101019`,
`DIALOG_POST_SUB_REROLL=503292` and an identical op stream. Any other change
needs a new reroll search.
