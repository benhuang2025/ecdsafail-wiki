## Summary

This commit makes no optimization. It only changes the tail nonce in
`src/point_add/mod.rs` (`DIALOG_TAIL_NONCE` default in `build()`) from
100002962138 to 300322437. The new nonce draws a different clean set of 9,024
test shots, whose average executed Toffoli is 2 lower. The diff touches only
that literal and the comment above it, and the emitted op count is unchanged
(10,204,150). For why a nonce moves the score, see
[nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

`git apply --ignore-whitespace`. `./benchmark.sh` should give 1162 qubits,
1,389,036 average Toffoli and 0 / 0 / 0 failures.
