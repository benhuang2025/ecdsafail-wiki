## Summary

The circuit is unchanged. The commit sets the default of the `DUMMY_TOFFOLIS`
padding knob to 0, which removes the whole block of self-cancelling Toffoli
pairs that the organisers had left at the end of the circuit. That removes
8,690 × 2 = 17,380 executed Toffoli per shot. The result, 2715 qubits ×
3,942,753 Toffoli, is the organisers' circuit without padding: the README's
"current main" reference number. Every later commit starts from this value
and has no padding.

## What changed and why it saves Toffoli

- `src/point_add/mod.rs`, `build()`: the default of `DUMMY_TOFFOLIS` goes
  from `8_690` to `0`.
- With `n = 0`, the `if n > 0` guard skips the block, so neither the pairs nor
  their ancilla are emitted.
- The block ran `n` times `ccx(tx[0], ty[0], c); ccx(tx[0], ty[0], c)` on a
  fresh ancilla `c` after the point addition was finished. Each pair is the
  identity, because CCX is self-inverse, but the simulator charges every
  unconditional CCX on every shot, so each unit cost exactly 2 average
  Toffoli. The code is quoted in [`c55911f`](c55911f.md).
- See [scoring-and-validation](../concepts/scoring-and-validation.md) and
  [dead-gate-strip](../concepts/dead-gate-strip.md).

## Why it is still correct, and what it risks

The change is exact. The removed gates were identity pairs and their ancilla
never set the peak, so outputs, ancilla cleanliness, phase and peak qubits are
those of the base. The run passed with 0 classical, 0 phase and 0 ancilla
failures. There is no tail nonce in this era. The 9,024 test inputs are a
SHAKE256 hash of the op stream, so the draw changed, but the arithmetic is the
same on every input.

## Classification rationale

The only edit is the padding constant: Neutral / Mechanical, "DUMMY_TOFFOLIS
padding change". It is the last such commit, because no padding is left after
it.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout ed34c00 -- src/point_add`. The base is the git parent.
   `git diff --ignore-cr-at-eol ed34c00 f43a73e -- src/point_add` is 2 lines
   in 1 file.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line endings.
   It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol f43a73e -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no
   `DUMMY_TOFFOLIS` or other environment overrides set. Expect:
   - 2715 qubits
   - 3,942,753 average Toffoli (rounded)
   - score 10,704,574,395
   - 0 classical, 0 phase and 0 ancilla failures

There is no tail nonce in this era. The 9,024 test inputs are a hash of the
op stream, so the score only reproduces with an identical op stream.
