## Summary

The dialog GCD shrinks `u` and `v` by about 0.71 bits per step on average, so
each step only works on the low `active_width` bits of the two registers.
`active_width` comes from a straight-line envelope plus a safety margin. This
commit lowers the margin from 27 to 26 bits. Widths are rounded up to even,
so 179 of the 397 steps become 2 bits narrower, and the rest are unchanged.

Every narrowed bit removes one CSWAP, one gated-load CCX and one adder
Toffoli in each of the four GCD passes. A few steps also get a narrower
branch comparator. That adds up to exactly the 4,596 Toffoli saved. Qubits
are unchanged, because the early steps, where the peak is not decided, are
clamped at 256 anyway. The reroll pair was re-searched to (0, 28).

## What changed and why it saves Toffoli

1. **`src/point_add/mod.rs`, `configure_ecdsafail_submission_route()`:
   `DIALOG_GCD_WIDTH_MARGIN` 27 → 26.**
   - `dialog_gcd_tobitvector_active_width(step)` computes
     `ideal = 256 − step · 0.7075 + MARGIN`, rounds `ideal / 2` up and
     doubles it, and clamps to `[1, 256]`. The slope 0.7075 is the default of
     `DIALOG_GCD_WIDTH_SLOPE_X1000`, the empirical shrink rate of
     `max(bitlen(u), bitlen(v))`.
   - With margin 26, the summed width over steps 0 to 396 drops from 56,566
     to 56,208 bits: 358 bits, on 179 steps (from step 40 on, every second
     or third step), 2 bits each.
   - Each step uses `active_width` in four places. The Toffoli cost per bit,
     per GCD pass, is:
     - the conditional swap of `u_active` and `v_active`
       (`dialog_gcd_compressed_block_tobitvector_cswap`): 1 Toffoli per bit;
     - the gated load `gated[i] = b0 & u[i]` in
       `dialog_gcd_controlled_sub_selected`: 1 CCX per bit (the clear is by
       `hmr` + `cz_if`, which is free);
     - the measurement-based Cuccaro subtract `v −= gated`: 1 Toffoli per bit;
     - the branch comparator, only on steps where the active width is below
       the scheduled compare width (late steps).
   - The forward and reverse transcript passes each run this, for both GCD
     passes (the quotient pass and the inverse-multiply pass). The total is
     4 × 3 × 358 = 4,296 Toffoli from the body, plus 4 × 75 = 300 from the
     comparator (summed compare width 19,684 → 19,609). That is 4,596, the
     measured change.
   - See [comparator-and-width-truncation](../concepts/comparator-and-width-truncation.md)
     for width envelopes, and [adders-and-carries](../concepts/adders-and-carries.md)
     for the measured Cuccaro adder.
2. **Reroll pair: `DIALOG_REROLL` 50 → 0, `DIALOG_POST_SUB_REROLL` 39 → 28.**
   These are the counts of identity `X;X` pairs that `build_builder()` emits
   before and after the first subtraction. They only re-draw the 9,024 test
   inputs.

## Why it is still correct, and what it risks

The width envelope is an approximation. If, at some step, `u` or `v` still
has a bit set above `active_width`, the swap and the subtract ignore that bit
and the GCD goes wrong. The run then shows a classical failure, or ancilla
garbage, because `6189d5f`'s late-step u-high borrow also assumes those bits
are zero. A 1-bit lower margin roughly doubles the chance that a slow-shrinking
input crosses the envelope at a narrowed step.

The reroll pair (0, 28) draws a clean set: 9,024 of 9,024 shots pass with
0 classical, 0 phase and 0 ancilla failures. See
[nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

The only circuit change narrows the registers the GCD body works on, so
comparator/width truncation fits.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 144e07f -- src/point_add`. The base is the git
   parent. `git diff --ignore-cr-at-eol 144e07f 113f346 -- src/point_add` is
   19 lines in 1 file.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line endings.
   It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 113f346 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `DIALOG_*`,
   `KAL_*`, `KARA_*` or `ROUND84_*` environment variables set, because
   `set_default_env` keeps any value already in the environment. Expect:
   - 1443 qubits
   - 1,731,723 average Toffoli (rounded)
   - score 2,498,876,289
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the reroll pair `DIALOG_REROLL=0`,
`DIALOG_POST_SUB_REROLL=28` and an identical op stream. Any other change needs
a new reroll search.
