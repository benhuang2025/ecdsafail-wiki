## Summary

This commit makes no optimization. It only changes the tail nonce in
`src/point_add/mod.rs` (`"TAIL_NONCE"` in `env_raw()`) from 25000058104875 to
25700399837515. The new nonce draws a different clean set of 9,024 test shots,
whose average executed Toffoli is 5 lower (944,566.008 by the submission
note). The diff touches only the nonce literal. `apply_tail_nonce()` writes
the nonce into the `q_target` of the 96 trailing X ops, so the op count is
unchanged by construction, and the q73d recipe and its 105 rewrite rows
(`q73d_rewrite.txt`) are untouched. For why a nonce moves the score, see
[nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Reproduce

From `git checkout 7c1a800 -- src/point_add`, apply the patch below with
`git apply --ignore-whitespace`. `./benchmark.sh` should give 1173 qubits,
944,566 average Toffoli and 0 / 0 / 0 failures.
