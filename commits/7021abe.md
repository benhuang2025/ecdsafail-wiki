## Summary

The x-tail Karatsuba square keeps a 258-qubit register `z1_reg` live through
its Solinas reduction, which is where the global peak of 1543 sat. During that
window `z1_reg` holds `2·lo·hi`, which is below 2^257, so its top wire is
always 0. This commit frees that wire for the window and allocates a fresh zero
wire before the step that can set it again. The square phase drops by one
qubit and the global peak becomes 1542, now set by the GCD body. The freeing
itself costs no Toffoli.

The changed op stream needed a new Fiat–Shamir reroll, and the author found no
clean island at the base's comparator margin. Widening the GCD branch
comparator schedule margin from 5 to 7 bits (+592 Toffoli) made a clean island
at reroll pair (6, 0) possible. One qubit is worth about 1,100 Toffoli at this
size, so the trade still pays.

## What changed and why it saves qubits

1. **`KARA_FREE_Z1_TOPBIT=1`** in `squaring_sub_from_acc_karatsuba()`,
   `src/point_add/mod.rs`.
   - The square splits `x = lo + hi·2^128` and computes
     `z1_reg = (lo + hi)²` (258 qubits, width `2(h+1)`), `z0 = lo²` and
     `z2 = hi²`. After `z1 −= z0; z1 −= z2`, `z1_reg = 2·lo·hi`. Since
     `lo, hi < 2^128`, that is below 2^257, so bit 257 (the last wire) is 0 on
     every branch of the superposition. See
     [squaring-and-karatsuba](../concepts/squaring-and-karatsuba.md).
   - New code: right after the two subtractions,
     `let top = z1_reg.pop(); b.free(top);`. `z1_reg` is now `mut`. The two
     combine steps that pad `z1_reg` to `3h` bits now allocate
     `3h − z1_reg.len()` pad wires instead of `3h − 2(h+1)`, so they still see
     a `3h`-wide operand (one more zero pad wire stands in for the freed bit).
   - The wire stays freed through the whole Solinas reduction (phases
     `r84k_sol_subadd` to `r84k_sol_halve`) and the inverse
     `mid −= z1`. Right after that, and before `z1 += z2` can carry into bit
     257 again, `b.alloc_qubit()` grabs a fresh zero wire and pushes it back
     onto `z1_reg`. The inverse squares then see the full register.
   - The author's comment reports the square phase falling to 1541 and the
     global binder moving to the GCD body at 1542. See
     [venting-and-wire-loans](../concepts/venting-and-wire-loans.md) and
     [peak-qubits-and-budgets](../concepts/peak-qubits-and-budgets.md).
2. **`DIALOG_GCD_PA9024_COMPARE_SCHEDULE_MARGIN`: 5 → 7** in
   `configure_ecdsafail_submission_route()`.
   - The GCD branch comparator width at each step is
     `min(SCHEDULE[step] + MARGIN, active_width, DIALOG_GCD_COMPARE_BITS = 59)`
     (`dialog_gcd_compare_bits_for_step`). A larger margin makes the compare
     wider and more accurate, so this is a loosening.
   - Summed over the 399 steps the widths go from 20,010 to 20,158 bits, +148,
     changing 81 steps. The compare runs four times per step (forward and
     reverse transcript, both GCD pairs) at one Toffoli per bit:
     4 × 148 = +592 Toffoli, the measured change.
   - The comment says a 2-D search over (reroll, post-sub reroll, margin) found
     a clean island only at margin 7 for this op stream.
3. **Reroll pair: `DIALOG_REROLL` 28 → 6, `DIALOG_POST_SUB_REROLL` 5 → 0.**
   Identity `X;X` counts that re-draw the 9,024 test inputs without changing
   the circuit (see [`ecbf87b`](ecbf87b.md)).

## Why it is still correct, and what it risks

The free is exact. Bit 257 of `2·lo·hi` is 0 for every input, so the wire is
in |0⟩ and not entangled with anything when it is reset and returned to the
pool. The fresh wire that replaces it is also |0⟩, which is the value bit 257
would have had at that point. `z1_reg` therefore holds the same value as in
the base at every step that reads it, and the inverse uncompute still clears
it.

The margin change makes the circuit more accurate, not less: wider compares
fail on fewer inputs. All existing approximations still have to be right on
the new test draw. The reroll pair (6, 0) gives 9,024 of 9,024 passing shots
with 0 classical, 0 phase and 0 ancilla failures. See
[nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

The qubit comes from shortening a wire's lifetime: it is freed while it is
provably zero and re-allocated when it is needed again. That is
ancilla-lifetime / venting. The margin change is a Toffoli cost paid to find a
clean island, not a lever of its own.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 287595e -- src/point_add`.
   - The git parent is `fe29b53` (josusanmartin, comparator cap 58), which was
     built on mpjunior92's `40574d3`. Diffing against it (170 lines) would also
     show 287595e's doublings block replacing `KARA_SOL_SHIFT22_DOUBLES`,
     F_CUT 79 → 78, the comparator cap going back from 58 to 59 and 287595e's
     memory log being added. This commit was built on `287595e`.
   - `git diff --ignore-cr-at-eol 287595e 7021abe -- src/point_add` is 42 lines
     in 1 file.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line endings.
   It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 7021abe -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `DIALOG_*`,
   `KAL_*`, `KARA_*` or `ROUND84_*` environment variables set, because
   `set_default_env` keeps any value already in the environment. Expect:
   - 1542 qubits
   - 1,695,679 average Toffoli (rounded)
   - score 2,614,737,018
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the reroll pair `DIALOG_REROLL=6`,
`DIALOG_POST_SUB_REROLL=0` and an identical op stream. Any other change needs
a new reroll search.
