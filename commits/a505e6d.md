## Summary

This commit adds one more positional dead-gate strip to mochimodev's
1152-qubit trailmix circuit. A fire census over 10^8 random inputs found
2,101 CCX gates in the final op stream whose two controls were never 1 at
the same time. Their op indices are baked into a new source table, and
`build()` deletes them as its last step, after the CCX fan-out rewrite. A
self-check aborts the build if any listed index is not a CCX.

The gates never fired in the census, so on the test draw they are pure cost:
the scorer charges a CCX whether or not it flips its target. Removing them
saves 2,039 average executed Toffoli at the same 1152 qubits. The tail nonce
is re-hunted and force-set (9000624727621).

## What changed and why it saves Toffoli

- **New `src/point_add/m60_dead_t10.rs`** (generated, 182 lines).
  - It holds `pub(crate) const M60_DEAD_T10: [usize; 2101]`, a sorted list of
    op indices into the stream that `build()` returns after the fan-out loop.
    The values run from 20,425 to 9,757,276.
  - The header says the gates are "census-verified never-firing (both
    controls never simultaneously 1) over 1e8 faithful-RNG inputs", and that
    the source was `repo-c2b/dead_t10.txt`.
  - Many entries come in arithmetic runs with step 3, such as
    4,753,033, 4,753,036, … These look like one CCX per bit of the same
    ripple, repeated across GCD steps.
- **`src/point_add/mod.rs`, new `apply_m60_dead_t10(ops)`.**
  - It puts the indices into a `HashSet`.
  - For each one it asserts that `ops[i].kind == CCX`. The message is
    "skip-set misaligned with this nonce/config -- aborting".
  - It then drops those ops. `M60_DISABLE=1` skips the pass.
  - It is called at the end of `build()`, in place of `ops`, after
    `single_ccx_fanout::rewrite_first_target_fanout` has converged.
- **Nonce.** `build()` now begins with
  `std::env::set_var("DIALOG_TAIL_NONCE", "9000624727621")`.
  - This is a forced write, not `set_default_env`, so it also overrides a
    shell `DIALOG_TAIL_NONCE`. The `Q1153_SECOND512_SUBMISSION_NONCE`
    constant (193806910775884) is left in place but no longer takes effect.
  - The nonce tail is the last 96 ops of the stream, after every listed
    index, so the drop list does not depend on the nonce.
- **Why it saves.** `sim.rs` adds a CCX's condition count to the Toffoli tally
  before it looks at the controls (see
  [dead-gate-strip](../concepts/dead-gate-strip.md)). A gate whose controls
  are never both 1 does nothing but is still charged.
  - An unconditional CCX saves one Toffoli per shot. The measured saving,
    2,039, is a little below 2,101. Two things can explain the gap: the
    average is taken over a new test draw, and some of the dropped gates may
    be classically conditioned, so charged on only some shots.

## Why it is still correct, and what it risks

- The removal is empirical, not exact.
  - The source comment calls it "bit-exact" and the submission note
    "value-exact". That only holds for the inputs the census sampled.
  - On an input where a listed CCX would have fired, the target keeps a wrong
    value. That ends up as a wrong output (classical) or a dirty ancilla.
  - Each such input is a new hard input that the nonce must avoid. See
    [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).
- The list is positional. Any change that shifts op indices before a listed
  gate makes the list delete the wrong gates.
  - The CCX self-check catches the case where a shifted index lands on a
    non-CCX. It does not catch one that lands on a different, live CCX.
  - This is the "classical 9024" failure mode described in
    [dead-gate-strip](../concepts/dead-gate-strip.md).
  - `M60_DISABLE=1` turns the pass off while you experiment.
- The shipped nonce `9000624727621` draws a clean set: 9,024 of 9,024 shots,
  0 classical, 0 phase and 0 ancilla failures, average 1,318,723.928 Toffoli
  (submission note).

## Classification rationale

The commit only deletes never-firing CCX gates from the finished stream, which
is the census strip case of dead-gate/self-inverse removal. The structural
variant, keyed by call index, is [`6dafa07`](6dafa07.md). This one goes back
to raw op indices, applied after the fan-out rewrite.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 422f21d -- src/point_add`. The base is the git parent.
   `git diff --ignore-cr-at-eol 422f21d a505e6d -- src/point_add` is 226
   changed lines in 2 files.
2. **Copy the generated table from the commit:**
   `git checkout a505e6d -- src/point_add/m60_dead_t10.rs`. It is the
   2,101-entry op-index list described above, not hand-written code.
3. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`. The flag lets the patch apply whether the files use LF or CRLF line endings. It
   covers `mod.rs`: the module declaration, `apply_m60_dead_t10`, the forced
   nonce and the final call.
4. **Check the tree.** `git diff --ignore-cr-at-eol a505e6d -- src/point_add`
   should print nothing.
5. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `SUB4_*`,
   `TLM_*`, `M60_*` or `SINGLE_CCX_*` overrides set. `DIALOG_TAIL_NONCE` is
   overwritten by `build()` in any case. Expect:
   - 1152 qubits
   - 1,318,724 average Toffoli (1,318,723.928 before rounding)
   - score 1,519,170,048
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `9000624727621` and an identical op
stream. Any upstream change both needs a new nonce and invalidates the index
list.
