## Summary

Two lines of work had split on the same day.

- [`b02b354`](b02b354.md), this author's, made the constant-propagation post-pass
  stronger. It added a fixpoint loop, self-inverse CCX pair cancellation and affine
  equal/complementary-control detection.
- [`cea9f5f`](cea9f5f.md), BitWonka's, lent the known-1 wire `u[0]` during each GCD
  subtract and apply step, which reached 1165 qubits. It also ported two small Toffoli
  cuts. It still ran the original constant pass.

This commit is the union. It has the enhanced `constprop.rs`, byte-identical to
`b02b354`, on top of the `cea9f5f` circuit, with a new tail nonce.

Relative to `cea9f5f`, the enhanced pass removes 354 more average Toffoli
(1,413,487 → 1,413,133). Relative to the chosen base `b02b354`, the commit adds
the qubit loan and the two Toffoli cuts: −1 qubit and −908 Toffoli. Jackylee0424's
fold-threshold change in [`f265bb1`](f265bb1.md), `MIN_G` 16, is **not**
included, and this tree keeps `MIN_G` 18.

## What changed and why it saves qubits and Toffoli

Against `b02b354`, the diff is exactly the `cea9f5f` stack. See
[cea9f5f](cea9f5f.md) for the full mechanism.

1. **Odd-`u[0]` loan.**
   - `trailmix_ludicrous/gcd.rs` adds `park_known_one` / `restore_known_one`. After each
     step's controlled swap, `u[0]` (always 1, because `u` is odd) is flipped to 0 and
     returned to the free pool with the new `BExt::loan_zero_qubit`.
   - The pool is free for the duration of the controlled subtract and the fused apply step.
     Then the wire is reclaimed with `reclaim_zero_qubit` (`reacquire`) and flipped back.
   - This works because the subtract never reads `u[0]`: bit 0 is a CX, since `x[0] = 1`.
   - It is baked with `TLM_PARK_ODD_U0=1` and `TLM_LOAN_ODD_U0=1` in `build()`. It is the
     source of the 1166 → 1165 drop.
2. **`d AND NOT e` from the live `e AND d`** in `trailmix_ludicrous/fused.rs`
   (`toggle_dnot_e_from_intersection`). Two CX gates replace one CCX at each build of
   the fused fold's `dne` control, using the identity `d·¬e = d ⊕ e·d`.
3. **`single_ccx_fanout.rs`** (new, 375 lines). `build()` applies the identity
   `CCX(a,b→t); CX(t→u); CCX(a,b→t) = CX(t→u); CCX(a,b→u)` once, at its first valid
   site, after `build_trailmix_ludicrous_ops()`. It asserts that exactly one op disappears.
4. **Nonce.** The default `DIALOG_TAIL_NONCE` goes from 3000001941 to 1200017123.

`constprop.rs` is identical to the base's. It runs inside
`build_trailmix_ludicrous_ops()`, before the fan-out rewrite, so the enhanced
pass now sees the loan-shaped stream. The submission does not say how many
gates it removes there.

## Why it is still correct, and what it risks

Every component is exact, and each one was validated on its own tree.

- **The constant, pair and affine rewrites** apply only to provably constant,
  equal or complementary controls, or to provably cancelling pairs. The author
  checked them against 108,480 inputs, with no counterexample.
- **The loan** relies on `u[0] = 1` after every cswap and on nothing reading `u[0]` inside the window.
- **The `dne` identity and the fan-out rewrite** are gate identities.

The new combination still has to be checked as a whole, because the
constant pass now runs over a different stream. Nonce `1200017123` gives 0
classical, 0 phase and 0 ancilla failures over all 9,024 shots. The author
also checked that with the enhancement disabled, the tree reproduces the
`cea9f5f` submission exactly. See
[nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

The author's own lever is the enhanced constant-propagation pass, carried onto
a tree that lacked it, so the published label fits the intent. Measured
against the smallest-diff base `b02b354`, however, the patch is BitWonka's loan
stack. On the diff alone this would be **Register and Scratch Allocation →
ancilla-lifetime / venting**. The commit is a merge of two existing levers,
and it brings no new mechanism.

+        epochs.x_controls[key.target as usize],

+        epochs.hard_touches[key.control_b as usize],

+fn advance_epochs(op: &Op, index: usize, epochs: &mut Epochs) -> bool {

+        return true;
+    }

+fn validate_protected_tail(ops: &[Op], protected: usize) -> Result<Vec<Op>, String> {
+    if protected > ops.len() || protected % 2 != 0 {
+        return Err("invalid protected-tail length".to_owned());

+            return Err(format!(

+/// Apply exactly one target-fanout conjugation:
+///
+/// CCX(a,b,t); CX(t,u); CCX(a,b,t) = CX(t,u); CCX(a,b,u).
+///
+/// Dependency epochs permit commuting operations around the sole CX blocker.
+/// Condition-stack transitions are barriers, and the fixed nonce suffix is
+/// checked byte-for-byte after the rewrite.
+pub(crate) fn rewrite_first_target_fanout(
+    ops: Vec<Op>,
+    protected_tail_ops: usize,
+) -> Result<(Vec<Op>, FanoutWitness), String> {
+    let protected_tail = validate_protected_tail(&ops, protected_tail_ops)?;
+    let prefix_len = ops.len() - protected_tail_ops;
+    let mut epochs = Epochs::new(max_wire(&ops) + 1);
+    let mut candidates = HashMap::<GateKey, Candidate>::new();
+
+    for index in 0..prefix_len {
+        let op = ops[index];
+        if let Some(key) = ccx_key(&op) {
+            let current_snapshot = snapshot(key, &epochs);
+            if let Some(prior) = candidates.get(&key).copied() {
+                let mut deltas = [0u64; 8];
+                let monotonic = deltas
+                    .iter_mut()
+                    .zip(current_snapshot.into_iter().zip(prior.snapshot))
+                    .all(|(delta, (current, old))| {
+                        if let Some(value) = current.checked_sub(old) {
+                            *delta = value;
+                            true
+                        } else {
+                            false
+                        }
+                    });
+                let blocker_index = epochs.last_x_control[key.target as usize];
+                let blocker = (blocker_index != NO_INDEX).then(|| ops[blocker_index]);
+                if monotonic
+                    && deltas == [0, 0, 1, 0, 0, 0, 0, 0]
+                    && prior.index < blocker_index
+                    && blocker_index < index
+                    && blocker.is_some_and(|blocker| {
+                        blocker.kind == OperationType::CX
+                            && blocker.q_control1.0 == key.target
+                            && blocker.q_target.0 != key.control_a
+                            && blocker.q_target.0 != key.control_b
+                            && blocker.q_target.0 != key.target
+                    })
+                {
+                    let blocker = blocker.unwrap();
+                    let mut replacement = Op::empty();
+                    replacement.kind = OperationType::CCX;
+                    replacement.q_control2.0 = key.control_a;
+                    replacement.q_control1.0 = key.control_b;
+                    replacement.q_target = blocker.q_target;
+                    replacement.c_condition = blocker.c_condition;
+                    let witness = FanoutWitness {
+                        first_index: prior.index,
+                        blocker_index,
+                        second_index: index,
+                        control_a: key.control_a,
+                        control_b: key.control_b,
+                        old_target: key.target,
+                        new_target: blocker.q_target.0,
+                        condition: blocker.c_condition.0,
+                    };
+                    let mut rewritten = Vec::with_capacity(ops.len() - 1);
+                    for (op_index, stream_op) in ops.into_iter().enumerate() {
+                        if op_index == prior.index || op_index == index {
+                            continue;
+                        }
+                        rewritten.push(stream_op);
+                        if op_index == blocker_index {
+                            rewritten.push(replacement);
+                        }
+                    }
+                    if rewritten.len() + 1 != prefix_len + protected_tail_ops {
+                        return Err("single-fanout rewrite changed the wrong op count".to_owned());
+                    }
+                    if rewritten[rewritten.len() - protected_tail_ops..] != protected_tail {
+                        return Err("single-fanout rewrite changed the nonce suffix".to_owned());
+                    }
+                    return Ok((rewritten, witness));
+                }
+            }
+            candidates.insert(
+                key,
+                Candidate {
+                    index,
+                    snapshot: current_snapshot,
+                },
+            );
+        }
+        if advance_epochs(&op, index, &mut epochs) {
+            candidates.clear();
+        }
+    }
+    Err("no target-fanout conjugation found".to_owned())
+}
