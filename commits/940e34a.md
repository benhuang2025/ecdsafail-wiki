## Summary

This commit changes one constant on moscowchill's [`9805dee`](9805dee.md).
Each replay add of the ping-pong divider is split into chunks. The carry
between two chunks is measured out, and its phase is repaired by comparing
only the top `REPLAY_CHUNK_COMPARE` bits of the producing chunk. This commit
narrows that compare from 22 to 20 bits. One compare bit is one Toffoli on the
roughly half of shots where the repair runs. The base's notes priced this
knob at about 1,100 Toffoli per bit, and the measured saving is 2,273
average Toffoli at the same 1278 qubits.

The frontier at the time, `6b5c82c`, had instead cut the divide depth to 694
rounds. This commit keeps 698 rounds and the 20-bit endpoint window of
`9805dee`, and spends its λ on the compare instead. That scores 1,120,806
better than `6b5c82c`.

## What changed and why it saves Toffoli

1. **`replay_chunk_compare()` default: 22 → 20** in
   `src/point_add/pingpong_div.rs` (`SUB4_PP_REPLAY_CHUNK_COMPARE`).
   - In `add_chunked_measured_with`, each chunk-boundary carry is erased by
     `hmr(carry, phase)` and repaired with
     `cmp_lt_phase_conditioned(&acc[hi−k..hi], &addend[hi−k..hi], phase)`,
     `k = min(REPLAY_CHUNK_COMPARE, chunk width)`. The carry out of a chunk
     equals `[sum < addend]` over that chunk, so applying that comparison as a
     phase cancels the measurement's kickback.
   - The compare runs only when `phase` = 1: `k` CCX forward, then an
     `hmr`/`cz_if` inverse with no Toffoli. So a bit is about 0.5 executed
     Toffoli per boundary.
   - In this tree the chunk layout is chosen per round against the peak
     budget (`chunk_layout`), so the number of wide boundaries per replay
     cell varies, averaging between one and two. The same window also caps
     the exact leading chunk that `chunk_layout` may use, and it applies to
     the square's chunked adds.
   - 0xrlawrence's table in `memory/11-lambda-walk-and-local-gpu-search.md`
     (in the base tree) measured the reverse move 22 → 26 at +4,475 Toffoli,
     about 1,100 per bit. That matches the −2,273 here. See
     [comparator-and-width-truncation](../concepts/comparator-and-width-truncation.md)
     and [measurement-uncompute](../concepts/measurement-uncompute.md).
2. **Tail nonce** (`SUB4_PINGPONG_TAIL_NONCE` default in `build()`,
   `src/point_add/mod.rs`): 68367898080254 → 176078461220.

## Why it is still correct, and what it risks

The values are unchanged. Only the boundary phase repair is approximate: when
the top 20 bits of a wide chunk's sum and addend tie, the compare can be
wrong, and the shot keeps a stray **phase**. That is about 2^−20 per wide
boundary, four times the old rate. Leading chunks no wider than the window
are still compared in full and stay exact. The same table says 22 → 26
removed 0.5 λ. If this window's λ scales as 2^−k, that puts the 20-bit window
about 1.6 λ above the 22-bit one, roughly 1,400 Toffoli per λ. That is still a
better rate than the depth cuts in the same table (about 880–1,100 Toffoli
per λ), which is why the author spent λ here rather than on the 694-round
depth. The shipped nonce `176078461220` draws a
clean set: 0 classical, 0 phase and 0 ancilla failures. See
[nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

The only circuit change against the base narrows a truncated comparator,
which is comparator/width truncation.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 9805dee -- src/point_add`.
   - Against `9805dee`, `git diff --ignore-cr-at-eol 9805dee 940e34a -- src/point_add`
     is 4 lines in 2 files.
   - Do not start from the git parent `6b5c82c`. Against it the diff is
     23 lines in 2 files, and it reverts moscowchill's sell/buy package:
     `SUB4_PP_ROUNDS` 694 → 698 and `SUB4_PP_ENDPOINT_FOLD_WINDOW` 26 → 20,
     with their comments.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line
   endings. It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 940e34a -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `SUB4_*`
   environment variables set. Expect:
   - 1278 qubits
   - 917,481 average Toffoli (rounded)
   - score 1,172,540,718
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `176078461220` and an identical op
stream. Any other change needs a new nonce hunt.
