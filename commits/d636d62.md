## Summary

In this June circuit the `λ²` term of the point addition (`x3 = λ² − …`) is a
256-bit schoolbook square. Its widest rows are added into the product register in two
windows, to keep the qubit peak down. The carry that crosses the window
boundary is parked on a fresh wire, `cout`, and must be cleaned afterwards.
The base cleaned it coherently: it recomputed the carry with a truncated
comparator and XORed the result into `cout`, which costs one Toffoli per
compared bit on every shot.

This commit measures `cout` out instead (`hmr`) and replays the same
comparator only as a phase fix-up, conditioned on the measurement outcome. The
fix-up runs on about half the shots, so the comparator costs half as much on
average. The author spent part of the saving on a wider, safer compare (18 →
22 bits). The net is −387 average Toffoli at the same 1218 qubits.

## What changed and why it saves Toffoli

**Background: windowed square rows (see [squaring-and-karatsuba](../concepts/squaring-and-karatsuba.md), section "Early squarers (May–July)").**
`multiply.rs::schoolbook_square_symmetric_lowq_selfhosted` builds the square
row by row. Row `i` has `width = n − i + 1` bits (`x_i`, a zero gap bit, then
the cross terms `x_i·x_{i+1+k}`). It is added into `tmp_ext[2i..]`. With
`SQUARE_ROW_MAX_SEG = 191` (set in `mod.rs`), any row wider than 191 bits goes
through `square_row_windowed_apply` and is split into
`ceil(width/191) = 2` windows. Only one window's row bits are materialised at a
time, which keeps the transient row register small. The 256-bit square
(`squaring_sub_from_acc_schoolbook_lowq_shift22`, the round-84 `λ²` square,
called from `rounds/dialog/mod.rs`) has
66 such rows (i = 0..65). Each has one interior boundary. The square is applied
once forwards and once inverted (`forward = false`, the subtract), so there are
about 132 boundary cleanups per point addition.

At each boundary, window 0's carry-out goes to a fresh wire `cout` and feeds
window 1 as its carry-in. After the add, `cout` still holds the carry. The
reverse sweep at the end of `square_row_windowed_apply` cleans it by
recomputing `carry = (partial_sum < seg + cin)` from the finished partial sum
and a rebuilt copy of the source window `seg`. With
`SQUARE_ROW_WINDOW_CLEAN_COMPARE_BITS = k > 0`, only the top `k` bits of the
window are compared, the carry-in from below is replaced by a fresh zero
(`cmp_cin`), and only those `k` bits of `seg` are rebuilt (`build_seg(suffix_lo, hi)`).

**The change.**

1. `src/point_add/arith/multiply.rs`, `square_row_windowed_apply`: a new switch
   `SQUARE_ROW_WINDOW_MEASURED_CARRY_CLEAR`
   (`square_row_window_measured_carry_clear_enabled()`). When it is `1`, all
   four cleanup sites (truncated and full-width, forward and inverse) change
   from
   ```
   cmp_lt_into_fast_with_cin_borrowed_carries(b, u, v, cin, cout, carries)   // cout ^= (u < v + cin)
   ```
   to
   ```
   phase = b.alloc_bit();
   b.hmr(cout, phase);                                                        // cout -> |0>, outcome bit `phase`
   cmp_lt_phase_conditioned_with_cin_borrowed_carries(b, u, v, cin, carries, phase)
   ```
   The `u, v` operands, the X-wrapping for the inverse (borrow) case, and the
   borrowed carry lane `tmp_ext[row_top..]` are unchanged.
2. `src/point_add/arith/compare.rs`: new
   `cmp_lt_phase_conditioned_with_cin_borrowed_carries`. Under
   `push_condition(phase)` it runs the forward carry chain of the fast
   comparator (`cmp_lt_fast_prefix_window_forward`, one CCX per bit), applies
   `cz(u[n−1], u[n−1])` (the builder turns an aliased CZ into a `Z` on that
   wire, which now holds the comparison result), and then unwinds the chain
   with `cmp_lt_fast_prefix_window_inverse` (hmr erases, no Toffoli). It is the
   existing `cmp_lt_phase_conditioned_borrowed_carries` without an extra
   quantum control.
3. `src/point_add/mod.rs`, `configure_ecdsafail_submission_route()`:
   - `SQUARE_ROW_WINDOW_MEASURED_CARRY_CLEAR` = `1` (new default).
   - `SQUARE_ROW_WINDOW_CLEAN_COMPARE_BITS`: 18 → 22.
   - `DIALOG_TAIL_NONCE`: 402004742830 → 4836419.
4. A new notes file `src/point_add/memory/2026-06-11-measured-square-carry-selective-k3.md`.
   It is documentation only. It also mentions a `DIALOG_GCD_SELECTIVE_K3_STEP`
   lever, but no code for that lever is in this diff.

**Why it saves Toffoli.** `hmr` resets `cout` but leaves the phase
`(−1)^(phase·carry)`. The conditional block applies exactly `(−1)^carry` when
`phase = 1`, which cancels it. See
[measurement-uncompute](../concepts/measurement-uncompute.md). Under a
classical condition, the scorer charges the CCX gates only when the condition
is true, which is about half the shots.

Per truncated boundary cleanup, in executed Toffoli:
- Base: `k = 18` CCX to rebuild the `seg` suffix, plus 18 CCX in the
  comparator, for 36.
- New: `k = 22` CCX to rebuild the suffix (this still runs every shot), plus
  22 × ½ = 11 in the conditional comparator, for 33.

That is about 3 Toffoli saved per cleanup. Over about 132 cleanups it comes to
about 396, close to the measured −387. Qubits are unchanged, because the
comparator still borrows its carry lane from the clean high tail of `tmp_ext`.

## Why it is still correct, and what it risks

- **The measured erase is exact.** For a given comparator result, `hmr` plus
  the conditional `Z` is the same uncompute as the coherent XOR.
- **The truncation is probabilistic, as before.** The 22-bit compare ignores
  the carry coming from the lower bits of the window. It gives the wrong carry
  when the top 22 bits of the partial sum and of `seg` tie, about 2^-22 per
  cleanup, against 2^-18 before. So this commit lowers that risk.
- **The failure channel moves.** Before, a wrong compare left `cout` dirty,
  which is an ancilla failure. Now `cout` is always reset by `hmr`, and a
  wrong compare leaves a wrong phase, which is a phase failure.
- The submission note says the 18- and 19-bit measured variants scored better
  on paper, but their nonce candidates kept failing by one phase batch. 22 bits
  gave a clean island.
- The shipped nonce `4836419` draws a clean set: 9,024 shots, 0 classical,
  0 phase and 0 ancilla failures (submission note). See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

The saving comes from replacing a coherent uncompute of `cout` with an X-basis
measurement and a conditional phase repair. That is measurement uncompute. The
compare-width change goes the other way, wider and less truncated. It spends
part of the saving to make the nonce hunt feasible, so it is not a separate
truncation lever.

   - 1218 qubits
   - 1,402,192 average Toffoli (rounded; 1,402,192.228 in the submission note)
   - score 1,707,869,856
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `4836419` and an identical op stream.
Any other change needs a new nonce hunt.
