## Summary

Sky13 edits one pin, `HEO_PIN_PP_N_BADJ`, the per-band shift of the payload
cells' chunk-boundary compare width. Three bands move by one bit:

- division cells at ticks 220–249 lose one boundary-compare bit (a sell);
- multiply cells at ticks 346–365 lose one bit (a sell);
- multiply cells at ticks 220–264 gain one bit back (a buy).

The trade removes more compare bits than it adds, and the author priced the
buy to cover the λ the two sells spend. The SAT rewrite table is re-mined for
the new op stream (53 → 54 rows). The net is −14 Toffoli at 1174 qubits.

## What changed and why it saves Toffoli

All circuit changes are in `src/point_add/mod.rs`,
`install_skywalk_submission_recipe()`.

1. **`HEO_PIN_PP_N_BADJ`**

   - old: `350-399:m:0,400-553:m:-1,554-599:m:-2,400-449:d:2,649-699:a:-1,554-615:m:-1,589-615:d:-1,616-648:m:1,350-553:d:1,250-349:d:1,350-399:m:1`
   - new: `350-399:m:0,400-476:m:0,477-553:m:-1,554-599:m:-2,400-449:d:1,649-699:a:-1,554-615:m:-1,589-615:d:-1,616-648:m:0,350-553:d:1,250-349:d:1,350-399:m:1`

   How the pin is read (`e_badj()` in `pingpong.rs`, unchanged since
   [`265a9e9`](265a9e9.md); the `HEO_PIN_` prefix overrides the head's pinned
   `PP_N_BADJ`):
   - It is a list of `lo-hi:dir:delta` rules. `dir` is `d` (divide), `m`
     (multiply) or `a` (both). The **first** rule whose direction and
     inclusive round range match wins, so a `:0` rule stops the search and
     shadows every later rule for those rounds.
   - It shifts the width `k` of a *seeded* chunk-boundary carry erase that is
     not on the first chunk (`seeded && plo > 0`), at the erase site only. The
     chunk-layout planner still uses the unshifted width. `CMP_SEED_ALL=1` in
     this tree, so almost every later boundary is seeded.
   - The call sites are the B erases in `joint_lowfold.rs`,
     `joint_prebias.rs` and `retained_prebias.rs`, which the Skywalk payload
     cells reach through `pingpong::replay_add_halve` / `replay_double_add`.
   - The result is clamped to `[2, phi − 1 − floor]`, and a negative delta can
     only narrow, a positive one only widen.
   - The shift stacks on top of `chunk_compare(round)`, which already includes
     the `PP_CHUNK_SHAPE` band, `GO_CHUNK` and the per-cell `GO_CELLB` dB.

   `round` here is the cell's **proxy round**: `h7::proxy_round(esw)` is the
   first ping-pong round whose `PP_WIDTH_SCHEDULE` width is at most the tick's
   width in the fixed proxy envelope `env_front07_R393_clamp.txt`. Mapping the
   changed ranges through that envelope (my computation from the two tables):

   | rule | proxy rounds | ticks | old → new | effect |
   | --- | --- | --- | --- | --- |
   | `400-449:d` | 400–449 | division 220–249 (30 cells) | +2 → +1 | sell, one bit narrower |
   | `616-648:m` | 616–648 | multiply 346–365 (20 cells) | +1 → 0 | sell, one bit narrower |
   | `400-476:m` (new, placed before the old `400-553:m:-1`, which becomes `477-553:m:-1`) | 400–476 | multiply 220–264 (45 cells) | −1 → 0 | buy, one bit wider |

   - The divide rule now equals what the later `350-553:d:1` would give.
   - Multiply cells at ticks 265–307 (proxy 477–553) keep their −1.
   - Each boundary erase is `hmr` of the boundary carry and then, only on
     outcome 1, a phase compare of the top `k` bits. So one compare bit is
     worth about 0.5 executed Toffoli per boundary. See
     [measurement-uncompute](../concepts/measurement-uncompute.md) and
     [comparator-and-width-truncation](../concepts/comparator-and-width-truncation.md).
   - How many boundaries each cell has depends on its chunk layout, so the
     bit count of the trade cannot be read from the diff. The submission note
     prices the package at about −24 T without rows.

2. **SAT rewrite rows: `sky12_rewrite.txt` (53 rows) → `sky13_rewrite.txt`
   (54 rows).**
   - The new widths shift the op stream, so the rows were re-proved. The code
     comment calls them "54 square rows re-proved by SAT on the sky13 op
     stream".
   - Comparing the files, 28 rows name the same wires as a sky12 row, all at
     an index shift of −924. The other 26 are new.
   - The loader in `build()` is unchanged. It finds the one global shift
     under which every row names an unconditioned CCX, then replaces each
     CCX with the row's CX chain (plus an X when `cst = 1`). It does not
     re-check the proof. See [dead-gate-strip](../concepts/dead-gate-strip.md).
   - One more row is about −1 Toffoli on every shot.
   - `sky12_rewrite.txt` stays in the tree, unused.
3. **Tail nonce**: `TAIL_NONCE` goes from 12002628222642 to 13000697424674.

## Why it is still correct, and what it risks

- **The two sells** double the top-k tie error of those boundary erases. A
  wrong compare leaves a wrong phase, which shows up as a **phase** failure.
- **The buy** halves the tie error on 45 multiply cells.
- The submission note gives the package's paired-nonce λ change as
  −0.032 ± 0.014 and the final λ as 19.309 ± 0.032, inside the 19.5 limit
  that the code comment cites.
- The rewrite rows are exact on reachable states if their proofs hold. The
  build only asserts that each row still names its CCX.
- The shipped nonce `13000697424674` draws a clean island: 0 classical,
  0 phase and 0 ancilla failures. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

This is a sell/buy re-balance of compare widths with a net reduction in
compare bits: comparator/width truncation, as for sky12
([`84e78ce`](84e78ce.md)). The extra rewrite row is a small side effect, not
the lever.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 1034430 -- src/point_add`. The base is the git
   parent. `git diff --ignore-cr-at-eol 1034430 1c54ce2 -- src/point_add` is
   64 lines in 2 files.
2. **Copy the new rewrite table from the commit:**
   `git checkout 1c54ce2 -- src/point_add/skywalk_data/sky13_rewrite.txt`.
   It holds the 54 SAT rows described above.
3. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line
   endings. It covers `mod.rs`.
4. **Check the tree.** `git diff --ignore-cr-at-eol 1c54ce2 -- src/point_add`
   should print nothing.
5. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh`. `build()` clears
   the process environment and then installs the pinned recipe, so `HEO_*`,
   `GO_*`, `SKY_*`, `PP_*` and `SUB4_*` overrides have no effect. Do not set
   them anyway. Expect:
   - 1174 qubits
   - 944,655 average Toffoli (rounded)
   - score 1,109,024,970
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `13000697424674` and an identical op
stream. [`af01015`](af01015.md), [`83a3765`](83a3765.md) and
[`1c185d1`](1c185d1.md) keep this circuit and only re-roll the nonce.
