## Summary

After `6bf73fe` moved the x-tail square's reduction in place, the 1307-qubit
peak is set only by the dialog-GCD forward walk (the compressed-block
"tobitvector" walk; background in [8316db1](8316db1.md) and
[9a81017](9a81017.md); see [dialog-gcd-early](../concepts/dialog-gcd-early.md)). Two adjacent walk
steps, 10 and 11, tie at the peak. Both still have the full 256-bit active
width, so their controlled add/sub body asks for the largest scratch pool,
`2·body_len − 1 = 509` wires.

One new knob, `DIALOG_GCD_TRIO_WIDTH_NOTCH=1`, relieves both steps:
- **Step 11:** its add/sub body skips the top 2 bits (width 256 → 254), so it
  needs 4 fewer scratch wires.
- **Step 10:** the scratch pool borrows one more wire that is known to be
  `|0⟩` at that moment, the shift2 cell of its sibling step 11, instead of
  allocating it.

The peak drops by one qubit. The narrower body also saves 16 Toffoli. The
commit adds a lot of other code (clean constant adders, a K2 "state-updating
reverse-pop" codec and two build-time self-tests), but on this route none of it
runs. The tail nonce was re-hunted.

## What changed and why it saves qubits

### The live lever: `DIALOG_GCD_TRIO_WIDTH_NOTCH=1` (`src/point_add/mod.rs`)

The walk keeps its per-step branch bits in a K=2 pair-compressed log. Each
block of two steps has a 6-cell raw block: `b0` and `b0_and_b1` for each step,
plus one shift2 bit `s2` per step that records whether that step stripped a
second zero from `v`. Before each step's controlled subtract/add body,
`dialog_gcd_build_composite_scratch` (`rounds/dialog/compressed.rs`) gathers
`want` scratch lanes. It borrows lanes known to be `|0⟩` first and allocates
the rest as `owned`. The owned count is what reaches the peak.

1. **H3, body-width notch.** In `rounds/dialog/mod.rs`,
   `dialog_gcd_body_carry_trunc_width(active_width, step)` gives the width of
   the add/sub body. It is `active_width − w`, where `w` is the per-step carry
   band trim. New code: if the notch is on and
   `step == dialog_gcd_trio_width_notch_step()` (default 11), add
   `dialog_gcd_trio_width_notch_extra()` (default 2) to `w`.
   - Step 11's body width goes from 256 to 254. Its body length goes from 255
     to 253, and `want` goes from 509 to 505.
   - Only the body is narrowed. The comparator, the cswap shift and the runway
     layout still call `dialog_gcd_tobitvector_active_width` and see the full
     256 bits.
   - New helpers: `dialog_gcd_trio_width_notch_enabled`,
     `dialog_gcd_trio_width_notch_step`, `dialog_gcd_trio_width_notch_extra`.
2. **H1, sibling-s2 borrow.** In `dialog_gcd_build_composite_scratch`, under
   the existing `DIALOG_GCD_BORROW_CURRENT_S2=1` branch (which already borrows
   the current step's own `s2` cell): if the notch is on and the step is the
   first of its pair (`slot == 0`, group size 2), also borrow the sibling's
   cell `raw_block[2·group_size + 1]`. The usual guards apply: the pool is not
   full, the cell is not already in it, and it is not inside the active `u` or
   `v`.
   - Why the cell is `|0⟩`: going forward, the sibling's `s2` is written only
     by the sibling's SHIFT phase, which comes after this step's body has
     finished and freed its scratch. Going backward, it has already been
     uncomputed by the sibling's reverse unshift, which runs before this
     step's reverse add. The scratch pool returns every borrowed lane clean,
     so the cell is still `|0⟩` when the sibling needs it.
   - This applies at every even step, but it only matters at step 10. It
     costs no gate, since it only changes which wire is used.
   - The slot-1 step cannot do the same, because step 10's `s2` is already
     written by then. That is why H1 alone does nothing: step 11 would still
     tie at 1307. H3 is what clears step 11.
3. `DIALOG_TAIL_NONCE`: 4009893105 → 5001200692.

**Toffoli.** The 2 skipped body bits each saved a gated-load CCX and a carry
CCX. Step 11's body runs in the forward and reverse walk of both GCD
divisions, so 2 bits × 2 Toffoli × 4 walks = 16, which matches the measured
−16.

See [peak-qubits-and-budgets](../concepts/peak-qubits-and-budgets.md) for why
the whole set of co-binding phases must drop before the peak moves, and
[venting-and-wire-loans](../concepts/venting-and-wire-loans.md) for borrowing
known-clean cells.

  says it is inert because `ROUND84_INPLACE_SOLINAS_FOLD=1` takes the other
  branch.
- **`rounds/dialog/config.rs` and `compressed.rs`**: a "state-updating reverse
  pop" variant of the K2 pair block (`dialog_gcd_k2_state_updating_reverse_pop_enabled`,
  `dialog_gcd_k2_pair_state_core`, `…_state_controls`, `…_state_s2`, and
  `state_updating` branches in the forward and reverse block lifecycles and
  in the ipmul and quotient lifecycles). It keeps the controls inside the
  5-cell compressed block instead of a separate raw block. It needs
  `DIALOG_GCD_K2_STATE_UPDATING_REVERSE_POP=1`, which nothing sets. The
  current-s2 borrow is also guarded with `!state_updating`.
- **`mod.rs`**: `r84_clean_direct_selftest()` and
  `dialog_gcd_k2_su_reverse_pop_selftest()`, run from `build()` only when
  `R84_CLEAN_DIRECT_SELFTEST=1` or `DIALOG_GCD_K2_SU_REVERSE_POP_SELFTEST=1`.
  Each one simulates the new gadgets on all basis states of a small register.
- **`compressed.rs`**: a `TRACE_COMPOSITE=1` debug print of the scratch pool
  for each step.

## Why it is still correct, and what it risks

H1 is exact. It borrows a wire that is provably `|0⟩` for the whole time the
scratch pool holds it, and the pool returns it to `|0⟩`.

H3 is a width truncation. Step 11's body adds or subtracts only the low 254
bits of `u` and `v`. This is exact whenever bits 254 and 255 of both operands,
and the carry into them, are zero at step 11. The width envelope is 10 bits
looser than the worst observed bit length (`WIDTH_MARGIN=10`), so in practice
those bits are 0 by step 11. This is the same argument as the existing
per-step body-carry band trims (`DIALOG_GCD_BODY_CARRY_BAND_TRIMS`). If it ever
failed, the walk would produce a wrong `u` or `v`, which would show up as a
classical mismatch and as ancilla garbage after the reverse walk. Nonce
`5001200692` validated with 0 classical, 0 phase and 0 ancilla failures over
all 9,024 shots. See
[nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

The inert code has no effect on the op stream.

## Classification rationale

The qubit comes from re-using a clean cell as scratch (H1) and from shrinking
one step's scratch demand (H3), so Register and Scratch Allocation →
scratch/ancilla reuse fits. The runner-up was comparator/width truncation,
because H3 is technically a width cut. But it is used here only to clear a
co-binder, and it saves just 16 Toffoli.

   - 1306 qubits

+///  (2) the apply/reverse raw6 fallback round-trips: `clear_raw_block_copy`
+///      (pack raw6 -> compressed5, CX-host) followed by
+///      `copy_compressed_block_to_raw` (the encoder-inverse-based unpack used by
+///      the apply lifecycle that Step E now feeds a dedicated raw6) returns every
+///      reachable raw6 to itself, phase/ancilla clean. Validates the apply-raw6
+///      fallback the panic-gotcha edits depend on.
+/// Panics on any mismatch.
+fn dialog_gcd_k2_su_reverse_pop_selftest() {
+    use crate::sim::Simulator;
+    use sha3::{
+        digest::{ExtendableOutput, Update, XofReader},
+        Shake128,
+    };
+    fn set_reg<R: XofReader>(sim: &mut Simulator<'_, R>, qs: &[QubitId], val: u64, shot: usize) {
+        for (i, &q) in qs.iter().enumerate() {
+            if ((val >> i) & 1) != 0 {
+                *sim.qubit_mut(q) |= 1u64 << shot;
+            } else {
+                *sim.qubit_mut(q) &= !(1u64 << shot);
+            }
+        }
+    }
+    fn get_reg<R: XofReader>(sim: &Simulator<'_, R>, qs: &[QubitId], shot: usize) -> u64 {
+        let mut out = 0u64;
+        for (i, &q) in qs.iter().enumerate() {
+            out |= ((sim.qubit(q) >> shot) & 1) << i;
+        }
+        out
+    }
+
+    // ---- Part 1: encoder ∘ encoder_inverse over pair_state_core == identity ----
+    // The forward lifecycle emits `encode_core_before_s2` = encoder(state_core);
+    // the reverse emits `decode_core_after_s2_pop` = encoder_inverse(state_core).
+    // Over a full block (no intervening body, since the body only touches u/v),
+    // the encode then its inverse must restore every compressed cell. 5 cells =>
+    // 32 basis states fit in 64 shots in a single batch.
+    {
+        let mut b = B::new();
+        let compressed = b.alloc_qubits(DIALOG_GCD_HIGH_TAIL_ALIAS_BLOCK_BITS);
+        let core = dialog_gcd_k2_pair_state_core(&compressed);
+        emit_dialog_gcd_k2_pair_core_encoder(&mut b, &core);
+        emit_dialog_gcd_k2_pair_core_encoder_inverse(&mut b, &core);
+        let nq = b.next_qubit as usize;
+        let nb = b.next_bit as usize;
+        let mut seed = Shake128::default();
+        seed.update(b"k2-su-encode-roundtrip");
+        let mut xof = seed.finalize_xof();
+        let mut sim = Simulator::new(nq, nb, &mut xof);
+        for shot in 0..32usize {
+            set_reg(&mut sim, &compressed, shot as u64, shot);
+        }
+        sim.apply_iter(b.ops.iter());
+        assert_eq!(sim.phase, 0, "K2 SU encoder round-trip phase garbage");
+        for shot in 0..32usize {
+            assert_eq!(
+                get_reg(&sim, &compressed, shot),
+                shot as u64,
+                "K2 SU encoder∘inverse not identity for compressed={shot:#x}"
+            );
+            for q in DIALOG_GCD_HIGH_TAIL_ALIAS_BLOCK_BITS..nq {
+                assert_eq!(
+                    (sim.qubit(QubitId(q as u64)) >> shot) & 1,
+                    0,
+                    "K2 SU encoder round-trip ancilla {q} dirty for compressed={shot:#x}"
+                );
+            }
+        }
+    }
+
+    // ---- Part 2: clear_raw_block_copy ∘ copy_compressed_block_to_raw round-trip ----
+    // The apply lifecycle (fed a dedicated raw6 by the Step-E edits) decodes via
+    // copy_compressed_block_to_raw, which runs encoder_inverse. We pack a fresh
+    // raw6 into a zero compressed block with clear_raw_block_copy (CX-host), then
+    // unpack it back with copy_compressed_block_to_raw; raw6 must be restored, the
+    // compressed cells must return to |0>, phase clean. raw6 = 6 cells => 64 basis
+    // states in one batch. Forced CX-host (swap-host off) so the operands are the
+    // genuine reachable inputs.
+    {
+        std::env::remove_var("DIALOG_GCD_APPLY_REPLAY_SWAP_HOST");
+        let mut b = B::new();
+        let compressed = b.alloc_qubits(DIALOG_GCD_HIGH_TAIL_ALIAS_BLOCK_BITS);
+        let raw6 = b.alloc_qubits(6);
+        dialog_gcd_k2_pair_clear_raw_block_copy(&mut b, &compressed, &raw6, 2);
+        dialog_gcd_k2_pair_copy_compressed_block_to_raw(&mut b, &compressed, &raw6, 2);
+        let nq = b.next_qubit as usize;
+        let nb = b.next_bit as usize;
+        let mut seed = Shake128::default();
+        seed.update(b"k2-su-pack-roundtrip");
+        let mut xof = seed.finalize_xof();
+        let mut sim = Simulator::new(nq, nb, &mut xof);
+        for shot in 0..64usize {
+            set_reg(&mut sim, &raw6, shot as u64, shot); // compressed starts |0>
+        }
+        sim.apply_iter(b.ops.iter());
+        assert_eq!(sim.phase, 0, "K2 SU pack round-trip phase garbage");
+        for shot in 0..64usize {
+            assert_eq!(
+                get_reg(&sim, &raw6, shot),
+                shot as u64,
+                "K2 SU clear∘copy not identity for raw6={shot:#x}"
+            );
+            assert_eq!(
+                get_reg(&sim, &compressed, shot),
+                0,
+                "K2 SU pack round-trip compressed not cleared for raw6={shot:#x}"
+            );
+            for q in (DIALOG_GCD_HIGH_TAIL_ALIAS_BLOCK_BITS + 6)..nq {
+                assert_eq!(
+                    (sim.qubit(QubitId(q as u64)) >> shot) & 1,
+                    0,
+                    "K2 SU pack round-trip ancilla {q} dirty for raw6={shot:#x}"
+                );
+            }
+        }
+    }
+
+    eprintln!(
+        "DIALOG_GCD_K2_SU_REVERSE_POP_SELFTEST: PASS (encoder round-trip 32/32 basis states, \
+         pack round-trip 64/64 raw6 states; value+phase+ancilla clean)"
+    );
+}
