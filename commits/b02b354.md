## Summary

[`497cc20`](497cc20.md) added a post-pass over the finished op stream. It
drops CCX gates with a provably-0 control and folds CCX gates with a
provably-1 control to CX. This commit makes that pass stronger in three ways,
and runs them in a loop until nothing changes:

- The constant pass is re-run on its own output. Each fold to CX can make a later control constant.
- A self-inverse pass cancels two identical CCX gates that nothing between them can notice.
- An affine pass writes each wire as a constant XOR a set of symbolic variables. It drops
  a CCX whose two controls are provably complementary, so their AND is 0, and folds to CX
  a CCX whose controls are provably equal.

The author's run removes 1,640 emitted Toffoli in total, 386 more than before:
94 from the fixpoint and 292 complementary-pair drops. The average executed
Toffoli falls by 398 at 1166 qubits. All rewrites are exact. The tail nonce
was re-hunted.

## What changed and why it saves Toffoli

The whole change is in `src/point_add/trailmix_ludicrous/constprop.rs`, which
grows from 607 to 1,722 lines and is copied, plus the nonce in `mod.rs`.
`analyze()`, the {Zero, One, Unknown} constant pass, is unchanged. See
[497cc20](497cc20.md) for its rules.

### 1. Fixpoint driver (`run`)

`run` now loops for at most `CONSTPROP_MAX_ITERS` rounds, default 16. Each
round does three steps:

1. **The constant pass** `analyze` → `apply_decisions`.
2. **`find_inverse_pairs`.** Matched pairs are deleted.
3. **`analyze_affine`** → `apply_decisions`, unless `CONSTPROP_AFFINE_DISABLE=1`.

The loop stops after a round with no transform. Each step is sound on its own
input, so the composition is sound. The scorer charges a CCX one Toffoli per
shot whose classical condition is true, whatever its quantum controls hold. So
every dropped CCX saves its full executed count. A fold to CX or X saves the
same, because CX and X are free.

### 2. Self-inverse pair cancellation (`find_inverse_pairs`)

- **Rule.** Two CCX gates at `p < i` cancel exactly when all of the following hold:
  - they have the same target `t`, the same unordered control pair `{a, b}` and the same
    `c_condition`;
  - nothing in between writes or reads `t`;
  - nothing in between writes `a` or `b`;
  - the condition-stack epoch is the same, meaning no `PushCondition` or `PopCondition`
    in between;
  - no bit on the condition stack, and not the `c_condition` bit, is written in between.
- **Scan.** One forward scan keeps last-write and last-read stamps per qubit and a
  last-write stamp per bit. It also keeps one pending CCX candidate per target, and
  deletes both gates when a match appears.
- **Use.** The submission note does not say how many pairs this found. I could not
  count them without running the build.

### 3. Affine GF(2) relations (`analyze_affine`)

- **Representation.** Each qubit's value is written exactly as `cst XOR (XOR of the
  variables in set)`.
  - Each input qubit (reg0 and reg1) gets its own variable. Ancillas start as `0`
    with an empty set.
  - `X` flips `cst`, and `CX` XORs both the sets and the constants. `R` resets the
    wire to 0.
  - `Hmr`, a CCX target, a write whose condition may be false, and any set larger than
    `CAP_SET = 2048` all become a fresh variable. Losing precision this way is safe.
  - `Swap` swaps the two forms.
  - Unlike `analyze`, every classical bit is seeded `Unknown` here, including the per-shot
    Q.x and Q.y bit registers.
- **Rule at each CCX.**
  - If `set(a) == set(b)` and `cst(a) == cst(b)`, then `a = b` on every shot, so
    `a AND b = a`. The gate becomes `CX(a → t)` (`FoldEqualCtrls`).
  - If the sets are equal but the constants differ, then `a = NOT b`, so
    `a AND b = 0`. The gate is dropped (`DropComplementCtrls`).
- **Use.** The author reports 292 complementary drops. Complementary pairs arise naturally
  when one wire is a copy of another with an X applied. The note also says about 7,400
  control pairs only *looked* complementary on test inputs and could not be proved, so
  they were not touched.

### Verification harness (debug only)

`CONSTPROP_VERIFY=<n>` replays the unmodified stream of each round through a
copy of the simulator loop, using `n` extra input draws. Three functions check
the claims:

- `verify_control_constancy` checks the constant claims.
- `verify_inverse_pairs` checks that the target register is identical before both gates
  of each pair.
- `verify_affine_relations` checks the equal and complementary claims.

A failed pair or affine claim panics. `CONSTPROP_VERIFY_NEW_ONLY=1` skips
re-verifying round 1 of the constant pass. The grader build sets none of these.

### `src/point_add/mod.rs`

The default `DIALOG_TAIL_NONCE` in `build()` goes from 123000008384 to 3000001941.

## Why it is still correct, and what it risks

Every rewrite is an exact identity on all basis inputs and all shots, as long
as the static analyses are right:

- a CCX with a 0 control, or with complementary controls, is a no-op;
- a CCX with a 1 control, or with equal controls, is a CX;
- two identical CCX with untouched operands in between cancel.

None of them changes phases. The affine pass seeds all bits `Unknown`, so it
does not share the small gap of the constant pass, which seeds the per-shot
Q-coordinate bits `Zero` (see [497cc20](497cc20.md)). The author's empirical
check found no counterexample over 108,480 inputs (12 draws × 9,024 shots). A
wrong rewrite would show up as classical or ancilla failures. The new nonce
`3000001941` gives 0 classical, 0 phase and 0 ancilla failures over all
9,024 shots. See [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

The pass derives values and relations of quantum wires on the host and uses
them to specialize gates, which is constant propagation. The runner-up is
**Dead-Code and Redundancy Elimination → dead-gate/self-inverse removal**. The
pair-cancellation pass is literally self-inverse removal, and most of the new
saving comes from drops. See [dead-gate-strip](../concepts/dead-gate-strip.md),
which lists this file's `find_inverse_pairs` among the exact removals.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout ed2715f -- src/point_add`.
   - `git diff --ignore-cr-at-eol ed2715f b02b354 -- src/point_add` touches 2 files, almost all of it `constprop.rs`.
   - Diffing against the git parent `550595a` would also revert jackylee0424's
     `LUD_EXTRA_FOLD_MIN_G` 18 → 17. That edit has no effect, see [550595a](550595a.md),
     but this commit was built without it.
2. **Copy the rewritten pass from the commit:**
   `git checkout b02b354 -- src/point_add/trailmix_ludicrous/constprop.rs`.
3. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`. The flag lets the patch apply whether the files use LF or CRLF line endings. It covers `mod.rs`.
4. **Check the tree.** `git diff --ignore-cr-at-eol b02b354 -- src/point_add`
   should print nothing.
5. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `DIALOG_*`, `TLM_*`, `LUD_*` or `CONSTPROP_*`
   environment variables set. Expect:
   - 1166 qubits
   - 1,414,041 average Toffoli (rounded; 1,414,041.157 before rounding)
   - score 1,648,771,806
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `3000001941` and an identical op
stream. Any other change needs a new nonce hunt.
