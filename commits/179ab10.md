## Summary

This commit changes one constant, the start iteration `K0` of the empirical
width envelope used to truncate the Kaliski inverse's width loops (W-TRUNC).
`K0` goes from 27 to 25. The whole envelope shifts two iterations earlier, so
every truncated loop is 1 or 2 bits narrower, 4/3 bits on average, and with
margin 3 clipping now starts at iteration 31 instead of 33. That saves 5,862 average Toffoli at the same 2309 qubits.

The submission note describes this as "two more early iterations" of
truncation. That undersells it: the shift lowers the envelope at every later
iteration too. The saving is about 4/3 of what the 1-bit margin cut in
[`fc8b9e6`](fc8b9e6.md) gave (4,380 × 4/3 ≈ 5,840), which fits.

## What changed and why it saves Toffoli

- `src/point_add/kaliski_state.rs`, `kal_wtrunc_k0()`: the default of
  `KAL_WTRUNC_K0` goes from 27 to 25, with a comment.
- **What `K0` controls.** `kal_wtrunc_width(iter, n)` returns
  `min(n, w_env(iter) + margin)`, where `w_env(it) = n` for `it < K0` and
  `n − ⌊(it − K0)·2/3⌋` afterwards. The margin is 3 and `n = 256`. Every
  W-TRUNC site in `kaliski_walk.rs` uses `min(provable, kal_wtrunc_width)`:
  the STEP-0 `v_w == 0` OR chain, the STEP-2 comparator `u > v_w`, and the
  STEP-4 load and subtract, in both the forward and backward iterations. See
  [`fc8b9e6`](fc8b9e6.md) for the full list.
- **How much narrower.** With `x = it − 27`, the new envelope is lower by
  `⌊(2x + 4)/3⌋ − ⌊2x/3⌋`. That is 1 when `x mod 3` is 0 or 2, and 2 when
  `x mod 3 = 1`. With margin 3 the clipped width first drops below 256 at
  iteration 31 instead of 33, and every later iteration loses 4/3 bits on
  average.
- **Why it saves Toffoli.** Each bit removed from a loop removes about one
  Toffoli from that loop in that iteration. The loops run in about 1,600
  Kaliski iterations (forward and backward of pair1 with 399 iterations and
  pair2 with 397).

## Why it is still correct, and what it risks

This is a probabilistic truncation, like the margin. It assumes that after
`it` iterations the bit length of `u` and `v_w` has shrunk by at least
`⌊2(it − 25)/3⌋ − 3` bits. A slow-converging input whose high bits are still
nonzero gets a wrong comparison or subtraction, which shows up as a classical
mismatch. Moving `K0` earlier eats about 1.3 bits of the 1 to 7 bits of slack
the original 80k-sample fit had above the sample maximum.

There is no nonce in this era, so each `K0` value draws its own 9,024-shot
test set. The author's sweep on this circuit gave:
- `K0 = 25`: clean, 0 classical, 0 phase and 0 ancilla failures;
- `K0 = 23`: 2 classical mismatches;
- `K0 = 29`: 1 mismatch and 2 phase failures. This one is wider than the base,
  so its failure is an island effect from other approximate knobs, not
  the truncation.

See [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

The only change narrows the GCD walk's comparators, OR chains and adders, so
comparator/width truncation fits. Iteration/threshold tuning is the
runner-up, since `K0` is an iteration index, but what it controls is a bit
width.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 2abe7f4 -- src/point_add`. The base is the git
   parent. `git diff --ignore-cr-at-eol 2abe7f4 179ab10 -- src/point_add` is
   7 lines in 1 file.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`. The flag lets the patch apply whether the files use LF or CRLF line endings. It is the
   complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 179ab10 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `KAL_*`
   or other tuning environment variables set, and with `DUMMY_TOFFOLIS` unset.
   Expect:
   - 2309 qubits
   - 2,837,081 average Toffoli (rounded)
   - score 6,550,820,029
   - 0 classical, 0 phase and 0 ancilla failures

There is no nonce in this tree: the test set is a hash of the op stream, so the
score only reproduces with an identical op stream. Any other change draws a new
island.
