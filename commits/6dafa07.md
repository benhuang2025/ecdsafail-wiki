## Summary

In the base, jieyilong's q1153 route deleted about 16,500 dead CCX gates
after the build, by op index (`drop_dead_robust_k1_skip_59084.idx`, then
`drop_dead_second_fs512.idx`). This commit switches those lists off. In their
place it puts skip rules inside the gate emitters themselves. Each
trailmix primitive (`cuccaro_carry`, the `+f` fold windows, the constant
chunk adders, the comparators, the Gidney threaded adder and its erase, the
fused fold and the GCD swap and shift loops) now counts its own calls. It
checks a compiled-in table of `(call index, bit)` pairs, and simply does not
emit a CCX, CCZ or cswap that the table marks dead.

The tables were generated by tagging every emitted op with its source context
and mapping the old dead-op indices onto those contexts. A few blanket rules
were added on top, such as "never emit fold carry 30 or 31". The new rules
drop slightly more than the lists did: 789 fewer average Toffoli at the same
1153 qubits. The `.idx` files stay in the tree but are no longer read. The
tail nonce was re-hunted (13100076815176).

## What changed and why it saves Toffoli

### The mechanism

- **Op-site tracing** (`src/point_add/mod.rs`).
  - `push_op`, `ccx`, `ccz` and `cswap` become `#[track_caller]`.
  - With `TRACE_OP_SITES` set, every emitted op records
    `(file, line, context)` in `OP_SITE_TRACE`. The context is a 32-bit tag
    set by `set_op_trace_context`: `primitive_tag << 24 | call_index << 8 | bit`.
    For example, `0x02…` is the Cuccaro forward carry, `0x0b…` the GCD right
    shift and `0x1b…` the forward GCD cswap.
  - `constprop.rs::run` carries the site list through its drop and fold
    decisions (`apply_site_decisions`, `filter_sites`), so the sites still
    line up with the final stream.
  - This is mining infrastructure only. With the variable unset, nothing is
    recorded and the stream is unchanged.
- **Per-primitive call counters.**
  - New thread-local indices: `CUCCARO_CALL_INDEX`, `CONST_CHUNK_CALL_INDEX`
    and `ADD_CONST_CALL_INDEX` (`arith.rs`); compare-direct and compare-cin
    (`comparator.rs`); fold chunk, dirty-fold, clean-window, boundary-zero and
    fused-cdouble shifts (`fused.rs`); right and left shift (`gcd.rs`);
    threaded add, hybrid add, erase-gated and erase-gated-capped (`gidney.rs`).
  - `load_schedule()` resets them all, so the numbering is deterministic per
    build.
- **Skip tables.** The tables are compiled-in constants of two shapes:
  `(call, lo_bit, hi_bit)` ranges, and sorted `u32` "remainder" keys
  `call << 8 | bit`, looked up with `binary_search`. One comment states their
  origin: "Generated from /tmp/codex_idx_merged_context_compare_full.txt, rows
  with drops >= 2". That is, they are the old index lists translated into
  source contexts. Sizes in the shipped tree:

  | file | tables (ranges / keys) | gates covered |
  | --- | --- | --- |
  | `arith.rs` | `FFG_DEAD_HYBRID_CARRY_RANGES` 94 / `FFG_TOP29_REMAINDER_KEYS` 62; `CONST_CHUNK_DEAD_RANGES` 111 / `CONST_CHUNK_REMAINDER_KEYS` 283; Cuccaro and add-const rules written as `match` arms | about 1,700 bit sites plus the blanket rules |
  | `comparator.rs` | `COMPARE_CIN_STRUCTURAL_DEAD_RANGES` 116 / keys 179; `COMPARE_STRUCTURAL_DEAD_TOP_RANGES` 396 / `COMPARE_DIRECT_REMAINDER_KEYS` 512 | about 2,440 |
  | `fused.rs` | clean-fold 492, chunk-fold 100, dirty-fold 27 and clean-window 9 ranges; clean-fold 288, chunk-fold 229 and boundary-zero 157 keys | about 2,560 |
  | `gcd.rs` | `GCD_REVERSE_CSWAP_DEAD_RANGES` 143, forward-cswap 106 keys; `GCD_SHIFT_DEAD_RANGES` 75, right-shift 497 and left-shift 63 keys (the reverse-cswap remainder keys are present but not enabled) | about 1,130 cswaps |
  | `gidney.rs` | threaded-add forward 88, sum 118 ranges; forward 540 and sum 809 keys; 408 boundary calls; erase-CCZ and capped-erase-CCZ call lists (98 + 248 remainder, 10 + 35 + 11 residual) | about 3,600 |

- **Blanket rules** (no table; enabled in `build()`):
  - `TLM_FFG_SKIP_TOP_CARRY31` and `TLM_FFG_SKIP_TOP_CARRY30`: the `+f` fold's
    hybrid window never emits the carry CCX for bits 31 and 30.
    `f = 2^32 + 977` has zeros in bits 10–31, so a carry reaches there only
    if about 20 register bits in a row are 1.
  - `TLM_FFG_SKIP_INVERSE_MOD_SUB_TOP29` with `TLM_FFG_INVERSE_TOP29_MAX_CALL = 180`:
    bit 29 in the inverse-apply mod-sub folds, up to call 180.
  - `TLM_FUSED_CLEAN_FOLD_SKIP_TOP31`: the same idea in the fused clean fold.
  - `TLM_GCD_SKIP_REVERSE_DIAGONAL_EDGE`: in `reverse_gcd_jump`, skip the
    cswap of bit `j` at step `i` when `i + j ≥ 265`
    (`TLM_GCD_REVERSE_DIAGONAL_MIN`, default 265). By then both GCD registers
    have shrunk below that bit, so the swap acts on two zeros. A cswap is
    `CX; CCX; CX`, and on two zero bits it does nothing.
- **What is skipped.** Only the controlled-AND gates are skipped:
  - the carry `ccx(x[i], y[i], c)` in both halves of `cuccaro_carry`;
  - the carry `ccx(a[i], cin, cout)` in `const_chunk_add_clean`;
  - the hybrid `+f` carries;
  - the comparator carries and the phase-repair CCZ in the measured erases;
  - the forward, boundary and sum CCX of `controlled_clean_add_threaded`;
  - the cswaps of `controlled_right_shift`, `controlled_left_shift` and the
    GCD swap loops.

  The CX bookkeeping around each skipped gate is still emitted. Every skip
  removes one Toffoli-count gate on every shot where its condition holds (the
  phase-repair CCZs of the measured erases run only on shots whose outcome
  bit is 1).

### Configuration

- `build()` (`mod.rs`) sets 29 new defaults (`TLM_FFG_SKIP_STRUCTURAL_DEAD_CALLS`,
  `TLM_CUCCARO_SKIP_STRUCTURAL_DEAD_CALLS`, `TLM_COMPARE_SKIP_*`,
  `TLM_GIDNEY_SKIP_*`, `TLM_CONST_CHUNK_SKIP_*`, `TLM_FUSED_SKIP_*`,
  `TLM_ADD_CONST_SKIP_STRUCTURAL_DEAD_CARRIES`, `TLM_GCD_SKIP_*`, and the
  blanket rules above).
- It removes `DROP_DEAD_ROBUST` and `DROP_DEAD_ROBUST_SECOND`, and deletes
  `apply_drop_dead_robust_if_enabled`. `build()` returns the trailmix stream
  directly. The fan-out rewrite stays disabled.
- The skip tables are keyed by call order inside each primitive, not by
  global op index. An upstream change that only shifts op positions no
  longer invalidates them. A change that adds or removes a call of the same
  primitive still does.
- Present but not enabled: `TLM_SQUARE_SHIFTED_FFG_PREFIX_SKIP` (wired into
  `square.rs::apply_shifted_128_tagged` with `with_shifted_square_ffg_prefix_scope`),
  `TLM_GCD_SKIP_TOP_ZERO_SHIFT_EDGE`, `TLM_GIDNEY_SKIP_TOP2_THREAD`,
  `TLM_GIDNEY_SKIP_FULLVENT_TOP2` and `TLM_GCD_SKIP_EXACT_REVERSE_CSWAPS`.
- New trace switches: `TRACE_TLM_CUCCARO`, `TRACE_TLM_CONST_CHUNK`,
  `TRACE_TLM_COMPARE_DIRECT` and `TRACE_TLM_GIDNEY_THREAD`.
- Nonce: `Q1153_SECOND512_SUBMISSION_NONCE` goes from 10058189779 to
  13100076815176.

## Why it is still correct, and what it risks

Despite the "STRUCTURAL" and "EXACT" names, nothing here is proved. The
tables come from the same random-input fire census as the index lists. A
skipped gate is one that was never seen to fire. "EXACT_REMAINDER" means the
exact list of leftover sites not covered by a range, not an exactness proof.
The blanket rules are high-probability facts, not certainties: a fold carry
reaching bit 30 or 31, or a GCD register still holding a 1 at `i + j ≥ 265`.

On any input where a skipped gate would have fired, the result is wrong.
- A skipped carry or cswap leaves a wrong value or a dirty carry wire, so a
  classical or ancilla failure.
- A skipped phase-repair CCZ leaves a phase error, so a phase failure.

The submission note says only the y/apply and GCD skip families that
validated with no ancilla garbage were kept. The shipped nonce
`13100076815176` draws a clean set: 9,024 of 9,024 shots, 0 classical,
0 phase and 0 ancilla failures, average 1,367,697.510 Toffoli (submission
note). See [dead-gate-strip](../concepts/dead-gate-strip.md) and
[nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

The change deletes never-firing Toffoli gates and nothing else, so
dead-gate/self-inverse removal fits. What is new is the form, not the lever:
the census result is moved from a positional post-pass into
call-index-keyed skips at the emitting site. This is the first "structural"
re-expression of a census strip on the trailmix line.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout da51a48 -- src/point_add`.
   - `git diff --ignore-cr-at-eol da51a48 6dafa07 -- src/point_add` is
     3,852 lines in 9 files.
   - The git parent `4cd1b2f` gives 3,856 lines. It is the same circuit as
     `da51a48` with odinfree's re-rolled nonces. Diffing against it would
     show a revert of odinfree's nonce `930308424560` in the two fallback
     `DIALOG_TAIL_NONCE` defaults: `build()` in `mod.rs`, and
     `install_q1153_submission_defaults()` in `trailmix_ludicrous/mod.rs`,
     both back to `2430844`. Those defaults never run.
2. **Copy the five primitive files from the commit:**
   `git checkout 6dafa07 -- src/point_add/trailmix_ludicrous/arith.rs src/point_add/trailmix_ludicrous/comparator.rs src/point_add/trailmix_ludicrous/fused.rs src/point_add/trailmix_ludicrous/gcd.rs src/point_add/trailmix_ludicrous/gidney.rs`.
   - Most of their 3,600-line delta is the generated skip tables described
     above. The rest is the call counters, the `if !…_has_structurally_dead_…`
     guards around each CCX, CCZ or cswap, and the trace hooks.
3. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`. The flag lets the patch apply whether the files use LF or CRLF line endings. It
   covers `mod.rs`, `trailmix_ludicrous/mod.rs`, `square.rs` and `constprop.rs`.
4. **Check the tree.** `git diff --ignore-cr-at-eol 6dafa07 -- src/point_add`
   should print nothing.
5. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `SUB4_*`,
   `TLM_*`, `DIALOG_*`, `TRACE_*` or `SINGLE_CCX_*` overrides set. Expect:
   - 1153 qubits
   - 1,367,698 average Toffoli (1,367,697.510 before rounding)
   - score 1,576,955,794
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `13100076815176` and an identical op
stream. Any other change needs a new nonce hunt, and possibly a re-mine of the
skip tables.
