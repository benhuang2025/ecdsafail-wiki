## Summary

The ping-pong divider's walk records one sign bit per round on a "tape". The
replay reads the tape, and the walk-back reads it again later to undo the
walk. The qubit peak sits in the replay, where every tape wire is still alive.

This commit frees the first two tape wires, `tape[0]` and `tape[1]`, as soon as
the replay no longer needs them. It erases each one by measurement and rebuilds
it from other live registers just before the walk-back uses it. The replay
plateau then carries two fewer wires, so the peak drops from 1266 to 1264
qubits. Rebuilding costs 112 extra Toffoli. At this size a qubit is worth about
715 Toffoli of score (903,502 / 1264), so the trade pays well.

## What changed and why it saves qubits

All changes are in `src/point_add/pingpong_div.rs`, plus five new default pins
in `src/point_add/mod.rs`. Each erased wire follows the same pattern:

```
b.hmr(tape[k], c);  b.free(tape[k]);   // X-basis measure, reset, free the wire; c = outcome bit
...                                     // the replay runs with one fewer live wire
s = <recompute sign_k from live registers>
b.z_if(s, c);                           // undo the phase (-1)^(c·sign_k) the measurement left
<use s where tape[k] was used>
```

See [measurement-uncompute](../concepts/measurement-uncompute.md) for why
`hmr` plus a later `z_if` is a valid uncompute.

There are three levers, each switched on by a pin in `mod.rs`:

1. **A0 (`SUB4_PP_A0_FREE=1`)**: `tape[0]`, the round-0 lift bit, in both the
   divide and the multiply traversal.
   - It is erased right after walk round 0 in the divide traversal, and right
     after the whole walk in the multiply traversal.
   - At walk-back round 0 it is rebuilt by the new `recompute_a0(b, v)` from the
     restored round-0 output `w` in `v`. The function uses the identity
     `a0 = s ^ carry_256((L ^ s) + K)`, where `s` is the sign of `w`, `L` is the
     low 256 bits of `w`, and `K = 2^255 + h` with `h = round1_h()`.
   - The carry chain is truncated to `round1_window(N)` positions. Its AND wires
     are uncomputed by `hmr` plus `cz_if`, so the rebuild costs about one
     Toffoli per chain position.
   - The rebuild runs in `walk_back_round` (multiply traversal) and in
     `value_walk_back` (divide traversal).
2. **SIGN1 (`SUB4_PP_SIGN1_FREE=1`, `SUB4_PP_SIGN1_EARLY=1`, `SUB4_PP_SIGN1_RESPEND=0`)**:
   `tape[1]` in the divide traversal.
   - It is erased right after replay round 1 consumes it.
   - In `value_walk_back` round 1 it is rebuilt as `sign_1 = NOT v[1]`, using one
     X and one CX and no Toffoli. This works because `v` is round 1's untouched
     source, and the walk-back has restored it exactly.
   - With `RESPEND=0`, the freed wire is not given back to the chunk-ladder
     budget, so it lowers the peak instead.
3. **B-chain (`SUB4_PP_BCHAIN_MUL=1`)**: `tape[1]` in the multiply traversal.
   The pin's value is the tape index J, here 1.
   - It is erased right after the walk.
   - It is rebuilt just before the final replay batch reads it, with
     `sign_J = 1 ^ b_r1 ^ parity(tape[1..r1] without J)`. Here `b_r1` is bit 1
     of round `r1`'s target: `v[1]` if `r1` is even, `u[1]` if odd. That costs
     only X and CX gates.
   - The fresh wire must outlive the batch, so the code restores the loaned
     odd passengers before allocating it and re-loans them afterwards.

Smaller supporting edits:
- `Plan` gains a `mul` flag.
- `SUB4_PP_PEAK_MUL` and `SUB4_PP_WALK_PEAK_MUL` allow a separate peak plan for
  the multiply traversal. They are not set here, so both traversals use
  `SUB4_PP_PEAK`.
- The simulator self-test takes an optional `SUB4_PP_SELFTEST_SEED`.
- The tail nonce goes from 75787140768792 to 94006560419609.

## Why it is still correct, and what it risks

- **SIGN1 and B-chain are exact.** Each rebuild is an identity that holds on
  every input, given the walk-back has restored the registers it reads.
- **A0 is probabilistic.** Its carry chain is truncated, in the same 2^-26
  class as the existing fused round-1 borrow. On a rare input the rebuilt bit
  is wrong, and the walk-back then leaves garbage, which shows up as a
  classical or ancilla failure.
- **Phase.** If `z_if` is skipped, the measurement phase stays and the run
  fails with phase garbage. The debug switches `SUB4_PP_A0_NOFIX`,
  `SUB4_PP_SIGN1_NOFIX` and `SUB4_PP_BCHAIN_NOFIX` exist to test exactly this.
  Leave them unset.
- The shipped nonce draws a clean test set: 9,024 of 9,024 shots, with 0
  classical, 0 phase and 0 ancilla failures. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

The qubit saving comes from shortening the lifetime of three tape wires: they
are freed while unused and recomputed later. That is ancilla-lifetime /
venting. Measurement is only the tool that erases them, so this is not filed
as measurement uncompute.
