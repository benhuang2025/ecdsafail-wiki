## Summary

The new lever is the dialog-GCD width-envelope slope: 1.014 → 1.016 bits of
shrink per step. Over 259 steps, the summed active width drops by 64 bits and
the summed branch-comparator width by 10 bits. Over four transcript passes that
is 4 × (4 × 64 + 10) = 1,064 Toffoli. That matches the gain over the parent
`22624a0`.

The commit's tree is closest to `02049b8`. Against that base it also carries
the two carry-window cuts of [`22624a0`](22624a0.md): `KAL_DOUBLE_CARRY_TRUNC_W`
22 → 21 (−1,038) and `KAL_FOLD_CARRY_TRUNC_W` 22 → 21 (−518), without that
commit's comments. The total against the base is −2,620 Toffoli at 1313 qubits.
The tail nonce was re-hunted.

## What changed and why it saves Toffoli

All changes are in `configure_ecdsafail_submission_route()` in
`src/point_add/mod.rs`.

1. **`DIALOG_GCD_WIDTH_SLOPE_X1000`: 1014 → 1016.**
   - `dialog_gcd_tobitvector_active_width(step)` =
     `ceil_even(256 − step × slope + 10)`. Each step's swap, gated load,
     controlled subtract and K2 shift cascade run on `u[..aw]`, `v[..aw]`, at
     about 4 Toffoli per bit per pass (see [`ec0fa98`](ec0fa98.md)).
   - The branch comparator is `min(45, aw)` bits.
   - Σ aw goes 35,206 → 35,142 (−64). Σ comparator width goes 10,855 → 10,845
     (−10). Over forward and reverse passes for both GCD factors:
     4 × (4 × 64 + 10) = 1,064.
2. **`KAL_DOUBLE_CARRY_TRUNC_W`: 22 → 21.** This is the carry window of the
   Solinas constant add in the four modular doubling and halving helpers, 4
   calls per apply step: −1,038, as in [`4ef0046`](4ef0046.md).
3. **`KAL_FOLD_CARRY_TRUNC_W`: 22 → 21.** This is the carry window of the
   overflow and underflow fold after each of the 518 chunked apply adds and
   subtracts: −518, as in [`587b6d8`](587b6d8.md). See
   [modular-fold](../concepts/modular-fold.md).
4. **`DIALOG_TAIL_NONCE`: 5005587 → 19080008907.** This reseeds the 9,024 test
   inputs. The submission note says it was found by a CPU prefilter fleet and
   confirmed with `eval_circuit`. See
   [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Why it is still correct, and what it risks

All three changes are probabilistic truncations:

- **Width envelope.** An input whose GCD converges more slowly than the
  steeper envelope keeps a set bit above `aw`. The transcript is then wrong,
  giving a classical failure plus phase or ancilla garbage.
- **Carry windows.** A carry from bit 32 that runs through more than 21 ones is
  lost, about 2^−22 per call for random data. That gives a classical failure,
  and garbage when the inverse does not undo it.

λ rises over the parent. The shipped nonce 19080008907 draws a clean set: the
official run reports 0 classical, 0 phase and 0 ancilla failures over all 9,024
shots.

## Classification rationale

The new lever narrows per-step register widths, which is comparator/width
truncation. The carry-window cuts are inherited from the parent lineage.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 02049b8 -- src/point_add`.
   - The git parent `22624a0` already has both windows at 21, with long
     comments on them. This tree has the same values but `02049b8`'s older
     comments.
   - Diffing against the parent (17 lines) would show those comments being
     deleted, alongside the slope and nonce changes.
   - Against `02049b8`, `git diff --ignore-cr-at-eol 02049b8 196d830 -- src/point_add`
     is 8 lines in 1 file. That diff also shows the two window values, which
     this commit shares with the parent.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line
   endings. It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 196d830 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no
   `DIALOG_*` or `KAL_*` environment variables set, because `set_default_env`
   keeps any value already in the environment. Expect:
   - 1313 qubits
   - 1,533,427 average Toffoli (rounded)
   - score 2,013,389,651
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with `DIALOG_TAIL_NONCE=19080008907` and an
identical op stream. Any other change needs a new nonce hunt.
