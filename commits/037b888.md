## Summary

This commit makes no optimization. It only changes the tail nonce in
`src/point_add/mod.rs` (`SUB4_PINGPONG_TAIL_NONCE` default in `build()`) from
82505456522172 to 900613964630. The new nonce draws a different clean set of
9,024 test shots, whose average executed Toffoli is 10 lower. The diff touches
only the nonce literal. For why a nonce moves the score, see
[nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

`git apply --ignore-whitespace`. `./benchmark.sh` should give 1266 qubits,
911,392 average Toffoli and 0 / 0 / 0 failures.
