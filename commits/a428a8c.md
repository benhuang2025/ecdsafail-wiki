## Summary

One constant. The second Kaliski inversion pair, which uncomputes λ, runs one
iteration fewer: 397 instead of 398. That removes one forward and one backward
Kaliski iteration and one modular doubling of λ, 3,479 Toffoli. Qubits are
unchanged. The submission note repeats the description of the previous
commit's `(u, v_w)` swap merge, but that code is already in the base; this
commit only changes the iteration count.

## What changed and why it saves Toffoli

- `src/point_add/point_add.rs`, `build_standard_point_add()`: `pair2_default`
  on the default `stack_2565_enabled()` branch goes from 398 to 397.
  `KAL_PAIR2_ITERS` still overrides it.
- Pair2 is the in-place-v Kaliski run
  `with_kal_inv_raw_borrow_v_w_pair(..., pair2_iters, KalPair::Pair2, ...)`.
  Its body applies `pair2_iters` modular doublings to λ to cancel the
  `2^iters` scale of a fixed-length Kaliski run. See [`a3ee589`](a3ee589.md)
  for the Kaliski background.
- One fewer iteration removes:
  - one forward and one backward bulk iteration (iteration 397, past the
    254-iteration swap-merge prefix, so a full unmerged iteration);
  - one `mod_double_inplace_fast` on λ.

## Why it is still correct, and what it risks

A fixed Kaliski length only works for inputs that terminate within it. An
input whose pair2 denominator `Qx − Rx` needs 398 steps is now left unfinished,
so λ is not cleared: ancilla garbage or a classical mismatch. The comment
records that 396 and 399 fail on this circuit shape and 397 is clean.

Non-monotone results like "399 fails, 398 and 397 pass" are expected here.
There is no tail nonce in this era, so each iteration count is a different op
stream with a different hashed test draw. The shipped draw is clean: 0
classical, 0 phase and 0 ancilla failures. See
[nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 36a2989 -- src/point_add`. The base is the git
   parent. `git diff --ignore-cr-at-eol 36a2989 a428a8c -- src/point_add` is
   8 lines in 1 file.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`. The flag lets the patch apply whether the files use LF or CRLF line endings. It is the
   complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol a428a8c -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `KAL_*`,
   `POINT_ADD_*` or `BY_*` environment variables set. Expect:
   - 2310 qubits
   - 3,358,280 average Toffoli (rounded)
   - score 7,757,626,800
   - 0 classical, 0 phase and 0 ancilla failures

There is no tail nonce in this era: the test set is a hash of the op stream,
so the score only reproduces with an identical op stream.
