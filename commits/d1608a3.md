## Summary

This commit makes no optimization. It only changes the tail nonce in
`src/point_add/mod.rs` (`TAIL_NONCE` entry of `env_raw()`) from 18000451506351
to 18000769990959. The new nonce draws a different clean set of 9,024 test
shots, whose average executed Toffoli is 6 lower. With line endings ignored,
the diff touches only the nonce literal. The raw diff also rewrites
`sky18_rewrite.txt`, but only its line endings change. `apply_tail_nonce` only
retargets the fixed 96-X identity tail, so the op count is unchanged. For why
a nonce moves the score, see
[nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).
