## Summary

Two independent Toffoli cuts are stacked, and both remove gates.

1. **Strip budget 2.5.** The risk-ranked dead-gate strip from the same 320M
   census goes from budget 2.0 to 2.5. That adds 311 deletions and 103 CX/CZ
   downgrades (15,683 → 16,097 keys), for about −372 average Toffoli.
2. **Codec edit.** jackylee0424's one-entry edit to `NORMALIZER_OPS`
   ([`330d42d`](330d42d.md)) comes back. It turns `CCX(w6, w10 → w9)` into a CX
   that cancels the next CX, for about −344. The author's own previous
   submission, 37ab267, was built on a tree without it.

The two compose cleanly: the build still reports "0 stale keys skipped". The
author also tried the other six CCX entries of the normalizer table, each with
either control dropped. Every variant broke the circuit, so the table appears
mined out.

## What changed and why it saves Toffoli

1. **`src/point_add/deep_strip_keys.rs`** (same census header: 320,000,000 input
   pairs on the 9,073,163-op pre-strip stream). 414 key lines are added and none
   removed: `DEAD_KEYS` 11,979 → 12,290 and `DOWNGRADE_KEYS` 3,704 → 3,807.
   - The note's ladder for this stream, all builds evaluated at 1154 qubits.
     Δλ is the measured number of extra failing shots per draw; hunt cost grows
     about as e^Δλ.

   - The marginal return bends here, from about 1.7M score per unit of λ up to
     budget 2.0, to 1.19M from 2.0 to 2.5. The author's objective is
     score gain × e^−Δλ, which peaks near Δλ ≈ 1.5–1.9. See
     [dead-gate-strip](../concepts/dead-gate-strip.md).
2. **`src/point_add/trailmix_ludicrous/codec.rs`, `NORMALIZER_OPS[34]`:**
   `(2,6,10,9)` → `(1,10,9,0)`, the same edit as 330d42d.
   - The CCX becomes `CX(w10 → w9)` and cancels the following `CX(w10 → w9)`.
   - The table runs once when each Triple window is encoded (`compress_3sym`)
     and once when it is decoded (`compress_3sym_reverse`). With 86 windows per
     walk and two GCD phases, that is 344 CCX.
   - Measured: budget 2.5 with the original codec gives 1,290,130.962; adding
     the edit gives 1,289,784.622. See
     [trailmix-jump-gcd](../concepts/trailmix-jump-gcd.md) for the codec.
3. **Tail nonce:** `SUB4_TAIL_NONCE` default 100388236067 → 700076886370 in
   `src/point_add/mod.rs`.

## Why it is still correct, and what it risks

- **Strip: empirical.** At budget 2.5 the strip adds about 1.9 expected failing
  shots per draw, against 1.57 at 2.0.
- **Codec edit: a reachability claim.** It is right if `w6 = 1` whenever
  `w10 = 1` at that point, on every reachable codec state.
  - The six sibling edits the author tried (`(2,7,9,10)`, `(2,6,8,10)`,
    `(2,6,7,8)` twice, `(2,6,10,8)`, `(2,7,8,9)`, each with either control
    dropped) all gave 7,159–9,024 classical mismatches and 141/141 phase
    garbage.
  - This one gives 0 / 0 / 0 at the shipped nonce. With only 125 reachable
    symbol triples, a false claim would show up on many shots, so it very
    likely holds on all reachable states. The commit does not prove it.
- **Pricing.** `results.tsv` records the average executed Toffoli even on failed
  runs, so a candidate's score can be measured before a clean nonce is found.
  Re-measuring the r2.0 circuit this way reproduced its official 1,290,503.181
  exactly.
- The shipped nonce `700076886370` draws a clean set: 9,024 of 9,024 shots, 0
  classical, 0 phase and 0 ancilla failures. The build logs "removed 12290 /
  12290 dead; downgraded 3807 / 3807 to CX/CZ; 0 stale keys skipped". See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

Both cuts remove gates that are redundant on the inputs that occur: census-dead
or control-redundant gates in the strip, and a CCX with a redundant control in
the codec. That is dead-gate/self-inverse removal.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 37ab267 -- src/point_add`.
   - The git parent `7fa872d` has the same circuit with a different nonce, and
     its diff to this commit is the same size (418 lines). `37ab267` is used
     because it is the author's own previous submission.
   - `git diff --ignore-cr-at-eol 37ab267 7726431 -- src/point_add` is 418 lines
     in 3 files: 414 added key lines, the codec entry and the nonce.
2. **Copy the generated table from the commit:**
   `git checkout 7726431 -- src/point_add/deep_strip_keys.rs`.
3. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line endings.
   It covers `mod.rs` and `codec.rs`.
4. **Check the tree.** `git diff --ignore-cr-at-eol 7726431 -- src/point_add`
   should print nothing.
5. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no `TLM_*` or
   `SUB4_*` overrides set. Expect:
   - 1154 qubits
   - 1,289,771 average Toffoli (1,289,771.080 before rounding)
   - score 1,488,395,734
   - 0 classical, 0 phase and 0 ancilla failures
6. **Nonce caveat.** The score only reproduces with the nonce `700076886370` and an
   identical op stream. Any other change needs a new nonce hunt.
