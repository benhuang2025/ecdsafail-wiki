## Summary

This applies the width-margin lever of [01260e8](01260e8.md) and
[5b3887b](5b3887b.md) to the author's own tree, [9d30eb7](9d30eb7.md), which
has the 20-bit carry windows and the last apply cut at 170. The cut is larger
than either of those: the dialog-GCD width envelope `256 − 0.95·step + margin`
goes from margin 25 to margin 7. The slope stays 0.950.

Each step-bit costs 4 Toffoli in the K=2 walk, plus capped comparator bits.
The saving is 72,840 Toffoli, exactly what the width formula predicts. Qubits
are unchanged. The author used a classical convergence pre-filter feeding a
GPU screen to find a clean nonce, `277`. The author reports that margin 6
"starts degrading the island density".

## What changed and why it saves Toffoli

`src/point_add/mod.rs`, `configure_ecdsafail_submission_route()`:

- `DIALOG_GCD_WIDTH_MARGIN`: 25 → 7.
- `DIALOG_TAIL_NONCE`: 25 → 277.

`dialog_gcd_tobitvector_active_width(step)` returns
`256 − 0.95·step + margin`, rounded up to an even number and clamped to
[1, 256]. The width bounds four loops in each walk step, each about 1 Toffoli
per bit:
- the branch `cswap`;
- the gated load;
- the subtract or add body;
- the K=2 conditional-shift cascade.

It also caps the branch comparator at `min(74, active_width)`. See
[01260e8](01260e8.md).

Replaying the formula over the 259 steps:

| | summed width per walk | summed comparator width | steps clamped at 256 |
| --- | --- | --- | --- |
| base (margin 25) | 40,922 | 18,422 | 29 |
| this commit (margin 7) | 36,590 | 17,540 | 10 |

Per walk that is 4 × 4,332 + 882 = 18,210 Toffoli. The four walks give
72,840, the measured drop. The runway transcript allocation falls from 488 to
464 bits. The peak is set by the apply chunked add, so it stays at 1390.

## Why it is still correct, and what it risks

The envelope is a statistical fit, and margin 7 leaves little room.
- Every bit above `active_width` is assumed to be 0 in `u` and `v`. The walk
  ignores those bits, and part of the transcript is parked there.
- An input whose GCD values run more than about 7 bits behind the 0.95
  bits/step line loses live bits. Its walk then fails: the result is a
  classical mismatch, and ancilla garbage after the reverse walk.
- The 20-bit carry windows of [9d30eb7](9d30eb7.md) are also still in place,
  so both risks add up.
- The author's search used a classical pre-filter for convergence and width,
  feeding a GPU screen. It found nonce `277`, whose 9,024-shot test set gives
  0 classical, 0 phase and 0 ancilla failures.

See [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

## Classification rationale

A narrower per-step register width is comparator/width truncation. There is
no other change.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 9d30eb7 -- src/point_add`.
   - Do not start from the git parent `5b3887b`. That is newjordan's tree,
     built on robertkodra's `a772a45`.
   - Against the parent, the diff would also show changes that are not part
     of this commit: the `KAL_DOUBLE/FOLD_CARRY_TRUNC_W` windows going 24 → 20,
     `CUT` and `CUT2` going 58/114 → 56/112, and the slope going 948 → 950.
     These are differences between the two lineages.
   - Against `9d30eb7`, `git diff --ignore-cr-at-eol 9d30eb7 247db26 -- src/point_add`
     is 4 lines in 1 file.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line
   endings. It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol 247db26 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no
   `DIALOG_*` or `KAL_*` environment variables set, because
   `set_default_env` only fills in unset variables. Expect:
   - 1390 qubits
   - 1,551,423 average Toffoli (rounded)
   - score 2,156,477,970
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with `DIALOG_TAIL_NONCE=277` and an identical op
stream. Any other change needs a new nonce hunt.
