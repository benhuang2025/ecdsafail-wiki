## Summary

alexander-sei's comparator cut [`fc27501`](fc27501.md) was built on an older
tree, so it did not have 10d9e's fold-window cut from [`af0f90a`](af0f90a.md).
This commit puts that cut back: `KAL_FOLD_CARRY_TRUNC_W` goes from 24 to 23.
The fold that ends each modular add in the GCD apply pass then has one fewer
carry position, which is one Toffoli per fold. There are 518 folds per shot, so
the saving is 518 Toffoli, the same as in `af0f90a`. Qubits are unchanged. The
nonce was re-hunted, and the author also added a session note.

## What changed and why it saves Toffoli

**Background.** The circuit is the dialog-GCD route (`emit_dialog_gcd_raw_pa`
in `src/point_add/mod.rs`). Two calls each run a reversible binary GCD: the
quotient dy/dx and the product with c = ox − Rx. Each call's apply pass does,
per GCD step, `y = 2y mod p`, then `y = y + b0·x mod p`, then a conditional
swap. [98416e4](98416e4.md) has the GCD step, and [af0f90a](af0f90a.md) explains
the fold.

**The fold window.** The modular add `dialog_gcd_cmod_add_materialized_pseudomersenne_chunked`
ends with
`cadd_nbit_const_direct_trunc_fast(acc[..73], c, acc_ovf, KAL_FOLD_CARRY_TRUNC_W)`.
This adds c = 2^32 + 977 when the raw add overflowed. Its carry chain stops `w`
positions above bit 32, and each position costs one CCX. The matching subtract
paths use `csub_nbit_const_direct_trunc_fast` with the same window.

**The changes:**

- `src/point_add/mod.rs`, `configure_ecdsafail_submission_route()`:
  - `KAL_FOLD_CARRY_TRUNC_W`: 24 → 23. There are 259 apply steps × 2 GCD calls
    = 518 folds, each one Toffoli cheaper.
  - `DIALOG_TAIL_NONCE`: 127 → 55.
- New file `src/point_add/memory/2026-06-05-kalfold23-island-3155.md` (42
  lines). This is 10d9e's session note from `af0f90a`. It records how many test
  inputs each candidate lever broke at the inherited nonce on `dda7bfd`:
  slope 1005 = 13, margin 8 = 16, apply-clean 19 = 11, 258 iterations = 10,
  double 23 = 9 and fold 23 = 6. It also describes the full-validation nonce
  searcher `src/bin/island_search_jac.rs`, at about 7 nonces/s on 11 threads.
  That file is outside `src/point_add` and is not part of this commit.

## Why it is still correct, and what it risks

The fold is wrong only when its carry would have run past the window. That
needs about 23 consecutive 1 bits above bit 32, roughly 2^-24 per firing fold.
A failure leaves the high bits of `y` wrong, which shows up as a classical
failure. The comment calls the lever "value-exact on the reachable support",
which is too strong, but its contribution to λ is small, about 0.1 failing shots
per draw.

On this tree it breaks only 0 classical and 2 phase shots at the inherited
nonce, according to 10d9e's later note `memory/2026-06-05-width-envelope-sweep-1382q.md`
(added in [`ae3b97b`](ae3b97b.md)). A clean island turned up at nonce `55` after about 15
seconds of searching. That nonce draws a clean set: 0 classical, 0 phase and 0
ancilla failures over all 9,024 shots.

## Classification rationale

The census files this under comparator/width truncation. The knob narrows the
carry window of the modular fold's constant add, so "fold/carry truncation"
fits better. That is the label used for [`438ef00`](438ef00.md), which tightens
the matching doubling window.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout fc27501 -- src/point_add`. The base is the git parent.
   `git diff --ignore-cr-at-eol fc27501 bc858e8 -- src/point_add` is 54 lines
   in 2 files.
2. **Apply the patch below** from the repo root with `git apply --ignore-whitespace`.
   The flag lets the patch apply whether the files use LF or CRLF line endings.
   It is the complete diff against the base.
3. **Check the tree.** `git diff --ignore-cr-at-eol bc858e8 -- src/point_add`
   should print nothing.
4. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh` with no
   `DIALOG_*`, `KAL_*`, `KARA_*` or `ROUND84_*` environment variables set.
   `set_default_env` only fills variables that are unset. Expect:
   - 1390 qubits
   - 1,519,217 average Toffoli (rounded)
   - score 2,111,711,630
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `55` and an identical op stream. Any
other change needs a new nonce hunt.
