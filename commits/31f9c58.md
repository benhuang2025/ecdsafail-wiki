## Summary

In the trailmix route, most adders, comparators and folds choose how many
extra carry ancillas ("vents") to hold by looking at the headroom under a
qubit cap, `TLM_TARGET_Q`, and the square has its own cap,
`TLM_SQUARE_PEAK_CAP`. This commit forces both caps from 1153 down to 1149.
Every budgeted region then picks a narrower, Toffoli-costlier layout, and the
realized peak drops from 1153 to 1150 qubits.

That costs 2,909 average Toffoli, less than the 3 × ~1,115 Toffoli that three
qubits are worth at this size, so the score drops by 500,251. Two other
changes come with it. The inverse apply pass skips the payload swap in only
the last 2 GCD steps, not 3. And the identity-keyed dead-gate strip is
switched off and replaced by a pinned list of 16,850 per-op actions,
addressed by position in the exact op stream this build produces.

## What changed and why it saves qubits

All code changes are in `src/point_add/mod.rs`. One generated data file is
new.

### 1. Forced settings at the top of `build()`

```rust
std::env::set_var("SUB4_APPLY_STRIP", "0");
std::env::set_var("TLM_TARGET_Q", "1149");
std::env::set_var("TLM_SQUARE_PEAK_CAP", "1149");
std::env::set_var("TLM_APPLY_INV_CSWAP_SKIP_LAST", "2");
```

These are `set_var`, not `set_default_env`, so they override both the later
defaults in the code and anything in the caller's environment. The comment
says this is deliberate, "so the benchmark environment cannot select a
different geometry".

- **`TLM_TARGET_Q` 1153 → 1149.** `target_qubit_headroom()` returns
  `TLM_TARGET_Q − active_qubits`. Every vented adder and fold that sizes
  itself to that headroom gets 4 fewer wires, so it keeps fewer carries in
  ancillas and recomputes more of them with Toffolis.
- **`TLM_SQUARE_PEAK_CAP` 1153 → 1149.** `square_peak_hard_cap()` gives the
  square the same lower ceiling. The square is a co-binder of the peak, so
  both caps have to move.
- The realized peak lands at 1150, one above the cap value. The cap sweep in
  `memory/05-qubit-reduction.md` (in the tree since before `afcc72e`) shows
  the same offset: cap 1149 gave a 1150 peak. See
  [peak-qubits-and-budgets](../concepts/peak-qubits-and-budgets.md) and
  [venting-and-wire-loans](../concepts/venting-and-wire-loans.md) ("The
  second meaning of vent").
- **`TLM_APPLY_INV_CSWAP_SKIP_LAST` 3 → 2.** The inverse apply pass again
  performs the 256-Toffoli payload swap at step `ITERS − 3` (step 256 at
  `ITERS = 259`). That costs 256 Toffoli per shot but removes the inputs that
  fail because a late swap was skipped. See [`474c29a`](474c29a.md). The
  function name `apply_q1150_inverse_cswap_action_mask` refers to this
  "q1150 inverse-cswap route".
- **`SUB4_APPLY_STRIP` = 0** turns off `apply_deep_strip_identity`, and with
  it the post-strip fanout loop, which only runs when the strip is on. The
  affine bridges still run, because they come before the strip.

### 2. New `apply_q1150_inverse_cswap_action_mask(ops)`

- Called just before the tail nonce. It reads
  `include_str!("route_042_action_mask.tsv")`: 16,850 lines of
  `<op index>\t<action>`, with strictly increasing indices.
- Actions:
  - `delete` (13,119 lines) removes the op.
  - `drop_q2` (2,219) turns a CCX/CCZ into CX/CZ by dropping `q_control2`.
  - `drop_q1` (1,512) drops `q_control1` and keeps `q_control2`.
- Fail-closed checks: the input must have exactly `EXPECTED_PARENT_OPS =
  9,031,804` ops, every `drop_*` must hit a CCX/CCZ, exactly 16,850 actions
  must apply, and the output must have exactly 9,018,685 ops
  (9,031,804 − 13,119).
- This is a positional strip in the sense of
  [dead-gate-strip](../concepts/dead-gate-strip.md). It does the same job as
  the identity-keyed table it replaces (10,734 deletes and 2,848 downgrades in
  the base), re-derived for the new, narrower-cap op stream. The file carries
  no header saying how it was mined; by its actions it is a fire-census
  strip of that stream.
- Any upstream change that alters the op count aborts the build, instead of
  deleting the wrong gates.

### 3. Fixed tail nonce

The `SUB4_TAIL_NONCE` lookup is removed. The nonce is now a constant,
`CLEAN_NONCE = 1_001_537_523_329`, passed straight to `apply_tail_nonce`.

### 4. New file `src/point_add/route_042_action_mask.tsv` (copied)

The 16,850-line generated action list described in part 2.

**Net.** The tighter caps cost Toffoli in every budgeted region, plus 256 T
for the restored swap, partly offset by the new mask. The total is +2,909 T
for −3 qubits. The break-even for −3 qubits is about
3 × 1,281,867 / 1150 ≈ 3,344 T, so the trade pays.

## Why it is still correct, and what it risks

- **The cap change is exact.** It only changes which adder layout is chosen.
- **The swap change returns λ.** One more apply-cswap is performed, so fewer
  slow-converging inputs fail.
- **The mask is empirical**, like the strip it replaces. A deleted gate that
  would have fired on some input gives a classical or phase failure there,
  which adds to λ.
- **It is tied to one stream.** Any edit upstream of the mask, including
  setting a different `TLM_*` value (which `set_var` now blocks), changes the
  op count and trips the assert. Later edits on this route have to re-mine
  the mask.
- The shipped nonce `1001537523329` draws a clean test set: 0 classical,
  0 phase and 0 ancilla failures. See
  [nonce-island-and-lambda](../concepts/nonce-island-and-lambda.md).

This was the last frontier on the trailmix route. The next accepted commit,
[`897dda2`](897dda2.md), replaced the GCD inverse with ping-pong division.

## Classification rationale

The score win is −3 qubits bought with Toffoli by shrinking the live vent
budget through the caps. Commits that only move these caps are filed as
ancilla-lifetime / venting. The action mask re-expresses the census-mined
strip for the new geometry and is not what drives the improvement.

## Reproduce

1. **Start from the base.** Clone https://github.com/ecdsafail/ecdsafail-challenge
   and run `git checkout 0422437 -- src/point_add`. The base is the git
   parent. `git diff --ignore-cr-at-eol 0422437 31f9c58 -- src/point_add` is
   16,964 changed lines in 2 files, 16,850 of them the new mask.
2. **Copy the generated mask from the commit:**
   `git checkout 31f9c58 -- src/point_add/route_042_action_mask.tsv`. Part 2
   above describes its format and counts.
3. **Apply the patch below** from the repo root with
   `git apply --ignore-whitespace`. The flag lets the patch apply whether the
   files use LF or CRLF line endings. It covers `mod.rs`.
4. **Check the tree.** `git diff --ignore-cr-at-eol 31f9c58 -- src/point_add`
   should print nothing.
5. **Run the benchmark.** Run `./setup.sh && ./benchmark.sh`. The four
   settings in part 1 are forced inside `build()`, and the nonce is a
   constant, so environment overrides of those have no effect. Leave the
   other `SUB4_*` and `TLM_*` variables unset. Expect:
   - 1150 qubits
   - 1,284,776 average Toffoli (rounded)
   - score 1,477,492,400
   - 0 classical, 0 phase and 0 ancilla failures

The score only reproduces with the nonce `1001537523329` and an identical op
stream. Any other change needs a new mask and a new nonce hunt.
